# Χρήση με AI

Κατέβασε τα αρχεία markdown ενός μαθήματος (οδηγός, θέματα, λύσεις) σε ένα zip και δώσε τα σε ένα εργαλείο AI.

!!! warning "Οι λύσεις «AI, μη επαληθευμένο» μπορεί να έχουν λάθη"
    Έλεγξε πάντα με τη μεταγραφή και με τον διδάσκοντα.

## Οδηγίες

- **NotebookLM**: νέο notebook → Add source → ανέβασε τα `.md` του zip (αποσυμπίεσέ το πρώτα).
- **ChatGPT Projects**: νέο Project → Add files → ανέβασε τα `.md`.
- **Claude Projects**: νέο Project → Add content → ανέβασε τα `.md`.
- **Gemini Gems**: νέο Gem → Knowledge → πρόσθεσε τα `.md`.

## Τρία έτοιμα prompts

**Προσομοίωση εξέτασης**

```text
Λειτουργείς ως εξεταστής του μαθήματος. Διάλεξε θέματα από τα παλιά θέματα που σου έδωσα και ρώτησέ με ένα-ένα.
Μην δείξεις καμία λύση μέχρι να απαντήσω. Μετά βαθμολόγησε την απάντησή μου και εξήγησε τα λάθη.
```

**Εξήγηση θέματος**

```text
Εξήγησε βήμα-βήμα το θέμα [επικόλλησε εδώ]: τι ζητάει, ποια θεωρία χρειάζεται και πώς λύνεται.
Αν υπάρχει λύση στα αρχεία, σύγκρινέ την με τη δική σου και πες αν διαφέρουν.
```

**Τι πέφτει συνήθως**

```text
Ανάλυσε όλες τις συνεδρίες εξετάσεων και φτιάξε πίνακα με τα θέματα που επανεμφανίζονται, πόσες φορές και σε ποια έτη.
Πρότεινε σειρά μελέτης.
```
