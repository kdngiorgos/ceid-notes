# ⭕ Κανόνες

> Είναι το κανάλι με τους κανόνες χρήσης του CEID Discord server, όπως δημοσιεύτηκαν το 2020 και συμπληρώθηκαν το 2025. Δεν περιέχει υλικό μαθημάτων, θέματα ή λύσεις. Οι δημοσιευμένοι κανόνες χρήσης του server (αντιγραφή στις εξετάσεις, συμπεριφορά, εμπορικές δραστηριότητες) παρατίθενται εδώ όπως δημοσιεύτηκαν.

[⬇ Κατέβασε για AI](../../downloads/community-kanones.zip){ .md-button }


## Τι θα βρεις εδώ

Το κανάλι #⭕κανόνες έχει 11 μηνύματα στη βάση, που περιέχουν τη λίστα κανόνων του server: οκτώ κανόνες από τον Σεπτέμβριο 2020 Discord 2020-09 (διαθέσιμο στο πλήρες πακέτο) και έναν ένατο από τον Ιούνιο 2025 Discord 2025-06 (διαθέσιμο στο πλήρες πακέτο). Η εξαγωγή δεν έχει άλλα μηνύματα από το κανάλι για την περίοδο 2021–2025, και δεν περιέχει συζήτηση στο κανάλι.

## Χρήσιμες πληροφορίες

Οι κανόνες, με τη σειρά που δημοσιεύτηκαν:

- **Εξετάσεις (κανόνες 1–3, 2020).** Απαγορεύεται η χρήση του server για αντιγραφή ή παράβαση των εξεταστικών κανόνων του πανεπιστημίου, και η ανταλλαγή θεμάτων στο κανάλι του μαθήματος κατά τη διάρκεια εξέτασης. Καθ' όλη τη διάρκεια της εξέτασης το κανάλι του μαθήματος παραμένει κλειστό. Κάθε παράβαση βαραίνει τον χρήστη προσωπικά Discord 2020-09 (διαθέσιμο στο πλήρες πακέτο).
- **Συμπεριφορά (κανόνες 4 και 6, 2020).** Απαγορεύονται υβριστικά και προσβλητικά σχόλια προς χρήστες της εφαρμογής και προς μέλη της πανεπιστημιακής κοινότητας Discord 2020-09 (διαθέσιμο στο πλήρες πακέτο).
- **Πολιτικά θέματα (κανόνας 5, 2020).** Απαγορεύονται συζητήσεις με πολιτικό ή κομματικό περιεχόμενο Discord 2020-09 (διαθέσιμο στο πλήρες πακέτο).
- **Χώρος συζήτησης μαθήματος (κανόνας 7, 2020).** Η συζήτηση για ένα μάθημα γίνεται αποκλειστικά στο κανάλι του Discord 2020-09 (διαθέσιμο στο πλήρες πακέτο).
- **Προβλήματα και αναφορές (κανόνας 8, 2020).** Κάθε πρόβλημα με τη χρήση της εφαρμογής ή ζήτημα προσωπικού χαρακτήρα αναφέρεται στο κανάλι #🚫αναφορά. Το ιστορικό του καναλιού αυτού το βλέπουν μόνο οι διαχειριστές Discord 2020-09 (διαθέσιμο στο πλήρες πακέτο).
- **Εμπορικές δραστηριότητες (κανόνας 9, 2025).** Απαγορεύεται κάθε αγοραπωλησία θεμάτων, εργασιών ή σημειώσεων, και κάθε χρήση του server για προσωπικό κέρδος. Αυτό περιλαμβάνει και την προσέγγιση μελών εκτός του server για προσφορά υπηρεσιών. Κάθε παράβαση βαραίνει τον χρήστη προσωπικά και τον καθιστά υπεύθυνο έναντι του νόμου Discord 2025-06 (διαθέσιμο στο πλήρες πακέτο).

## Συχνές ερωτήσεις

Κανένα μήνυμα του καναλιού δεν είναι ερώτηση φοιτητή. Οι παρακάτω ερωτήσεις καλύπτονται από τους κανόνες:

- **Μπορώ να μοιραστώ θέματα εξέτασης στο server;** Όχι κατά τη διάρκεια της εξέτασης (κανόνας 2)· γενικά δεν επιτρέπεται η χρήση του server για αντιγραφή ή παράβαση των εξεταστικών κανόνων (κανόνας 1), και σε καμία περίπτωση προς πώληση (κανόνας 9) Discord 2020-09 (διαθέσιμο στο πλήρες πακέτο), Discord 2025-06 (διαθέσιμο στο πλήρες πακέτο).
- **Μπορώ να πουλήσω ή να αγοράσω σημειώσεις, εργασίες ή θέματα;** Όχι· απαγορεύεται κάθε αγοραπωλησία Discord 2025-06 (διαθέσιμο στο πλήρες πακέτο).
- **Πού συζητάμε ένα μάθημα;** Στο κανάλι του μαθήματος, όχι στο γενικό κανάλι Discord 2020-09 (διαθέσιμο στο πλήρες πακέτο).
- **Πού αναφέρω ένα πρόβλημα με τον server ή ένα προσωπικό ζήτημα;** Στο #🚫αναφορά· μόνο οι διαχειριστές βλέπουν το ιστορικό του Discord 2020-09 (διαθέσιμο στο πλήρες πακέτο).
- **Επιτρέπονται πολιτικές ή κομματικές συζητήσεις;** Όχι Discord 2020-09 (διαθέσιμο στο πλήρες πακέτο).

## Πηγές & αξιοπιστία

- Δύο περίοδοι έχουν μηνύματα: Discord 2020-09 (διαθέσιμο στο πλήρες πακέτο) (οκτώ κανόνες, 9 μηνύματα) και Discord 2025-06 (διαθέσιμο στο πλήρες πακέτο) (ο κανόνας 9, 2 μηνύματα). Πρόκειται για κανόνες του server, όχι για γνώμες φοιτητών.
- Η βάση δεν δείχνει ποιος δημοσίευσε τη λίστα ούτε αν ισχύει σήμερα ολόκληρη. Η αρίθμηση συνεχίζει από το 8 στο 9, άρα ο κανόνας 9 φαίνεται προσθήκη μεταγενέστερη του 2020. Δεν βρέθηκαν πληροφορίες για άλλες αλλαγές μεταξύ 2020 και 2025.
- Δεν βρέθηκαν πληροφορίες για τους εξεταστικούς κανονισμούς του πανεπιστημίου, για τη διαδικασία καταγγελίας ή για συγκεκριμένες ποινές.
- Ο φάκελος `other/` περιέχει ένα αρχείο HTML, που δεν χρησιμοποιήθηκε για αυτόν τον οδηγό.
