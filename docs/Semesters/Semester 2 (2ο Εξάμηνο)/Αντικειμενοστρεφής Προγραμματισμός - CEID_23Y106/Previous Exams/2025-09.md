    #### 🔹 Θέμα 3ο (2 Μονάδες) — Σχεδίαση Κλάσης & Constructor Chaining σε Java

    **Πλήρης Υλοποίηση σε Java:**
    ```java
    public class Student {
        // Ιδιωτικά πεδία (Encapsulation)
        private String name;
        private String id;
        private int year;

        // 1ος Constructor: Μόνο όνομα
        public Student(String name) {
            // Κλήση του 2ου constructor με προεπιλεγμένο id = -1
            this(name, -1);
        }

        // 2ος Constructor: Όνομα και ID
        public Student(String name, int id) {
            // Κλήση του βασικού/πλήρους 3ου constructor με προεπιλεγμένο year = 1
            this(name, id, 1);
        }

        // 3ος Constructor (Master/Canonical): Όλα τα πεδία
        public Student(String name, int id, int year) {
            this.name = name;
            this.id = (id == -1) ? "Unknown" : String.valueOf(id);
            this.year = year;
        }

        // Μέθοδος εμφάνισης στοιχείων
        public void display() {
            System.out.println("Student Information:");
            System.out.println("  Name : " + this.name);
            System.out.println("  ID   : " + this.id);
            System.out.println("  Year : " + ((this.year <= 0) ? "N/A" : this.year));
        }

        // Μέθοδος δοκιμής (main)
        public static void main(String[] args) {
            Student s1 = new Student("Nikos");
            Student s2 = new Student("Maria", 1092345);
            Student s3 = new Student("Giannis", 1087654, 3);

            s1.display();
            s2.display();
            s3.display();
        }
    }
    ```
