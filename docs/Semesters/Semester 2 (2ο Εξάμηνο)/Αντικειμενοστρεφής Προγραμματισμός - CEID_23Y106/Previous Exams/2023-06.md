    **Αιτιολόγηση:**

    ## Θέμα Java 3/10 (XWindow(4), static count)

    *Αξιοπιστία: δύο ανεξάρτητες λύσεις συμφωνούν · εμπιστοσύνη λύτη: μέτρια*

    Το `new XWindow(4)` καλεί τον `Window()`: size=3, `count`=1. Μετά `this.size = x--` → size=4. Η `Window.setCount()` δίνει count=2. Τυπώνει 4 και 2. **4 / 2 (4η επιλογή).** (Οι αγκύλες/παρένθεση της κλάσης `Window` λείπουν στη μεταγραφή· θεωρείται τυπογραφικό.)

    ## Θέμα Java 4/10 (XWindow(6), --x)

    *Αξιοπιστία: 2 από 3 ανεξάρτητες λύσεις συμφωνούν (η άλλη διαφωνούσε) · εμπιστοσύνη λύτη: μέτρια*

    `new XWindow(6)`: count=1, size=--x=5. `new Window()`: count=2. `w1.size`=5, `w.count`=2 (static). **5 / 2 (3η επιλογή).**

    ## Θέμα C++ 8/10 (Rectangle r; Shape s; s = r)

    *Αξιοπιστία: μία λύση AI, δεν έχει αντιπαραβληθεί με δεύτερη · εμπιστοσύνη λύτη: υψηλή*

    `s.width=4`, μετά `s = r` αντιγράφει το υποαντικείμενο Shape του r (slicing): s.width=1. `r.width`=1. **1 / 1 (4η επιλογή).**

    ## Θέμα C++ 10/10 (δείκτες Rectangle/Shape)

    *Αξιοπιστία: μία λύση AI, δεν έχει αντιπαραβληθεί με δεύτερη · εμπιστοσύνη λύτη: υψηλή*

    `r` και `s` δείχνουν στο ίδιο αντικείμενο· `s->width = 4` αλλάζει το κοινό πεδίο. **4 / 4 (4η επιλογή).**

    ## Θέμα Θεωρία C++ 3/10 (σωστή δήλωση κλάσης)

    *Αξιοπιστία: μία λύση AI, δεν έχει αντιπαραβληθεί με δεύτερη · εμπιστοσύνη λύτη: υψηλή*

    Η C++ απαιτεί `;` μετά το `}` και δεν έχει `public class`/`object`. **`class A { int x; };` (1η επιλογή).**

    ## Θέμα C++ 3/10 (Resource, new χωρίς delete)

    *Αξιοπιστία: μία λύση AI, δεν έχει αντιπαραβληθεί με δεύτερη · εμπιστοσύνη λύτη: υψηλή*

    Το αντικείμενο δημιουργείται με `new` και δεν γίνεται ποτέ `delete`· ο destructor δεν καλείται (διαρροή μνήμης). **«Constructor» μόνο (2η επιλογή).**

    ## Θέμα Java 9/10 (compString)

    *Αξιοπιστία: δύο ανεξάρτητες λύσεις συμφωνούν · εμπιστοσύνη λύτη: χαμηλή*

    Ο κώδικας όπως μεταγράφηκε έχει `if !result` χωρίς παρενθέσεις, που δεν μεταγλωττίζεται (πιθανώς τυπογραφικό της εκφώνησης ή της μεταγραφής). Αν διορθωθεί σε `if (!result)`: "Hello" ≠ "Ioannis", μήκη 5 και 7, το `s1.length() > s2.length()` είναι ψευδές → επιστρέφεται `s2+s1` = `IoannisHello`. **"IoannisHello" (2η επιλογή· η 4η είναι το ίδιο χωρίς εισαγωγικά, που δεν είναι έγκυρο literal).**

    ## Θέμα Java 2/10 (charCount)

    *Αξιοπιστία: 2 από 3 ανεξάρτητες λύσεις συμφωνούν (η άλλη διαφωνούσε) · εμπιστοσύνη λύτη: υψηλή*

    Ο βρόχος πρέπει να είναι `i < s.length()` (μέθοδος με παρενθέσεις, όχι `<=`), και η σύγκριση `c == s.charAt(i)`. **3η επιλογή.**

    ## Θέμα Java 1/10 (changeString)

    *Αξιοπιστία: 2 από 3 ανεξάρτητες λύσεις συμφωνούν (η άλλη διαφωνούσε) · εμπιστοσύνη λύτη: υψηλή*

    Τα String είναι αμετάβλητα· η `snew.replace(c1,c2)` επιστρέφει νέο String που απορρίπτεται, άρα το `snew` παραμένει «Dagat». **"Dagat" (4η επιλογή).**

    ## Θέμα Java 8/10 (biggerWindow)

    *Αξιοπιστία: 2 από 3 ανεξάρτητες λύσεις συμφωνούν (η άλλη διαφωνούσε) · εμπιστοσύνη λύτη: μέτρια*

    Η μέθοδος στιγμιοτύπου καλείται σε αντικείμενο, με το άλλο ως όρισμα: και `wa.biggerWindow(wb)` και `wb.biggerWindow(wa)` είναι έγκυρα· η `Window.wa...` δεν είναι. **«Και 1 και 2» (4η επιλογή· στη μεταγραφή οι επιλογές φαίνονται ως 4).**

    ## Θέμα C++ 9/10 (Base με destructor και virtual method)

    *Αξιοπιστία: μία λύση AI, δεν έχει αντιπαραβληθεί με δεύτερη · εμπιστοσύνη λύτη: υψηλή*

    - `base->baseMethod()` → `method()` virtual → `A::method` → «from A».
    - `delete base` (virtual destructor): πρώτα `~A` → `method()` → «from A»· μετά `~Base` → στον destructor της βάσης ο δυναμικός τύπος είναι Base → «from Base».

    **from A / from A / from Base (4η επιλογή).**

    ## Θέμα Θεωρία C++ 6/10 (σύμβολο εκτός εμβέλειας)

    *Αξιοπιστία: μία λύση AI, δεν έχει αντιπαραβληθεί με δεύτερη · εμπιστοσύνη λύτη: υψηλή*

    Τελεστής επίλυσης εμβέλειας. **`::` (2η επιλογή).**
