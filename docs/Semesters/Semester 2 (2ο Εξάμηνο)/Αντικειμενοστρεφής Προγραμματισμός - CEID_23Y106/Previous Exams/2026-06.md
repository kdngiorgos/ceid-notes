    # AI λύσεις — 2026-06

    > Οι λύσεις γράφτηκαν από μοντέλα AI και δεν έχουν ελεγχθεί από άνθρωπο. Η αρίθμηση ακολουθεί το αρχείο θεμάτων.

    ## Θέμα 1

    *Αξιοπιστία: μία λύση AI, δεν έχει αντιπαραβληθεί με δεύτερη · εμπιστοσύνη λύτη: υψηλή*

    **a.** `remove("A")` αφαιρεί την πρώτη εμφάνιση: [A,B,A] → [B,A]. **[B, A]**

    **b.** Το HashSet δεν δέχεται διπλότυπα: {2,4,6}. **3**

    **c.** `s1 == s2`: το `"Ja"+"va"` είναι σταθερά compile-time και γίνεται intern → **true**. `s1 == s3`: το `new String` δημιουργεί νέο αντικείμενο → **false**. `s2.equals(s3)`: ίδιο περιεχόμενο → **true**.

    **d.** Αρχική τιμή 0. **0**

    ## Θέμα 2

    *Αξιοπιστία: μία λύση AI, δεν έχει αντιπαραβληθεί με δεύτερη · εμπιστοσύνη λύτη: υψηλή*

    **a.** Το `==` συγκρίνει αναφορές· δύο διαφορετικά αντικείμενα. **false**

    **b.** `count` στατικό: 1 → 2 → 4. **4**

    **c.** Δεν μεταγλωττίζεται: ο στατικός τύπος `A` δεν έχει μέθοδο `g()` (χρειάζεται cast σε `B`).

    **d.** i=3: push 3, push 2, pop → τυπώνει 2 (μένει [3]). i=2: push 2, push 1, pop → 1 (μένει [3,2]). i=1: push 1, push 0, pop → 0. **Έξοδος: `2 1 0 `**

    ## Θέμα 3

    *Αξιοπιστία: μία λύση AI, δεν έχει αντιπαραβληθεί με δεύτερη · εμπιστοσύνη λύτη: υψηλή*

    Αποφυγή επανάληψης με αλυσίδωση κατασκευαστών (`this(...)`) προς τον πιο πλήρη:

    ```java
    public class Course {
        private String title;
        private String teacher;
        private int ects;
        private int students;

        public Course(String title) {
            this(title, "Unknown");
        }
        public Course(String title, String teacher) {
            this(title, teacher, -1);
        }
        public Course(String title, String teacher, int ects) {
            this.title = title;
            this.teacher = teacher;
            this.ects = ects;
            this.students = 0;
        }
        public void enroll() { students++; }
        public void display() {
            System.out.println("Title: " + title + ", Teacher: " + teacher
                    + ", ECTS: " + ects + ", Students: " + students);
        }
    }
    ```

    Έλεγχος: `c1` → Unknown, -1, 2 εγγραφές· `c2` → -1, 0· `c3` → 6, 0, όπως στα σχόλια.

    ## Θέμα 4

    *Αξιοπιστία: μία λύση AI, δεν έχει αντιπαραβληθεί με δεύτερη · εμπιστοσύνη λύτη: υψηλή*

    ```java
    public static void printLength(String[] names, int pos) {
        try {
            System.out.println("Length: " + names[pos].length());
        } catch (ArrayIndexOutOfBoundsException e) {
            System.out.println("Invalid position: " + pos);
        } catch (NullPointerException e) {
            System.out.println("Null element at position " + pos);
        }
    }
    ```

    Για την κλήση του main: `pos=0` → «Length: 5», `pos=1` → null → NPE μήνυμα, `pos=5` → εκτός ορίων μήνυμα.

    ## Θέμα 5

    *Αξιοπιστία: μία λύση AI, δεν έχει αντιπαραβληθεί με δεύτερη · εμπιστοσύνη λύτη: υψηλή*

    **a.** Η παράμετρος `&x` είναι αναφορά: x=7 τυπώνει 7, και το `a` γίνεται 7. **`77`**

    **b.** sum(10)=10+2+3=15, sum(10,20)=10+20+3=33, sum(10,20,30)=60. **108**

    **c.** Το `const int id` πρέπει να αρχικοποιηθεί στη λίστα αρχικοποίησης μελών (δεν μπορεί να ανατεθεί στο σώμα). Σωστή η **1**. (Η 2 δεν μεταγλωττίζεται, η 3 αρχικοποιεί τον `id` λάθος μέσα στο σώμα και δεν δέχεται id· η 4 είναι λάθος.)

    **d.** Το `t` δημιουργείται (C), τυπώνεται M, και ο destructor καλείται στο τέλος της `main` (D). **CMD (επιλογή a).**
