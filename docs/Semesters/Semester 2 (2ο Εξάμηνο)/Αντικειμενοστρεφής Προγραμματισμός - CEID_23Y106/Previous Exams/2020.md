# **Μέρος 1**<sup>**ο**</sup>

**Διάρκεια 40 λεπτά.** (Η συνολική διάρκεια της εξέτασης είναι 65 λεπτά περιλαμβανομένης και της παράδοσης  του γραπτού σας).

Σας ζητείται να αναπτύξετε μια εφαρμογή Click Away με βάση το αντικειμενοστρεφές παράδειγμα προγραμματισμού και την γλώσσα Java.

H εφαρμογή θα διαθέτει γραφική διεπαφή που περιέχει τρία buttons (New Customer, New Shopkeeper, Start click Away) και συμπεριφορά που περιγράφεται στη συνέχεια:

1. Με το πάτημα του κουμπιού New Customer δημιουργείται ένας νέος πελάτης.

2. Με το πάτημα του κουμπιού New Shopkeeper δημιουργείται ένας νέος καταστηματάρχης.

3. Με το πάτημα του κουμπιού Start click Away ο πελάτης αρχίζει να δημιουργεί παραγγελίες (order) και ο καταστηματάρχης αρχίζει να τις παίρνει και να τις διαχειρίζεται. Ο πελάτης βάζει τις παραγγελίες στο μαγαζί του οποίου ο καταστηματάρχης τις παίρνει και τις διαχειρίζεται.

Η παραγγελία περιγράφεται από την ημερομηνία και ώρα δημιουργίας της, έναν αριθμό που δείχνει τη σειρά με την οποία η παραγγελία δημιουργήθηκε από τον πελάτη (αριθμός παραγγελίας)  και τον κωδικό του προϊόντος.

Ο πελάτης δημιουργεί 30 παραγγελίες και τις βάζει στο κατάστημα.

Το κατάστημα έχει έναν χώρο υποδοχής των παραγγελιών (order box). Ο χώρος υποδοχής των παραγγελιών έχει χωρητικότητα μιας παραγγελίας. Με την δημιουργία του χώρου υποδοχής τοποθετείται μέσα του μια εικονική παραγγελία με αριθμό παραγγελίας 0.

Όταν ο πελάτης τοποθετεί μια νέα παραγγελία και υπάρχει ήδη παραγγελία μέσα στον χώρο υποδοχής παραγγελιών, η παλιά χάνεται.

Πελάτης και καταστηματάρχης λειτουργούν ταυτόχρονα.

**Περιορισμός:** Δεν θα χρησιμοποιήσετε κατασκευές συγχρονισμού.

Για τις παρακάτω δράσεις, και αυτές που θα σας δοθούν στη συνέχεια, αξιοποιήστε την αφαιρετικότητα στις διεργασίες (procedural abstraction) για να δώσετε όσο πιο πλήρη κώδικα γίνεται στα ανώτερα επίπεδα αφαιρετικότητας. Η **κύρια απαίτηση της εξέτασης είναι** να αξιοποιήσετε με τον καλύτερο δυνατό τρόπο  τις βασικές έννοιες της αντικειμενοστρεφούς τεχνολογίας και τους μηχανισμούς και κατασκευές της γλώσσας που υλοποιούν τις έννοιες αυτές.

**Όλος ο πηγαίος κώδικας σας θα βρίσκεται σε ένα αρχείο.** Το όνομα του αρχείου θα αρχίζει με τους χαρακτήρες SC και θα ακολουθεί ο αριθμός μητρώου σας (μόνο το αριθμητικό μέρος) (πχ. SC123456). Η απαίτηση αυτή παραβιάζει τους κανόνες ανάπτυξης <u>java κώδικα αλλά επιβάλλεται για την εξέταση.</u>

    ## Θέμα Α.1 (βασικές κλάσεις)

    *Αξιοπιστία: μία λύση AI, δεν έχει αντιπαραβληθεί με δεύτερη · εμπιστοσύνη λύτη: μέτρια*

    **Μέθοδος.** Αναγνωρίζουμε τις οντότητες: `Order`, `OrderBox` (χωρητικότητα 1), `Shop` (έχει το OrderBox και τον καταστηματάρχη), `Customer` και `Shopkeeper` (ταυτόχρονα, άρα `Thread`/`Runnable`) και το GUI (`ClickAwayFrame`, JFrame με 3 buttons, `setLayout(null)`). Λόγω του περιορισμού «χωρίς κατασκευές συγχρονισμού» (όχι `synchronized`, `wait/notify`, locks) η επικοινωνία γίνεται με απλή κοινή αναφορά στο OrderBox. Επειδή η παλιά παραγγελία χάνεται όταν γράφεται νέα, ο καταστηματάρχης θυμάται τον αριθμό της τελευταίας που επεξεργάστηκε και επεξεργάζεται μόνο παραγγελίες με νέο αριθμό (και όχι την εικονική 0). Τερματίζει όταν δει την παραγγελία 30 (δεν μπορεί να χαθεί, αφού δεν ακολουθεί άλλη).

    ```java
    import java.awt.event.*;
    import java.util.Date;
    import javax.swing.*;

    class Order {
        private final Date created = new Date();   // ημερομηνία/ώρα δημιουργίας
        private final int number;                  // αριθμός παραγγελίας
        private final int productCode;
        Order(int number, int productCode) { this.number = number; this.productCode = productCode; }
        int getNumber() { return number; }
        int getProductCode() { return productCode; }
        Date getCreated() { return created; }
    }

    class OrderBox {                               // χωρητικότητα μίας παραγγελίας
        private Order order = new Order(0, 0);     // εικονική παραγγελία 0
        void put(Order o) { order = o; }           // η παλιά χάνεται
        Order get() { return order; }
    }

    class Shop {
        private final OrderBox box = new OrderBox();
        private Shopkeeper keeper;
        OrderBox getBox() { return box; }
        void setKeeper(Shopkeeper k) { keeper = k; }
    }

    class Customer extends Thread {
        private final Shop shop;
        Customer(Shop shop) { this.shop = shop; }
        public void run() {
            for (int i = 1; i <= 30; i++)
                shop.getBox().put(new Order(i, (int)(Math.random() * 1000)));
        }
    }

    class Shopkeeper extends Thread {
        private final Shop shop;
        private int lastHandled = 0;
        Shopkeeper(Shop shop) { this.shop = shop; shop.setKeeper(this); }
        void handle(Order o) { System.out.println("Handling order " + o.getNumber()); }
        public void run() {
            while (lastHandled < 30) {
                Order o = shop.getBox().get();
                if (o.getNumber() != lastHandled && o.getNumber() != 0) {
                    handle(o);
                    lastHandled = o.getNumber();
                }
            }
        }
    }

    class ClickAway extends JFrame {
        private Shop shop = new Shop();
        private Customer customer;
        private Shopkeeper keeper;
        ClickAway() {
            setLayout(null); setSize(400, 120); setLocation(100, 100);
            JButton c = new JButton("New Customer"), s = new JButton("New Shopkeeper"),
                    go = new JButton("Start click Away");
            c.setBounds(10, 10, 120, 30); s.setBounds(140, 10, 120, 30); go.setBounds(270, 10, 120, 30);
            add(c); add(s); add(go);
            c.addActionListener(e -> customer = new Customer(shop));
            s.addActionListener(e -> keeper = new Shopkeeper(shop));
            go.addActionListener(e -> { if (customer != null && keeper != null) { keeper.start(); customer.start(); } });
            setVisible(true); toFront();
        }
        public static void main(String[] a) { new ClickAway(); }
    }
    ```

    Σχόλια: (α) χωρίς συγχρονισμό η επικοινωνία δεν είναι εγγυημένα ορατή μεταξύ νημάτων (θεωρητικά θα χρειαζόταν `volatile` στο `order`· αν και αυτό θεωρηθεί «κατασκευή συγχρονισμού», η εκφώνηση το αποκλείει και αποδέχεται ότι παραγγελίες χάνονται). (β) Το όνομα του αρχείου πρέπει να είναι `SC<ΑΜ>.java` σύμφωνα με την εκφώνηση· τότε καμία κλάση δεν είναι `public`, και το `main` μπαίνει στην κλάση που εκτελείται.

    ## Θέμα Α.2 (UML)

    *Αξιοπιστία: μία λύση AI, δεν έχει αντιπαραβληθεί με δεύτερη · εμπιστοσύνη λύτη: μέτρια*

    Σχέσεις (το διάγραμμα σχεδιάζεται στο χαρτί):
    - `Customer` και `Shopkeeper` κληρονομούν (generalization) από `Thread` (ή υλοποιούν `Runnable`).
    - `Shop` **σύνθεση** 1–1 με `OrderBox` (το OrderBox ζει με το κατάστημα).
    - `OrderBox` **συσσώρευση/συσχέτιση** 0..1 `Order` (χωρητικότητα 1, αρχικά η εικονική παραγγελία 0).
    - `Customer` --> `Shop` (συσχέτιση, μέλος `shop`)· `Customer` δημιουργεί *0..30* `Order` (εξάρτηση «creates»).
    - `Shopkeeper` --> `Shop` (συσχέτιση)· `Shop` 1–1 `Shopkeeper`.
    - `ClickAway` (JFrame) έχει 3 `JButton` και αναφορές σε `Customer`, `Shopkeeper`, `Shop`.
    - Βασικά μέλη: `Order{created, number, productCode}`, `OrderBox{put(Order), get()}`, `Customer{run()}`, `Shopkeeper{lastHandled, handle(Order), run()}`.
