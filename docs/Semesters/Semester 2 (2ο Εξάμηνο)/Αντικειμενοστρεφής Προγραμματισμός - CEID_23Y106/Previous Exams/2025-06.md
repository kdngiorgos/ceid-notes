    # AI λύσεις — 2025-06

    > Οι λύσεις γράφτηκαν από μοντέλα AI και δεν έχουν ελεγχθεί από άνθρωπο. Η αρίθμηση ακολουθεί το αρχείο θεμάτων.

    ## Θέμα 1

    *Αξιοπιστία: δύο ανεξάρτητες λύσεις συμφωνούν · εμπιστοσύνη λύτη: υψηλή*

    **a.** `add(1,20)` εισάγει στη θέση 1 και μετατοπίζει: [10,15] → [10,20,15]. **[10, 20, 15]**

    **b.** Αντιστροφή πίνακα με `length/2 = 2` ανταλλαγές: (1↔5) → {5,3,2,4,1}, (3↔4) → {5,4,2,3,1}. **[5, 4, 2, 3, 1]** (απαιτεί `import java.util.Arrays`).

    **c.** `remove("Charlie")` δεν βρίσκει στοιχείο, επιστρέφει false, χωρίς εξαίρεση. **2**

    **d.** Τα πεδία δεν είναι πολυμορφικά, οι μέθοδοι είναι. Η `obj.print()` εκτελεί την `B.print()`, που τυπώνει το `x` της `B`. **20**

    ## Θέμα 2

    *Αξιοπιστία: δύο ανεξάρτητες λύσεις συμφωνούν · εμπιστοσύνη λύτη: υψηλή*

    **a.** Μετά τα push: στοίβα (κορυφή) 1,2,3. Οι pops για i=0..3 είναι 4: τυπώνει «1 2 3 », και η 4η `pop()` σε άδεια στοίβα ρίχνει `EmptyStackException`. **Έξοδος `1 2 3 ` και μετά EmptyStackException.**

    **b.** [1,8,4,11,5]: i=0 → το 1 περιττό, αφαιρείται → [8,4,11,5]· i=1 → 4 άρτιο· i=2 → 11 περιττό, αφαιρείται → [8,4,5]· i=3 → size=3, τέλος (το 5 παραλείφθηκε, αλλά δεν ελέγχεται). **[8, 4, 5]** (το πρόβλημα: η αφαίρεση μέσα σε βρόχο με δείκτη μετατοπίζει στοιχεία).

    **c.** Οι πίνακες int αρχικοποιούνται με 0. **0**

    **d.** Δεν μεταγλωττίζεται: ο στατικός τύπος του `obj` είναι `Parent`, που δεν έχει μέθοδο `onlyInChild()`. Λύση: cast `((Child) obj).onlyInChild()`.

    ## Θέμα 3

    *Αξιοπιστία: δύο ανεξάρτητες λύσεις συμφωνούν · εμπιστοσύνη λύτη: υψηλή*

    Προβλήματα: (1) διαίρεση ακεραίων: `1 / a` δίνει 0 για |a|>1 και χάνεται το δεκαδικό μέρος (πρέπει `1.0 / a`)· (2) για `a == 0` ρίχνει `ArithmeticException`. Επέκταση:

    ```java
    double reciprocal(int a) {
        if (a == 0)
            throw new IllegalArgumentException("Division by zero: 0 has no reciprocal");
        return 1.0 / a;
    }
    ```

    Ο καλών μπορεί να το πιάσει με `try { ... } catch (IllegalArgumentException e) { ... }`. (Εναλλακτικά `try/catch (ArithmeticException)` γύρω από `1 / a` με το `a` ως `double`.)

    ## Θέμα 5

    *Αξιοπιστία: δύο ανεξάρτητες λύσεις συμφωνούν · εμπιστοσύνη λύτη: μέτρια*

    - **i.** Η friend συνάρτηση έχει πρόσβαση σε όλα τα μέλη: **d**.
    - **ii.** Πολυμορφισμός: δείκτης βάσης σε αντικείμενο παράγωγης (με virtual): **c**.
    - **iii.** Σε C++ (friend, member initialization list) ο constructor της παραγόμενης καλεί τον constructor της βάσης στη member initialization list: **c**. (Το «super» είναι Java.)
