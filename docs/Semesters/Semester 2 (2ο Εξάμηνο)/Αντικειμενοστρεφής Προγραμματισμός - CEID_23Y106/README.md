# Αντικειμενοστρεφής Προγραμματισμός

> Εισαγωγή στο αντικειμενοστρεφές παράδειγμα προγραμματισμού με Java (και μετάβαση σε C++): αντικείμενα, κλάσεις, κληρονομικότητα, πολυμορφισμός, εξαιρέσεις, γραφικές διεπαφές και νήματα. Είναι το δεύτερο μάθημα προγραμματισμού του προγράμματος και στηρίζεται στον διαδικαστικό προγραμματισμό που προηγήθηκε. Το μάθημα πέρασε σε νέα φάση τα τελευταία χρόνια: άλλαξε διδάσκων και η εξέταση έγινε γραπτή, σε αντίθεση με τη δεκαετία του Θραμπουλίδη που γινόταν με πολλαπλής επιλογής στο υπολογιστικό κέντρο.

## Τι θα μάθεις

Το επίσημο περίγραμμα οργανώνεται σε έντεκα ενότητες [Περίγραμμα](https://www.ceid.upatras.gr/sites/default/files/ap-ceid_nny106_perigrammamathimatos_gr_1.pdf): τους περιορισμούς του διαδικαστικού προγραμματισμού και τη μετάβαση στο αντικειμενοστρεφές παράδειγμα· τους μηχανισμούς αντιμετώπισης της πολυπλοκότητας (αφαιρετικότητα δεδομένων και διεργασιών)· το νοητικό μοντέλο του OOP (αντικείμενο, κλάση, στιγμιότυπο, αναφορά)· εισαγωγή στη Java· το πρόγραμμα ως συνάθροιση αντικειμένων και τα βασικά διαγράμματα UML· κληρονομικότητα και πολυμορφισμό· διαχείριση εξαιρέσεων και garbage collection· γραφικές διεπαφές και event handling· υλοποίηση των ίδιων εννοιών σε C++· εισαγωγή στα νήματα (multithreading)· και το μοντέλο πελάτη–εξυπηρετητή (sockets, servlets).

Στην πράξη το μάθημα είναι Java-κεντρικό. Οι διαλέξεις του eClass ακολουθούν τη σειρά του μαθήματος — εισαγωγή και πρόγραμμα ως αντικείμενα, Java as an OOP language, η προσέγγιση LEGO, κληρονομικότητα, διεπαφές, γραφικές διεπαφές/event handling, εξαιρέσεις, ταυτοχρονισμός eClass (διαθέσιμο στο πλήρες πακέτο). Η C++ εμφανίζεται προς το τέλος (εβδομάδα 13) ως μετάβαση για όσους ξέρουν ήδη Java eClass (διαθέσιμο στο πλήρες πακέτο). Η ύλη της εξέτασης δεν είναι σταθερή από έτος σε έτος· διάβασε πάντα τις διαφάνειες και τις ανακοινώσεις του τρέχοντος έτους.
