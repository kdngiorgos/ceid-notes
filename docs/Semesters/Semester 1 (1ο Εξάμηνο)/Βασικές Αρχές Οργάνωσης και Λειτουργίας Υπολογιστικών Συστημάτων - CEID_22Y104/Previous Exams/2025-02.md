**A+B** | **Γ – B**

Η αρτηρία διευθύνσεων ενός υπολογιστή έχει εύρος 24 δυαδικών ψηφίων. Αν η μέγιστη φυσική μνήμη που μπορούμε να προσαρτήσουμε σε αυτόν είναι 64 Mbytes, πόση ποσότητα δεδομένων θα πρέπει να αντιστοιχεί σε κάθε διεύθυνση;

| Διεύθυνση | Δεδομένο | Διεύθυνση | Δεδομένο | Διεύθυνση | Δεδομένο | Διεύθυνση | Δεδομένο | Διεύθυνση | Δεδομένο |

| 0x200 | 0xAB | 0x205 | 0xAA | 0x20A | 0x31 | 0x20F | 0xAB | 0x214 | 0x06 |

| 0x202 | 0xD3 | 0x207 | 0xCC | 0x20C | 0xFE | 0x211 | 0xD3 | 0x216 | 0x1E |
| 0x203 | 0xA2 | 0x208 | 0xDD | 0x20D | 0x18 | 0x212 | 0xA2 | 0x217 | 0x25 |
| 0x204 | 0xBC | 0x209 | 0xEE | 0x20E | 0x11 | 0x213 | 0xBC | 0x218 | 0xF4 |

Θεωρήστε ότι πριν την εκτέλεση κάθε μίας από τις παρακάτω εντολές στο AT91, τα περιεχόμενα των R1, R2 και R3 είναι αντίστοιχα 0x7, 0x204 και 0x02. Να συμπληρώσετε στον παρακάτω πίνακα τα περιεχόμενα των R1 και R2 μετά την εκτέλεση κάθε εντολής.

| Εντολή | Περιεχόμενο R1 μετά την εντολή | Περιεχόμενο R2 μετά την εντολή |
|---|---|---|
| LDR R1, [R2] | | |
| LDRH R1, [R2, # -4 ] | | |
| LDRB R1, [R2, R3, LSL #3]! | | |
| LDR R1, [R2], #8 | | |

Για το AT91, ένας προγραμματιστής έγραψε το ακόλουθο πρόγραμμα:

```
.arm
.text
.global main
main:
STMDB R13!, {R0-R12}
LDR R0, =Array
ADD R3, R0, #16
Loop:
LDR R1, [R0]
MOV R2, R1, LSL #1
ADD R1, R1, R2
STR R1, [R0]
ADD R0, R0, #4
CMP R0, R3
BLT Loop
LDMIA R13!, {R0-R12}
MOV PC, R14
.data
Array: .word 14, 12, 2, 41
```

- Ποιον υπολογισμό επιτελεί αυτό το πρόγραμμα;

Στον κώδικα "συμπλήρωμα ως προς 2" οι A, B και Γ αναπαρίστανται ως: $A=11000_{2s}$, $B=100011_{2s}$ και $\Gamma=01000001_{2s}$. Να εκτελέσετε τις πράξεις A+B και Γ – B χρησιμοποιώντας κάθε φορά τα ελάχιστα δυαδικά ψηφία και να καταγράψετε τις τιμές των σημαιών κατάστασης Z, C, N, V. Να σχολιάσετε την ορθότητα των αποτελεσμάτων. Σε περίπτωση λάθους αποτελεσμάτων να αναφέρετε (χωρίς να το δείξετε) το πως μπορούμε να εκτελέσουμε ορθά αυτές τις πράξεις.

**A+B** | **Γ – B**

Η αρτηρία διευθύνσεων ενός υπολογιστή έχει εύρος 16 δυαδικών ψηφίων. Αν η μέγιστη φυσική μνήμη που μπορούμε να προσαρτήσουμε σε αυτόν είναι 256 Kbytes, πόση ποσότητα δεδομένων θα πρέπει να αντιστοιχεί σε κάθε διεύθυνση;

Στην μνήμη του AT91 βρίσκονται αποθηκευμένα τα ακόλουθα δεδομένα:

Θεωρήστε ότι πριν την εκτέλεση κάθε μίας από τις παρακάτω εντολές στο AT91, τα περιεχόμενα των R1, R2 και R3 είναι αντίστοιχα 0xA, 0x208 και 0x02. Να συμπληρώσετε στον παρακάτω πίνακα τα περιεχόμενα των R1 και R2 μετά την εκτέλεση κάθε εντολής.

| Εντολή | Περιεχόμενο R1 μετά την εντολή | Περιεχόμενο R2 μετά την εντολή |
|---|---|---|
| LDR R1, [R2] | | |
| LDRH R1, [R2, # -4 ] | | |
| LDRB R1, [R2, R3, LSL #1]! | | |
| LDR R1, [R2], #4 | | |

Για το AT91, ένας προγραμματιστής έγραψε το ακόλουθο πρόγραμμα:

```
.arm
.text
.global main
main:
STMDB R13!, {R0-R12}
LDR R0, =Array
ADD R3, R0, #16
Loop:
LDR R1, [R0]
MOV R2, R1, LSL #2
ADD R1, R1, R2
STR R1, [R0]
ADD R0, R0, #4
CMP R0, R3
BLT Loop
LDMIA R13!, {R0-R12}
MOV PC, R14
.data
Array: .word 14, 12, 2, 41
```

- Ποιον υπολογισμό επιτελεί αυτό το πρόγραμμα;
- Θα λειτουργήσει σωστά για προσημασμένα δεδομένα;
