## 2025_2.pdf (σελ. 1-3)

### Θέμα 1°

1. Η πράξη 0110101 + 0011000 σε αριθμητική συμπληρώματος ως προς 1 με ακρίβεια 7 δυαδικών ψηφίων παράγει λάθος αποτέλεσμα, γιατί:
   - [ ] Α. Υπάρχει υπερχείλιση.
   - [ ] Β. Υπάρχει κρατούμενο εξόδου που δεν πρέπει να αγνοήσουμε.
   - [ ] Γ. Απαιτείται μετατροπή πρώτα σε πρόσημο-μέτρο.
   - [ ] Δ. Το Α και το Β.

2. Ο αριθμός –41₅ (ο δείκτης εκφράζει το αριθμητικό σύστημα αναπαράστασης) έχει παράσταση σε συμπλήρωμα ως προς 2:
   - [ ] Α. 11101000
   - [ ] Β. 1001001
   - [ ] Γ. 10111
   - [ ] Δ. 11101011

3. Η πρόσθεση των αριθμών 0 10000000 0110...0 και 1 01111111 1010...0 σε IEEE Single Precision Floating Point μας δίνει το αποτέλεσμα (ο δείκτης εκφράζει το αριθμητικό σύστημα / κώδικα αναπαράστασης):
   - [ ] Α. 1,125₁₀
   - [ ] Β. 1,25₁₀ * 10⁻¹
   - [ ] Γ. 1 10000000 0010 ... 0 IEEE-754 SP
   - [ ] Δ. 1,101₂

4. Αν όλοι οι κατασκευαστές υιοθετούσαν την ίδια αναπαράσταση σταθερής υποδιαστολής, τότε η εισαγωγή του IEEE 754 standard για αριθμούς κινητής υποδιαστολής θα ήταν άχρηστη;
   - [ ] Α. Όχι, γιατί θα υπήρχε μεγάλη σπατάλη μνήμης και αυξημένη κατανάλωση για τους υπολογισμούς.
   - [ ] Β. Όχι, γιατί δε θα υπήρχαν κανονικοποιημένοι αριθμοί.
   - [ ] Γ. Όχι, γιατί δε θα μπορούσαν να παρασταθούν τα ±∞.
   - [ ] Δ. Ναι, αφού τα πάντα θα γινόταν με αναπαραστάσεις σταθερής υποδιαστολής.

5. Για τη διόρθωση απλού λάθους ο καλύτερος κώδικας είναι:
   - [ ] Α. Ο κώδικας ισοτιμίας στήλης – γραμμής.
   - [ ] Β. Ο κώδικας ισοτιμίας.
   - [ ] Γ. Ο κώδικας Hamming.
   - [ ] Δ. Εξαρτάται από το μήκος των δεδομένων.

6. Πόσα δυαδικά ψηφία ελέγχου απαιτούνται κατ' ελάχιστο για την διόρθωση απλού λάθους μηνύματος μήκους 64 δυαδικών ψηφίων ?
   - [ ] Α. 5
   - [ ] Β. 6
   - [ ] Γ. 7
   - [ ] Δ. Κανένα από τα Α, Β, Γ.

7. Όταν ένα σύστημα έχει αρτηρία διευθύνσεων 16 bit και κάθε θέση μνήμης αποθηκεύει 8 bit, η μέγιστη φυσική μνήμη του συστήματος είναι :
   - [ ] Α. 32 KBytes
   - [ ] Β. 128 KBytes
   - [ ] Γ. 64 KBytes
   - [ ] Δ. Κανένα από τα Α, Β, Γ

8. Δύο υπολογιστικά συστήματα που διαθέτουν ακριβώς το ίδιο σύνολο εντολών σε γλώσσα Assembly μπορούν να εκτελέσουν τον ίδιο κώδικα μηχανής ?
   - [ ] Α. Ναι, αν έχουν τον ίδιο χώρο διευθύνσεων.
   - [ ] Β. Ναι, αν έχουν το ίδιο λειτουργικό σύστημα.
   - [ ] Γ. Ναι. Πάντα.
   - [ ] Δ. Όχι.

### Θέμα 2°

- $745{,}66_8$

### Θέμα 3°

Να εκφράσετε τους ακόλουθους **προσημασμένους** αριθμούς που δίνονται με τη μορφή πρόσημο και μέτρο, στο συμπλήρωμα ως προς 16 (ο δείκτης εκφράζει το αριθμητικό σύστημα της κάθε αναπαράστασης) :

- $-(1110101101_2)$
- $+(5745{,}66_8)$
- $-(1332)_4$

### Θέμα 4°

Ένα υπολογιστικό σύστημα χρησιμοποιεί αριθμητική συμπληρώματος ως προς 2 και διαθέτει καταχωρητές των 8 δυαδικών ψηφίων. Να δείξετε το πως θα εκτελεστούν στο σύστημα αυτό οι πράξεις Α + Β, Β – Γ και Δ – Α όπου $A = -65_{10}$, $B = +117_{10}$, $\Gamma = -26_{10}$ και $\Delta = +77_{10}$. Για κάθε πράξη σημειώστε τις σημαίες κατάστασης (Ζ, Ν, C, V) και βάσει αυτών αποφανθείτε εάν το αποτέλεσμα της πράξης είναι ορθό ή μη.

### Θέμα 5°

Δίδεται το ακόλουθο πρόγραμμα για τον υπολογισμό μιας έκφρασης σε μία μηχανή με καταχωρητές γενικού σκοπού και 3 έντελα σε κάθε εντολή. Ζητείται να δώσετε την έκφραση που υπολογίζει το πρόγραμμα και να αναπτύξετε πρόγραμμα που να υπολογίζει την ίδια έκφραση σε μια μηχανή συσσωρευτή.

Αρχιτεκτονική με καταχωρητές γενικού σκοπού:

```text
LOAD R1, D
LOAD R2, E
LOAD R3, C
MUL R1, R1, R2
SUB R1, R3, R1
LOAD R4, B
DIV R1, R1, R4
LOAD R4, A
ADD R4, R4, R1
SUB R2, R2, R3
DIV R1, R4, R2
STORE G, R1
```

### Θέμα 6°

- Να αναφέρετε τα επίπεδα ιεραρχίας μνήμης ενός σύγχρονου υπολογιστικού συστήματος, τις τεχνολογίες μνήμης που χρησιμοποιούμε για το καθένα και τις ελάχιστες μονάδες ανταλλαγής πληροφορίας μεταξύ τους.
- Να αναφέρετε όλες τις σχεδιαστικές υπομονάδες που θα συναντήσει κάποιος σε ένα σημερινό ολοκληρωμένο κύκλωμα μικροεπεξεργαστή.
- Να αναφέρετε τεχνικές μείωσης του χρόνου προσπέλασης της πληροφορίας σε έναν σκληρό δίσκο.
- Πόσα είδη αρτηριών διαφορετικών ταχυτήτων υπάρχουν συνήθως σε ένα σημερινό υπολογιστικό σύστημα; Να τα αναφέρετε και να δώσετε τα χαρακτηριστικά τους.

    | Αρχιτεκτονική με καταχωρητές γενικού σκοπού | Τιμή | Μηχανή συσσωρευτή |
    |---|---|---|
    | LOAD R1, D | R1 = D | LOAD E |
