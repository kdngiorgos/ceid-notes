```
        INX H
        MOV B, M
        MVI C, 00
AGAIN:  SUB B

```

Σε περίπτωση λάθους αποτελεσμάτων να αναφέρετε (χωρίς να το δείξετε) το πως μπορούμε να εκτελέσουμε ορθά αυτές τις πράξεις.

**Α+Β** | **Γ – Β**

### Θέμα 4ο [1,0 μονάδα]

Η μέγιστη φυσική μνήμη που μπορεί να προσαρτήσουμε σε ένα υπολογιστικό σύστημα είναι 4 GBytes. Αν σε κάθε θέση μνήμης μπορούμε να αποθηκεύουμε πληροφορία 16 δυαδικών ψηφίων, να προσδιορίσετε το εύρος της αρτηρίας διευθύνσεών του.

### Θέμα 5ο [2,0 μονάδες]

Να γραφεί πρόγραμμα για τον υπολογισμό της έκφρασης $X = C + (B \times D + A) \times C - E / Z$, για:

### Θέμα 6ο [1,9 μονάδες]

Για τον επεξεργαστή 8085, ένας προγραμματιστής έγραψε το ακόλουθο πρόγραμμα:

```
        LXI H, 4000
        MOV A, M
        INX H
        MOV B, M
        MVI C, 00
AGAIN:  SUB B
        JC DONE
        INR C
        JMP AGAIN
DONE:   ADD B
        INX H
        MOV M, C
        INX H
        MOV M, A
        HLT
```

Θεωρήστε ότι πριν την εκτέλεση του προγράμματος στις θέσεις μνήμης 4000₁₆ και 4001₁₆ είναι αποθηκευμένες οι τιμές 15₁₆ και 08₁₆, αντίστοιχα και ότι στις εντολές αφαίρεσης η σημαία κρατουμένου τίθεται όταν η αφαίρεση είναι ανεπιτυχής.

- Πόσες φορές θα εκτελεστεί η εντολή JMP AGAIN;
- Τι θα αποθηκευτεί στις θέσεις 4002₁₆ και 4003₁₆ στο τέλος του προγράμματος;
- Ποια αριθμητική πράξη επιτελεί αυτό το πρόγραμμα;
- Θα λειτουργήσει σωστά για προσημασμένους αριθμούς;
