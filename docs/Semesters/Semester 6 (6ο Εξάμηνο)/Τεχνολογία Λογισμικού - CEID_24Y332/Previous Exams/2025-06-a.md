    ## Θέμα Β

    *Αξιοπιστία: δύο ανεξάρτητες λύσεις συμφωνούν · εμπιστοσύνη λύτη: μέτρια*

    Κανόνες ICONIX: ο actor μιλά μόνο με boundary· boundary↔control· control↔control· control↔entity· όχι boundary↔boundary ή entity↔entity. Υπάρχουν πολλές αποδεκτές λύσεις· μία ενδεικτική (η σειρά των βημάτων 1–7 της ροής σημειώνεται):

    ```
    Objects:  Actor: Πελάτης
              Boundary: [Οθόνη Αξιολόγησης], [Οθόνη Επιβεβαίωσης]
              Control: (Ανάκτηση Εκδηλώσεων), (Έλεγχος Βαθμολογίας), (Αποθήκευση Βαθμολογίας)
              Entity: <Εκδήλωση>, <Βαθμολογία>
              Use case: Αναζήτηση

    1  Πελάτης --> [Οθόνη Αξιολόγησης]
    2  [Οθόνη Αξιολόγησης] --> (Ανάκτηση Εκδηλώσεων) --> <Εκδήλωση>
       (Ανάκτηση Εκδηλώσεων) --> [Οθόνη Αξιολόγησης]      (εμφάνιση λίστας)
    3  Πελάτης --> [Οθόνη Αξιολόγησης]                   (επιλογή εκδήλωσης και βαθμού 1-5)
    4  [Οθόνη Αξιολόγησης] --> (Έλεγχος Βαθμολογίας) --> [Οθόνη Επιβεβαίωσης]
    5  Πελάτης --> [Οθόνη Επιβεβαίωσης]
    6  [Οθόνη Επιβεβαίωσης] --> (Αποθήκευση Βαθμολογίας) --> <Βαθμολογία>
    7  Πελάτης --> [Οθόνη Αξιολόγησης] ---> (use case «Αναζήτηση»)
    ```

    ## Θέμα Γ

    *Αξιοπιστία: δύο ανεξάρτητες λύσεις συμφωνούν · εμπιστοσύνη λύτη: μέτρια*

    Μετατροπή σχέσεων: το «#» γίνεται protected, το «−» private, το «+» public. Η κατευθυνόμενη συσχέτιση 1–1 Customer→ShoppingCart δίνει στον Customer ένα πεδίο τύπου ShoppingCart. Η σύνθεση 1–0..* ShoppingCart◆→CartItem δίνει στο ShoppingCart συλλογή CartItem (τα μέρη δημιουργούνται και καταστρέφονται μαζί με το σύνολο), άρα προσθέτω και μέθοδο addItem.

    ```java
    import java.util.ArrayList;
    import java.util.List;

    public class Customer {
        protected String customerId;
        protected String name;
        private ShoppingCart cart;          // association 1 -> 1

        public Customer(String customerId, String name) {
            this.customerId = customerId;
            this.name = name;
            this.cart = new ShoppingCart();
        }
        public ShoppingCart getCart() { return cart; }
    }

    public class ShoppingCart {
        private double totalAmount;
        private List<CartItem> items = new ArrayList<>();   // composition 1 -> 0..*

        public void addItem(CartItem item) { }
        public void removeItem(String itemId) { }
        public double calculateTotal() { return 0; }
    }

    public class CartItem {
        private String itemId;
        private double price;
        private int quantity;

        public void updateQuantity(int quantity) { }
    }
    ```
