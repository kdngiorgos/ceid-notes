    ## Θέμα Γ

    *Αξιοπιστία: δύο ανεξάρτητες λύσεις συμφωνούν · εμπιστοσύνη λύτη: χαμηλή*

    Προσοχή: η φωτογραφία είναι κομμένη (λείπει η εκφώνηση και το δεξί άκρο του διαγράμματος), άρα η λύση βασίζεται μόνο στα ορατά στοιχεία και σε υποθέσεις που σημειώνονται.

    Αντιστοίχιση σχέσεων:
    - Realization CreditCardProcessor → PaymentProcessor: `implements`.
    - Dependency ShoppingCart → CreditCardProcessor: χρήση ως παράμετρος μεθόδου, όχι πεδίο (υπόθεση: μέθοδος `checkout`).
    - Association CreditCardProcessor (1) → Transaction (0..*): πεδίο λίστας στον CreditCardProcessor.
    - Υπογραμμισμένο `MAX_TRANSACTION_AMOUNT {readOnly}`: `public static final`. Η τιμή δεν φαίνεται· η 10000.0 είναι αυθαίρετη.

    ```java
    import java.util.ArrayList;
    import java.util.List;

    public interface PaymentProcessor {
        boolean processPayment(double amount);
    }

    public class CreditCardProcessor implements PaymentProcessor {
        private String cardNumber;
        public static final double MAX_TRANSACTION_AMOUNT = 10000.0;  // τιμή υποθετική
        private List<Transaction> transactions = new ArrayList<>();   // 1 -> 0..*

        @Override
        public boolean processPayment(double amount) { return false; }
        public boolean chargeCard(double amount) { return false; }
    }

    public class ShoppingCart {
        private double totalAmount;

        public void removeItem(String itemId) { }
        public double calculateTotal() { return 0; }
        // εξάρτηση: το CreditCardProcessor εμφανίζεται μόνο ως παράμετρος
        public boolean checkout(CreditCardProcessor processor) { return false; }
    }

    public class Transaction {
        private String transactionId;
        private String status;

        public String getTransactionDetails() { return null; }
    }
    ```
