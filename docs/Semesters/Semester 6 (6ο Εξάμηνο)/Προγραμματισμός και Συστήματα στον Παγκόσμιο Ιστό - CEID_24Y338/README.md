# Προγραμματισμός και Συστήματα στον Παγκόσμιο Ιστό

> Εισαγωγικό μάθημα που συνδυάζει τον προγραμματισμό web εφαρμογών (HTML/CSS/JavaScript, PHP ή Node.js, MySQL) με τη θεωρία των συστημάτων του Παγκόσμιου Ιστού (HTTP, DNS, κρυφές μνήμες, αντιπρόσωποι, πλεονασμός/CDN). Η αξιολόγηση είναι κατά βάση ένα μεγάλο προγραμματιστικό project στο τέλος, με μια σύντομη γραπτή πολλαπλής επιλογής· η γραπτή έχει, κατά φοιτητές, αρνητική βαθμολόγηση και βάση 3.

## Τι θα μάθεις

Το επίσημο περίγραμμα χωρίζει το μάθημα σε δύο μέρη [Περίγραμμα](https://www.ceid.upatras.gr/sites/default/files/ceid_ny538_gr.pdf):

- **Προγραμματισμός στον Παγκόσμιο Ιστό:** HTML4/HTML5, CSS, JavaScript, Bootstrap, εισαγωγή σε AngularJS, server-side τεχνολογίες με PHP, διασύνδεση με MySQL, XML/XSL, AJAX/JSON/jQuery/Node.js, mobile web, web APIs και κοινωνικά δίκτυα.
- **Συστήματα στον Παγκόσμιο Ιστό:** αρχές κρυφών μνημών (caching) και πλεονασμού περιεχομένου, πρωτόκολλα URL/DNS/HTTP (απλό, persistent, pipelining), υποστήριξη HTTP για caching και ασφάλεια μεταφοράς (SSL/TLS, HTTPS), μετρικές απόδοσης, αλγόριθμοι συνέπειας και ακύρωσης (leases, subscriptions, cache validation) και συστήματα πλεονασμού/καθρεπτισμού και διανομής αιτήσεων.

Στην πράξη, όπως φαίνεται και στις διαλέξεις 2025-26, το πρώτο μέρος καλύπτεται αναλυτικά με διαφάνειες HTML/CSS/Bootstrap, JavaScript (JS1–JS6, με Node.js), PHP1/PHP2, usability και διαχείριση χρηστών/sessions eClass (διαθέσιμο στο πλήρες πακέτο).
