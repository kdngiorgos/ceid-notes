---

Ο παρακάτω κώδικας σε ένα HTML αρχείο, θα εμφανίσει μία εικόνα που όταν την επιλέξουμε θα εμφανίσει ένα παράθυρο διαλόγου (pop up) με τίτλο «Test picture»:
```html
<a href = "mypage.html">
  <img src = "images/myimage.png" alt = "Test picture">
</a>
```

---

> [Σχήμα: πολύπλοκος πίνακας με επικεφαλίδα «Πίνακας 1» και κελιά «Κελί 1», «Κελί 2», «Κελί 3»· τα όρια των κελιών δυσδιάκριτα. Η διάταξη των κελιών (ένα κελί κάτω από την επικεφαλίδα, δύο στην επόμενη γραμμή) δεν αποδίδεται πλήρως.]

Ο παρακάτω κώδικας JavaScript θα επιστρέψει το πρώτο στοιχείο με id = 'button':

```html
<script src="script.js"></script>
```
έχει ως αποτέλεσμα ότι το script φορτώνεται και εκτελείται πριν φορτωθεί το DOM.

```javascript
console.log('A');

console.log('C');
```

    ## Θέμα 14 (Express /users/:id)

    *Αξιοπιστία: λύθηκε με βάση τις φωτογραφίες του θέματος· μία λύση AI*

    Στην εικόνα `Messenger_creation_1A295866-8081-4C5C-BEE4-D8C29FE72EEF.png` ο κώδικας διακρίνεται καθαρά (με αποκομμένα μόνο τα πρώτα γράμματα `app.` στο αριστερό περιθώριο):
    ```javascript
    const express = require('express');
    const app = express();
    app.get('/users/:id', (req, res) => { res.send(`User ID: ${req.params.id}`); });
    app.listen(3000);
    ```
    Η εκφώνηση ρωτά:
    «Στον παρακάτω κώδικας Express εκτελείται, μια αίτηση στο URL 'http://localhost:3000/users/123' θα εμφανίσει το μήνυμα 'User ID: 123' στον περιηγητή.»

    - **Απάντηση:** **Σωστό**
    - **Αιτιολόγηση:** Η διαδρομή `app.get('/users/:id', ...)` ορίζει παράμετρο διαδρομής (route parameter) `:id`. Κατά την αποστολή GET αιτήματος στο `http://localhost:3000/users/123`, η τιμή `123` δεσμεύεται στο `req.params.id`. Η μέθοδος `res.send(`User ID: ${req.params.id}`)` στέλνει πίσω στον περιηγητή την απάντηση `User ID: 123`.

    ## Θέμα 15 (response.text())

    Η αρχή της πρότασης είναι κομμένη («…aScript»), αλλά η μέθοδος `.text()` του Response επιστρέφει την απόκριση ως κείμενο. **Σωστό**.

    ## Θέμα 16 (εκτέλεση PHP, «απαραίτητο να έχουμε εγκατεστημένη τη…»)

    *Αξιοπιστία: λύθηκε με βάση τις φωτογραφίες του θέματος· μία λύση AI*

    Στην εικόνα `Messenger_creation_1A295866-8081-4C5C-BEE4-D8C29FE72EEF.png` (και σε πανομοιότυπη εμφάνιση στην εξεταστική 2024-06) η πλήρης πρόταση είναι:
    «Για να εκτελέσουμε PHP αρχεία στον υπολογιστή μας είναι απαραίτητο να έχουμε εγκατεστημένη τη MySQL.»

    - **Απάντηση:** **Λάθος**
    - **Αιτιολόγηση:** Για την εκτέλεση αρχείων PHP απαιτείται μόνο ο διερμηνέας της PHP (PHP interpreter / CLI ή ενσωματωμένος σε web server όπως Apache/Nginx). Η βάση δεδομένων MySQL είναι ένα ανεξάρτητο σύστημα διαχείρισης βάσεων δεδομένων και δεν είναι απαραίτητη για την εκτέλεση της PHP, εκτός αν η συγκεκριμένη εφαρμογή χρησιμοποιεί βάση δεδομένων MySQL.
