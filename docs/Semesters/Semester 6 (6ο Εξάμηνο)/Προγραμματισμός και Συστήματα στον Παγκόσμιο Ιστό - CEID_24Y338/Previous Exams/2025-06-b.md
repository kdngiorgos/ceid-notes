# Προγραμματισμός και Συστήματα στον Παγκόσμιο Ιστό — Ιούνιος 2025 (Ομάδα Β)

## Messenger_creation_1A295866-8081-4C5C-BEE4-D8C29FE72EEF.png

[δυσανάγνωστο]Α Μηχανικών Η/Υ & Πληροφορικής

Προγραμματισμός & Συστήματα στον Παγκόσμιο Ιστό

Για κάθε σωστή απάντηση λαμβάνετε 1 μονάδα (στις 30), ενώ κάθε λάθος στοιχίζει 0,5 μονάδα (στις 30).

---

Τα HTML αρχεία πρέπει να γίνουν compile πριν να είναι δυνατή η εμφάνισή τους στον Mozilla Firefox browser.

---

Σε μία μη διατεταγμένη λίστα (unordered list), που δημιουργούμε με χρήση των HTML tags `<ul>` και `<li>`, τα στοιχεία της λίστας θα εμφανίζονται με τυχαία σειρά εμφάνισης σε κάθε φόρτωση του HTML αρχείου στον browser.

---

Ο παρακάτω κώδικας σε ένα HTML αρχείο, θα εμφανίσει μία εικόνα που όταν την επιλέξουμε θα εμφανίσει ένα παράθυρο διαλόγου (pop up) με τίτλο «Test picture»:
```html
<a href = "mypage.html">
  <img src = "images/myimage.png" alt = "Test picture">
</a>
```

---

Με την HTML δε είναι δυνατό να δημιουργήσουμε ένα πολύπλοκο πίνακα όπως ο παρακάτω:

> [Σχήμα: πολύπλοκος πίνακας με επικεφαλίδα «Πίνακας 1» και κελιά «Κελί 1», «Κελί 2», «Κελί 3»· τα όρια των κελιών δυσδιάκριτα. Η διάταξη των κελιών (ένα κελί κάτω από την επικεφαλίδα, δύο στην επόμενη γραμμή) δεν αποδίδεται πλήρως.]

---

Σε ένα αρχείο CSS περιέχεται ο κώδικας `.special {color: blue}`. Αυτό σημαίνει πως όλες οι HTML ετικέτες με το αλφαριθμητικό "special" θα εμφανιστούν με μπλε γραμματοσειρά.

---

Η JavaScript είναι μια γλώσσα ασθενών τύπων, όπου οι μεταβλητές δεν συνδέονται με ένα συγκεκριμένο τύπο δεδομένων.

---

Αν ένα κουμπί υποβολής (`<button type="submit">`) μέσα σε μια φόρμα έχει έναν event listener για το συμβάν που καλεί το `event.preventDefault()`, η φόρμα θα υποβληθεί κανονικά όταν πατηθεί το κουμπί.

---

Ο παρακάτω κώδικας JavaScript θα επιστρέψει το πρώτο στοιχείο με id = 'button':
```javascript
…et element = document.querySelector('#button');
```

---

Η συμπερίληψη ενός script στην αρχή της σελίδας ως:
```html
<script src="script.js"></script>
```
έχει ως αποτέλεσμα ότι το script φορτώνεται και εκτελείται πριν φορτωθεί το DOM.

---

Ο παρακάτω κώδικας Node.js θα τυπώσει στην κονσόλα τα γράμματα 'A', 'B', 'C' με αυτήν ακριβώς τη σειρά:
```javascript
console.log('A');
setTimeout(() => {
  console.log('B');
}, 0);
console.log('C');
```

---

Η συνάρτηση 'fetch()' στην JavaScript εκτελείται συγχρονικά, 'παγώνοντας' την εκτέλεση του υπόλοιπου κώδικα μέχρι να επιστρέψει η απάντηση.

---

Ένα promise στη JavaScript θα εκτελεστεί πριν από οποιαδήποτε εντολή στη στοίβα κλήσης.

---

Για την φόρτωση εξωτερικών πόρων σε JSON μορφή μπορεί να χρησιμοποιηθεί το XMLHTTPRequest.

---

Ο παρακάτω κώδικας Express εκτελείται, μια αίτηση στο URL `http://localhost:3000/users/123` θα εμφανίσει το μήνυμα 'User ID: 123' στον περιηγητή.
```javascript
const express = require('express');
const app = express();
…('/users/:id', (req, res) => { res.send(`User ID: ${req.params.id}`); });
app.listen(3000);
```

---

…aScript μπορούμε να χειριστούμε ένα response που επιστρέφει η fetch() ως κείμενο με τη μέθοδο .text()
