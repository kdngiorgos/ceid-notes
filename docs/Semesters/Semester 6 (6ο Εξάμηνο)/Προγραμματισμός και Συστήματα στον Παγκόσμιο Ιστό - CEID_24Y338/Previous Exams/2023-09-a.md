Για κάθε σωστή απάντηση λαμβάνετε 1 μονάδα (στις 30), ενώ κάθε λάθος στοιχίζει 0,5 μονάδα (στις 30)

1. Το `<lecturer>David Billington</lecturer>` είναι element
2. Όταν η εσωτερική καθυστέρηση είναι μεγάλη, τότε μειώνεται η ωφελιμότητα της ύπαρξης αντιπροσώπων με KM, σε σχέση με την απευθείας σύνδεση με την πηγή.
3. Τα δεδομένα που εισάγει ο χρήστης σε πεδία τύπου password (όπως το παρακάτω) κρυπτογραφούνται από τον browser του χρήστη με χρήση του αλγορίθμου SHA256 ή αντίστοιχου.  
`Password: <input type="password" name="encrypted">`
4. Η εκτέλεση της παρακάτω συνάρτησης JavaScript θα δημιουργήσει σφάλμα:
```javascript
function printMessage(message, times) {
  for (let i = 0; i < times; i++) {
    console.log(message);
  }
  console.log('Value of i is ' + i);
}
```
5. Ο παρακάτω κώδικας JavaScript θα επιστρέψει όλα τα στοιχεία με id = 'button':  
`let element = document.querySelector('#button');`
6. Στον παρακάτω κώδικα Javascript η σειρά εκτύπωσης θα είναι: 3,2,1,4
```javascript
(function () {
  console.log(1);
  setTimeout(function() {console.log(2)}, 1000);
  setTimeout(function() {console.log(3)}, 0);
  console.log(4);
}) ();
```
7. Είναι δυνατή η εκτέλεση PHP εφαρμογών χωρίς να έχει εγκατασταθεί στον server η MySQL ή κάποιο αντίστοιχο software για διαχείριση βάσεων δεδομένων (π.χ. PostgreSQL)
8. Θεωρήστε ένα JavaScript script, σε απομακρυσμένο server, το οποίο τυπώνει απλά την τρέχουσα ώρα. Ένας χρήστης που καλεί το script από τον browser του υπολογιστή του, έχει τη δυνατότητα να επηρεάσει την ώρα που εμφανίζεται στον browser (π.χ αλλάζοντας την ώρα στο ρολόι του υπολογιστή του).
9. Στο jQuery με το `$(".mydiv")` επιλέγουμε όλα τα div που έχουν id="mydiv".
10. Η ακόλουθη έκφραση JSON δεν είναι συντακτικά σωστή  
`{'ids':[1, 2, 3], 'val':'ok'}`
11. Η PHP αποστέλλει στη MySQL τα queries ως απλό κείμενο (string) ενώ παράλληλα πραγματοποιεί έλεγχο στην εγκυρότητα της σύνταξης του query πριν την αποστολή.
12. Ο JavaScript κώδικας `var myvar = new String("Beer");` είναι ένας εναλλακτικός τρόπος να δημιουργήσουμε το αλφαριθμητικό "Beer".
13. Κάθε πάροχος συνδεσιμότητας (ISP) διαθέτει δικό του DNS server, τον οποίο του παρέχουν οι κυβερνητικές υπηρεσίες κάθε χώρας.
14. Η δήλωση ενός εξωτερικού DTD αρχείου είναι ως εξής `<!DOCTYPE catalog System "catalog.xml">`

    # AI λύσεις — 2023-09-a

    > Οι λύσεις γράφτηκαν από μοντέλα AI και δεν έχουν ελεγχθεί από άνθρωπο. Η αρίθμηση ακολουθεί το αρχείο θεμάτων.

    ## Θέμα 1

    *Αξιοπιστία: δύο ανεξάρτητες λύσεις συμφωνούν · εμπιστοσύνη λύτη: υψηλή*

    Στοιχείο XML = αρχική ετικέτα + περιεχόμενο + τελική ετικέτα. **Σωστό**.

    ## Θέμα 2

    *Αξιοπιστία: δύο ανεξάρτητες λύσεις συμφωνούν · εμπιστοσύνη λύτη: μέτρια*

    Αναμενόμενος χρόνος με αντιπρόσωπο ≈ $L_{int} + (1-h)L_{ext}$ έναντι $L_{ext}$ απευθείας. Το κέρδος $h\,L_{ext} - L_{int}$ μικραίνει όσο μεγαλώνει η εσωτερική καθυστέρηση. **Σωστό**.

    ## Θέμα 3

    *Αξιοπιστία: δύο ανεξάρτητες λύσεις συμφωνούν · εμπιστοσύνη λύτη: υψηλή*

    Το πεδίο password απλώς κρύβει τους χαρακτήρες· δεν κρυπτογραφεί (ούτε SHA256). **Λάθος**.

    ## Θέμα 4

    *Αξιοπιστία: δύο ανεξάρτητες λύσεις συμφωνούν · εμπιστοσύνη λύτη: υψηλή*

    Η `i` δηλώνεται με `let` μέσα στο for, άρα δεν υπάρχει εκτός. Η κλήση `console.log('Value of i is ' + i)` ρίχνει ReferenceError (επαληθεύτηκε με node, όταν καλείται η συνάρτηση). **Σωστό**.

    ## Θέμα 5

    *Αξιοπιστία: δύο ανεξάρτητες λύσεις συμφωνούν · εμπιστοσύνη λύτη: υψηλή*

    Η `querySelector` επιστρέφει μόνο το πρώτο στοιχείο· «όλα» θα ήθελε `querySelectorAll`. **Λάθος**.

    ## Θέμα 6

    *Αξιοπιστία: δύο ανεξάρτητες λύσεις συμφωνούν · εμπιστοσύνη λύτη: υψηλή*

    Επαλήθευση με node: 1, 4, 3, 2. Η πρόταση δίνει 3,2,1,4. **Λάθος**.

    ## Θέμα 7

    *Αξιοπιστία: δύο ανεξάρτητες λύσεις συμφωνούν · εμπιστοσύνη λύτη: υψηλή*

    Η PHP δεν απαιτεί βάση δεδομένων· μπορεί να τρέξει χωρίς MySQL. **Σωστό**.

    ## Θέμα 8

    *Αξιοπιστία: δύο ανεξάρτητες λύσεις συμφωνούν · εμπιστοσύνη λύτη: μέτρια*

    Αν το script φορτώνεται στον browser (`<script src=...>`), εκτελείται στο client και διαβάζει το ρολόι του client, άρα ο χρήστης επηρεάζει την ώρα. (Αν το script έτρεχε στον server δεν θα ίσχυε· η εκφώνηση υπονοεί client-side εκτέλεση.) **Σωστό**.

    ## Θέμα 9

    *Αξιοπιστία: δύο ανεξάρτητες λύσεις συμφωνούν · εμπιστοσύνη λύτη: υψηλή*

    Το `".mydiv"` είναι επιλογέας κλάσης· για id θα ήταν `"#mydiv"`. **Λάθος**.

    ## Θέμα 10

    *Αξιοπιστία: δύο ανεξάρτητες λύσεις συμφωνούν · εμπιστοσύνη λύτη: υψηλή*

    Το JSON απαιτεί διπλά εισαγωγικά για κλειδιά και strings· τα μονά δεν επιτρέπονται (το `JSON.parse` απορρίπτει το κείμενο, επαληθεύτηκε με node). Η πρόταση «δεν είναι συντακτικά σωστή» είναι **Σωστό**.

    ## Θέμα 11

    *Αξιοπιστία: δύο ανεξάρτητες λύσεις συμφωνούν · εμπιστοσύνη λύτη: υψηλή*

    Η PHP στέλνει το query ως string χωρίς έλεγχο σύνταξης· τον έλεγχο κάνει ο MySQL. **Λάθος**.

    ## Θέμα 12

    *Αξιοπιστία: 2 από 3 ανεξάρτητες λύσεις συμφωνούν (η άλλη διαφωνούσε) · εμπιστοσύνη λύτη: υψηλή*

    **Λάθος**  
    Η εντολή `new String("Beer")` δημιουργεί ένα αντικείμενο περιτυλίγματος (String object με `typeof === 'object'`) και όχι ένα πρωταρχικό αλφαριθμητικό (string primitive με `typeof === 'string'`).

    ## Θέμα 13

    *Αξιοπιστία: δύο ανεξάρτητες λύσεις συμφωνούν · εμπιστοσύνη λύτη: υψηλή*

    Οι ISP συνήθως διαθέτουν δικούς τους DNS servers, αλλά δεν τους παρέχουν οι κυβερνητικές υπηρεσίες· τους στήνουν οι ίδιοι. **Λάθος**.

    ## Θέμα 14

    *Αξιοπιστία: δύο ανεξάρτητες λύσεις συμφωνούν · εμπιστοσύνη λύτη: μέτρια*

    Η XML είναι case-sensitive και η σωστή δήλωση είναι `<!DOCTYPE catalog SYSTEM "catalog.dtd">` (SYSTEM με κεφαλαία, αρχείο DTD). Εδώ το `System` είναι λάθος. **Λάθος**.
