## received_337622758684321.png

# 15 Σεπτεμβρίου 2023 - Ομάδα Α
Τμήμα Μηχανικών Η/Υ & Πληροφορικής  
Προγραμματισμός & Συστήματα στον Παγκόσμιο Ιστό  

Για κάθε σωστή απάντηση λαμβάνετε 1 μονάδα (στις 30), ενώ κάθε λάθος στοιχίζει 0,5 μονάδα (στις 30)

1. Το `<lecturer>David Billington</lecturer>` είναι element
2. Όταν η εσωτερική καθυστέρηση είναι μεγάλη, τότε μειώνεται η ωφελιμότητα της ύπαρξης αντιπροσώπων με KM, σε σχέση με την απευθείας σύνδεση με την πηγή.
3. Τα δεδομένα που εισάγει ο χρήστης σε πεδία τύπου password (όπως το παρακάτω) κρυπτογραφούνται από τον browser του χρήστη με χρήση του αλγορίθμου SHA256 ή αντίστοιχου.  
`Password: <input type="password" name="encrypted">`
4. Η εκτέλεση της παρακάτω συνάρτησης JavaScript θα δημιουργήσει σφάλμα:
```javascript
function printMessage(message, times) {
  for (let i = 0; i < times; i++) {
    console.log(message);
  }
  console.log('Value of i is ' + i);
}
```
5. Ο παρακάτω κώδικας JavaScript θα επιστρέψει όλα τα στοιχεία με id = 'button':  
`let element = document.querySelector('#button');`
6. Στον παρακάτω κώδικα Javascript η σειρά εκτύπωσης θα είναι: 3,2,1,4
```javascript
(function () {
  console.log(1);
  setTimeout(function() {console.log(2)}, 1000);
  setTimeout(function() {console.log(3)}, 0);
  console.log(4);
}) ();
```
7. Είναι δυνατή η εκτέλεση PHP εφαρμογών χωρίς να έχει εγκατασταθεί στον server η MySQL ή κάποιο αντίστοιχο software για διαχείριση βάσεων δεδομένων (π.χ. PostgreSQL)
8. Θεωρήστε ένα JavaScript script, σε απομακρυσμένο server, το οποίο τυπώνει απλά την τρέχουσα ώρα. Ένας χρήστης που καλεί το script από τον browser του υπολογιστή του, έχει τη δυνατότητα να επηρεάσει την ώρα που εμφανίζεται στον browser (π.χ αλλάζοντας την ώρα στο ρολόι του υπολογιστή του).
9. Στο jQuery με το `$(".mydiv")` επιλέγουμε όλα τα div που έχουν id="mydiv".
10. Η ακόλουθη έκφραση JSON δεν είναι συντακτικά σωστή  
`{'ids':[1, 2, 3], 'val':'ok'}`
11. Η PHP αποστέλλει στη MySQL τα queries ως απλό κείμενο (string) ενώ παράλληλα πραγματοποιεί έλεγχο στην εγκυρότητα της σύνταξης του query πριν την αποστολή.
12. Ο JavaScript κώδικας `var myvar = new String("Beer");` είναι ένας εναλλακτικός τρόπος να δημιουργήσουμε το αλφαριθμητικό "Beer".
13. Κάθε πάροχος συνδεσιμότητας (ISP) διαθέτει δικό του DNS server, τον οποίο του παρέχουν οι κυβερνητικές υπηρεσίες κάθε χώρας.
14. Η δήλωση ενός εξωτερικού DTD αρχείου είναι ως εξής `<!DOCTYPE catalog System "catalog.xml">`
