    # Λύσεις — Προγραμματισμός και Συστήματα στον Παγκόσμιο Ιστό — Φεβρουάριος 2025 (Ομάδα Β)

    > Οι απαντήσεις 1–46 μεταφέρονται από το παλιό previous_exams.md και δεν έχουν επαληθευτεί· μεταφέρεται μόνο η απάντηση και η αιτιολόγηση, όχι η διατύπωση των προτάσεων. Οι φωτογραφίες λύσεων στο τέλος είναι ανεπιβεβαίωτες.

    ## Παλιό αρχείο: 1b2025FEB.jpg (απαντήσεις 1–14)

    **1.** ΛΑΘΟΣ. Το `type="password"` απλώς αποκρύπτει οπτικά τους χαρακτήρες (masking). Δεν παρέχει καμία κρυπτογράφηση· τα δεδομένα μεταδίδονται σε plain text εκτός αν χρησιμοποιείται HTTPS.

    **2.** ΛΑΘΟΣ. Ο κώδικας είναι καθόλα έγκυρος. Ένα tag `<a>` μπορεί να περικλείει οποιοδήποτε inline ή block στοιχείο (όπως `<img>`) χωρίς να απαιτείται κείμενο.

    **3.** ΣΩΣΤΟ. Ο ID selector `#special` εφαρμόζει το στυλ στα στοιχεία με αυτό το ID (αν και το πρότυπο HTML επιτάσσει μοναδικότητα ID ανά σελίδα).

    **4.** ΣΩΣΤΟ. Μέσω της ετικέτας `<meta name="viewport" content="width=device-width, initial-scale=1.0">` που καθορίζει την κλίμακα και το πλάτος οθόνης.

    **5.** ΛΑΘΟΣ. Δεν είναι καλοσχηματισμένο (well-formed) επειδή δεν κλείνει η ριζική ετικέτα (λείπει το `</books>`).

    **6.** ΣΩΣΤΟ. Ένα έγγραφο μπορεί να περιέχει πολλαπλά αδελφά στοιχεία με το ίδιο όνομα και namespace (π.χ. πολλαπλά `<book>` στοιχεία).

    **7.** ΛΑΘΟΣ. Το XSL/XSLT περιγράφει το μετασχηματισμό και τη μορφοποίηση (styling/transformation). Τη δομή την περιγράφει το DTD ή το XML Schema (XSD).

    **8.** ΣΩΣΤΟ. Η JavaScript είναι δυναμικά τυποποιημένη γλώσσα (dynamically/loosely typed).

    **9.** ΣΩΣΤΟ. Τα σύγχρονα logs (1, 4) εκτελούνται πρώτα. Το `setTimeout(..., 0)` μπαίνει στην ουρά macrotasks και εκτελείται αμέσως μετά (3), ενώ το 2 μετά από 1 δευτερόλεπτο.

    **10.** ΛΑΘΟΣ. Επιλέγει το πρώτο στοιχείο με ετικέτα `<button>`. Για επιλογή βάσει ID απαιτείται `querySelector('#button')`.

    **11.** ΛΑΘΟΣ. Χωρίς `defer` ή `async`, η εκτέλεση του script μπλοκάρει άμεσα την ανάλυση (parsing) του DOM.

    **12.** ΣΩΣΤΟ. Ο βρόχος `for...in` διατρέχει όλα τα αριθμήσιμα κλειδιά (keys) ενός αντικειμένου.

    **13.** ΛΑΘΟΣ. Η επίσκεψη μέσω browser στέλνει HTTP GET αίτημα. Εφόσον έχει οριστεί μόνο `app.post('/', ...)`, θα επιστραφεί σφάλμα `Cannot GET /`.

    **14.** ΣΩΣΤΟ. Τα promises ανήκουν στην ουρά microtasks, η οποία εξυπηρετείται πάντα κατά προτεραιότητα πριν από την ουρά macrotasks (task queue).

    ## Παλιό αρχείο: 2b2025FEB.jpg (απαντήσεις 15–30)

    **15.** ΣΩΣΤΟ. Το `$.ajax()` υποστηρίζει πλήρως ασύγχρονη φόρτωση JSON ορίζοντας `dataType: 'json'`.

    **16.** ΣΩΣΤΟ. Απαιτείται πρόσβαση μέσω web server (`http://localhost/...`) ώστε ο διακομιστής να εκτελέσει το PHP parsing και να επιστρέψει HTML, αντί να ανοίξει ως απλό κείμενο (`file:///`).

    **17.** ΛΑΘΟΣ. Στην PHP οι πίνακες είναι συσχετιστικοί και υποστηρίζουν αραιούς πίνακες (sparse arrays) χωρίς κανένα σφάλμα.

    **18.** ΛΑΘΟΣ. Λόγω του κενού διαστήματος στο τέλος (`'username '`), το κλειδί δεν θα ταιριάξει με το όνομα του πεδίου (`'username'`).

    **19.** ΣΩΣΤΟ. Ο τελεστής συνένωσης συμβολοσειρών (`.`) πραγματοποιεί αυτόματη μετατροπή τύπου (type juggling).

    **20.** ΛΑΘΟΣ. Ο PHP interpreter παράγει απλό ρεύμα κειμένου/χαρακτήρων και δεν εκτελεί σημασιολογικό έλεγχο εγκυρότητας της HTML.

    **21.** ΣΩΣΤΟ. Υποστηρίζεται πλήρως σε όλα τα λειτουργικά συστήματα.

    **22.** ΣΩΣΤΟ. Περιλαμβάνει Windows, Apache Web Server, MySQL Database και PHP runtime.

    **23.** ΣΩΣΤΟ. Οι browsers δεν διαθέτουν μηχανή εκτέλεσης PHP· απαιτείται αίτηση μέσω HTTP στον Apache (`http://localhost/test.php`).

    **24.** ΛΑΘΟΣ. Το μέγεθος των αντικειμένων παίζει καθοριστικό ρόλο (για πολύ μεγάλα αντικείμενα υπάρχει επιβάρυνση δικτύου/δίσκου και αντικατάστασης στην cache).

    **25.** ΣΩΣΤΟ. Ο browser αποστέλλει ξεχωριστή αίτηση GET για κάθε επιμέρους πόρο (εικόνα, css, js).

    **26.** ΣΩΣΤΟ. Εξαλείφει την καθυστέρηση του 3-way handshake και επιτρέπει την αποστολή πολλαπλών αιτήσεων χωρίς αναμονή της απόκρισης της προηγούμενης.

    **27.** ΣΩΣΤΟ. Γρήγορη ευστοχία (fast hit): αντικείμενο έγκυρο εντός TTL. Αργή ευστοχία (slow hit): το TTL έληξε και απαιτείται επικύρωση (revalidation/Conditional GET).

    **28.** ΣΩΣΤΟ. Μέσω ευρετικών μεθόδων εκτίμησης (heuristic expiration, π.χ. ποσοστό του χρόνου από το Last-Modified).

    **29.** ΛΑΘΟΣ. Το Conditional GET (`If-Modified-Since`) κάνει τον έλεγχο και τη λήψη σε 1 μήνυμα (επιστρέφει 304 αν δεν άλλαξε). Η HEAD μέθοδος θα απαιτούσε 2 μηνύματα.

    **30.** ΛΑΘΟΣ. Το DNS είναι κατανεμημένο, ιεραρχικό σύστημα παγκόσμιων εξυπηρετητών (root servers, gTLD, ccTLD, authoritative) και δεν λειτουργεί ως μονοπώλιο κρατικών υπηρεσιών.

    ## Παλιό αρχείο: 3b2025FEB.jpg (απαντήσεις 31–46)

    **40.** ΣΩΣΤΟ. Καθορίζουν τη διάρκεια ζωής (freshness lifetime) στην κρυφή μνήμη (HTTP Caching).

    **Λάθος. ❌**

    Η HTTP **GET** αίτηση για ένα σύνθετο ιστο-αντικείμενο **δεν προκαλεί αυτόματα 10 GET αιτήσεις** προς τον server.

    ### Ανάλυση της διαδικασίας φόρτωσης ενός σύνθετου ιστο-αντικειμένου

    * Όταν ένας πελάτης (π.χ. browser) κάνει μία **GET αίτηση** για μια HTML σελίδα, λαμβάνει μόνο το αρχικό HTML.
    * Το HTML μπορεί να περιέχει **ενσωματωμένα αντικείμενα** (π.χ. εικόνες, CSS, JavaScript, βίντεο, ανενεργά `iframe`).
    * **Ο browser είναι αυτός που δημιουργεί τις επιπλέον GET αιτήσεις** για κάθε ξεχωριστό αντικείμενο που απαιτείται για την πλήρη φόρτωση της σελίδας.
    * Ο web server **δεν στέλνει αυτόματα τα 10 αντικείμενα**. Ο browser αναλύει το HTML και ζητά όσα αντικείμενα χρειάζονται.
