# Προγραμματισμός και Συστήματα στον Παγκόσμιο Ιστό — Σεπτέμβριος 2023 (Παραλλαγή Β)

## received_330595272663574.jpg

1. Αν θέλω να ελέγξω την εγκυρότητα των δεδομένων μιας HTML φόρμας πριν την υποβολή της, μπορώ να το κάνω με μια JavaScript συνάρτηση αξιοποιώντας το onload() event
2. Ο παρακάτω PHP κώδικας θα εκτελεστεί κανονικά χωρίς κάποιο PHP error, παρότι στην HTML δεν υπάρχει το tag <h7>. Η PHP παράγει HTML κώδικα χωρίς να εξετάζει αν είναι valid ή όχι.
```php
for ($i=1; $i<=7; $i++)
{
  echo "<h".$i.">This is header ".$i."</h".$i.">";
}
```
3. Η παρακάτω φόρμα στέλνει με το πάτημα του submit τα δεδομένα στο αρχείο form1.php
```html
<form name="form1.php" method="post" action="form2.php">
Username: <input type="text" name="username"><br>
Password: <input type="password" name="password"><br>
<input type="submit" value="Login">
</form>
```
4. Η παρέλευση του TTL ενός αντικειμένου καθορίζει το αν θα υπάρξει αργή ή γρήγορη ευστοχία στην KM ενός αντιπροσώπου.
5. Με την καθιέρωση της HTML 5 ως τεχνολογία του παγκόσμιου ιστού, οι σελίδες που έχουν φτιαχτεί ακολουθώντας το πρότυπο της HTML 4 έπαψαν να λειτουργούν.
6. Η XSL δίνει μορφή στην δομημένη συγκρότηση της HTML
7. Το TTL ενός αντικειμένου μπορεί να παρακαμφθεί με την εντολή min-fresh στο σώμα μιας αίτησης.
8. Ο παρακάτω Javascript κώδικα θα εκτυπώσει τα εξής: 0,1,2,3,4
```javascript
for (var i = 0; i < 5; i++) {
  setTimeout(function() { console.log(i); }, i * 1000 );
}
```
9. Ο παρακάτω php κώδικας δεν είναι σωστός και θα επιστρέψει error, καθώς στην PHP δεν είναι εφικτή η συνένωση μιας μεταβλητής τύπου int με μία τύπου string, όπως παρακάτω:
```php
$var1 = 2023;
$var2 = "The current year is ";
$var3 = $var2.$var1;
```
10. Αν μία web εφαρμογή χρησιμοποιεί και ένα σύστημα βάσεων δεδομένων (π.χ. MySQL), ο web server και ο database server δεν είναι απαραίτητο να είναι εγκατεστημένα στο ίδιο φυσικό/εικονικό μηχάνημα.
11. Η εντολή κεφαλίδας "If-none-match" δέχεται τα ίδια ορίσματα με την "if-modified-since".
12. Ο JavaScript κώδικας μπορεί να εκτελεστεί στον browser του υπολογιστή μας χωρίς να απαιτείται η εγκατάσταση κάποιου τρίτου λογισμικού (π.χ. WAMP)
13. Με την εντολή no-cache στην κεφαλίδα μιας αίτησης, ο πελάτης μπορεί να ορίσει ότι δε θέλει το ανακτώμενο αντικείμενο να αποθηκευτεί στην τοπική του κρυφή μνήμη.
14. Για να ληφθούν τα ενσωματωμένα (embedded) ιστοαντικείμενα μιας ιστοσελίδας, χρειάζεται μόνο μια HTTP GET αίτηση προς τον εξυπηρετητή, στην οποία ομαδοποιούνται όλα τα ομοειδή αντικείμενα (π.χ. μια αίτηση αρκεί για να ληφθούν όλα τα ιστοαντικείμενα τύπου JPEG)..
15. Οι παροχείς περιεχομένου προτιμούν λύσεις πλεονασμού περιεχομένου των πηγών (αντίγραφα) – web replication – από λύσεις αντιπροσώπων (web caching).
16. Οι πελάτες έχουν τον έλεγχο του περιεχομένου στους ανάστροφους αντιπροσώπους που περιέχουν αντίγραφα ιστοτόπων
