# Προγραμματισμός και Συστήματα στον Παγκόσμιο Ιστό — Ιανουάριος 2022 (α)

## received_368868894728493.jpeg

**Ερώτηση 1** (Σωστό / Λάθος — 1 βαθμός)

Σε μία μη διατεταγμένη λίστα (unordered list), που δημιουργούμε με χρήση των HTML tags `<ul>` και `<li>`, τα στοιχεία της λίστας θα εμφανίζονται με τυχαία σειρά εμφάνισης σε κάθε φόρτωση του HTML αρχείου στον browser.

- [ ] Σωστό
- [ ] Λάθος

---

**Ερώτηση 2** (Σωστό / Λάθος — 1 βαθμός)

Ο παρακάτω κώδικας σε ένα HTML αρχείο, θα εμφανίσει έναν σύνδεσμο (hyperlink) που όταν τον επιλέξουμε θα μας οδηγήσει στην αρχική σελίδα του Πανεπιστημίου Πατρών
```html
<a href = "www.upatras.gr">Παν.Πατρών</a>
```

- [ ] Σωστό
- [ ] Λάθος

### Ερώτηση 3 (Σωστό / Λάθος — 1 βαθμός)

Ο παρακάτω κώδικας σε ένα HTML αρχείο, θα εμφανίσει μία εικόνα που όταν την επιλέξουμε με πάτημα του ποντικιού θα μας οδηγήσει στο αρχείο mypage.html

```html
<a href = "mypage.html">
    <img src = "images/myimage.png" alt = "Test picture">
</a>
```

- [ ] Λάθος
