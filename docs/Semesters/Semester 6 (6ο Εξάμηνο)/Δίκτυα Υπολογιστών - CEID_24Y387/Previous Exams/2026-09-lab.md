Συμπληρώστε τα ψηφία του Α.Μ. ξεκινώντας από ΑΡΙΣΤΕΡΑ. Συμπληρώστε από κάτω πάλι το Όνομα - Επώνυμο - ΑΜ σας.

```

/ip address add address=10.0.0.9/30 interface=ether2
```

Υπο-Ερωτ.6♣ Τι είναι το trunk interface;
Επιλέξτε ΟΛΕΣ τις σωστές περιγραφές.

- [ ] Είναι interface που χρησιμοποιείται μόνο για πρόσβαση χρηστών.
- [ ] Μεταφέρει μόνο ένα VLAN κάθε φορά, χωρίς tagging.
- [ ] Χρησιμοποιείται για την υλοποίηση VLAN trunking πρωτοκόλλων όπως 802.1Q.
- [ ] Είναι το ίδιο με το loopback interface.
- [ ] Ένα interface που μπορεί να μεταφέρει πολλαπλά VLANs ταυτόχρονα.

Ερωτ.9♣ Ποια από τα παρακάτω είναι σωστά σχετικά με τη λειτουργία της εντολής traceroute;

- [ ] Οι ενδιάμεσοι δρομολογητές απαντούν με ICMP Echo Reply μηνύματα.
- [ ] Η εντολή traceroute λειτουργεί μόνο σε δίκτυα IPv4 και δεν υποστηρίζει IPv6.
- [ ] Η εντολή traceroute ανακαλύπτει τη διαδρομή μέσω ανταλλαγής ARP μηνυμάτων μεταξύ όλων των δρομολογητών.
- [ ] Όταν το TTL γίνει 0 σε κάποιον δρομολογητή, αυτός επιστρέφει μήνυμα ICMP Time Exceeded.
- [ ] Η τεχνική βασίζεται στην προοδευτική αύξηση της τιμής TTL των πακέτων.
- [ ] Απαιτείται να δημιουργηθεί TCP σύνδεση με κάθε ενδιάμεσο δρομολογητή της διαδρομής.

> [Συνέχεια του κώδικα της Ερωτ.10 από την προηγούμενη φωτογραφία]

```
/ip dhcp-server network add address=192.168.20.0/24 gateway=192.168.20.1 dns-server=8.8.8.8
/ip pool add name=pool1 ranges=192.168.20.100-192.168.20.200
```

- [ ] Δημιουργεί DHCP server στο interface ether2.
- [ ] Ορίζει DNS server 8.8.8.8 για τους DHCP clients.
- [ ] Ρυθμίζει static IP διευθύνσεις στο interface ether2 αντί για δυναμικές.
- [ ] Ρυθμίζει firewall rule που μπλοκάρει DHCP traffic (UDP 67/68).
- [ ] Ορίζει το ether2 ως DHCP client αντί για DHCP server.
- [ ] Δημιουργεί VPN tunnel μεταξύ DHCP server και clients.
- [ ] Χρησιμοποιεί pool διευθύνσεων 192.168.20.100–192.168.20.200 για DHCP leases.
- [ ] Μετατρέπει το ether2 σε bridge port χωρίς VLANs.
- [ ] Ορίζει gateway 192.168.20.1 για τους DHCP clients.
- [ ] Απενεργοποιεί το routing μεταξύ των υποδικτύων.
- [ ] Ενεργοποιεί δυναμική απόδοση IP διευθύνσεων στους clients.
- [ ] Ενεργοποιεί NAT masquerade για το δίκτυο 192.168.20.0/24.

**Ερωτ.11♣** Ποια από τα παρακάτω περιγράφουν σωστά τη λειτουργία της εντολής ping και των ICMP μηνυμάτων που χρησιμοποιεί (ICMPv4);

- [ ] Το ICMP Time Exceeded αποστέλλεται όταν ο προορισμός δεν είναι προσβάσιμος.
- [ ] Η εντολή ping στέλνει ICMP Echo Reply προς τον προορισμό για έλεγχο διαθεσιμότητας.
- [ ] Η εντολή ping χρησιμοποιεί UDP πακέτα για να ελέγξει τη διαθεσιμότητα ενός host.
- [ ] Η εντολή ping λαμβάνει ICMP Echo Reply από τον προορισμό όταν αυτός είναι ενεργός και προσβάσιμος.
- [ ] Η εντολή ping στέλνει ICMP Echo Request προς μια διεύθυνση IP για έλεγχο διαθεσιμότητας.
- [ ] Μπορεί να λάβει ICMP Destination Unreachable όταν ο προορισμός είναι μη προσβάσιμος ή δεν υπάρχει διαδρομή προς αυτόν.
- [ ] Η εντολή ping στέλνει ICMP Destination Unreachable μηνύματα όταν ο προορισμός δεν είναι προσβάσιμος.
