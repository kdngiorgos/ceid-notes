    # Λύσεις — Αρχές Γλωσσών Προγραμματισμού και Μεταφραστών — Ιούνιος 2025 — Παραλλαγή Α

    > Λύσεις που μεταφέρθηκαν από το παλιό συγκεντρωτικό αρχείο. Δεν έχουν επαληθευτεί· οι ασυμφωνίες με την εκφώνηση σημειώνονται στα warnings του αρχείου.

    **(α) Τύπος στην Ιεραρχία Chomsky:**
    - **Απάντηση:** Η γραμματική είναι **Τύπου 2 (Context-Free Grammar / Γραμματική Χωρίς Συμφραζόμενα)**.
    - **Αιτιολόγηση:** Στην αριστερή πλευρά κάθε κανόνα παραγωγής υπάρχει ακριβώς ένα μη-τερματικό σύμβολο ($\langle S \rangle$), ενώ στη δεξιά πλευρά υπάρχει οποιαδήποτε συμβολοσειρά αποτελούμενη από τερματικά και μη-τερματικά σύμβολα (συμπεριλαμβανομένου του κενού $\epsilon$). Δεν είναι Τύπου 3 (Κανονική) διότι δεν είναι δεξιά ούτε αριστερά γραμμική (έχει παρενθέσεις που κλείνουν και φωλιάζουν αναδρομικά).

    **(β) Είδος Συμβολοσειρών & Μικρότερα Μέλη:**
    - **Περιγραφή Γλώσσας:** Παράγει όλες τις **ισοζυγισμένες και ορθά φωλιασμένες ακολουθίες στρογγυλών `()` και τετράγωνων `[]` παρενθέσεων** (η γνωστή γλώσσα Dyck 2 τύπων παρενθέσεων $D_2$).
    - **Μικρότερα σε μήκος μέλη ($\le 4$ χαρακτήρες):**
      - Μήκος 0: $\epsilon$
      - Μήκος 2: `()`, `[]`
      - Μήκος 4: `()()`, `[][]`, `()[]`, `[]()`, `(())`, `[[]]`, `([])`, `[()]`

    **(γ) Έλεγχος Συμβολοσειράς `[][()]` μέσω Στοίβας Ολίσθησης - Ελάττωσης (Bottom-Up Shift-Reduce):**
    - Θεωρούμε είσοδο `[][()]$`. Επειδή $\langle S \rangle \to \epsilon$, μπορούμε να εισάγουμε αναγωγές κενού (ή να αναγνωρίσουμε $S \to S[S]$ και $S \to S(S)$):
      1. Αρχική κατάσταση: Στοίβα: `$`, Είσοδος: `[][()]$`
      2. Αναγωγή: $\epsilon \to S \implies$ Στοίβα: `$ S`
      3. Ολίσθηση (Shift) `[`: Στοίβα: `$ S [`
      4. Αναγωγή: $\epsilon \to S \implies$ Στοίβα: `$ S [ S`
      5. Ολίσθηση (Shift) `]`: Στοίβα: `$ S [ S ]`
      6. Ελάττωση (Reduce) $S[S] \to S \implies$ Στοίβα: `$ S`
      7. Ολίσθηση (Shift) `[`: Στοίβα: `$ S [`
      8. Ολίσθηση (Shift) `(`: Στοίβα: `$ S [ (`
      9. Αναγωγή: $\epsilon \to S \implies$ Στοίβα: `$ S [ ( S`
      10. Ολίσθηση (Shift) `)`: Στοίβα: `$ S [ ( S )`
      11. Ελάττωση (Reduce) $S(S) \to S \implies$ Στοίβα: `$ S [ S`
      12. Ολίσθηση (Shift) `]`: Στοίβα: `$ S [ S ]`
      13. Ελάττωση (Reduce) $S[S] \to S \implies$ Στοίβα: `$ S`
      14. Είσοδος `$`: Αποδοχή (Accept)! Η συμβολοσειρά ανήκει στη γλώσσα.

    **(δ) Είναι η γραμματική LL(1); Μετασχηματισμός σε LL(1):**
    - **Έλεγχος LL(1):** **ΟΧΙ**, δεν είναι LL(1).
      - *Αιτιολόγηση:* Περιέχει **άμεση αριστερή αναδρομή** (οι κανόνες ξεκινούν με $\langle S \rangle$), γεγονός που οδηγεί σε άπειρη αναδρομή σε LL(1) αναλυτή. Επιπλέον, είναι ασαφής (ambiguous).
    - **Μετασχηματισμός σε LL(1):**
      Εξαλείφουμε την αριστερή αναδρομή παράγοντας το πρώτο σύμβολο και το υπόλοιπο της ουράς:
      $$S \to (S) S \mid [S] S \mid \epsilon$$
      - Υπολογισμός συνόλων:
        - $\text{FIRST}((S)S) = \{ ( \}$
        - $\text{FIRST}([S]S) = \{ [ \}$
        - $\text{FIRST}(\epsilon) = \{ \epsilon \}$
        - $\text{FOLLOW}(S) = \{ ), ], \$ \}$
      - Τα $\text{FIRST}$ σύνολα των εναλλακτικών είναι ξένα μεταξύ τους, και $\text{FIRST} \cap \text{FOLLOW} = \emptyset$. Συνεπώς, η νέα γραμματική είναι **LL(1)**.

    **(α) Πεπερασμένο Αυτόματο (DFA) για δυαδικούς αριθμούς με το πολύ τρία '1' (0 έως 3 άσσους):**
    - Καταστάσεις: $q_0, q_1, q_2, q_3$ (αποδεκτές καταστάσεις που καταμετρούν 0, 1, 2, 3 άσσους) και $q_4$ (κατάσταση παγίδα / dead state για $\ge 4$ άσσους).
    - Αρχική κατάσταση: $q_0$.
    - Τελικές καταστάσεις: $F = \{q_0, q_1, q_2, q_3\}$.
    - Μεταβάσεις:
      - $\delta(q_0, 0) = q_0, \quad \delta(q_0, 1) = q_1$
      - $\delta(q_1, 0) = q_1, \quad \delta(q_1, 1) = q_2$
      - $\delta(q_2, 0) = q_2, \quad \delta(q_2, 1) = q_3$
      - $\delta(q_3, 0) = q_3, \quad \delta(q_3, 1) = q_4$
      - $\delta(q_4, 0) = q_4, \quad \delta(q_4, 1) = q_4$

    **(β) Κανονική Έκφραση (Regular Expression):**
    $$0^* (1 0^* + \epsilon) (1 0^* + \epsilon) (1 0^* + \epsilon)$$
    ή ισοδύναμα:
    $$0^* (\epsilon \mid 1) 0^* (\epsilon \mid 1) 0^* (\epsilon \mid 1) 0^*$$

    **Ανάλυση γραμμή-γραμμή:**
    1. `p = &data[1];`: Ο δείκτης `p` δείχνει στο στοιχείο `data[1]` (τιμή 4).
    2. `*(p+1) += 1;`: Το `p+1` δείχνει στο `data[2]`. Η τιμή του αυξάνεται κατά 1: `data[2] = 6 + 1 = 7`.
    3. `p = &p[1];`: Ισοδύναμο με `p = p + 1`. Ο δείκτης `p` πλέον δείχνει στο `data[2]`.
    4. `*(p-1) -= 1;`: Το `p-1` δείχνει στο `data[1]`. Η τιμή του μειώνεται κατά 1: `data[1] = 4 - 1 = 3`.
    5. `*p += (*(p-2))++;`:
       - Το `p-2` δείχνει στο `data[0]` (τρέχουσα τιμή 2).
       - Λόγω του μετα-αυξητικού τελεστή `++`, διαβάζεται πρώτα η παλιά τιμή (2) για την πρόσθεση:
         `*p += 2` $\implies$ `data[2] = 7 + 2 = 9`.
       - Στη συνέχεια, αυξάνεται το `data[0]`: `data[0] = 2 + 1 = 3`.

    **Τελικές τιμές πίνακα `data`:**
    - `data[0] = 3`
    - `data[1] = 3`
    - `data[2] = 9`

    **(α) Lambda Map & Reduce:**
    - Υπολογισμός $k$-οστών δυνάμεων:
      ```python
      powers = list(map(lambda x: x**k, numbers))
      ```
    - Άθροιση λίστας με reduce:

    **(β) Αποτέλεσμα Εκτέλεσης `functools.reduce`:**

    ```python
    result = functools.reduce(lambda x, y: x * y, numbers)

    ```
    - Βήμα 1: `(1 * 2) = 2`
    - Βήμα 2: `(2 * 3) = 6`
    - Βήμα 3: `(6 * 4) = 24`
    - **Τυπώνει:** `24`.

    **(γ) $\lambda$-Λογισμός ($\ eta$-Reductions):**
    $$(\lambda x. \lambda y. \lambda z. x^3 + y^3 + z^3) \; 3 \; 2 \; 1$$
    1. Αντικατάσταση $x = 3$:
       $$(\lambda y. \lambda z. 3^3 + y^3 + z^3) \; 2 \; 1 = (\lambda y. \lambda z. 27 + y^3 + z^3) \; 2 \; 1$$
    2. Αντικατάσταση $y = 2$:
       $$(\lambda z. 27 + 2^3 + z^3) \; 1 = (\lambda z. 27 + 8 + z^3) \; 1 = (\lambda z. 35 + z^3) \; 1$$
    3. Αντικατάσταση $z = 1$:
       $$35 + 1^3 = 35 + 1 = 36$$
    - **Τελικό αποτέλεσμα:** `36`.
