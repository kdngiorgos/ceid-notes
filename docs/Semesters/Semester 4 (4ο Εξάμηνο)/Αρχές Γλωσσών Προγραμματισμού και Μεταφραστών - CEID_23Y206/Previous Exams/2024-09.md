ΘΕΜΑ 1 – Λεξική και Συντακτική Ανάλυση (40%)
Σας δίνονται οι παρακάτω τρεις (3) απλές γραμματικές σε συμβολισμό BNF:
1. <A> ::= <A><A> | 0 | 1
2. <B> ::= 0<B> | 1<B> | 0
3. <C> ::= 0<C>0 | 1<C>1 | 0 | 1

(a) Να περιγράψετε τις ακολουθίες δυαδικών αριθμών που παράγουν οι τρεις γραμματικές. Δώστε και παραδείγματα.
(b) Αντιστοιχίστε τις ακολουθίες 10101, 011, 1, 000, 011100 στην/στις γραμματική/ές που τις παράγουν, ή σε καμία αν δεν μπορούν να παραχθούν.
(c) Δείξτε αν η ακολουθία 01110 παράγεται ή όχι από την $3^\eta$ γραμματική, κατασκευάζοντας τη Στοίβα Ταιριάσματος – Πρόβλεψης Top-Down συντακτικής ανάλυσης.
(d) Ποια ή ποιες από τις γραμματικές είναι κανονική και γιατί;
(e) Για την πρώτη κατά σειρά (με βάση με την παραπάνω αρίθμησή τους) από την/τις κανονικές γραμματικές που αναγνωρίσατε στο ερώτημα (d), παρουσιάστε αντίστοιχη κανονική έκφραση, καθώς και το διάγραμμα καταστάσεων – μεταβάσεων για το αντίστοιχο ντετερμινιστικό πεπερασμένο αυτόματο.
(f) Ποια ή ποιες από τις τρεις γραμματικές δεν είναι LL(1) και γιατί; Μετασχηματίστε την πρώτη κατά σειρά (με βάση με την αρίθμησή τους) από τις γραμματικές αυτές, σε ισοδύναμη LL(1) γραμματική.

ΘΕΜΑ 2 – Εμβέλεια και Μεταβίβαση Παραμέτρων (20%)
Δίνεται το παρακάτω πρόγραμμα σε μια γλώσσα τύπου Pascal που χρησιμοποιεί το στατικό κανόνα εμβέλειας:

```pascal
program MAIN;
var i, c: integer; a: array[1..2] of integer;
procedure F(x, y: integer);
  var d: integer;
  procedure G(a: integer);
  begin
    a := a + d;
  end;
begin
  d := -1;
  x := x - 1;
  G(i);
  G(y);
  c := x * y;
end;
BEGIN
  a[1] := 5;  a[2] := 4;  i:=2;
  F(a[i], a[i]);
  writeln('a[1]=', a[1]);  writeln('a[2]=', a[2]); writeln('c=', c);
END.
```

Μορφή εξόδου του προγράμματος για τις τρεις εντολές writeln:
> [Σχήμα: Πλαίσιο που γράφει:
a[1]=V1
a[2]=V2
c=V3]

(a) Ποια είναι τα περιβάλλοντα αναφοράς (τοπικά, μη-τοπικά, καθολικά) όλων των τμημάτων του προγράμματος;
(b) Ποιες τιμές (V1, V2, V3) θα τυπωθούν με την εντολή writeln, εφόσον οι διαδικασίες F και G καλούνται με τις παρακάτω περιπτώσεις τρόπου μεταβίβασης παραμέτρων; Εξηγήστε σύντομα τις διαδικασίες υπολογισμού σε όλες τις περιπτώσεις.
1. Όλες οι παράμετροι μεταβιβάζονται με κλήση με τιμή (call by value).
2. Όλες οι παράμετροι μεταβιβάζονται με κλήση με αναφορά (call by reference).
3. Όλες οι παράμετροι μεταβιβάζονται με τιμή – αποτέλεσμα (call by value-result).
4. Όλες οι παράμετροι μεταβιβάζονται με κλήση με όνομα (call by name).

ΘΕΜΑ 4 – Functional Programming και Γλώσσες ΒΔ (20%)
(α) Είναι γνωστό ότι στις συναρτησιακές γλώσσες, η αναδρομή αντικαθιστά την επανάληψη. Κάντε ακριβώς το ίδιο (σώμα αναδρομικής συνάρτησης και πρώτη κλήση) για τον παρακάτω βρόχο (η εντολή j^i σημαίνει ύψωση της μεταβλητής j σε δύναμη με εκθέτη i):

```pascal
R := 0; i := 1; j := 300;
while i < j do
    R := R + j^i; i := i + 2;
    j := j - 2
end while
return R
```

(β) Συμπληρώστε την αποτίμηση ? των παρακάτω εκφράσεων συνθήκης σε γλώσσα scheme:

```scheme
(if (< 4 5) 0 1) => ?
(cond
    ((< 10 9) 1)
    ((< 8 7) 2)
    (else 3)) => ?
```

(γ) Έστω σε Lisp οι παρακάτω Map/ Fold (Reduce) high-order functions. Συμπληρώστε τις αποτιμήσεις ? των εκφράσεων.

```lisp
(map (lambda (x) (* x 3))
    '(1 2 3 4 5)) => ?
(fold + 0 '(1 2 3 4 5)) => ?
(fold * 1 '(1 2 3 4 5)) => ?
(define (sum-of-triples v)
(fold + 0 (map (lambda (x) (* x 3)) v)))
(sum-of-triples '(1 2 3 4 5)) => ?
```

ΘΕΜΑ 5 - Python (15%)
Γράψτε ένα πρόγραμμα σε Python που να διαχειρίζεται μια λίστα αριθμών. Το πρόγραμμα θα πρέπει να χρησιμοποιεί τις κατάλληλες μεθόδους για την εκτέλεση των παρακάτω εργασιών:
(α) Δημιουργήστε μια λίστα με τους εξής αριθμούς: - 5, 12, 8, 3, 25, 18, 22,25,30
(β) Πρόσθεσε στην αρχή της λίστας τον αριθμό 7 και στο τέλος της λίστας τον αριθμό 20.
(γ) Διέγραψε τον αριθμό 8 από τη λίστα.
(δ) Ταξινόμησε τη λίστα των αριθμών σε αύξουσα σειρά.
(ε) Επίλεξε και τύπωσε τον δεύτερο και τον τέταρτο αριθμό από τη λίστα.
(στ) Υπολόγισε και εμφάνισε το συνολικό πλήθος των αριθμών στη λίστα.
(ζ) Επίλεξε και εμφάνισε τον αριθμό που βρίσκεται στη μέση της λίστας (αν το πλήθος είναι ζυγό, εμφάνισε τον μεσαίο αριθμό της κάτω μισής).
(η) Αντικατάστησε τον τελευταίο αριθμό της λίστας με τον αριθμό 15.
