## ΘΕΜΑ 2
Μία συνθηματική γλώσσα απλών προτάσεων, περιγράφεται από την παρακάτω *BNF γραμματική*, με τερματικά σύμβολα τα: **a b d S** όπου το **S** συμβολίζει τον χαρακτήρα «κενό» (space).

a. Τι είδους συμβολοσειρές περιγράφει η γραμματική; Περιγράψτε τη δομή και μερικά βασικά χαρακτηριστικά των συμβολοσειρών αυτών, παρουσιάζοντας και παραδείγματα.
b. Δημιουργώντας τη *Στοίβα Ολίσθησης – Ελάττωσης Bottom-Up* συντακτικής ανάλυσης, να αποφανθείτε αν η πρόταση **da ad** (ή αλλιώς **daSad**) είναι μέλος της συνθηματικής γλώσσας.
c. Είναι η γραμματική LL(1); Αιτιολογήστε την απάντησή σας, υποδεικνύοντας όλα τα σημεία της γραμματικής που δικαιολογούν τον ισχυρισμό σας. Αν η γραμματική δεν είναι LL(1), τι είδους μετασχηματισμοί και σε ποια σημεία πρέπει να γίνουν, ώστε να δημιουργηθεί μια ισοδύναμη LL(1) γραμματική; (δεν χρειάζεται να παρουσιάσετε τους ίδιους τους μετασχηματισμούς, ούτε την ισοδύναμη γραμματική)

$$<\text{πρόταση}> ::= <\text{λέξη}> \mid <\text{πρόταση}>\mathbf{S}<\text{λέξη}>$$
$$<\text{λέξη}> ::= <\text{συλλαβή}> \mid <\text{συλλαβή}><\text{λέξη}><\text{συλλαβή}>$$
$$<\text{συλλαβή}> ::= <\text{βάση}> \mid <\text{βάση}><\text{σύμφωνο}> \mid \mathbf{a}<\text{βάση}> \mid \mathbf{a}<\text{σύμφωνο}>$$
$$<\text{βάση}> ::= <\text{σύμφωνο}>\mathbf{a}$$
$$<\text{σύμφωνο}> ::= \mathbf{b} \mid \mathbf{d}$$

## ΘΕΜΑ 3
Δίνονται τα παρακάτω δύο προγράμματα μιας γλώσσας προγραμματισμού η οποία όσον αφορά το συντακτικό και τη γενική δομή των προγραμμάτων της είναι τύπου *Pascal*, ενώ υιοθετεί τις τεχνικές μεταβίβασης παραμέτρων καθώς και τη σημειογραφία και τη λειτουργικότητα δεικτών (pointers) της *C*. Τα προγράμματα εκτελούνται σε έναν compiler ο οποίος στην εντολή ανάθεσης προσδιορίζει πρώτα την *l-value* (αν χρειάζεται να προσδιοριστεί).

a. Ποιες είναι οι ομοιότητες και οι διαφορές των δύο προγραμμάτων, ιδιαίτερα όσον αφορά τον τρόπο μεταβίβασης παραμέτρων, τις μεταβλητές και τις σχέσεις τους;
b. Ποια είναι τα περιβάλλοντα αναφοράς των **P** και **MAIN** στο **Πρόγραμμα A**;
c. Στα παραπάνω δύο προγράμματα υπάρχει μία εντολή η οποία δεν είναι σωστή από σημασιολογική άποψη και θα προκαλέσει error. Ποια είναι και γιατί; Σβήστε την εντολή από τον κώδικα.
d. Ποια είναι η έξοδος των δύο προγραμμάτων κατά την εκτέλεσή τους; Εξηγείστε τις αλλαγές τιμών όλων των μεταβλητών κατά τη διαδικασία υπολογισμού.
e. Ποια θα ήταν η έξοδος του **Προγράμματος A** κατά την εκτέλεσή του, αν υποθέταμε ότι η μεταβίβαση παραμέτρων γινόταν με τους παρακάτω δύο τρόπους (παρουσιάστε και εξηγείστε τις αλλαγές τιμών όλων των μεταβλητών κατά τη διαδικασία υπολογισμού):
i. Κλήση με τιμή – αποτέλεσμα (call by value – result)
ii. Κλήση με όνομα (call by name)

### Πρόγραμμα A
```pascal
program MAIN;
    var n: integer;
        a: array [0..10] of integer;

    function P(x: integer): integer;
    begin
        write(x);
        n:= n + 2;
        write(x);
        x:= x + 8;
        P:= x;
    end;

BEGIN
    n:= 1;
    a[0]:= x; a[1]:= 100; a[2]:= 200;
    a[3]:= 300; a[4]:= 400; a[5]:= 500;
    a[6]:= 600;
    a[n+3]:= P(a[n+2]);
    write(a[1]);
    write(a[2]);
    write(a[3]);
    write(a[4]);
    write(a[5]);
END.
```

### Πρόγραμμα B
```pascal
program MAIN;
    var n: integer;
        a: array [0..10] of integer;

    function P(*x: integer): integer;
    begin
        write(*x);
        n:= n + 2;
        write(*x);
        *x:= *x + 8;
        P:= *x;
    end;

BEGIN
    n:= 1;
    a[0]:= x; a[1]:= 100; a[2]:= 200;
    a[3]:= 300; a[4]:= 400; a[5]:= 500;
    a[6]:= 600;
    a[n+3]:= P(&a[n+2]);
    write(a[1]);
    write(a[2]);
    write(a[3]);
    write(a[4]);
    write(a[5]);
END.
```
