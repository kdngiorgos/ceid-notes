(α) Που δεσμεύεται και πόση μνήμη (σε bytes) χρησιμοποιεί κάθε μεταβλητή στον παρακάτω κώδικα C; Περιγράψτε τον τρόπο πρόσβασης στη μνήμη του πίνακα κατά την αρχικοποίησή του. Αναφέρετε πιθανά ζητήματα απόδοσης.
```c
#define N 1024
static double A[N][N];

void init() {
  int i, j;
  for (j = 0; j < N; ++j)
    for (i = 0; i < N; ++i)
      A[i][j] = (i*j)/(i+j+1);
}
```

## ΘΕΜΑ 4 – Εμβέλεια και Μεταβίβαση Παραμέτρων (20%)
Δίνεται το παρακάτω πρόγραμμα σε μια γλώσσα τύπου Pascal που χρησιμοποιεί το στατικό κανόνα εμβέλειας:
```pascal
program MAIN;
    var i, a: integer;
    function P(j: integer): integer;
        function Q(k: integer): integer;
            begin
                if k < 4
                then i:= P(k);
                    Q:= k
                else write(k);
                    Q:= 0
            end;
        begin
            j:= j + j;
            P:= Q(j);
        end;
BEGIN
    i:= 1;
    a:= P(i);
    write(i, a);
END.
```
(α) Ποια είναι τα *περιβάλλοντα αναφοράς* (τοπικά, μη-τοπικά, καθολικά) όλων των τμημάτων του προγράμματος;
(β) Παρουσιάστε τη *στοίβα εκτέλεσης* (run-time stack) των εγγραφών ενεργοποίησης (Activation Records – AR) μόλις έχει γίνει η τελευταία κλήση της Q.
(γ) Ποιες τιμές θα τυπωθούν με τις εντολές `write`, στις παρακάτω περιπτώσεις τρόπου μεταβίβασης παραμέτρων; Παρουσιάστε τις αλλαγές τιμών όλων των μεταβλητών κατά τη διαδικασία υπολογισμού στις δύο περιπτώσεις.
i. Κλήση με τιμή (call by value).
ii. Κλήση με αναφορά (call by reference).

## ΘΕΜΑ 5 – Συναρτησιακός Προγραμματισμός (20%)
(α) Στον λ-λογισμό, μπορούμε να αναπαραστήσουμε τις λογικές τιμές true και false ως εξής:
$$\text{true} = \lambda x.\ \lambda y.\ x$$
$$\text{false} = \lambda x.\ \lambda y.\ y$$
Η αναπαράσταση του λογικού τελεστή not με την έκφραση $\text{not} = \lambda z.\ z\ \text{false}\ \text{true}$, επιφέρει το επιθυμητό αποτέλεσμα;
(Σημείωση: αρκεί να αποδείξετε ότι $\text{not true} = \text{false}$ και $\text{not false} = \text{true}$.)

(β) Σε μία γλώσσα συναρτησιακού προγραμματισμού, θεωρείστε τους κάτωθι κανόνες αναγωγής (reduction rules).
- Built-in rules: addition, substraction, multiplication, division
- User supplied rules:
```
square x = x * x
double x = x + x
sum [ ] = 0
sum (x:xs) = x + sum [x+1:xs]
```
Δώστε όλα τα ενδιάμεσα βήματα αναγωγής μέχρι την τελική αποτίμηση της έκφρασης `square (sum [1:100])` με πρόθυμη (eager evaluation) και οκνηρή (lazy evaluation) στρατηγική αποτίμησης. Πόσα βήματα (reductions) απαιτεί η κάθε στρατηγική; Ποια είναι η πιο αποδοτική;
