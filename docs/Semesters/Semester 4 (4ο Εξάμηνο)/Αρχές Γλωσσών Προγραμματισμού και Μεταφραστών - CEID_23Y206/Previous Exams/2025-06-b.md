## ΘΕΜΑ 1 – Συντακτική Ανάλυση (25%)

Δίνεται η παρακάτω απλή BNF γραμματική, με τερματικά σύμβολα τα: ( ) [ ]

$$<S> ::= <S>(<S>) \mid <S>[<S>] \mid \epsilon$$

(α) Τι τύπου είναι η γραμματική στην ιεραρχία Chomsky και γιατί;

(β) Τι είδους συμβολοσειρές περιγράφει η παραπάνω γραμματική; Περιγράψτε τα χαρακτηριστικά των συμβολοσειρών αυτών. Δώστε σχετικά παραδείγματα, καθώς και όλα τα μικρότερα μέλη της γλώσσας με μήκος έως και 4 χαρακτήρες.

(γ) Ελέγξτε αν η συμβολοσειρά `[]([]())` είναι μέλος της γλώσσας, παρουσιάζοντας τη Στοίβα Ταιριάσματος – Πρόβλεψης Top-Down συντακτικής ανάλυσης.

(δ) Είναι ή όχι η γραμματική LL(1) και γιατί; Αν όχι, μετασχηματίστε την σε μια ισοδύναμη LL(1) γραμματική.

## ΘΕΜΑ 3 – Εμβέλεια και Μεταβίβαση Παραμέτρων (25%)

Δίνεται το παρακάτω πρόγραμμα σε μια γλώσσα τύπου Pascal στην οποία ισχύει ο *στατικός κανόνας εμβέλειας*:

```pascal
program MAIN;
  var a: array[1..2] of integer; i, j: integer;

  procedure P(x: integer; y: integer);
  begin
    a[1] := a[1] + x;
    i := 2;
    x := x + 1;
    j := 1;
    y := y + x;
  end;

begin
  a[1] := 3; a[2] := 5;
  i := 1; j := 2;
  P(a[i], a[j]);
  writeln('output:', a[1], ' ', a[2]);
end.
```

Μορφή εξόδου του προγράμματος: `output: a_1 a_2`

Πίνακας αποτελεσμάτων

| Κλήση με | a[1] | a[2] |
|---|---|---|
| 1. τιμή | | |
| 2. αναφορά | | |
| 3. τιμή-αποτέλεσμα | | |
| 4. όνομα | | |

(a) Ποια είναι τα περιβάλλοντα αναφοράς όλων των τμημάτων του προγράμματος;

(b) Ποιες τιμές θα τυπωθούν στο τέλος για τα a[1] και a[2] στις παρακάτω περιπτώσεις μεταβίβασης παραμέτρων; Συμπληρώστε τον πίνακα και παρουσιάστε συνοπτικά τους υπολογισμούς σας.

1. Κλήση με τιμή (call by value)
2. Κλήση με αναφορά (call by reference)
3. Κλήση με τιμή-αποτέλεσμα (call by value) > [sic: στο 3 γράφεται «call by value», ενώ ο όρος είναι value-result]
4. Κλήση με όνομα (call by name)

## ΘΕΜΑ 4 – Μεταβλητές και Διαχείριση Μνήμης (10%)

```c
void main() {
  int *p, data[] = {2, 4, 6};
  p = &data[1];
  *(p+1) += 1;
  p = &p[1];
  *(p-1) -= 1;
  *p += (*(p-2))++;
  printf("%d %d %d\n", data[0], data[1], data[2]);
}
```

students = [

## ΘΕΜΑ 6 – Functional Programming και Γλώσσες ΒΔ (20%)

(α) Κάνοντας χρήση της *Python lambda map function*, γράψτε πρόγραμμα το οποίο **με μία και μόνο βασική εντολή**, θα υπολογίζει (και τυπώνει) το άθροισμα της k-στής δύναμης των ακέραιων αριθμών μιας λίστας L, όπου το k το δίνει ο χρήστης.

(β) Κάνοντας χρήση της *Python lambda reduce function*, γράψτε πρόγραμμα το οποίο **με μία και μόνο βασική εντολή**, θα υπολογίζει (και τυπώνει) το άθροισμα της k-στής δύναμης των ακέραιων αριθμών μιας λίστας L, όπου το k το δίνει ο χρήστης.

(γ) Τί τυπώνει το παρακάτω πρόγραμμα;

```python
import functools
numbers = [1, 2, 3, 4]
result= functools.reduce(lambda x, y: x * y, numbers)
print(result)
```

(δ) Τι αλλαγές πρέπει να κάνω στο παραπάνω πρόγραμμα, ώστε να τυπωθεί το γινόμενο των k-στών δυνάμεων; Η τιμή του k δίνεται από τον χρήστη.

(ε) Συμπληρώστε όλα τα στάδια αποτίμησης της παρακάτω έκφρασης σε λ-λογισμό:

$$(\lambda x.\; \lambda y.\; \lambda z.\; x^3 + y^3 + z^3)\; 3\; 2\; 1$$

(στ) Έστω μία βάση δεδομένων με δύο πίνακες (σχέσεις) R1(A,B,C,D) και R2(B,E,F,H) οι οποίοι συσχετίζονται στην κοινή στήλη (γνώρισμα) B και έστω ο παρακάτω κώδικας σε γλώσσα SQL:

```sql
Select A, B, E
From R1, R2
Where R1.B=R2.B and C<200
```

Περιγράψτε όλα τα ενδιάμεσα πλάνα εκτέλεσης που παράγει ο SQL Compiler για το παραπάνω ερώτημα μέχρι την εύρεση του τελικού πλάνου που είναι και το βέλτιστο. Θυμίζουμε την ύπαρξη ενσωματωμένου βελτιστοποιητή (embedded optimizer) ο οποίος μετατρέπει τον SQL κώδικα σε ισοδύναμη μορφή σχεσιακής άλγεβρας και στη συνέχεια εφαρμόζει τους γνωστούς ευριστικούς κανόνες βελτιστοποίησης. Σημειώνουμε ότι η στήλη C δέχεται αριθμητικές τιμές.
