## ΘΕΜΑ 3 – Μεταβλητές και Διαχείριση Μνήμης (10%)

Ποιες θα είναι οι τελικές τιμές του πίνακα data που θα τυπώσει το παρακάτω πρόγραμμα. Αναφέρετε και εξηγήστε τους υπολογισμούς σας.

```c
void main() {
  int *p, data[] = {6, 12, 18, 24};
  p = &data[2];
  *(p - 2) = *p / 3 + 1;
  p--;
  *(p + 2) = *p * 2 - 1;
  *p += p[1] / 3;
  *(p + 1) = *(p + 2) - *p;
  printf("%d %d %d %d\n", data[0], data[1], data[2], data[3]);
}
```

## ΘΕΜΑ 4 – Εμβέλεια και Μεταβίβαση Παραμέτρων (20%)

Δίνεται το παρακάτω πρόγραμμα σε μια γλώσσα τύπου Pascal στην οποία ισχύει ο *στατικός κανόνας εμβέλειας*:

```pascal
program MAIN;
  var b: array[1..3] of integer; k, m: integer;

  procedure Q(u: integer; v: integer);
  begin
    b[1] := b[1] + u;
    b[2] := b[2] + v;
    m := 3;
    u := u + 1;
    b[3] := b[3] + u;
    v := v + u;
  end;

begin
  b[1] := 1; b[2] := 2; b[3] := 3;
  k := 1; m := 2;
  Q(b[m], b[k]);
  writeln('output:', b[1], ' ', b[2], ' ', b[3]);
end
```

Μορφή εξόδου του προγράμματος: `output: b_1 b_2 b_3`

Πίνακας αποτελεσμάτων

| Κλήση με | b[1] | b[2] | b[3] |
|---|---|---|---|
| 1. τιμή | | | |
| 2. αναφορά | | | |
| 3. τιμή-αποτέλεσμα | | | |
| 4. όνομα | | | |

(a) Ποια είναι τα περιβάλλοντα αναφοράς όλων των τμημάτων του προγράμματος;

(b) Ποιες τιμές θα τυπωθούν στο τέλος για τα b[1], b[2] και b[3] στις παρακάτω περιπτώσεις μεταβίβασης παραμέτρων; Συμπληρώστε τον πίνακα (στην κόλα σας) και παρουσιάστε συνοπτικά τους υπολογισμούς σας.

1. Κλήση με τιμή (call by value)
2. Κλήση με αναφορά (call by reference)
3. Κλήση με τιμή-αποτέλεσμα (call by value-result)
4. Κλήση με όνομα (call by name)

## ΘΕΜΑ 6 – Functional Programming και Γλώσσες ΒΔ (25%)

(Α) Δίνονται σε *γλώσσα Prolog* οι παρακάτω 8 προτάσεις (facts) καθώς και ένας κανόνας (rule):

Facts: `studies(Charlie, csc135)`, `studies(Olivia, csc135)`, `studies(Jack, csc131)`, `studies(Arthur, csc134)`, `teaches(Sioutas, csc135)`, `teaches(Garofalakis, csc131)`, `teaches(Hadjidoukas, csc171)`, `teaches(Vonitsanos, csc134)`

Rules: `professor(X, Y) :- teaches(X, C), studies(Y, C).`

(α) Σχεδιάστε τις δομές δεδομένων (δέντρα) για τις παραπάνω 8 προτάσεις. Πώς «διαβάζονται» οι παραπάνω προτάσεις;

(β) Οι κανόνες είναι θεωρήματα που επιτρέπουν στο διερμηνέα να συναγάγει την αλήθεια προτάσεων. Πως διαβάζεται ο παραπάνω κανόνας;

(γ) Γράψτε σε γλώσσα Prolog τα ακόλουθα ερωτήματα:
(γ1) Τι μελετάει ο Charlie `//charlie studies what?//`
(γ2) Ποιοι είναι οι μαθητές του Καθηγητή Garofalakis `// Who are the students of professor Garofalakis?//`

(B) Έστω μία βάση δεδομένων με δύο πίνακες (σχέσεις) R1(A,B,C) και R2(C, E, F) οι οποίοι συσχετίζονται στην κοινή στήλη (γνώρισμα) C και έστω ο παρακάτω κώδικας σε *γλώσσα SQL*:

```sql
Select A
From R1,R2
Where R1.C=R2.C and C<400
```

Περιγράψτε όλα τα ενδιάμεσα πλάνα εκτέλεσης που παράγει ο SQL Compiler για το παραπάνω ερώτημα μέχρι την εύρεση του τελικού πλάνου που είναι και το βέλτιστο. Θυμίζουμε την ύπαρξη ενσωματωμένου βελτιστοποιητή (embedded optimizer) ο οποίος μετατρέπει τον SQL κώδικα σε ισοδύναμη μορφή σχεσιακής άλγεβρας και στη συνέχεια εφαρμόζει τους γνωστούς ευριστικούς κανόνες βελτιστοποίησης. Σημειώνουμε ότι η στήλη C δέχεται αριθμητικές τιμές.

(Γ) (α) Κάνοντας χρήση της *Python lambda map function*, γράψτε πρόγραμμα το οποίο **με μία και μόνο βασική εντολή**, θα υπολογίζει (και τυπώνει) το άθροισμα των κύβων των ακέραιων αριθμών μιας λίστας L.

(β) Κάνοντας χρήση της *Python lambda reduce function*, γράψτε πρόγραμμα το οποίο **με μία και μόνο βασική εντολή**, θα υπολογίζει (και τυπώνει) το άθροισμα των τετραγώνων των ακέραιων αριθμών μιας λίστας L.

(γ) Στον *λ-λογισμό*, μπορούμε να αναπαραστήσουμε τις λογικές τιμές true και false ως εξής:

$$true \equiv \lambda x.\, \lambda y.\, X, \qquad false \equiv \lambda x.\, \lambda y.\, Y$$

Η αναπαράσταση του λογικού τελεστή not με την έκφραση $not \equiv \lambda z.\, z\; false\; true$, επιφέρει το επιθυμητό αποτέλεσμα;

(Σημείωση: αρκεί να αποδείξετε ότι not true = false και not false = true)

(Δ) Σε μία γλώσσα *συναρτησιακού προγραμματισμού*, θεωρείστε τους κάτωθι κανόνες αναγωγής (reduction rules).

- Built-in rules: addition, substraction, multiplication, division
- User supplied rules:

```
square x  = x * x
double x  = x + x
sum [ ]   = 0
sum (x:xs) = x + sum [x+1:xs]
```

Δώστε όλα τα ενδιάμεσα βήματα αναγωγής μέχρι την τελική αποτίμηση της έκφρασης `square(sum [1:100])` με *πρόθυμη στρατηγική αποτίμησης* (eager evaluation), *οκνηρή στρατηγική αποτίμησης* (lazy evaluation) και *Γραφο-Υβριδική (Outer-Most Graph Reduction)* στρατηγική αποτίμησης. Πόσα βήματα (reductions) απαιτεί η κάθε στρατηγική; Ποια είναι η πιο αποδοτική;
