# Αρχές Γλωσσών Προγραμματισμού και Μεταφραστών

Καλύπτει λεξική και συντακτική ανάλυση (κανονικές εκφράσεις, πεπερασμένα αυτόματα, γραμματικές BNF, εργαλεία flex/bison), εμβέλεια και διαχείριση μνήμης, μεταβίβαση παραμέτρων, και τα παραδείγματα συναρτησιακού (λ-λογισμός) και λογικού προγραμματισμού. ## Τι θα μάθεις

Το επίσημο περίγραμμα ορίζει δώδεκα ενότητες, από την ιστορία των γλωσσών μέχρι τη λεξική/συντακτική ανάλυση και τα παραδείγματα προγραμματισμού [Περίγραμμα](https://www.ceid.upatras.gr/sites/default/files/ceid_ny132_gr.pdf). Στην πράξη οι διαφάνειες (Chapters 0–7) ακολουθούν αυτή τη ροή:

- Εισαγωγή, ιστορική εξέλιξη γλωσσών, κριτήρια καλού σχεδιασμού, μεταφραστές και διερμηνευτές.
- Φάσεις μετάφρασης, τυπικές γλώσσες, σύνταξη: λεξική ανάλυση με κανονικές εκφράσεις/αυτόματα (flex) και συντακτική ανάλυση με γραμματικές χωρίς συμφραζόμενα/BNF (bison).
- Μεταβλητές, εκφράσεις, εντολές και τύποι δεδομένων.
- Εμβέλεια (στατικός/δυναμικός κανόνας) και χρόνος δέσμευσης μνήμης, εγγραφές ενεργοποίησης (activation records).
- Υποπρογράμματα και τρόποι μεταβίβασης παραμέτρων: call by value / reference / name.
- Συναρτησιακός προγραμματισμός (λ-λογισμός, αναγωγή, οκνηρή/πρόθυμη αποτίμηση, map-reduce) και λογικός προγραμματισμός (Prolog).
- Στοιχεία γλωσσών βάσεων δεδομένων και σχεσιακής άλγεβρας, που εμφανίζονται σε παλιότερες διαφάνειες eClass (διαθέσιμο στο πλήρες πακέτο).

## Πώς βαθμολογείται

- Περίγραμμα: τελική γραπτή εξέταση 100% της βαθμολογίας, «διαβαθμισμένης δυσκολίας» (σύνθετα προβλήματα, ερωτήσεις σύντομης απάντησης, ερωτήσεις κρίσεως), συν εργασία με flex/bison [Κατάλογος: Περίγραμμα](https://www.ceid.upatras.gr/sites/default/files/ceid_ny132_gr.pdf).
- Κατά φοιτητές (2025-04) ο διαμοιρασμός είναι περίπου 70% γραπτή + 30% flex/bison· αν κάποιος παραδώσει και το πρότζεκτ Python, γίνεται 60% γραπτή + 20% flex/bison + 20% Python Discord 2025-04 (διαθέσιμο στο πλήρες πακέτο).
- Το 2026 φοιτητής περιγράφει πάλι 70/30 (ακούσματα, χωρίς επιβεβαίωση), με το flex/bison υποχρεωτικό για όσους είναι πριν το νέο πρόγραμμα Discord 2026-06 (διαθέσιμο στο πλήρες πακέτο).
- Κάποιοι αναφέρουν βάση 3,5 για κάθε μέρος, αρκεί ο συνδυασμός γραπτής και πρότζεκτ να ξεπερνά το 5 Discord 2026-06 (διαθέσιμο στο πλήρες πακέτο), Discord 2026-07 (διαθέσιμο στο πλήρες πακέτο).
- Η ύλη της λεξικής/συντακτικής ανάλυσης (BNF) φέρεται να πιάνει το μεγαλύτερο μέρος του βαθμού, περίπου 30–40% Discord 2024-05 (διαθέσιμο στο πλήρες πακέτο). Το 2025 η Python έπιανε ~15% (ένα θέμα) Discord 2025-06 (διαθέσιμο στο πλήρες πακέτο).
- Το 2024 το άριστα της γραπτής αναφερόταν στις 11 μονάδες, με την Python ως μπόνους ~1 μονάδα· τα κριτήρια άλλαξαν με το νέο πρόγραμμα Discord 2024-06 (διαθέσιμο στο πλήρες πακέτο).
- Ο βαθμός του πρότζεκτ κρατιέται για έναν χρόνο (κατά φοιτητές) και ανακοινώνεται μαζί με τη θεωρία στο eClass Discord 2024-09 (διαθέσιμο στο πλήρες πακέτο), Discord 2026-09 (διαθέσιμο στο πλήρες πακέτο).

## Εργασίες & εργαστήρια

- **Πρότζεκτ flex/bison (υποχρεωτικό):** κατασκευή λεκτικού και συντακτικού αναλυτή πάνω σε δεδομένη γραμματική (π.χ. επέκταση SELECT/WHERE για mini-SQL). Η εκφώνηση «Εργαστηριακή Άσκηση 2026» ζητά γραμματική, κανόνες και αναγνώριση σωστών/λανθασμένων προτάσεων eClass (διαθέσιμο στο πλήρες πακέτο).
- **Πρότζεκτ Python (προαιρετικό για μεγαλύτερα έτη):** διεπαφή με CSV/pandas, αποθήκευση δεδομένων χωρίς αντικατάσταση και GUI με Tkinter eClass (διαθέσιμο στο πλήρες πακέτο).
- Και τα δύο περνιούνται με **προφορική εξέταση**: στο flex/bison εκτελείς το πρόγραμμα, αλλάζεις το αρχείο εισόδου και εξηγείς τον κώδικα· στην Python ο έλεγχος είναι πιο χαλαρός Discord 2025-06 (διαθέσιμο στο πλήρες πακέτο), Discord 2026-06 (διαθέσιμο στο πλήρες πακέτο).
- Το πρότζεκτ υποβάλλεται μέχρι τα τέλη Αυγούστου/Σεπτέμβρη και κρατιέται για ένα ακαδημαϊκό έτος· για παλιότερα έτη η Python ήταν μπόνους Discord 2026-06 (διαθέσιμο στο πλήρες πακέτο).
