## 3.png

Ερώτηση 2 / 4 (Πολλαπλής Επιλογής (Μοναδική Απάντηση) — 1 βαθμός)

Αν
$$j \ln\left[\frac{y(t)}{x(t)}\right] = t\Omega_0$$

Ποια η σχέση ανάμεσα στους μετασχηματισμούς Fourier των σημάτων $x(t)$ και $y(t)$; Θεωρήστε ότι
$$\frac{y(t)}{x(t)} > 0, \forall t \in \mathbb{R}$$

.
- [ ] $Y(j\Omega) = \Omega_0 X(j\Omega)$
- [ ] $Y(j\Omega) = X(j(\Omega - \Omega_0))$
- [ ] $Y(j\Omega) = X(j(\Omega + \Omega_0))$
- [ ] $Y(j\Omega) = e^{-j\Omega_0} X(j\Omega)$

    ## 1.jpg

    3. Αν $j \bullet \ln\left(\frac{y(t)}{x(t)}\right) = t \bullet \Omega_0$ ποια η σχέση ανάμεσα στους μετασχηματισμούς Fourier των σημάτων $x(t)$ και $y(t)$; Θεωρήστε ότι $\frac{y(t)}{x(t)} > 0, \forall t \in \mathbb{R}$

    Απάντηση
    $$j \bullet \ln\left(\frac{y(t)}{x(t)}\right) = t \bullet \Omega_0 \Rightarrow \ln\left(\frac{y(t)}{x(t)}\right) = \frac{t \bullet \Omega_0}{j} \Rightarrow \frac{y(t)}{x(t)} = e^{\frac{t \bullet \Omega_0}{j}} \Rightarrow \frac{y(t)}{x(t)} = e^{\frac{t \bullet \Omega_0}{j}} \Rightarrow$$
    $$\Rightarrow y(t) = x(t) \bullet e^{\frac{t \bullet \Omega_0}{j}} \Rightarrow y(t) = e^{-j \bullet \Omega_0 \bullet t} \bullet x(t) \leftrightarrow Y(j \bullet \Omega) = X(j(\Omega - \Omega_0))$$
