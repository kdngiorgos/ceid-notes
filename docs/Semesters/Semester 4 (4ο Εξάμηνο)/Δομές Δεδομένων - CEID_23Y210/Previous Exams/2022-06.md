    Μέτα: E F C D B V W L M G (A)  
    Συμ: E C F B D (A) V L W G M  

    Δέντρο αποσύνθεσης:
    - Ρίζα A
    - Αριστερό υποδένδρο:
      - Μέτα: E F C D (B)
      - Συμ: E C F (B) D
      - Ρίζα B, δεξί παιδί D, αριστερό:
        - Μέτα: E F (C)
        - Συμ: E (C) F
        - Ρίζα C, αριστερό παιδί E, δεξί παιδί F
    - Δεξί υποδένδρο:
      - Μέτα: V W L M (G)
      - Συμ: V L W (G) M
      - Ρίζα G, δεξί παιδί M, αριστερό:
        - Μέτα: V W (L)
        - Συμ: V (L) W
        - Ρίζα L, αριστερό παιδί V, δεξί παιδί W

    Τελικό δυαδικό δένδρο:
    ```
            A
           / \
          B   G
         / \ / \
        C  D L  M
       / \   / \
      E   F V   W
    ```

    Επιβεβαίωση:
    Μέτα: E F C D B V W L M G A

    ## IMG_6446.png

    WTTFRIED12ILHELGOLEIBNIZ

    Χειρόγραφα βήματα Replacement Selection:
    - WTT -> T -> F -> T
    - $W F^* T$ -> T -> R -> TT
    - $W F^* R^*$ -> W -> I -> (TTW) => 1η ταινία
    - $I^* F^* R^*$ -> $F^*$ -> E -> $F^*$
    - $I^* E^* R^*$ -> $I^*$ -> D -> $F^* I^*$
    - D E $R^*$ -> $R^*$ -> 1 -> $F^* I^* R^*$ => 2η ταινία
    - D E $1^*$ -> $1^*$ -> 2 -> $F^* I^* R^* 1^*$
    - D E $2^*$ -> $2^*$ -> I -> ( $F^* I^* R^* 1^* 2^*$ )
    - D E I -> D -> L -> D
    - L E I -> E -> H -> D E
    - L H I -> H -> E -> D E H => 3η ταινία
    - L $E^* I$ -> I -> L -> D E H I
    - L $E^* L$ -> L -> G -> D E H I L
    - G* $E^* L$ -> L -> O -> D E H I L L
    - $G^* E^* O$ -> O -> L -> (D E H I L L O)
    - $G^* E^* L^*$ -> $E^*$ -> E -> $E^*$
    - $G^* E^* L^*$ -> $E^*$ -> I -> $E^* E^*$ => 4η ταινία
    - $G^* I^* L^*$ -> $G^*$ -> B -> $E^* E^* G^*$
    - B $I^* L^*$ -> $I^*$ -> N -> $E^* E^* G^* I^*$
    - B N $L^*$ -> $L^*$ -> I -> $E^* E^* G^* I^* L^*$
    - B N $I^*$ -> $N^*$ -> 2 -> ($E^* E^* G^* I^* L^* N^*$)
    - B $2^* I$ -> - -> - -> ($B 2^* I$)

    - Ταινία 2: F I R 1 2
