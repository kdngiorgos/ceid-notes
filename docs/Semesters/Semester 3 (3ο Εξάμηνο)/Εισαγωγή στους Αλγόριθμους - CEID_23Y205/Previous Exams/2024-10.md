Ερώτηση 1 / 4 (Συμπλήρωση Κενών (Χαλαρή Ταυτοποίηση) — 3 βαθμοί)

Σύγκριση ρυθμών αύξησης

* Στην άσκηση που ακολουθεί, ο αριθμός "α" υπολογίζεται διαιρώντας τα τελευταία 2 ψηφία του ΑΜ σας με το 4 και προσθέτοντας στο υπόλοιπο τον αριθμό 1.
$$a = ((AM \bmod 100) \bmod 4) + 1$$

Έστω ένας υπολογιστής που εκτελεί $2^6$ στοιχειώδεις λειτουργίες ανά δευτερόλεπτο. Αν για την επίλυση ενός προβλήματος μεγέθους $n$, έχετε δύο αλγόριθμους $A_1$ και $A_2$ όπου ο αριθμός στοιχειωδών λειτουργιών τους είναι
$T(A_1) = an \log_2 n$ και $T(A_2) = 2^a \sqrt{n}$ αντίστοιχα, τότε:
- Ποιος είναι ο πραγματικός χρόνος εκτέλεσης των $A_1$ και $A_2$ για $n = 2^4$;
- Για κάθε έναν από τους $A_1$ και $A_2$ ποια είναι η μέγιστη τιμή του $n$ για την οποία ο υπολογιστής θα δώσει αποτέλεσμα σε α − δευτερόλεπτα υπολογισμού;

## Screenshot_2024-10-10_at_7.30.54_PM.png

> [Λείπει από τη φωτογραφία: επικεφαλίδα ερώτησης (αριθμός και τύπος)]

Πολυπλοκότητα απλών αλγορίθμων

* Στην άσκηση που ακολουθεί, ο αριθμός "α" υπολογίζεται διαιρώντας τα τελευταία 2 ψηφία του ΑΜ σας με το 4 και προσθέτοντας στο υπόλοιπο τον αριθμό 1.
$$a = ((AM \bmod 100) \bmod 4) + 1$$

Δίνεται το παρακάτω τμήμα κώδικα.
```
s1 = 0 ;
s2 = a ;
for i = 0 to n {
    for j = 1 to n {
        s1 = s1 + 1 ;
        s2 = s2 + a ;
    }
}
c = s1 + s2 ;
```
- Πόσες επαναλήψεις εκτελούνται στο παραπάνω τμήμα κώδικα;
- Ποια είναι η ασυμπτωτική πολυπλοκότητα του αλγορίθμου;
- Ας υποθέσουμε ότι n=6. Ποια θα είναι η τιμή του c μετά το πέρας της εκτέλεσης του κώδικα;
