# Αρχιτεκτονική Υπολογιστών

> Εισαγωγή στην αρχιτεκτονική και την οργάνωση υπολογιστών με βάση τη σύγχρονη αρχιτεκτονική RISC-V: μέτρα απόδοσης, αρχιτεκτονική συνόλου εντολών (ISA), προγραμματισμός σε συμβολική γλώσσα, υπολογιστική αριθμητική, σχεδίαση επεξεργαστή ενός κύκλου ρολογιού (datapath/control), διοχέτευση εντολών (pipeline) και κρυφές μνήμες (cache). ## Τι θα μάθεις

Το μάθημα στηρίζεται στη RISC-V, μια ανοιχτή και αρθρωτή αρχιτεκτονική RISC που χρησιμοποιείται ως εκπαιδευτικό εργαλείο. Σύμφωνα με το επίσημο περίγραμμα [Περίγραμμα](https://www.ceid.upatras.gr/assets/2026/07/CEID_23Υ203_GR.pdf), οι θεματικές ενότητες είναι:

- Εισαγωγή στην αρχιτεκτονική και την τεχνολογία των υπολογιστών.
- Μέτρα αξιολόγησης της απόδοσης.
- Η αρχιτεκτονική συνόλου εντολών (ISA) RISC-V.
- Συμβολική γλώσσα και γλώσσα μηχανής· από τον κώδικα υψηλού επιπέδου στην εκτέλεση από το υλικό.
- Υπολογιστική αριθμητική: αναπαραστάσεις, πράξεις και υλοποίηση.
- Σχεδίαση επεξεργαστή ενός κύκλου ρολογιού: διαδρομή δεδομένων (datapath) και μονάδα ελέγχου (control unit).
- Εισαγωγή στη διοχέτευση εντολών (pipeline) και στις επιπλοκές της (hazards).
- Εισαγωγή στη σχεδίαση και τη λειτουργία των κρυφών μνημών (caches).

Στόχοι κατά το περίγραμμα: να περιγράφεται η οργάνωση ενός υπολογιστικού συστήματος, να συγκρίνεται η απόδοση με κατάλληλες μετρικές, να γράφονται προγράμματα assembly RISC-V και να αξιοποιείται ο προσομοιωτής RARS [Περίγραμμα](https://www.ceid.upatras.gr/assets/2026/07/CEID_23Υ203_GR.pdf).
