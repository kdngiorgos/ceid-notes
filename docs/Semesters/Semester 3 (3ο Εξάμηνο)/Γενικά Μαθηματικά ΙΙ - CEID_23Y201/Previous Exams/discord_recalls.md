# Γενικά Μαθηματικά ΙΙ — Ανακλήσεις και πληροφορίες εξετάσεων από το Discord

> Περίληψη όσων έγραψαν φοιτητές στο κανάλι του μαθήματος για τις εξετάσεις. Είναι **ανεπίσημες, μη επαληθευμένες** αναφορές (εκτός όπου μεταφέρεται ανακοίνωση eClass, που αναφέρεται ρητά)· τα ονόματα χρηστών παραλείπονται. Οι ημερομηνίες είναι οι ημερομηνίες των μηνυμάτων, όχι απαραίτητα των εξετάσεων. Μεταγραφές θεμάτων που υπάρχουν: [2024-06](2024-06.md), [2026-02](2026-02.md).
