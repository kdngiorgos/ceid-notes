# Θεωρία Γραφημάτων και Εφαρμογές — Ανακλήσεις και πληροφορίες εξετάσεων από το Discord

> Περίληψη όσων έγραψαν φοιτητές στο κανάλι του μαθήματος για τις εξετάσεις. Είναι **ανεπίσημες, μη επαληθευμένες** αναφορές· τα ονόματα χρηστών παραλείπονται. Οι ημερομηνίες είναι οι ημερομηνίες των μηνυμάτων, όχι απαραίτητα των εξετάσεων. Όπου μεταφέρεται ανακοίνωση eClass ή του διδάσκοντα, σημειώνεται ρητά.
