    ## Θέμα 4, εκδοχή Α

    *Αξιοπιστία: ⚠ οι ανεξάρτητες λύσεις διαφωνούν: δες όλες και έλεγξε μόνος σου · εμπιστοσύνη λύτη: χαμηλή*

    **Λύση 1:** $A\oplus(A\oplus\Gamma)=\Gamma$. Μένει $\Gamma\oplus(B\oplus A)$.

    **Απάντηση: $A\oplus B\oplus\Gamma$.**

    **Λύση 2:** Η πράξη της συμμετρικής διαφοράς $\oplus$ είναι προσεταιριστική και αντιμεταθετική, με ουδέτερο στοιχείο το κενό σύνολο $\emptyset$, και ικανοποιεί $X \oplus X = \emptyset$ καθώς και $X \oplus \emptyset = X$ για κάθε σύνολο $X$.

    Αναδιατάσσοντας τους όρους:
    $$A \oplus (A \oplus \Gamma) \oplus (B \oplus A) = (A \oplus A \oplus A) \oplus B \oplus \Gamma$$

    Επειδή $A \oplus A = \emptyset$, έχουμε:
    $$(A \oplus A) \oplus A = \emptyset \oplus A = A$$

    Επομένως, η παράσταση απλοποιείται σε:
    $$A \oplus B \oplus \Gamma$$
    (ή ισοδύναμα $A \oplus (B \oplus \Gamma)$), όπου κάθε σύνολο εμφανίζεται ακριβώς μία φορά.

    **Λύση 3 (τρίτη γνώμη):** Η πράξη της συμμετρικής διαφοράς $\oplus$ είναι προσεταιριστική και αντιμεταθετική. Επίσης, για κάθε σύνολο $X$ ισχύει $X \oplus X = \emptyset$ και $X \oplus \emptyset = X$. 
    Αναλύοντας την αρχική παράσταση έχουμε:
    $B \oplus (A \oplus A) \oplus (B \oplus A) \oplus A$
    Αντικαθιστούμε το $A \oplus A$ με $\emptyset$:
    $= B \oplus \emptyset \oplus (B \oplus A) \oplus A$
    $= B \oplus (B \oplus A) \oplus A$
    Λόγω προσεταιριστικότητας και αντιμεταθετικότητας, αναδιατάσσουμε τους όρους:
    $= (B \oplus B) \oplus (A \oplus A)$
    $= \emptyset \oplus \emptyset$
    $= \emptyset$

    Η τελική παράσταση είναι το κενό σύνολο $\emptyset$. Σε αυτήν, τα σύνολα $A$ και $B$ εμφανίζονται 0 φορές, ικανοποιώντας τον περιορισμό της εκφώνησης να εμφανίζονται "το πολύ μία φορά".

    ## Θέμα 6, εκδοχή Α

    *Αξιοπιστία: δύο ανεξάρτητες λύσεις συμφωνούν · εμπιστοσύνη λύτη: υψηλή*

    Συνεκτικό Γ με $n\ge3$ κορυφές και $n$ ακμές. Αν ήταν άκυκλο, θα ήταν δέντρο με $n-1$ ακμές — αντίφαση. Άρα έχει κύκλο.

    ## Θέμα 6, εκδοχή Β

    *Αξιοπιστία: δύο ανεξάρτητες λύσεις συμφωνούν · εμπιστοσύνη λύτη: υψηλή*

    Κάθε κορυφή έχει βαθμό ≥ 2. Έστω $P=(v_0,v_1,\dots,v_k)$ μονοπάτι μέγιστου μήκους (υπάρχει, το γράφημα έχει ακμές αφού οι βαθμοί ≥2). Η $v_0$ έχει ≥2 γείτονες· ένας είναι ο $v_1$, έστω $w$ άλλος. Αν $w\notin P$, το $(w,v_0,\dots,v_k)$ θα ήταν μεγαλύτερο μονοπάτι — αντίφαση. Άρα $w=v_i$ με $i\ge2$, και το $(v_0,v_1,\dots,v_i,v_0)$ είναι κύκλος.

    ## Θέμα 7, εκδοχή Α

    *Αξιοπιστία: ⚠ οι ανεξάρτητες λύσεις διαφωνούν: δες όλες και έλεγξε μόνος σου · εμπιστοσύνη λύτη: χαμηλή*

    **Λύση 1:** - (a) **Λάθος**: το $K_{2,3}$ είναι δισυνεκτικό ως προς κορυφές αλλά δεν έχει κύκλο που να περνά από και τις 5 κορυφές του.
    - (b) **Σωστό**, με την προϋπόθεση ότι το γράφημα έχει ≥2 κορυφές: χωρίς γέφυρες, κάθε κορυφή έχει ακμή και η ακμή αυτή ανήκει σε κύκλο. (Για το γράφημα με μία κορυφή η πρόταση θα ήταν λάθος· ο ορισμός των σημειώσεων δεν είναι γνωστός.)
    - (c) **Λάθος**: τρίγωνο συν απομονωμένη κορυφή: $n=4$, $m=3$, $n=m+1$, αλλά δεν είναι συνεκτικό.

    **Λύση 2:** a. **Λάθος**
    b. **Σωστό**

    **Λύση 3 (τρίτη γνώμη):** a) **Σωστό**. Οι δισυνεκτικές συνιστώσες ως προς κορυφές (blocks) ενός γραφήματος αποτελούν διαμέριση του συνόλου των ακμών του. Επομένως, δύο διαφορετικές δισυνεκτικές συνιστώσες δεν μπορούν να έχουν καμία κοινή ακμή (μπορούν να έχουν το πολύ μία κοινή κορυφή, η οποία ονομάζεται σημείο άρθρωσης).

    b) **Λάθος**. Ένα μονοπάτι που περιέχει όλες τις κορυφές του γραφήματος ονομάζεται μονοπάτι Hamilton. Η συνεκτικότητα από μόνη της δεν εξασφαλίζει την ύπαρξη μονοπατιού Hamilton. Παρόλα αυτά, είναι εφικτό κάθε κορυφή του να ανήκει σε κάποιο κύκλο. Για παράδειγμα, αν θεωρήσουμε ένα γράφημα που αποτελείται από δύο ξεχωριστά τρίγωνα τα οποία ενώνονται μεταξύ τους με μία ακμή (γέφυρα), το γράφημα αυτό δεν είναι δισυνεκτικό ως προς ακμές, αλλά κάθε κορυφή του ανήκει σε έναν από τους δύο κύκλους.
