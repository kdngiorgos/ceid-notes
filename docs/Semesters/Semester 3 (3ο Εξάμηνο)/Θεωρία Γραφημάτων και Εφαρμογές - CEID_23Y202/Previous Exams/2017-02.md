## Εξεταση Φεβρου 2017 - Απαντησεις.pdf

**Θεωρία Γραφημάτων και Εφαρμογές  -  Διακριτά Μαθηματικά ΙΙ Φεβρουάριος 2017**

_ΕΓΘΑ_ : Σ. Κοσμαδάκης, «Εισαγωγή στα Γραφήματα, Θεωρία-Ασκήσεις».

**Α**

**1** Έστω η παρακάτω σχέση $Q(k)$ πάνω στο σύνολο $\{1, 2\}$ – όπου $k$ τυχαίος ακέραιος: $Q(k) = \{ (u, v) : u - v = k \}$.

**α** Βρείτε όλα τα ζεύγη που ανήκουν στις σχέσεις $Q(0)$, $Q(1)$, $Q(2)$.

**β** Βρείτε ποιές από τις σχέσεις $Q(0)$, $Q(1)$, $Q(2)$, είναι μεταβατικές, και ποιές είναι συμμετρικές.

**2** Να αποδειχτεί ότι: για κάθε δέντρο $G$ με μέγιστο βαθμό $Κ$, υπάρχει τρόπος να χρωματιστούν οι ακμές του $G$ με $Κ$ χρώματα (το πολύ), έτσι ώστε: τα χρώματα δύο οποιωνδήποτε ακμών με κοινό άκρο, να είναι διαφορετικά.

_**Νύξη**_ Χρησιμοποιείστε την επαγωγή για τα δέντρα.

**Β**

Σε κάθε ένα από τα παρακάτω ερωτήματα, βρείτε αν η αναφερόμενη ιδιότητα είναι _σωστή_ ή _λάθος_.

**1** Για κάθε γράφημα $G$, η παρακάτω σχέση $R_{\kappa}$ ανάμεσα στις κορυφές του $G$, είναι μεταβατική: $R_{\kappa} = \{ (u, v) : \text{υπάρχει ένας κύκλος του } G \text{ που περιέχει τις κορυφές } u, v \}$.

**2** Αν μία κορυφή ενός γραφήματος $G$ είναι κομβικό σημείο, δεν μπορεί να περιέχεται σε κύκλο του $G$.

**3** Το άθροισμα δύο κύκλων που έχουν ακριβώς μία κοινή ακμή, θα είναι κύκλος.

**4** Δύο διαφορετικές δισυνεκτικές συνιστώσες ως προς κορυφές ενός γραφήματος, δεν μπορούν να έχουν κοινή κορυφή.

**Γ**

Αποδείξτε τα παρακάτω. Μπορείτε να χρησιμοποιήσετε οποιαδήποτε ιδιότητα από την θεωρία.

**1** Αν ένα κατευθυνόμενο γράφημα περιέχει μία κλειστή διαδρομή, θα περιέχει και ένα κύκλο.

**2** Αν μία σχέση $R$, πάνω σε ένα σύνολο $A$, είναι μεταβατική, τότε η σχέση $R^{\text{inv}} = \{ (u, v) : v \, R \, u \}$, πάνω στο $A$, θα είναι μεταβατική.

**3** Αν ένα γράφημα με $m$ ακμές, $n$ κορυφές και $k$ συνεκτικές συνιστώσες δεν περιέχει κύκλο, θα είναι $m = n - k$.

**4** Αν ένα συνεκτικό γράφημα έχει γέφυρα, δεν είναι δισυνεκτικό ως προς ακμές.

**Δ**

Αποδείξτε τα παρακάτω. Μπορείτε να χρησιμοποιήσετε οποιαδήποτε ιδιότητα από την θεωρία.

**1** Αν τα γραφήματα $G_1 = (V_1, E_1)$ και $G_2 = (V_2, E_2)$ έχουν τουλάχιστον δύο κοινές κορυφές και είναι δισυνεκτικά ως προς κορυφές, το γράφημα $G = (V_1 \cup V_2, E_1 \cup E_2)$ θα είναι δισυνεκτικό ως προς κορυφές.

**2** Κάθε ακμή ενός γραφήματος $G$, περιέχεται σε κάποια συνεκτική συνιστώσα του $G$.

**3** Κάθε συνεκτικό γράφημα με $n$ κορυφές και $n+1$ ακμές, περιέχει το πολύ τρεις κύκλους.

**4** Κάθε συνεκτικό γράφημα με _ακριβώς μία_ γέφυρα, έχει _το πολύ δύο_ δισυνεκτικές συνιστώσες ως προς ακμές.
