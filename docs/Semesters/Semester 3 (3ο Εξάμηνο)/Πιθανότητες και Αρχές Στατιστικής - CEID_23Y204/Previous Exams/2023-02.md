# Πιθανότητες και Αρχές Στατιστικής
Εξέταση Φεβρουαρίου 2023

**1.** (1.5) Το κουτί Ι περιέχει 3 κόκκινες και 2 μπλε σφαίρες, ενώ το κουτί ΙΙ περιέχει 2 κόκκινες και 8 μπλε σφαίρες. Ρίχνουμε ένα νόμισμα και αν έρθει αποτέλεσμα «Κεφαλή» βγάζουμε μια τυχαία σφαίρα από το πρώτο κουτί, αλλιώς βγάζουμε μια τυχαία σφαίρα από το δεύτερο κουτί.  
α) Πόση είναι η πιθανότητα η μπάλα που βγάλαμε να είναι μπλε;  
β) Αν η μπάλα που βγάλαμε είναι κόκκινη, πόση είναι η πιθανότητα να την βγάλαμε από το κουτί Ι;

**2.** (2.0) Η τυχαία μεταβλητή Χ έχει συνάρτηση πυκνότητας πιθανότητας (pdf):

$$f(x) = \begin{cases} cx^2, & 0 \le x \le 1 \\ 0, & \text{αλλιώς} \end{cases}$$

Να βρεθούν α) η σταθερά c β) η $E(X^2)$ γ) η $E[(X-1)^2]$ δ) η διασπορά της Χ.

**3.** (1.5) Η πιθανότητα μιας παρενέργειας σε ένα φάρμακο είναι 0,001. Να υπολογίσετε την πιθανότητα, μεταξύ 2.000 ασθενών που λαμβάνουν το φάρμακο, να εμφανίσουν την παρενέργεια περισσότεροι από 2 ασθενείς α) ακριβώς β) προσεγγιστικά μέσω της κατανομής Poisson.

**4.** (2.0) Ρίχνουμε ένα ζάρι 120 φορές. Πόση η πιθανότητα να έρθει αποτέλεσμα 4 τουλάχιστον 15 και το πολύ 23 φορές α) ακριβώς β) προσεγγιστικά;  
Δίνεται ότι $\Phi(-2{,}3) \approx 0{,}01, \Phi(0{,}85) \approx 0{,}80, \Phi(1{,}16) \approx 0{,}87, \Phi(-1.34) \approx 0{,}09$

**5.** (2.0) Η τυχαία μεταβλητή Χ έχει συνάρτηση πυκνότητας πιθανότητας (pdf):

$$f(x) = \begin{cases} (k+1)x^k, & 0 \le x \le 1 \\ 0, & \text{αλλιώς} \end{cases}$$

Έστω τυχαίο δείγμα $X_1, X_2, \dots, X_n$ από πληθυσμό που ακολουθεί αυτήν την κατανομή.  
α) Να εκτιμηθεί η παράμετρος k με τη μέθοδο των ροπών. Να εξηγηθεί το σκεπτικό αυτής της μεθόδου. β) Να βρεθεί εκτιμήτρια μέγιστης πιθανοφάνειας για την παράμετρο k. Να εξηγηθεί το σκεπτικό της μεθόδου μέγιστης πιθανοφάνειας.

**6.** (2.0) Θεωρούμε ότι οι βαθμοί της τελικής εξέτασης ενός μαθήματος ακολουθούν κανονική κατανομή με διασπορά 4. Για να εκτιμήσουμε την άγνωστη μέση τιμή $\mu$ των βαθμών διαλέγουμε τυχαία κάποια γραπτά και βλέπουμε ότι οι βαθμοί τους είναι:  
8, 9, 3, 5, 6, 7, 6, 3, 10  
α) Να βρεθεί 99% διάστημα εμπιστοσύνης για την $\mu$.  
β) Πόσα γραπτά, κατ' ελάχιστον, θα έπρεπε να δούμε ώστε το 95% διάστημα εμπιστοσύνης να έχει εύρος το πολύ 1,5;  
Δίνεται ότι $z_{0{,}005} = 2{,}58$, $z_{0{,}01} = 2{,}33$, $z_{0{,}025} = 1{,}96$, $z_{0{,}05} = 1{,}645$

Οι βαθμοί των θεμάτων αθροίζουν σε 11 και υπάρχει δυνατότητα επιλογής.

      $P(I \mid \text{Κόκκινη}) = \frac{\frac{1}{2}\frac{3}{5}}{\frac{1}{2}\frac{3}{5} + \frac{1}{2}\frac{2}{10}} = \frac{3/10}{3/10 + 1/10} = \mathbf{\frac{3}{4} = 0.75}$.
    - **Θέμα 2:** $\int_0^1 c x^2 dx = 1 \implies c/3 = 1 \implies \mathbf{c = 3}$.
      $E[X^2] = \int_0^1 x^2 (3x^2) dx = \frac{3}{5}$. $E[X] = \int_0^1 x (3x^2) dx = \frac{3}{4}$.
      $\operatorname{Var}(X) = \frac{3}{5} - \frac{9}{16} = \frac{3}{80}$. $E[(X-1)^2] = E[X^2] - 2E[X] + 1 = \frac{3}{5} - \frac{3}{2} + 1 = \frac{1}{10}$.
    - **Θέμα 3:** $n = 2000, p = 0.001 \implies \lambda = np = 2$.
      α) Ακριβώς: $1 - \sum_{k=0}^2 \binom{2000}{k} (0.001)^k (0.999)^{2000-k}$.
      β) Poisson: $1 - e^{-2}(1 + 2 + 2) = 1 - 5e^{-2} \approx \mathbf{0.3233}$.
    - **Θέμα 4:** $n = 120, p = 1/6 \implies \mu = 20, \sigma = \sqrt{120 \cdot \frac{1}{6} \cdot \frac{5}{6}} = \frac{10}{\sqrt{6}} \approx 4.08$.
      $P(14.5 \le X \le 23.5) = \Phi\left(\frac{23.5-20}{4.08}\right) - \Phi\left(\frac{14.5-20}{4.08}\right) = \Phi(0.85) - \Phi(-1.34) = 0.80 - 0.09 = \mathbf{0.71}$.
    - **Θέμα 5:** $k$ εκτιμητής: $\hat{k}_{\text{MM}} = \frac{2\bar{X}-1}{1-\bar{X}}$, $\hat{k}_{\text{MLE}} = -\frac{n}{\sum \ln X_i} - 1$.
    - **Θέμα 6:** $\sigma = 2, n = 9, \bar{x} = \frac{57}{9} = 6.33$.
      $99\%$ Δ.Ε. ($z_{0.005} = 2.58$): $6.33 \pm 2.58 \frac{2}{3} = [4.61, 8.05]$.
