# Πιθανότητες
Ιούνιος 2020

1. (α) Ποια η πιθανότητα να φέρουμε τουλάχιστον μια φορά άσσο σε 3 ζαριές με ένα ζάρι;  
(β) Ποια η πιθανότητα να φέρουμε τουλάχιστον μια φορά άσσο σε 12 ζαριές με δύο ζάρια;

2. Έστω τ.μ. $X$ τέτοια ώστε:
$$P\{X = 1\} = p = 1 - P\{X = -1\}$$
Βρείτε μία $c \ne 1$ (ως συνάρτηση της $p$) τέτοια ώστε $E[c^X] = 1$.

3. Σε ένα ψηφιακό κανάλι επικοινωνίας, υποθέτουμε ότι η πιθανότητα να λάβουμε λανθασμένο ένα bit είναι $10^{-5}$, και ότι τα λάθη λήψης είναι ανεξάρτητα για τα διάφορα bits. Εάν μεταδίδονται 16 εκατομμύρια bits ποια η πιθανότητα να συμβούν περισσότερα από 150 λάθη; Δώστε α) ακριβή τύπο β) προσέγγιση.

    ## iounios_2020_lyseis.pdf (σελ. 2-4)

    $\downarrow$ βιβλίου σελ 32 Παρ 1.1.6

    ΙΟΥΝΙΟΣ 2020,

    α) Ποια η πιθανότητα να φέρουμε ΤΟΥΛΑΧΙΣΤΟΝ 1 φορά ΑΣΣΟ σε 3 ζαριές με ένα ζάρι;  
    Α: τουλάχιστον μια φορά άσσο σε 3 ζαριές  
    Στη ρίψη ενός ζαριού, το απλό ενδεχόμενο μπορεί να παρασταθεί όπου κάθε συνιστώσα συμβολίζει το αποτέλεσμα στην αντίστοιχη ρίψη ζαριού:  
    $\Omega = \{(\alpha, \beta, \gamma) : \alpha, \beta, \gamma = 1, 2, \dots, 6\}$  
    άρα $6^3$ ισοπίθανα στοιχεία.

    Α': όταν καμία από τις συνιστώσα του απλού ενδεχομένου ΔΕΝ ισούται με άσσο.  
    Άρα $A' = \{(\alpha, \beta, \gamma) : \alpha, \beta, \gamma = 2, 3, 4, 5, 6\} : 5^3 \text{ ισοπίθ. στοιχ.}$

    $$P(A) = 1 - P(A') = 1 - \left(\frac{5}{6}\right)^3 \Rightarrow$$

    $$P(A) = 0{,}413$$

    Στην ρίψη 2 ζαριών: $36^{12}$ ισοπίθανα στοιχεία

    $B'$: σε 12 ζαριές με 2 ζάρια καμία φορά άσσο: $35^{12}$

    Έχω  
    $$P(B) = 1 - P(B)' = 1 - \frac{35^{12}}{36^{12}} = 1 - \left(\frac{35}{36}\right)^{12}$$

    Έχουμε: $P(x=1) = p$, $P(x=-1) = 1-p$  
    $E(x) = \sum_k p_k x_k \rightarrow E(c^x) = \sum_k p_k c^{x_k}$ ①

    $E(c^x) = 1 \xrightarrow[\text{για } k=1,-1]{①} E(c^x) = p_1 c^1 + p_{-1} c^{-1} = 1 \Rightarrow$

    $\Rightarrow p \cdot c + (1-p) \frac{1}{c} = 1 \Rightarrow \frac{c^2 p + 1 - p}{c} = 1 \Rightarrow$

    $\begin{pmatrix} p_1 = p \\ p_{-1} = 1-p \end{pmatrix} \Rightarrow c^2 p - c + (1-p) = 0$ ②

    Κλασικός τρόπος: $\Delta = (-1)^2 - 4 \cdot p \cdot (1-p) = 1 - (4p - 4p^2) = 4p^2 - 4p + 1 = (2p-1)^2 \ge 0$

    $$c_{1,2} = \frac{1 \pm (2p-1)}{2p} \begin{cases} 1 & \text{απορρ. αφού } c \ne 1 \\ \frac{2-2p}{2p} = \frac{1-p}{p} \end{cases}$$

    $2^{\text{ος}}$ τρόπος:  
    ② $\Rightarrow c^2 p - p - c + 1 = 0 \Rightarrow p(c^2 - 1) = c - 1 \Rightarrow$

    $\Rightarrow p = \frac{c-1}{c^2-1} \Rightarrow p = \frac{1}{c+1} \Rightarrow c+1 = 1/p \Rightarrow$

    $\Rightarrow c = \frac{1}{p} - 1 \Rightarrow c = \frac{1-p}{p}$

    3) Έστω $X$ τυχαία μεταβλητή (τ.μ.) που δείχνει τον αριθμό των λανθασμένων bit που λαμβάνουμε. Η $X$ ακολουθεί διωνυμική κατανομή με $p = 10^{-5}$ και $n = 16 \cdot 10^6$. Η πιθανότητα που θέλουμε είναι:  
    $\Pr\{X > 150\} = 1 - \Pr\{X \le 150\} = 1 - (\Pr\{X=0\} + \Pr\{X=1\} + \dots + \Pr\{X=150\}) =$  
    $$= 1 - \sum_{i=0}^{150} \Pr\{X=i\} = 1 - \sum_{i=0}^{150} \binom{16 \cdot 10^6}{i} (10^{-5})^i \cdot (1-10^{-5})^{16 \cdot 10^6 - i}$$

    Επειδή αυτή η πιθανότητα είναι δύσκολο να υπολογιστεί προσεγγίζουμε τη διωνυμική με την Poisson με $\lambda = p \cdot n = 160$ και έχουμε:  
    $\Pr\{X > 150\} = 1 - \Pr\{X \le 150\} = 1 - (\Pr\{X=0\} + \Pr\{X=1\} + \dots + \Pr\{X=150\}) =$  
    $$= 1 - \sum_{i=0}^{150} \Pr\{X=i\} = 1 - \sum_{i=0}^{150} e^{-\lambda} \frac{\lambda^i}{i!} = 1 - e^{-\lambda} \sum_{i=0}^{150} \frac{\lambda^i}{i!}$$

    Το τελευταίο άθροισμα μπορεί να προσεγγιστεί πολύ καλά από το $e^\lambda \dots$
