Άσκηση 5
Ένα παράλληλο σύστημα λειτουργεί όταν λειτουργεί τουλάχιστον ένα συστατικό τμήμα του. Έστω ένα παράλληλο σύστημα με n συστατικά τμήματα και έστω ότι κάθε τμήμα λειτουργεί, στοχαστικά ανεξάρτητα, με πιθανότητα 1/2. Βρείτε την πιθανότητα να λειτουργεί το τμήμα 1 του συστήματος, δοθέντος ότι το σύστημα λειτουργεί.

- [ ] $(1/4) / ((1/4)^n + (1/2)^n)$
- [ ] $(1/2)^{n+1} / ((1/4)^{n+1} + (1/2)^{n+1})$
- [ ] $((1/5) + (1/4)^2) / (1/2 - (1/2)^n)$
- [ ] $(1/2) / (1 - (1/2)^n)$
- [ ] $(3/4)^{n-1} / (1 - (1/2)^{n-1})$
- [ ] $(2/5)^{n+1} / ((1/4)^n + (1/2)^n)$
