    # Λύσεις — Πιθανότητες και Αρχές Στατιστικής — Δεκέμβριος 2020

    > Χειρόγραφες λύσεις φοιτητή για τις ασκήσεις 1, 2, 4, 5, 6 και 7 της δεύτερης προόδου. Τα τελικά αποτελέσματα των ασκήσεων συμφωνούν με μία από τις επιλογές της εκφώνησης.

    ## 1.jpg

    (1) Έστω $X$ τυχαία μεταβλητή που συμβολίζει τον αριθμό των κοινών σφαιρών με σύνολο τιμών $\Omega_X = \{1, 2, 3\}$

    Τότε $E(X) = \sum_{i=1}^3 x_i P(X = x_i)$

    Υπάρχουν 120 πιθανές τριάδες που κάθε παίχτης μπορεί να διαλέξει:
    $$\binom{10}{3} = 120$$

    $$P(X=3) = \frac{1}{120}$$

    • Για $X=1$:
    - Ο παίκτης Α μπορεί να διαλέξει 3 μπάλες, έστω $k_1, k_2, k_3$ (όπου $k_i \in \{1 \dots 10\}$)
    - Θέλουμε να έχει **ακριβώς μία** κοινή μπάλα με το Β
    - Έστω ότι έχουν κοινή την $k_1$
    Τότε οι πιθανοί συνδυασμοί με μοναδική κοινή σφαίρα την $k_1$ είναι $\binom{7}{2} = 21$
    Αλλά οποιαδήποτε από τις $k_1, k_2, k_3$ μπορεί να είναι κοινή άρα:
    $$P(X=1) = \frac{3 \cdot 21}{120} = \frac{63}{120}$$

    • Για $X=2$:
    - Και πάλι ο παίκτης Α μπορεί να διαλέξει 3 μπάλες, έστω $k_1, k_2, k_3$
    - Θέλουμε να έχει **ακριβώς δύο** κοινές με τον Β
    - Έστω ότι έχουν κοινές τις $k_1, k_2$
    Τότε οι πιθανοί συνδυασμοί με κοινές μπάλες τις $k_1, k_2$ είναι 7
    Αλλά οποιοδήποτε ζευγάρι από τις $k_1, k_2, k_3$ μπορεί να είναι κοινό άρα:
    $$P(X=2) = \frac{\binom{3}{2} \cdot 7}{120} = \frac{3 \cdot 7}{120} = \frac{21}{120}$$

    Άρα $E(X) = 1 \cdot \frac{63}{120} + 2 \cdot \frac{21}{120} + 3 \cdot \frac{1}{120} = \frac{63 + 42 + 3}{120} = \frac{108}{120} = 0{,}9$

    > Σημείωση: η φωτογραφία περιέχει χειρόγραφες απαντήσεις φοιτητή.

    ## 2.jpg

    (2) $Y = 2X \Leftrightarrow X = \frac{Y}{2}$ (1)

    $\Rightarrow \frac{dx}{dy} = \frac{1}{2} \Rightarrow \left|\frac{dx}{dy}\right| = \frac{1}{2}$

    οπότε $f_Y(y) = f_X(x) \cdot \left|\frac{dx}{dy}\right| = \frac{1}{2} f_X(x)$

    όμως λόγω της (1) $\Rightarrow f_Y(y) = \frac{1}{2} f_X(y/2)$

    Σωστή απάντηση το πρώτο

    > Σημείωση: η φωτογραφία περιέχει χειρόγραφες απαντήσεις φοιτητή.

    ## 4.jpg

    (4) Οι χρόνοι ζωής των λαμπτήρων ακολουθούν την εκθετική κατανομή με παράμετρο $\lambda = 0.2$

    Οπότε έχουμε: $\operatorname{Var}(x_i) = 25$

    • $\Lambda_{100} = \sum_{i=1}^{100} x_i$

    Οπότε θέλουμε να ισχύει $P(\Lambda_{100} > 525)$

    • Από το θεώρημα κεντρικού ορίου έχουμε:

    $$k = \frac{\Lambda_{100} - 100/0.2}{\sqrt{100 \cdot 25}} > \frac{525 - 500}{\sqrt{100 \cdot 25}} = \frac{25}{\sqrt{2500}} = \frac{1}{2}$$

    Άρα τελικά $P(S_{100} > 525) \approx P(k > 0.5) = 1 - \Phi(0.5) \approx 0.30$

    > Σημείωση: η φωτογραφία περιέχει χειρόγραφες απαντήσεις φοιτητή.

    ## 5.jpg

    (5) Έχουμε: $\operatorname{Var}(X) = \sigma^2 = 9$  
    $\mu = 20$

    • $P\{|X - \mu| \ge k\} \le \frac{\sigma^2}{k^2}$

    • Για μεταβλητή X που ακολουθεί κανονική κατανομή ισχύει:  
    $P(a \le X \le b) = P\left(\frac{a-\mu}{\sigma} \le Z \le \frac{b-\mu}{\sigma}\right) \Rightarrow$  
    $P(14 \le X \le 26) = P\left(\frac{14-20}{3} \le Z \le \frac{26-20}{3}\right) \Rightarrow$  
    $P(14 \le X \le 26) = P(-2 \le Z \le 2) \Rightarrow$  
    $P(14 \le X \le 26) = -0{,}02275 + 0{,}97725 = 0{,}9545 = A$ (από πίνακες)

    Από την ανισότητα Chebyshev ισχύει:  
    $$P\{|X - \mu| \le k\} \ge 1 - \frac{\sigma^2}{k^2} \Rightarrow P\{|X - 20| \le k\} \ge 1 - \frac{9}{k^2} \xrightarrow{k=6}$$  
    $$P\{14 \le X \le 26\} \ge 1 - \frac{9}{36} \Rightarrow P\{14 \le X \le 26\} \ge \frac{27}{36} = 0{,}75 = B$$

    Άρα $A - B \approx 0{,}2$

    > Σημείωση: η φωτογραφία περιέχει χειρόγραφες απαντήσεις φοιτητή.

    ## 6.jpg

    (6) Είναι $\Pi_X(z) = \frac{(1+z)^3}{8}$

    Ισχύει ότι $P(k) = P(X=k) = \frac{\Pi_X^{(k)}(0)}{k!}$

    Άρα $\Pi_X'(z) = \frac{1}{8} \cdot 3(z+1)^2$

    $\Pi_X''(z) = \frac{1}{8} \cdot 3 \cdot 2(z+1)$

    $$P(1 \le X \le 2) = \frac{\Pi_X''(0)}{2!} + \frac{\Pi_X'(0)}{1!} = \frac{6/8}{2} + 3/8 = \dots = 0{,}75$$

    > Σημείωση: η φωτογραφία περιέχει χειρόγραφες απαντήσεις φοιτητή.

    ## 7.jpg

    (7) Έχουμε τους παίκτες Α και Β οι οποίοι ρίχνουν διαδοχικά ένα ζάρι. Το παιχνίδι σταματά όταν ένας φέρει 5 με τον παίκτη Α να παίζει πρώτος. Θα υπολογίσουμε την πιθανότητα να κερδίσει ο Α.  
    Έχουμε:  
    $P(A) = \text{πιθανότητα να φέρει } 5 \text{ ο } A$  
    $P(B) = \text{πιθανότητα να φέρει } 5 \text{ ο } B$  
    $P(K) = \text{πιθανότητα να μην έρθει } 5$

    Αρχικά ο Α ρίχνει το ζάρι και έχουμε:  
    $$P(A) = \frac{1}{6} \qquad P(K) = \frac{5}{6}$$

    Αν δεν έρθει 5, ρίχνει ο Β και έχουμε:  
    $$P(A) = \frac{1}{6} = \frac{6}{36} \qquad P(B) = \frac{1}{6} \cdot \frac{5}{6} = \frac{5}{36} \qquad P(K) = \frac{5}{6} \cdot \frac{5}{6} = \frac{25}{36}$$

    Παρατηρούμε ότι από εδώ και πέρα το παιχνίδι επαναλαμβάνεται.  
    Ενώ η πιθανότητα να έχει τελειώσει είναι $P(T) = P(A) + P(B) = \frac{11}{36}$

    Με βάση αυτό, υπολογίζουμε την πιθανότητα να κερδίσει ο Α ως εξής:

    $$P(A') = \frac{P(A)}{P(T)} = \frac{\frac{6}{36}}{\frac{11}{36}} = \frac{6}{11} \approx 0{,}545$$

    > Σημείωση: η φωτογραφία περιέχει χειρόγραφες απαντήσεις φοιτητή.
