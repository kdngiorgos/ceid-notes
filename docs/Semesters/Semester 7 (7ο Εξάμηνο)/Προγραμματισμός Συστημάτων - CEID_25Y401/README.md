# Προγραμματισμός Συστημάτων

> Παράλληλος υπολογισμός από την πλευρά της αρχιτεκτονικής και των συστημάτων: ποσοτική ανάλυση απόδοσης (νόμος Amdahl, roofline, FLOP/s, εύρος ζώνης μνήμης, I/O throughput), ταξινομήσεις παραλληλίας (SIMD/MIMD, SMP/NUMA), συνοχή και συνέπεια κρυφής μνήμης (false sharing) και επιταχυντές (GPUs, DSAs). Στο πρακτικό μέρος ζητείται ανάπτυξη παράλληλου κώδικα με POSIX Threads και OpenMP και αξιολόγηση της απόδοσης με εργαλεία μετρητών. Διδάσκεται/εξετάζεται για πρώτη φορά το 2025-26, οπότε δεν υπάρχουν παλιά θέματα.

## Τι θα μάθεις

Το επίσημο περίγραμμα ορίζει δύο άξονες: αρχιτεκτονική/συστήματα παράλληλου υπολογισμού και πρακτικό παράλληλο προγραμματισμό [Περίγραμμα](https://www.ceid.upatras.gr/assets/2026/07/CEID_ΝΝΥ401_GR.pdf). Συγκεκριμένα:

- Ποσοτική ανάλυση απόδοσης: νόμος του Amdahl, μοντέλο roofline, μετρικές FLOP/s, latency, memory bandwidth και throughput.
- Ταξινομήσεις παραλληλίας: Flynn, SIMD/MIMD, συμμετρικοί πολυεπεξεργαστές (SMP) και NUMA, τοπολογίες δικτύων πολυεπεξεργαστών.
- Ιεραρχία κρυφής μνήμης, μηχανισμοί συνοχής (coherence) και συνέπειας (consistency), false sharing.
- Επιταχυντές, GPU αρχιτεκτονικές και αρχιτεκτονικές συγκεκριμένου τομέα (DSAs, π.χ. systolic arrays).
- Εξαρτήσεις δεδομένων, διανυσματικές εντολές και αξιοποίηση του μεταγλωττιστή για αποδοτικό κώδικα.
- Διεργασίες και νήματα επιπέδου πυρήνα/χρήστη, POSIX Threads και OpenMP, εργαλεία μέτρησης απόδοσης.
