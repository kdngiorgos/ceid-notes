# Βάσεις Δεδομένων — Ιανουάριος 2021 (Θέματα 1–2)

## unknown-2.png

**Θέμα 1: Σχεδίαση ΒΔ** [30 μονάδες]
Θεωρήστε μια βάση δεδομένων η οποία θα διατηρεί πληροφορία για μια βιβλιοθήκη. Οι πληροφορίες που πρέπει να διατηρούνται περιλαμβάνουν την πόλη και τη διεύθυνση στην οποία βρίσκεται η βιβλιοθήκη καθώς και τα τηλέφωνα επικοινωνίας. Στη βιβλιοθήκη εργάζεται ένας αριθμός υπαλλήλων για τους οποίους θέλουμε να γνωρίζουμε το ΑΦΜ τους, το ονοματεπώνυμο και τον μισθό που λαμβάνουν. Για τους υπαλλήλους που εργάζονται ως βιβλιοθηκονόμοι καταγράφουμε επίσης το πτυχίο που κατέχουν καθώς και τα χρόνια εμπειρίας τους. Κάθε βιβλιοθήκη διατηρεί έναν μεγάλο αριθμό βιβλίων διαθέσιμα προς δανεισμό. Για κάθε ένα από τα βιβλία θέλουμε να γνωρίζουμε το ISBN, τον τίτλο, τον συγγραφέα, τον εκδοτικό οίκο και τέλος τον συνολικό αριθμό των αντιτύπων. Τα βιβλία δανείζονται από τη βιβλιοθήκη τα μέλη της για τα οποία γνωρίζουμε το ονοματεπώνυμό τους, τη διεύθυνσή τους και ένα τηλέφωνο επικοινωνίας, ενώ για κάθε δανεισμό καταχωρείται και πληροφορία σχετικά με την ημερομηνία δανεισμού και την προβλεπόμενη ημερομηνία επιστροφής του βιβλίου.
i. Σχεδιάστε ένα διάγραμμα E-R για την παραπάνω εφαρμογή και διατυπώστε γραπτώς τις υποθέσεις που κάνατε. (20 μονάδες)
ii. Μετατρέψτε το E-R διάγραμμα που σχεδιάσατε σε σχεσιακό όπου θα φαίνονται τα κλειδιά (ξένα, πρωτεύοντα, κτλ) της κάθε σχέσης. (10 μονάδες)

**Θέμα 2: Γλώσσες Επερωτήσεων** [20 μονάδες]
Έστω μια βάση δεδομένων με τις παρακάτω σχέσεις:
- **_Προϊόν_** (<u>ID</u>, όνομα, τιμή, περιγραφή)
- **_Πελάτης_** (<u>ID</u>, όνομα, τηλέφωνο)
- **_Αγορά_**(Πελάτης_ID, Προϊόν_ID, ημερομηνία)

Να γράψετε σε SQL και σχεσιακή άλγεβρα τα παρακάτω ερωτήματα:
1. Τα ονόματα των προϊόντων που κοστίζουν πάνω από Χ Ευρώ.
2. Τα ονόματα των πελατών που έχουν αγοράσει κάποιο προϊόν που κοστίζει πάνω από Υ Ευρώ.
3. Τα ονόματα και τις τιμές των προϊόντων που δεν έχουν αγοραστεί.
4. Τα ονόματα των πελατών που έχουν αγοράσει προϊόντα συνολικής αξίας άνω των Ζ Ευρώ.
