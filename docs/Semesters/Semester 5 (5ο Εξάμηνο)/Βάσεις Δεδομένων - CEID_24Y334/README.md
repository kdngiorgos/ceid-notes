# Βάσεις Δεδομένων

> Το μάθημα-βάση για κάθε σύγχρονο σύστημα λογισμικού: μοντέλο οντοτήτων-συσχετίσεων, σχεσιακό μοντέλο, σχεσιακή άλγεβρα και λογισμός, SQL/QBE, συναρτησιακές εξαρτήσεις και κανονικοποίηση, οργάνωση αρχείων, ευρετηριοποίηση/κατακερματισμός, δοσοληψίες και NoSQL. Το μισό της δουλειάς γίνεται στο εργαστήριο με MySQL: τέσσερις δια ζώσης ασκήσεις (ER, create/insert, select, stored procedures/triggers) και ένα μεγάλο project (σχεδιασμός ΒΔ + εφαρμογή Java με GUI), που εξετάζεται προφορικά.

## Τι θα μάθεις

Το επίσημο περίγραμμα ορίζει ως στόχους τη κατανόηση των βασικών εννοιών των ΣΔΒΔ, των μοντέλων δεδομένων, της SQL/QBE, τη φυσική αποθήκευση/προσπέλαση και τη μεθοδολογία σχεδίασης ΒΔ [Περίγραμμα](https://www.ceid.upatras.gr/sites/default/files/ceid_ny334_gr.pdf). Οι διαφάνειες θεωρίας ακολουθούν αυτή ακριβώς τη σειρά eClass (διαθέσιμο στο πλήρες πακέτο):

- Εισαγωγή στα ΣΔΒΔ, όψεις δεδομένων, επίπεδα αφαιρετικότητας eClass (διαθέσιμο στο πλήρες πακέτο).
- Μοντέλο Οντοτήτων-Συσχετίσεων (ER), σύνθετα/πλειότιμα γνωρίσματα, ισχυρές και ασθενείς οντότητες, εξειδίκευση/γενίκευση [Περίγραμμα](https://www.ceid.upatras.gr/sites/default/files/ceid_ny334_gr.pdf).
- Σχεσιακό μοντέλο, σχεσιακή άλγεβρα, σχεσιακός λογισμός πλειάδων και πεδίων eClass (διαθέσιμο στο πλήρες πακέτο).
- SQL (DDL/DML, συνενώσεις, συναθροιστικές, όψεις, εμφωλευμένα ερωτήματα) και QBE eClass (διαθέσιμο στο πλήρες πακέτο).
- Περιορισμοί ακεραιότητας, σκανδάλες, εξουσιοδότηση eClass (διαθέσιμο στο πλήρες πακέτο).
- Συναρτησιακές εξαρτήσεις, κλειστότητες, ελάχιστο κάλυμμα και κανονικοποίηση (1NF–3NF/BCNF, αποσύνθεση χωρίς απώλειες) eClass (διαθέσιμο στο πλήρες πακέτο).
- Αποθήκευση και δομές αρχείων, ευρετηριοποίηση (B-trees/B+-trees) και κατακερματισμός eClass (διαθέσιμο στο πλήρες πακέτο).
- Χωρικές μέθοδοι προσπέλασης (k-d trees, quadtrees, R-trees), βελτιστοποίηση επερωτήσεων, δοσοληψίες/κλείδωμα και σύγχρονες ΒΔ (MapReduce, NoSQL, NewSQL) eClass (διαθέσιμο στο πλήρες πακέτο).

Το εργαστήριο στοχεύει στην πρακτική σχεδίαση και υλοποίηση σχεσιακών ΒΔ με MySQL σε 4 ενότητες: (1) ανάλυση απαιτήσεων και ER/σχεσιακό διάγραμμα, (2) δημιουργία ΒΔ (create/insert), (3) υποβολή ερωτημάτων (select/update/delete), (4) προγραμματισμός (triggers, stored procedures)· ολοκληρώνεται με ΒΔ πλήρους έκτασης και εφαρμογή Java για προβολή/μεταβολή δεδομένων [Περίγραμμα](https://www.ceid.upatras.gr/sites/default/files/ceid_ny334_gr.pdf).
