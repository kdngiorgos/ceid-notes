**ΘΕΜΑ 1 [2Μ]:** Εξηγείστε τι κάνουν οι 2 παρακάτω κώδικες. Ποιο είναι το βασικό σημείο στο οποίο διαφέρουν?

Κώδικας 1 (αριστερά):

```c
#include <stdio.h>
#include <stdlib.h>
#include <unistd.h>
#include <sys/wait.h>

int main(void)
{
    int i, tmp;

    pid_t pid[4];

    for (i=0; i<4; i++) {
        pid[i] = fork();
        if (pid[i] == 0) {
            break;
        }
    }

    if (pid[0] != 0 && pid[1] != 0 && pid[2] != 0 && pid[3] != 0) {
        // That's the father, it waits for all the childs
        printf("I'm the father [pid: %d, ppid: %d]\n", getpid(), getppid());
        for(i=0; i<4; i++) {
            wait(&tmp);
        }
    } else {
        // That's the child, it print its pid, its parent pid and exits
        printf("I'm one of the children [pid: %d, ppid: %d]\n", getpid(), getppid());
    }

    return 0;
}
```

Κώδικας 2 (δεξιά):

```c
#include <stdio.h>
#include <stdlib.h>

#define N 4

int main()
{
    int i;
    int pid;

    for (i=0; i<N; i++)
    {
        pid = fork();
        if (pid > 0)
        {
            printf(" Father = %5i, Id = %5i\nChild = %5i\n", getppid(), getpid(), pid);
            wait(NULL);
            break;
        }
    }

    return (0);
}
```

> [δυσανάγνωστο: τμήματα του κώδικα 2 (π.χ. η γραμμή `printf` και η ακριβής μορφή των `#include`) — η φωτογραφία είναι θολή· η μεταγραφή είναι ενδεικτική των διαφορών.]

**ΘΕΜΑ 2 [2Μ]:**

binary semaphore S1, S2, S3;  
S1 = ?;  
S2 = ?;  
S3 = ?;

| Διεργασία Δ1 | Διεργασία Δ2 | Διεργασία Δ3 |
| :--- | :--- | :--- |
| begin | begin | begin |
| ?? | ?? | ?? |
| print("Β"); | print("Α"); | print("Δ"); |
| ?? | ?? | ?? |
| print("Γ"); | print("Ζ"); | print("Ε"); |
| ?? | ?? | ?? |
| end | end | end |

Έστω τρεις διεργασίες, Δ1, Δ2 και Δ3, που εκτελούνται «παράλληλα», δηλ. εκτελούνται σύμφωνα με το σχήμα εκτέλεσης "cobegin Δ1; Δ2; Δ3; coend". Η διεργασία Δ1 εκτυπώνει αρχικά το γράμμα "Β" και μετά το γράμμα "Γ". Η διεργασία Δ2 εκτυπώνει αρχικά το γράμμα "Α" και μετά το γράμμα "Ζ". Η διεργασία Δ3 εκτυπώνει αρχικά το γράμμα "Δ" και μετά το γράμμα "Ε".

> [Λείπει από τη φωτογραφία: η παράγραφος με την ζητούμενη τελική έξοδο ("ΑΒΓΔΕΖ") και η σημείωση για τα σημεία με «??».]

**ΘΕΜΑ 3 [2Μ]:** Πέντε διεργασίες εισέρχονται σε ένα υπολογιστικό σύστημα με χρόνους άφιξης και εκτέλεσης οι οποίοι παρατίθενται στον παρακάτω πίνακα της επόμενης σελίδας (σε msec):

(i) Έστω ότι χρησιμοποιείται ο αλγόριθμος RR (Round Robin) με κβάντο χρόνου 8ms. Σχεδιάστε το διάγραμμα Gantt που αντιστοιχεί στην εκτέλεση των ανωτέρω διεργασιών στην ΚΜΕ και υπολογίστε το Χρόνο Αναμονής (ΧΑ) για τη διεργασία P5.

(ii) Σχεδιάστε ξανά το διάγραμμα Gantt για την εκτέλεση των ανωτέρω διεργασιών, υποθέτοντας τώρα ότι χρησιμοποιείται ο αλγόριθμος SRTF (Shortest Remaining Time First), και υπολογίστε εκ νέου το Χρόνο Αναμονής (ΧΑ) για τη διεργασία P5.

**Σημείωση:** Και για τους δύο αλγόριθμους θεωρήστε πως ο χρόνος εναλλαγής είναι αμελητέος.

| Διεργασία | Χρόνος Άφιξης | Χρόνος Εκτέλεσης |
| :---: | :---: | :---: |
| $\text{P}_1$ | 0 | 25 |
| $\text{P}_2$ | 4 | 12 |
| $\text{P}_3$ | 7 | 8 |
| $\text{P}_4$ | 10 | 15 |
| $\text{P}_5$ | 12 | 10 |

**ΘΕΜΑ 4 [2Μ]:** Θεωρείστε ένα σύστημα διαχείρισης μνήμης με Σελιδοποίηση (Paging), στο οποίο κάθε διεργασία μπορεί να έχει 32 σελίδες λογικής μνήμης. Μια διεργασία που εκτελείται στο σύστημα διαθέτει τον παρακάτω πίνακα σελίδων (όλοι οι αριθμοί είναι εκφρασμένοι στο δεκαδικό σύστημα):

| Αριθμός Σελίδας | Αριθμός Πλαισίου | Έγκυρο/ Άκυρο bit |
| :---: | :---: | :---: |
| 0 | 4 | 0 |
| ... | ... | ... |
| 7 | 15 | 1 |
| ... | ... | ... |
| [δυσανάγνωστο] | [δυσανάγνωστο] | [δυσανάγνωστο] |
| ... | ... | ... |
| 31 | [δυσανάγνωστο] | 0 |

Γνωρίζοντας πως το μέγεθος σελίδας στο παραπάνω σύστημα είναι 1024 bytes, ποια από τις παρακάτω προτάσεις είναι σωστή;

- [ ] (Α) Με 14 bits καλύπτεται το εύρος των λογικών διευθύνσεων της συγκεκριμένης διεργασίας.
- [ ] (Β) Η λογική διεύθυνση $\text{FFFF}_{16}$ (στο δεκαεξαδικό σύστημα) είναι μια έγκυρη λογική διεύθυνση της συγκεκριμένης διεργασίας, σύμφωνα με τα ανωτέρω δεδομένα.
- [ ] (Γ) Η λογική διεύθυνση $\text{3CCC}_{16}$ (στο δεκαεξαδικό σύστημα) της συγκεκριμένης διεργασίας αντιστοιχεί στη φυσική διεύθυνση $\text{9CCC}_{16}$ (στο δεκαεξαδικό σύστημα).
- [ ] (Δ) Η λογική διεύθυνση $\text{7CCC}_{16}$ (στο δεκαεξαδικό σύστημα) αναφέρεται σε μία σελίδα της συγκεκριμένης διεργασίας, η οποία δεν είναι φορτωμένη στη φυσική μνήμη του συστήματος.
