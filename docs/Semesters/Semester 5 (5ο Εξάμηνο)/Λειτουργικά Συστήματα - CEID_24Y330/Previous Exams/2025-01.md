**ΘΕΜΑ 1 [2Μ]:** (α) Ζητείται να συμπληρώσετε τα σημεία όπου εμφανίζονται '???', στον παρακάτω αλγόριθμο συγχρονισμού Ν διεργασιών **Process_Pi** ($1 \le i \le N$), με τη χρήση της μεθόδου **test&set()**.

```text
Process_Pi
shared boolean lock; /* κοινή μεταβλητή, αρχικά, FALSE */
int tmp; /* τοπική μεταβλητή της εκάστοτε διεργασίας */

repeat
    begin
        tmp = ???;
        while (tmp == ???) do ???;
        <κρίσιμο τμήμα>
        ???;
        <μη-κρίσιμο τμήμα>
    end
forever;
```

```text
boolean Test&Set(boolean lock)
shared boolean lock; /* κοινή μεταβλητή, αρχικά, FALSE */
int tmp; /* τοπική μεταβλητή */

begin
    ??? = lock; lock = ???; return(tmp);
end
```

Παρατηρήστε ότι η Test&Set() είναι μια σύνθετη εντολή που εκτελεί δύο προσπελάσεις στη διαμοιραζόμενη μεταβλητή lock.  
Παρόλα αυτά υποθέτουμε ότι το υλικό υποστηρίζει την ατομική εκτέλεση της εντολής αυτής (π.χ. με χρήση registers).

(β) Ζητείται να συμπληρώσετε τον κώδικα κάθε διεργασίας δίνοντας, στα σημεία όπου εμφανίζονται '?', κατάλληλες εντολές P (ή wait ή down) / V (ή signal ή up) σε σημαφόρους (που πρέπει να αρχικοποιήσετε κατάλληλα) ώστε εξασφαλιστεί ότι κατά την εκτέλεση των διεργασιών θα εμφανίζεται επαναληπτικά η ακολουθία '1 2 3', ως εξής: 1 2 3 1 2 3 1 2 3 ... κοκ...

| Διεργασία P1 | Διεργασία P2 | Διεργασία P3 |
| :--- | :--- | :--- |
| while (TRUE) {<br>?<br>print("1");<br>?<br>} | while (TRUE) {<br>?<br>print("2");<br>?<br>} | while (TRUE) {<br>?<br>print("3");<br>?<br>} |

**ΘΕΜΑ 2 [2Μ]:** Το παρακάτω πρόγραμμα εκτελείται ακολουθιακά (σειριακά) και περιλαμβάνει επτά εντολές (Ε1, Ε2, ..., Ε7) εκχώρησης τιμής σε μεταβλητές. Κάθε εντολή του προγράμματος εκτελείται ατομικά – αδιαίρετα.

```text
begin
    E1: M := (D + E); E2: N := (F - G); E3: P := M * N; E4: Q := A / B;
    E5: R := C * P; E6: S := 5 - Q; E7: Z := S + R;
end
```

Σχεδιάστε τον γράφο προτεραιότητας (precedence graph), που υλοποιεί το πιο πάνω πρόγραμμα με τη μέγιστη δυνατή παραλληλία. Δημιουργήστε επτά θυγατρικές διεργασίες (με χρήση fork()) που να αντιστοιχούν στις παραπάνω επτά εντολές. Συγχρονίστε τις διεργασίες αυτές κατάλληλα, χρησιμοποιώντας εντολές σημαφόρων signal() και wait(). Η γονική διεργασία, θα περιμένει να περατωθούν οι θυγατρικές, για να τυπώσει το τελικό αποτέλεσμα Z.

**ΘΕΜΑ 4 [2Μ]:** (α) Δίνεται η παρακάτω ουρά (0 – 199) από αιτήσεις Ε/Ε (disk I/O requests):  
Queue [0 – 199]: 98, 182, 36, 121, 14, 123, 64, 66 με Head pointer: 52  
Δώστε όλα τα ενδιάμεσα βήματα εξυπηρέτησης (servicing) της ουράς, για κάθε έναν από τους παρακάτω αλγορίθμους δρομολόγησης (Disk Scheduling Algorithms): SSTF, SCAN, C-SCAN και C-LOOK.  
(β) Περιγράψτε όλα τα ενδιάμεσα βήματα της διαδικασίας pathname translation που εκτελεί ένα σύστημα αρχείων (file system), το οποίο δέχεται σαν είσοδο το pathname ../d1/d2/d3/hash.c και παράγει σαν έξοδο το Inode# του αρχείου hash.c

**ΘΕΜΑ 5 [2Μ]:** Υπολογίστε τους μέσους χρόνους διεκπεραίωσης (ΜΧΔ) και αναμονής (ΜΧΑ) για τους αλγορίθμους χρονοδρομολόγησης: (α) PP(Preemptive-Priority: προεκχωρητικός αλγόριθμος προτεραιότητας βάσει αύξουσας τιμής), με χρήση αλγορίθμου FCFS στις περιπτώσεις που έχουμε ίσες προτεραιότητες (β) RR (Round Robin) με κβάντο χρόνου 8 χρονικές μονάδες. Θεωρήστε πως αν τη χρονική στιγμή που μια νέα διεργασία έρχεται στο σύστημα, διακόπτεται η εκτέλεση μιας διεργασίας (γιατί τελειώνει το κβάντο χρόνου της), τότε η νέα διεργασία εισέρχεται πριν από αυτήν που διακόπτεται στην ουρά των έτοιμων διεργασιών.     Πολυτεχνική Σχολή

    α) Κατ' αρχάς μετατρέπεται η λογική διεύθυνση 2111E στο δυαδικό σύστημα και υπολογίζεται το $s$ και το $d$

    $$2111\text{E} = 0010\ 0001\ 0001\ 0001\ 1110 = 0010\ 0 \quad 001\ 0001\ 0001\ 1110$$

    Το $s = 0010\ 0 = 4$ και το $d = 001\ 0001\ 0001\ 1110 = 111\text{E}$

    Από τον πίνακα τμημάτων βλέπουμε πως το τμήμα 4 αρχίζει από τη φυσική διεύθυνση $6000_{16}$ και έχει μέγιστο μέγεθος $1000_{16}$.

    Το $d = 111\text{E} > 1000$ και επομένως υπάρχει λάθος διευθυνσιοδότησης και γίνεται παγίδευση (trap) στο ΛΣ.
