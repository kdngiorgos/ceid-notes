**ΘΕΜΑ 1º (μονάδες 20)** Θεωρείστε το παρακάτω γράφημα με αρχική κατάσταση Α και τελική κατάσταση την G. Οι τιμές στις ακμές είναι οι τιμές της συνάρτησης κόστους, ενώ οι τιμές στον πίνακα είναι οι τιμές της ευρετικής συνάρτησης.

> [Σχήμα: Κατευθυνόμενο γράφημα με κόμβους S, A, B, C, D, E, F, G. Ακμές και κόστη: S->A (1), S->B (2), A->C (1), B->C (2), C->D (1), C->E (2), D->F (1), E->F (2), F->G (100).]

| Heuristic |
| :--- |
| A = 100 |
| B = 2 |
| C = 91 |
| D = 99 |
| E = 1 |
| F = 90 |
| S = 90 |
| G = 0 |

**Α)** Να εκτελέσετε τις παρακάτω μεθόδους αναζήτησης: i) BestFS και ii) A*, δείχνοντας αναλυτικά τα βήματα που ακολουθεί κάθε αλγόριθμος μέχρι τη λύση. Αν τυχόν υπάρξει ισοβαθμία, επιλύστε αλφαβητικά.  
**Β)** Βρίσκουν οι αλγόριθμοι βέλτιστη λύση; Εξηγήστε συνοπτικά.

**Θέμα 2º (Μονάδες 20)** Σε ένα πρόβλημα μεγιστοποίησης εφαρμόζουμε προσομοιωμένη ανόπτηση (simulated annealing). Δίνονται τα παρακάτω πιθανά 5 βήματα του αλγορίθμου (όχι απαραίτητα ότι θα εκτελεστούν):

| α/α | Τρέχουσα κατάσταση | Πιθανή νέα κατάσταση | Θερμοκρασία |
| :---: | :---: | :---: | :---: |
| 1 | 120 | 50 | 20 |
| 2 | 120 | 50 | 500 |
| 3 | 120 | 100 | 20 |
| 4 | 120 | 100 | 500 |
| 5 | 120 | 130 | 1000 |

**Α)** Να ταξινομήσετε, με κατάλληλη τεκμηρίωση, τα βήματα αυτά από το πιθανότερο να εκτελεστεί μέχρι το λιγότερο πιθανό.  
**Β)** Αν στην προσομοιωμένη ανόπτηση η θερμοκρασία $T \to \infty$ ο αλγόριθμος συμπεριφέρεται σαν: i) κατάβαση κλίσης με επιλογή του καλύτερου ii) κατάβαση κλίσης με τυχαία επιλογή (στοχαστική) iii) κατάβαση κλίσης με επιλογή του $1^{\text{ου}}$ καλύτερου iv) τυχαία επανεκκίνηση v) κανένα από τα παραπάνω. Να τεκμηριώσετε την επιλογή σας.

**ΘΕΜΑ 3º (μονάδες 20)** Δίνονται οι παρακάτω προτάσεις ΚΛΠΤ:  
1. $\forall x, y, z, k\ (\text{parent}(x, z) \land \text{parent}(y, k) \land \text{sibling}(x, y)) \Rightarrow \text{cousin}(z, k)$  
2. $\text{parent}(\text{maria}, \text{Χρήστης#0715})$  
3. $\text{parent}(\text{giannis}, \text{kostas})$  
4. $\text{sibling}(\text{maria}, \text{giannis})$

**Α)** Ελέγξτε με την μέθοδο αντίφασης της επίλυσης εάν από τις παραπάνω προτάσεις (1)-(4) προκύπτει το συμπέρασμα $\text{cousin}(\text{Χρήστης#0715}, \text{kostas})$.  
**Β)** Να γράψετε τις παραπάνω προτάσεις σε Prolog. Πώς μπορείτε να εκφράσετε τη σχέση cousin ως συμμετρική, ώστε το ερώτημα ?-cousin(X,Y) να τερματίζει;

**ΘΕΜΑ 4º (μονάδες 20)**

> [Σχήμα: Διάγραμμα τεχνητού νευρώνα με εισόδους $x_1, x_2$, βάρη $w_1, w_2$, άθροιση/συνάρτηση ενεργοποίησης $\sigma(z)$ και έξοδο $\hat{y}$]

Δίνεται νευρώνας με εισόδους $\mathbf{x} = [1.0, 2.0]^T$ και βάρη $\mathbf{w} = [w_1, w_2]^T = [-0.5, 0.3]^T$. Η συνάρτηση ενεργοποίησης είναι η $\sigma(z) = \frac{1}{1 + e^{-z}}$ και η συνάρτηση απώλειας η $E = \frac{1}{2}(y - \hat{y})^2$. Η επιθυμητή έξοδος είναι $y = 1.0$.

**Α)** Υπολογίστε την έξοδο $\hat{y} = \sigma(z) = \sigma(w_1 x_1 + w_2 x_2)$ (Forward Pass).  
**Β)** Υπολογίστε την τιμή της παραγώγου της sigmoid για το συγκεκριμένο $z$ δεδομένου ότι είναι $\sigma'(z) = \sigma(z)(1 - \sigma(z))$. Δίνεται: $e^x \approx 1 + x + \frac{x^2}{2!} + \frac{x^3}{3!}$  
**Γ)** Υπολογίστε την κλίση του σφάλματος ως προς το βάρος $w_1$ χρησιμοποιώντας τον κανόνα της αλυσίδας: $\frac{\partial E}{\partial w_1} = \frac{\partial E}{\partial \hat{y}} \frac{\partial \hat{y}}{\partial z} \frac{\partial z}{\partial w_1}$  
**Δ)** Πραγματοποιήστε μια ενημέρωση του βάρους $w_1$ με ρυθμό μάθησης $\eta = 0.1$:
$$w_1^{\text{new}} = w_1^{\text{old}} - \eta \frac{\partial E}{\partial w_1}$$

**ΘΕΜΑ 5º (μονάδες 20)**

Κάποια χαρακτηριστικά των καιρικών συνθηκών (outlook, temperature, humidity, windy) χρησιμοποιούνται για να αποφασίσουμε αν θα πραγματοποιηθεί (yes) ή όχι (no) ένας αγώνας κρίκετ. Διαθέτουμε τα δεδομένα του ακόλουθου πίνακα, στον οποίο επίσης φαίνονται οι πιθανές τιμές που μπορεί να λάβει κάθε χαρακτηριστικό. Χρησιμοποιώντας την Αφελή Μπεϋζιανή κατηγοριοποίηση καλείστε να αποφασίσετε αν θα πραγματοποιηθεί ο αγώνας Χ ο οποίος έχει τα εξής χαρακτηριστικά $X =$ {outlook = rain, temperature = hot, humidity = high, windy = true}.

| Outlook | Temperature | Humidity | Windy | Class |
| :--- | :--- | :--- | :--- | :--- |
| sunny | hot | High | false | NO |
| sunny | hot | High | true | NO |
| overcast | hot | High | false | YES |
| Rain | mild | High | false | YES |
| Rain | cool | Normal | false | YES |
| Rain | cool | Normal | true | NO |
| overcast | cool | Normal | true | YES |
| sunny | mild | High | false | NO |
| sunny | cool | Normal | false | YES |

**Α)** Υπολογίστε τις πιθανότητες $p(\text{yes})$, $p(\text{no})$. (2 μονάδες)  
**Β)** Υπολογίστε τις πιθανότητες $P(\text{sunny}|\text{yes})$, $P(\text{overcast}|\text{yes})$, $P(\text{rain}|\text{yes})$, $P(\text{sunny}|\text{no})$, $P(\text{overcast}|\text{no})$, $P(\text{rain}|\text{no})$ και τις αντίστοιχες πιθανότητες για τα χαρακτηριστικά temperature, humidity, windy. (8 μονάδες)  
**Γ)** Πως διαμορφώνεται η πιθανότητα $P(X|\text{yes})$ κάνοντας χρήση της βασικής υπόθεσης του Μπεϋζιανού κατηγοριοποιητή; Ομοίως υπολογίστε την $P(X|\text{no})$. (8 μονάδες)  
**Δ)** Σε ποια κλάση κατατάσσετε τον αγώνα Χ; (2 μονάδες)
