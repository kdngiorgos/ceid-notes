Αν εφαρμόσουμε την μέθοδο ‘αλυσίδωση προς τα εμπρός’ (forward chaining) και την μέθοδο ‘αλυσίδωση προς τα πίσω’ (backward chaining) σε μια βάση κανόνων για να εξάγουμε το ίδιο αποτέλεσμα, ποιο από τα παρακάτω ισχύει (όπου ο όρος «πιο αποδοτική» σημαίνει πυροδότηση λιγότερων κανόνων);  

- [ ] Η αλυσίδωση προς τα εμπρός είναι σίγουρα πιό αποδοτική  
- [ ] Η αλυσίδωση προς τα πίσω είναι σίγουρα πιό αποδοτική  
- [ ] Η αλυσίδωση προς τα εμπρός είναι πιθανότατα πιό αποδοτική  
- [ ] Η αλυσίδωση προς τα πίσω είναι πιθανότατα πιό αποδοτική

- [ ] $(\forall x)\ (\forall y)\ (\forall z)\ ((\text{μητέρα}(y,x) \land \neg \text{μητέρα}(z,x)) \lor (\text{μητέρα}(y,x) \land z=y))$

**Ερώτηση 7 / 8** (Πολλαπλής Επιλογής (Μοναδική Απάντηση) — 2 βαθμοί)  

Σε ένα σύστημα κανόνων που χρησιμοποιεί συντελεστές βεβαιότητας, υπάρχουν οι παρακάτω δύο κανόνες:  

| R1 | R2 |
| :--- | :--- |
| if shape is long<br><br>then fruit is pear (0.4) | if shape is long<br><br>and color is yellow<br><br>then fruit is pear (0.6) |

Δίνονται τα εξής δεδομένα: “shape is long (0.8)”, “color is yellow (0.7)”. Μετά την ενεργοποίηση/πυροδότηση των κανόνων, στην μνήμη εργασίας θα αποθηκευτεί το εξής αποτέλεσμα: ME ={ fruit is pear (CF12)}. Ποιο από τα παρακάτω είναι η τιμή του CF12;  

- [ ] 0.32  
- [ ] 0.42  
- [ ] 0.6056  
- [ ] 0.8744

**ΤΕΧΝΗΤΗ ΝΟΗΜΟΣΥΝΗ-ΣΕΠΤΕΜΒΡΙΟΣ 2020** (CEID_NY451)

**Ερώτηση 8 / 8** (Πολλαπλής Επιλογής (Μοναδική Απάντηση) — 1.50 βαθμοί)  

Δίνονται οι παρακάτω προτάσεις σε προτασιακή μορφή:  
(1) {R, ¬Q, ¬P}  
(2) {R, ¬Q, ¬T}  
(3) {Q}  
(4) {P, ¬S}  
(5) {Q, ¬T}  
(6) {S}  
(7) {¬R}  

Για να αποδείξουμε ότι το σύνολο αυτό είναι μη ικανοποιήσιμο, εφαρμόζουμε την διαδικασία της αντίφασης της επίλυσης με στρατηγική ελέγχου την P1 Επίλυση. Η προς απόδειξη πρόταση ήταν η R, η οποία έχει εισαχθεί στο σύνολο ως {¬R}. Ποια από τις παρακάτω ακολουθίες επιλύσεων θα προκύψει (όπου π.χ. (7)-(1) $\Rightarrow$ (8) σημαίνει επίλυση των (7) και (1) και παραγωγή της (8));  

- [ ] (7)-(1) $\Rightarrow$ (8), (8)-(5) $\Rightarrow$ (9), (9)-(4) $\Rightarrow$ (10), (10)-(6) $\Rightarrow$ {}  
- [ ] (7)-(1) $\Rightarrow$ (8), (8)-(3) $\Rightarrow$ (9), (9)-(4) $\Rightarrow$ (10), (10)-(6) $\Rightarrow$ {}  
- [ ] (3)-(1) $\Rightarrow$ (8), (6)-(4) $\Rightarrow$ (9), (9)-(8) $\Rightarrow$ (10), (10)-(7) $\Rightarrow$ {}  
- [ ] (7)-(2) $\Rightarrow$ (8), (8)-(5) $\Rightarrow$ (9), (9)-(4) $\Rightarrow$ (10), (10)-(6) $\Rightarrow$ {}
