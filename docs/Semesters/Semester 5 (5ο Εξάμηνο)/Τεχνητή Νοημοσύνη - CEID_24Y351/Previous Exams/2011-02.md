## 2024-06-24_2.13.59_.png

**Άσκηση 3 (Θέμα 4 - Φεβρουάριος 2011)**

Δίνονται οι παρακάτω πέντε κανόνες που χρησιμοποιούν συντελεστές βεβαιότητας (ΣΒ) και αποτελούν τη βάση κανόνων ενός συστήματος.

a. Αν δοθούν τα παρακάτω δεδομένα διαδοχικά με την σειρά που γράφονται, περιγράψτε την διαδικασία εξαγωγής συμπερασμάτων του συστήματος (πυροδοτούμενοι κανόνες, υπολογισμοί ΣΒ και περιεχόμενα της ΜΕ): “shape is long (0.7)”, “color is green (0.8)”, “connection is bunch”. Ποιο είναι το αποτέλεσμα της διαδικασίας;

| R1 | R2 | R3 |
| :--- | :--- | :--- |
| If shape is long<br>then fruit is banana<br>(0.5) | If shape is long and color is<br>yellow then fruit is banana<br>(0.8) | If shape is long and color<br>is green then fruit is pear<br>(0.6) |

| R5 | R4 | R2’ |
| :--- | :--- | :--- |
| If shape is long and color is<br>green and connection is free<br>then fruit is pear (0.9) | If shape is long and color is yellow<br>and connection is bunch<br>then fruit is banana (0.9) | If shape is long and (color is<br>yellow or connection is bunch)<br>then fruit is banana (0.8) |
