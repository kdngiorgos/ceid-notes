# Τεχνητή Νοημοσύνη — 2021 (online κουίζ, μερικό)

## ZuEMRR6.png

Ερώτηση 10 / 20 (Πολλαπλής Επιλογής (Μοναδική Απάντηση) — 6 βαθμοί)

Εφαρμογή Αλγορίθμου AC-3 (X,Y,Z,W)
Έστω οι μεταβλητές X, Y, Z και W, με πεδία $D_X = D_Y = D_Z = D_W = \{1,2,3,4\}$ και περιορισμούς $X > Y$, $Z < X$, και $W \le Y$. Ποια θα είναι τα πεδία των μεταβλητών μετά την εφαρμογή του αλγορίθμου AC-3;

- [ ] $D_X = \{2,3,4\}, D_Y = \{1,2,3\}, D_Z = \{1,2,3\}, D_W = \{1,2\}$
- [ ] $D_X = \{2,3,4\}, D_Y = \{1,2,3\}, D_Z = \{1,2,3\}, D_W = \{1,2,3\}$
- [ ] $D_X = \{2,3\}, D_Y = \{1,2\}, D_Z = \{1,2\}, D_W = \{1,2\}$
- [ ] $D_X = \{3,4\}, D_Y = \{1,2\}, D_Z = \{1,2,3\}, D_W = \{1\}$
