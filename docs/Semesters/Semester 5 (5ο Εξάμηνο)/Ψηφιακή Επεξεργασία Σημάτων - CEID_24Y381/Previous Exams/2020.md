Ερώτηση 1 / 3 (Πολλαπλής Επιλογής (Μοναδική Απάντηση) — 1 βαθμός)

Στην είσοδο ενός ΓΧΑ συστήματος με κρουστική απόκριση $h(n)$ οδηγούμε μια ασθενώς στάσιμη 2ης τάξης στοχαστική διαδικασία. Τι από τα παρακάτω θα πρέπει να ισχύει ώστε η στοχαστική μέση τιμή της διαδικασίας εξόδου να ταυτίζεται με αυτή της εισόδου;

- [ ] $\|h\|_2 = 1$
- [ ] $\|h\|_1 < \infty$
- [ ] $\|h\|_2 = \frac{1}{\sigma_w^2}$
- [ ] Να είναι το σύστημα FIR


Ερώτηση 2 / 3 (Πολλαπλής Επιλογής (Μοναδική Απάντηση) — 1 βαθμός)

Θεωρήστε ότι στην είσοδο ενός πραγματικού, αιτιατού FIR φίλτρου μήκους $4N + 1$ οδηγείτε λευκό θόρυβο μέσης ισχύος $\sigma_w^2$. Ποιά η μέση ισχύς της εξόδου;

- [ ] $\sigma_w^2 \sum_{n=0}^{4N} h_n^2$
- [ ] $\sigma_w^2 |H(1)|^2$
- [ ] $(2N + 1)\sigma_w^2$
- [ ] $(N + 1)\sigma_w^2$
