Ερώτηση 2 (Πολλαπλής Επιλογής (Μοναδική Απάντηση) — 1 βαθμός)

Αν

$$R(e^{j\omega}) = D(e^{j\omega})$$

$$\phi(\omega) = -k\omega$$

και $y_0(n)$, $y(n)$ οι έξοδοι του ιδανικού και του πραγματικού συστήματος αντίστοιχα για είσοδο $x(n)$. Ποιά η σχέση που συνδέει τις $y_0(n)$ και $y(n)$;

- [ ] $y(n) = y_0(n - k)$
- [ ] $y(n) = y_0(n + k)$
- [ ] $y(n) = \frac{y_0(n-k) + y_0(n+k)}{2}$
- [ ] $y(n) = y_0(n)$
