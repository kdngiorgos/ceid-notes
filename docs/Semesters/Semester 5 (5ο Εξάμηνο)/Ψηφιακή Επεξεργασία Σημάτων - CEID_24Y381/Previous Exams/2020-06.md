Ερώτηση 4 (Πολλαπλής Επιλογής (Μοναδική Απάντηση) — 1 βαθμός)

Θέλουμε να σχεδιάσουμε ένα FIR φίλτρο μήκους $2N+1$, που θα προσεγγίζει την άρτιας συμμετρίας απόκριση συχνότητας ενός ιδανικού συστήματος, με την τεχνική των Σειρών Fourier και επιπλέον $\int_0^{\pi} D(e^{j\omega})\,d\omega = 0$. Ποιά σχέση θα χρησιμοποιούμε;

- [ ] $h_n = \frac{1}{2\pi}\int_{-\pi}^{\pi} D(e^{j\omega})\,e^{-jn\omega}\,d\omega$
- [ ] $h_n = \frac{1}{\pi}\int_0^{\pi} D(e^{j\omega})\cos(n\omega)\,d\omega$
- [ ] $h_n = \frac{1}{\pi}\int_0^{\pi} D(e^{j\omega})\sin(n\omega)\,d\omega$
- [ ] $h_n - \frac{1}{\pi}\int_0^{\pi} D(e^{j\omega})\,e^{-jn\omega}\,d\omega$
