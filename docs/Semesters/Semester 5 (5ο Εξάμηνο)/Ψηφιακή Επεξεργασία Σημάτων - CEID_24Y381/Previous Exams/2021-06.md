# Ψηφιακή Επεξεργασία Σημάτων — Ιούνιος 2021

> Η μεταγραφή προέρχεται από τα στιγμιότυπα και τις φωτογραφίες της εξέτασης Ιουνίου 2021.

## 2021-06-12_172211.png

Αν $\mathcal{X}(t,\theta) = \mathcal{A}(\theta)\sin(\Omega_0 t) + \mathcal{B}(\theta)\sin(\Omega_1 t)$ όπου $\mathcal{A}(\theta)$ τυχαία μεταβλητή με συνάρτηση πυκνότητας πιθανότητας Γκαουσιανή $N(0,4)$ και $\mathcal{B}(\theta)$ τυχαία μεταβλητή με συνάρτηση πυκνότητας πιθανότητας ομοιόμορφη στο $[-1,1]$. Η διαδικασία $\mathcal{X}(t,\theta)$ είναι:

- [ ] Ασθενώς στάσιμη 2ης τάξης
- [ ] Τίποτα από τα υπόλοιπα
- [ ] Εργοδική 1ης τάξης
- [ ] Ασθενώς στάσιμη 1ης τάξης
- [ ] Αυστηρώς στάσιμη 1ης τάξης

## 2021-06-13_190413.png

Θεωρήστε ότι θέλετε να προσεγγίσετε με ένα FIR φίλτρο μήκους $2N + 1$ ένα ιδανικό ΓΧΑ σύστημα του οποίου η απόκριση συχνότητας έχει άρτια συμμετρία.

Ποιά από τις παρακάτω $R(e^{j\omega})$ θα χρησιμοποιούσατε;

- [ ] (a) $R(e^{j\omega}) = \sum_{n=0}^{N} \alpha_n \cos(n\omega)$
- [ ] (b) $R(e^{j\omega}) = \sum_{n=0}^{2N} \alpha_n \cos(n\omega)$
- [ ] (c) $R(e^{j\omega}) = \sum_{n=1}^{N} \alpha_n \sin(n\omega)$
- [ ] (d) $R(e^{j\omega}) = \sum_{n=1}^{2N} \alpha_n \sin(n\omega)$

> [Λείπει από τη φωτογραφία: κείμενο στο κάτω άκρο της εικόνας, μετά την επιλογή (d)]

## Capture.PNG

Στην είσοδο ενός ΓΧΑ συστήματος με κρουστική απόκριση h(n) οδηγούμε μια ασθενώς στάσιμη 2ης τάξης στοχαστική διαδικασία μηδενικής μέσης τιμής. Τι από τα παρακάτω θα πρέπει να ισχύει ώστε η διασπορά της διαδικασίας εξόδου να ταυτίζεται με αυτή της εισόδου;

- [ ] a. $\|h\|_2^2 = 1$
- [ ] b. $\|h\|_1 < \infty$
- [ ] c. $\|h\|_2 = \frac{1}{\sigma_w^2}$
- [ ] d. Να είναι το σύστημα FIR

> Σημείωση: η φωτογραφία περιέχει χειρόγραφες απαντήσεις φοιτητή.

## Screenshot_2021-06-13_at_7.49.08_PM.png

Ερώτηση 1 (Πολλαπλής Επιλογής (Μοναδική Απάντηση) — 1 βαθμός)

Αν η απόκριση πλάτους ενός FIR φίλτρου δίνεται από την σχέση

$$R(e^{j\omega}) = \sum_{n=1}^{N} \alpha_n \sin(n\omega)$$

Τι μήκος και τι συμμετρία έχει το φίλτρο;

- [ ] $2N + 1$ και άρτια
- [ ] $2N$ και άρτια
- [ ] $2N + 1$ και περιττή
- [ ] $2N$ και περιττή

## Screenshot_6.png

Ερώτηση 2 (Πολλαπλής Επιλογής (Μοναδική Απάντηση) — 1 βαθμός)

Θέλουμε να σχεδιάσουμε ένα FIR φίλτρο μήκους 2N+1 με την τεχνική των Σειρών Fourier. Ποιά σχέση θα χρησιμοποιήσουμε για τον υπολογισμό των βέλτιστων συντελεστών;

- [ ] $h_n = \frac{1}{2\pi} \int_{-\pi}^{\pi} D(e^{j\omega}) e^{-jn\omega} d\omega$
- [ ] $h_n = \frac{1}{\pi} \int_{0}^{\pi} D(e^{j\omega}) \sin(n\omega) d\omega$
- [ ] $h_n = \frac{1}{\pi} \int_{0}^{\pi} D(e^{j\omega}) \cos(n\omega) d\omega$
- [ ] $h_n = \frac{1}{\pi} \int_{0}^{\pi} D(e^{j\omega}) e^{-jn\omega} d\omega$
