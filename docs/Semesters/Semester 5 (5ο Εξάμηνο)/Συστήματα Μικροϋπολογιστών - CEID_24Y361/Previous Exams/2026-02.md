## Messenger_creation_449609D7-3344-4415-9F33-5991707F20F8.jpg

1. Να σχεδιαστεί και να εξηγηθεί αναλυτικά ο κύκλος απαίτησης και αναγνώρισης για τη διακοπή NMI~.

2. Θέλετε να προγραμματίσετε για το PIO του Z80, τη θύρα Α, στην κατάσταση λειτουργίας τρία (mode 3). Όπου οι περιττού αριθμού ακροδέκτες ($2\nu+1$) θα είναι είσοδοι και οι άρτιου αριθμού ακροδέκτες ($2\nu$) θα είναι έξοδοι. Θα επιτρέπονται διακοπές στη διεύθυνση ABCD (Hex), όταν δύο ακροδέκτες εισόδου ($\kappa$, $\kappa+2$), θα βρίσκονται σε υψηλή στάθμη δυναμικού. α) Να γράψετε όλες τις απαιτούμενες λέξεις διανυσμάτων, β) να εξηγήσετε αναλυτικά την τιμή του κάθε ψηφίου που επιλέξατε για καθεμία λέξη.

3. Να σχεδιαστεί και να εξηγηθεί αναλυτικά ο χρονισμός των σημάτων, για την εντολή STORE B2 (Hex), R2.

4. Να αναπτυχθεί ρουτίνα που να μετράει λάθη στο κανάλι 2, υπό μορφή παλμών, στη γραμμή CLK/TRG1, κατ' επιλογή με ή χωρίς διακοπές, για μέγιστο πλήθος 0A.

5. Θεωρείστε ένα μικροϋπολογιστικό σύστημα με τέσσερεις περιφερειακές συσκευές: α) να γράψετε και να εξηγήσετε επαρκώς το διάγραμμα λειτουργίας του, σε συνδυασμό των τεχνικών interrupts και polling, β) πως θα ανταποκριθεί το σύστημα για μια παραπάνω επεξεργασία;

6. Θεωρείστε ένα σύστημα ασφαλείας τράπεζας, που ενεργοποιείται και απενεργοποιείται με τη χρήση δύο μηχανισμών βιομετρικών αισθητήρων, έναν για κάθε λειτουργία. Να σχεδιαστεί το κατάλληλο σύστημα, να αναπτυχθεί και να εξηγηθεί ο κώδικας του προγραμματισμού του, με τη χρήση διάταξης τύπου Arduino.
