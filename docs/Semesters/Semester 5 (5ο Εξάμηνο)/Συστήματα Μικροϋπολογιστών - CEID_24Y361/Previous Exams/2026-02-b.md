# Συστήματα Μικροϋπολογιστών — Φεβρουάριος 2026 (παραλλαγή Β)

> Μεταγραφή από τη φωτογραφία `sklabos.png` (πέντε θέματα).

## sklabos.png

Ερωτήματα

1. Σε μια παράλληλη θύρα εισόδου/εξόδου ο καταχωρητής κατάστασης έχει την τιμή «31» (Hexadecimal) και οδηγεί μια συστοιχία από οκτώ leds, με τιμή διαύλου εξόδου «BC» (Hexadecimal). Να γράψετε τις αντίστοιχες εντολές του προγράμματος, για να διατηρήσετε μόνο την κατάσταση λειτουργίας όλων των leds, στις θέσεις με περιττό αριθμό. Να εξηγήσετε τον τρόπο εργασίας σας.

2. Θέλετε να προγραμματίσετε το PIO του Z80, στην κατάσταση λειτουργίας ένα (mode 1). α) Να γράψετε όλες τις απαιτούμενες λέξεις διανυσμάτων (10%), β) να εξηγήσετε αναλυτικά την τιμή του κάθε ψηφίου που επιλέξατε για καθεμία λέξη (10%).

3. Να σχεδιαστεί (10%) και να εξηγηθεί αναλυτικά (10%) ο χρονισμός των σημάτων, της εντολής HALT.

4. Θεωρείστε ένα Ultrasonic Sensor Module, που υπολογίζει την απόσταση από αντικείμενα μπροστά του, στέλνοντας έναν υπέρηχο και μέσω του χρόνου που κάνει το σήμα για να επιστρέψει στον αισθητήρα υπολογίζει την απόσταση. Να γραφεί και να εξηγηθεί ο κώδικας του προγραμματισμού του, για διάταξη Arduino Uno.

5. Υπολογίστε το μέγεθος αρχείου bitmap (10%) και εξηγήστε τη διαδικασία (10%). Θεωρήστε εικόνα 640x480 pixels, με 24-bit βάθος χρώματος (RGB).
