    Λύση

    Κάθε περιοχή διευθύνσεων μνήμης που δίνεται, έχει συνολική χωρητικότητα $400\text{h} = 0100\ 0000\ 0000 = 2^{10} \text{ θ.μ.} = 2^{10} \text{ bytes}$ (λόγω της οργάνωσης που έχουμε 1byte/θ.μ.). Αυτό σημαίνει ότι για να γεμίσουμε την κάθε περιοχή χρειαζόμαστε μνήμες SRAM του 1 KB. Για κάθε τέτοια μνήμη χρησιμοποιούμε ένα χάρτη διευθύνσεων (memory map) για να προσδιορίσουμε τα bits από το address bus που χρειάζονται για την επιλογή της κάθε μνήμης με τρόπο μοναδικό.

    Χάρτης μνήμης (Memory Map)
    | hex | $A_{15} \dots A_{12}$ | binary | $A_0$ | |
    |---|---|---|---|---|
    | 0000: | 0000 | 0000 0000 0000 | | $\text{SRAM}_1$ |
    | 03FF: | 0000 | 0011 1111 1111 | | |
    | 1000: | 0001 | 0000 0000 0000 | | $\text{SRAM}_2$ |
    | 13FF: | 0001 | 0011 1111 1111 | | |
    | 3000: | 0011 | 0000 0000 0000 | | $\text{SRAM}_3$ |
    | 33FF: | 0011 | 0011 1111 1111 | | |
    | F000: | 1111 | 0000 0000 0000 | | $\text{SRAM}_4$ |
    | F3FF: | 1111 | 0011 1111 1111 | | |

    Από το χάρτη μνήμης βρίσκουμε τα σταθερά bits για κάθε μια περιοχή διευθύνσεων από τις τέσσερις συνολικά περιοχές που έχουμε, τα οποία χρησιμοποιούνται για την επιλογή του κάθε ΟΚΜ.

    > [Σχήμα: Σχεδιάγραμμα διασύνδεσης ΚΜΕ με 4 μνήμες SRAM1, SRAM2, SRAM3, SRAM4 των 1KB (γραμμές A0-A9, D0-D7, R/W~, CE~). Οι γραμμές διευθύνσεων A15-A10 συνδέονται σε λογικές πύλες αποκωδικοποίησης (OR, AND/NOR) για την παραγωγή των σημάτων ενεργοποίησης CE~ κάθε μνήμης, καθώς και κοινός δίαυλος δεδομένων Data bus 8 bits.]
