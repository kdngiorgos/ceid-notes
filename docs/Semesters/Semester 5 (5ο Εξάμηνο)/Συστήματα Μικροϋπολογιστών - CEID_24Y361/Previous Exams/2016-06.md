# Συστήματα Μικροϋπολογιστών — Ιούνιος 2016

## 2016_.pdf

<u>Θεμαηα Μικποϋπολογιζηέρ 22/6/2016</u>

1. Διάγπαμμα σπονιζμού για έναν κύκλο Μ1 ηηρ πποζκόμιζηρ κυδικού opcode ηηρ επόμενηρ ππορ εκηέλεζηρ ενηολήρ και εξήγηζη. (1/3)

<mark>Απάνηηζη: ενόηηηα 3</mark>

2. Για ηο PIO ηος Z80 να ηεθεί η θύπα Α ζε λειηοςπγία mode 1 και να εξηγηθούν ηα βήμαηα. (1/3) <mark>Απάνηηζη: ενόηηηα 7</mark>

3. Για ηο μικποελεγκηή ATtiny2313 θέηυ απσικά ζηη ζηοίβα ηην ηιμή 83H, ποιο ηο μέγιζηο πλήθορ ππόζθεηυν ποςηινών και εξήγηζη. (1/3)

<mark>Απάνηηζη: ζελίδα 351</mark>

4. Σε μια παπάλληλη θύπα ειζόδος/εξόδος ο καηασυπηηήρ καηάζηαζηρ έσει ηην ηιμή «AF»Hexademical και οδηγεί μια ζςζηοισία από οκηώ leds, με ηιμή διαύλος εξόδος «FA»H. Να ανηιζηπέτεηε ηην καηάζηαζη λειηοςπγίαρ ηυν leds ζηιρ θέζειρ με πεπιηηό απιθμό. Να εξηγήζεηε ηα βήμαηα ζαρ. (1/3) <mark>Απάνηηζη: ενόηηηα 11</mark>

Να απανηηθούν ηα 3 από ηα 4 θέμαηα.

Επιπλέον θέμα (2 μονάδερ):

Να γίνει διάγπαμμα σπονιζμού για ένα από ηα ηπία (1 μονάδα) και να να εξηγηθεί (1 μονάδα)

- i. Αναγνώπιζη NMI

- ii. Αναγνώπιζη INT

- iii. Εκηέλεζη HALT

<mark>Απάνηηζη: ενόηηηα 4</mark>
