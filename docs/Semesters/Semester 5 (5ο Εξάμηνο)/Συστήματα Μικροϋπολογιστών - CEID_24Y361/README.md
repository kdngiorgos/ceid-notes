# Συστήματα Μικροϋπολογιστών

> Το υποχρεωτικό μάθημα υλικού του 5ου εξαμήνου: πώς είναι στημένος ένας μικροϋπολογιστής, πώς λειτουργεί η CPU, η μνήμη και τα περιφερειακά, και πώς προγραμματίζονται συγκεκριμένες οικογένειες (Z80, ATtiny/AVR, Cortex, Arduino/Raspberry). Στην πράξη εξετάζει κατά βάση σχεδίαση και εξήγηση: διαγράμματα χρονισμού εντολών του Z80, μετάβαση/ανάλυση καταστάσεων, συστήματα με περιφερειακές συσκευές, και προγραμματισμό μικροελεγκτών.

## Τι θα μάθεις

Το επίσημο περίγραμμα ορίζει έξι στόχους: υλοποίηση του μοντέλου ενός σύγχρονου μικροϋπολογιστή, κατανόηση/προγραμματισμό διατάξεων συγκεκριμένων οικογενειών, ικανότητα σχεδίασης μικροεπεξεργαστή, σχεδίαση/προγραμματισμό μικροελεγκτών, διασύνδεση περιφερειακών και πιστοποίηση ορθής λειτουργίας μέσω εργαλείων εξομοίωσης [Κατάλογος: Περίγραμμα](https://www.ceid.upatras.gr/sites/default/files/ceid_ny361_gr.pdf). Η ύλη καλύπτει:

- Δομή μικροϋπολογιστή και μικροϋπολογιστικού συστήματος, CPU, ALU, καταχωρητές.
- Στοιχεία μνήμης: SRAM, DRAM/SDRAM, ROM, διευθυνσιοδότηση, άμεση προσπέλαση (DMA).
- Κύκλος εντολής/μηχανής/ρολογιού, θύρες εισόδου-εξόδου, χρονιστές, μετρητές, ελεγκτές διακοπών.
- Zilog Z80: καταχωρητές, ακροδέκτες/χρονισμοί, σύνολο εντολών, διακοπές INT/NMI.
- Οικογένεια Intel, μικροελεγκτές 8/32-bit (π.χ. ATMEL), επανεκκίνηση, σειριακή/παράλληλη επικοινωνία.
- Αρχιτεκτονικές RISC/CISC και σύγχρονες εφαρμογές [Κατάλογος: Περίγραμμα](https://www.ceid.upatras.gr/sites/default/files/ceid_ny361_gr.pdf).

Στην πράξη, οι διαφάνειες και οι ασκήσεις του μαθήματος δίνουν μεγάλο βάρος στα διαγράμματα χρονισμού του Z80, στο PIO, στους μικροελεγκτές ATtiny/Arduino και σε θέματα Cortex/Raspberry Discord 2025-01 (διαθέσιμο στο πλήρες πακέτο).
