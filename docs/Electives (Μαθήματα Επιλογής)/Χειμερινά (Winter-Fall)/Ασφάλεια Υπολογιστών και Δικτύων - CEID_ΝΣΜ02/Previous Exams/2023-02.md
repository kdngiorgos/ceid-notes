**Ερωτ.2** Πως υλοποιείται μια TCP reset επίθεση ?
- [ ] Στέλνει ψεύτικα TCP reset πακετά και τερματίζει μια TCP σύνδεση

**Ερωτ.11** Πως υλοποιείται μια Ping Flood επίθεση από έναν επιτιθέμενο?
- [ ] Είναι ένας τύπος επίθεσης άρνησης υπηρεσίας στην οποία ένας μεγάλος αριθμός πακέτων User Datagram Protocol (UDP) αποστέλλεται σε έναν στοχευμένο διακομιστή με σκοπό να μειώσει την ικανότητα της να επεξεργάζεται και να αποκρίνεται την κανονική εισερχόμενη κίνηση του. Το τείχος προστασίας που προστατεύει τον στοχευμένο διακομιστή μπορεί επίσης να εξαντληθεί.
- [ ] Είναι μια επίθεση άρνησης εξυπηρέτησης (DoS), στην οποία ο εισβολέας στοχεύει να διαταράξει μια δικτυακή συσκευή στέλνοντας ένα πακέτο μεγαλύτερο από το μέγιστο επιτρεπόμενο μέγεθος, προκαλώντας την αδυναμία εκτέλεσης διεργασιών (crash).
- [ ] Είναι μια επίθεση άρνησης εξυπηρέτησης στην οποία ο εισβολέας προσπαθεί να κατακλύσει μια στοχευμένη συσκευή με πακέτα echo-request ICMP, με αποτέλεσμα ο στόχος να γίνει απρόσιτος στην κανονική κίνηση.
- [ ] Ένας εισβολέας δημιουργεί άρνηση υπηρεσίας, εκμεταλλευόμενος το γεγονός ότι μετά τη λήψη ενός αρχικού πακέτου SYN, ο διακομιστής θα ανταποκριθεί με ένα ή περισσότερα πακέτα SYN / ACK και θα περιμένει το τελικό βήμα στη χειραψία, το οποίο δεν έλθει ποτέ.

**Ερωτ.12** Για την ασφαλή αποθήκευση ενός αρχείου, μια εφαρμογή backup εκτελεί δύο (2) λειτουργίες στο αρχείο: (α) συμπίεση και (β) κρυπτογράφηση. Με ποια σειρά είναι προτιμότερη η εκτέλεση των δύο λειτουργιών και για ποιο λόγο;
- [ ] Συμπίεση - κρυπτογράφηση για υψηλότερη ταχύτητα
- [ ] Συμπίεση - κρυπτογράφηση για υψηλότερη ταχύτητα και μικρότερο αρχείο - αποτέλεσμα
- [ ] Κρυπτογράφηση - συμπίεση για μικρότερο αρχείο - αποτέλεσμα
- [ ] Δεν κάνει διαφορά

**Ερωτ.13** Πως υλοποιείται μια Ping of Death επίθεση από έναν επιτιθέμενο?
- [ ] Επιτίθεται σε σύστημα προσωρινής αποθήκευσης δεδομένων.
- [ ] Στέλνει ένα μεγάλο αριθμό UDP πακέτων σε έναν στοχευμένο διακομιστή για να μειώσει την ικανότητά του να επεξεργάζεται και να αποκρίνεται την κανονική εισερχόμενη κίνηση του.
- [ ] Προσπαθεί να κατακλύσει μια στοχευμένη συσκευή με πακέτα echo-request ICMP
- [ ] Στέλνει ένα πακέτο μεγαλύτερο από το μέγιστο επιτρεπόμενο μέγεθος, προκαλώντας την αδυναμία εκτέλεσης διεργασιών (crash)

**Ερωτ.14** Τι αφορά η SYN flood attack?
- [ ] Είναι μια επίθεση άρνησης εξυπηρέτησης (DoS), στην οποία ο εισβολέας στοχεύει να διαταράζει μια δικτυακή συσκευή στέλνοντας ένα πακέτο μεγαλύτερο από το μέγιστο επιτρεπόμενο μέγεθος, προκαλώντας την αδυναμία εκτέλεσης διεργασιών (crash).
- [ ] Ένας εισβολέας δημιουργεί άρνηση υπηρεσίας, εκμεταλλευόμενος το γεγονός ότι μετά τη λήψη ενός αρχικού πακέτου SYN, ο διακομιστής θα ανταποκριθεί με ένα ή περισσότερα πακέτα SYN / ACK και θα περιμένει το τελικό βήμα στη χειραψία, το οποίο δεν έλθει ποτέ.
