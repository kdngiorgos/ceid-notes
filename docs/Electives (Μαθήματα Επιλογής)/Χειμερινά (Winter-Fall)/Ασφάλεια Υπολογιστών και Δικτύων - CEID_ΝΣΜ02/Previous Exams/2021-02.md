Θέμα 14

Το σύστημα Linux χρησιμοποιεί τον αλγόριθμο κατακερματισμού MD5 για την αποθήκευση των κωδικών (passwords) των χρηστών. Κατά τη διαδικασία login, ο κωδικός password του χρήστη κωδικοποιείται σε MD5(password) και συγκρίνεται με το αποθηκευμένο κατακερματισμένο password για τον συγκεκριμένο χρήστη. Ισότητα στη σύγκριση οδηγεί σε ολοκλήρωση της διαδικασίας login, διαφορετικά η διαδικασία διακόπτεται.

Η μεθοδολογία επιτυγχάνει τα παρακάτω: (πολλαπλή επιλογή)

- [ ] Προστασία πρόσβασης των αρχείων ενός χρήστη από άλλους χρήστες
- [ ] Προστασία των κωδικών χρηστών εάν διαρρεύσει το αποθηκευμένο αρχείο passwords
- [ ] Αδυναμία του διαχειριστή συστήματος να μάθει τα passwords των χρηστών
- [ ] Αδυναμία επιτιθέμενου να μαντέψει το password νόμιμου χρήστη

> Σημείωση: η φωτογραφία περιέχει σημάνσεις απαντήσεων φοιτητή (μπλε τετράγωνα), που δεν μεταγράφονται.

Θέμα 15

Τι αφορά η SYN flood attack;

- [ ] Είναι μια επίθεση άρνησης εξυπηρέτησης στην οποία ο εισβολέας προσπαθεί να κατακλύσει μια στοχευμένη συσκευή με πακέτα echo-request ICMP, με αποτέλεσμα ο στόχος να γίνει απρόσιτος στην κανονική κίνηση.
- [ ] Ένας εισβολέας δημιουργεί άρνηση υπηρεσίας, εκμεταλλευόμενος το γεγονός ότι μετά τη λήψη ενός αρχικού πακέτου SYN, ο διακομιστής θα ανταποκριθεί με ένα ή περισσότερα πακέτα SYN / ACK και θα περιμένει το τελικό βήμα στη χειραψία, το οποίο δεν έλθει ποτέ.
- [ ] Είναι μια επίθεση άρνησης εξυπηρέτησης (DoS), στην οποία ο εισβολέας στοχεύει να διαταράξει μια δικτυακή συσκευή στέλνοντας ένα πακέτο μεγαλύτερο από το μέγιστο επιτρεπόμενο μέγεθος, προκαλώντας την αδυναμία εκτέλεσης διεργασιών (crash)
- [ ] Είναι ένας τύπος επίθεσης άρνησης υπηρεσίας στην οποία ένας μεγάλος αριθμός πακέτων User Datagram Protocol (UDP) αποστέλλεται σε έναν στοχευμένο διακομιστή με σκοπό να μειώσει την ικανότητα της να επεξεργάζεται και να αποκρίνεται την κανονική εισερχόμενη κίνηση του. Το τείχος προστασίας που προστατεύει τον στοχευμένο διακομιστή μπορεί επίσης να εξαντληθεί.

Θέμα 19

Τι αφορά η επίθεση DNS amplification attack;

- [ ] Αφορά επιθέσεις πλημμύρας στους DNS servers που σκοπό έχουν να τους κατακλύσουν με requests ώστε να εμποδίσουν τους νόμιμους χρήστες να έχουν πρόσβαση στους διακομιστές DNS του παρόχου.
- [ ] Αφορά κακόβουλη επίθεση όπου συσκευές υποβάλλουν πολλά αιτήματα για πολύ μεγάλες εγγραφές DNS σε δημόσιους nameservers, αλλά κατά την υποβολή των αιτημάτων, ο εισβολέας αλλάζει τη διεύθυνση επιστροφής για να είναι αυτή του στόχου -θύματος.
- [ ] Είναι μια επίθεση πλημμύρας όταν ένας εισβολέας προσπαθεί να υπερφορτώσει έναν διακομιστή με πακέτα TCP ACK. Όπως και άλλες επιθέσεις DDoS, ο στόχος μιας πλημμύρας ACK είναι να αρνηθεί την υπηρεσία σε άλλους χρήστες επιβραδύνοντας ή κάνοντας μη προσπελάσιμο τον διακομιστή χρησιμοποιώντας ανεπιθύμητα δεδομένα.
- [ ] Αφορά επίθεση επαναφοράς της σύνδεσης TCP, που είναι ένας τρόπος παραβίασης και τερματισμού της σύνδεσης ενός χρήστη στο Διαδίκτυο στέλνοντας ένα πλαστό πακέτο επαναφοράς TCP. Αυτή η τεχνική παραβίασης μπορεί να χρησιμοποιηθεί από ένα τείχος προστασίας ή από έναν κακόβουλο εισβολέα για να διακόψει τις συνδέσεις στο Διαδίκτυο.

    | :--- | :--- | :--- |
    | 2. DNS Cache Poisoning | E | B. Επίθεση με στόχο την επαναχρησιμοποίηση μιας υπάρχουσας καταχώρησης DNS (γενικά CNAME) που σχετίζεται με έναν δημόσιο πόρο cloud που έχει καταργηθεί |
    | 3. DNS Hijacking - Farming | D | C. Οι εγγραφές DNS τροποποιούνται σε επίπεδο καταχωρητή (μετά από παραβίαση των διαπιστευτηρίων του διαχειριστή) και οι χρήστες ανακατευθύνονται σε κακόβουλο ιστότοπο από τη χρήση έγκυρων τομέων. |
