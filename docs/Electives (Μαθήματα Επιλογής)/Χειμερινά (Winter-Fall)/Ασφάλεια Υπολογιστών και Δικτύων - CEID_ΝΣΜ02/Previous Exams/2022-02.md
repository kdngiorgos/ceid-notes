11. Πως υλοποιείται μια memcached DDoS επίθεση από έναν επιτιθέμενο?
- [ ] Προσπαθεί να κατακλύσει μια στοχευμένη συσκευή με πακέτα echo-request ICMP
- [ ] Επιτίθεται σε σύστημα προσωρινής αποθήκευσης δεδομένων.
- [ ] Στέλνει ένα πακέτο μεγαλύτερο από το μέγιστο επιτρεπόμενο μέγεθος, προκαλώντας αδυναμία εκτέλεσης διεργασιών (crash)
- [ ] Στέλνει ένα μεγάλο αριθμό UDP πακέτων σε έναν στοχευμένο διακομιστή για να μειώσει την ικανότητα του να επεξεργάζεται και να αποκρίνεται την κανονική εισερχόμενη κίνηση του

> [Λείπει από τη φωτογραφία: ο αριθμός της ερώτησης· το αριστερό άκρο κόβει την αρχή της διατύπωσης «Τι αφορά η SYN flood attack?»]

- [ ] Είναι μια επίθεση άρνησης υπηρεσίας στην οποία ο εισβολέας προσπαθεί να κατακλύσει μια στοχευμένη συσκευή με πακέτα echo-request ICMP, με αποτέλεσμα ο στόχος να γίνει απρόσιτος στην κανονική κίνηση
- [ ] Ένας εισβολέας δημιουργεί άρνηση υπηρεσίας, εκμεταλλευόμενος το γεγονός ότι μετά τη λήψη ενός αρχικού πακέτου SYN, ο διακομιστής θα ανταποκριθεί με ένα ή περισσότερα πακέτα SYN / ACK και θα περιμένει το τελικό βήμα στη χειραψία, το οποίο δεν έλθει ποτέ.
- [ ] Είναι μια επίθεση άρνησης υπηρεσίας (DoS), στην οποία ο εισβολέας στοχεύει να διαταράξει μια δικτυακή συσκευή στέλνοντας ένα πακέτο μεγαλύτερο από το μέγιστο επιτρεπόμενο μέγεθος, προκαλώντας την αδυναμία εκτέλεσης διεργασιών (crash).
- [ ] Είναι ένας τύπος επίθεσης άρνησης υπηρεσίας στην οποία ένας μεγάλος αριθμός πακέτων User Datagram Protocol (UDP) αποστέλλεται σε έναν στοχευμένο διακομιστή με σκοπό να μειώσει την ικανότητα της να επεξεργάζεται και να αποκρίνεται την κανονική εισερχόμενη κίνηση του. Το τείχος προστασίας που προστατεύει τον στοχευμένο διακομιστή μπορεί επίσης να εξαντληθεί.
