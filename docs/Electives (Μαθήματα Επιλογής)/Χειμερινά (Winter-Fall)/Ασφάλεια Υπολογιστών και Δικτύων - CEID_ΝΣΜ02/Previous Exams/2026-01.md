# Ασφάλεια Υπολογιστών και Δικτύων — Ιανουάριος 2026

> Μεταγραφή από το Screenshot_6.png.

## Screenshot_6.png

**Ερωτ.19** Πως υλοποιείται μια memcached DDoS επίθεση από έναν επιτιθέμενο?

- [ ] Στέλνει ένα μεγάλο αριθμό UDP πακέτων σε έναν στοχευμένο διακομιστή για να μειώσει την ικανότητά του να επεξεργάζεται και να αποκρίνεται την κανονική εισερχόμενη κίνηση του.
- [ ] Επιτίθεται σε σύστημα προσωπικής αποθήκευσης δεδομένων.
- [ ] Προσπαθεί να καταλύσει μια στοχευμένη συσκευή με πακέτα echo-request ICMP
- [ ] Στέλνει ένα πακέτο μεγαλύτερο από το μέγιστο επιτρεπόμενο μέγεθος, προκαλώντας την αδυναμία εκτέλεσης διεργασιών (crash).
