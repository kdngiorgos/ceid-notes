## IMG_5217.jpg

Πολυτεχνική Σχολή
Τμήμα Μηχανικών Ηλεκτρονικών Υπολογιστών & Πληροφορικής

Ακολουθούν μερικές απλές ερωτήσεις για τα θέματα των διαλέξεων. Κάθε ερώτηση έχει μία και μοναδική σωστή απάντηση και δεν υπάρχει αρνητική βαθμολόγηση, αλλά ο βαθμός θα συνεκτιμηθεί σε σχέση με την τυχαία απάντηση.

1. Ποιο μοντέλο cloud παρέχει έτοιμες εφαρμογές μέσω browser;
- [ ] IaaS
- [ ] PaaS
- [ ] SaaS
- [ ] FaaS

2. Ποιο χαρακτηριστικό αποτελεί βασικό όφελος του cloud computing;
- [ ] Δυνατότητα κλιμάκωσης ανάλογα με τη ζήτηση
- [ ] Μεγάλος χρόνος εγκατάστασης
- [ ] Σταθερή και μη μεταβαλλόμενη χωρητικότητα
- [ ] Ανάγκη για ιδιόκτητες υποδομές

3. Τι είναι το Serverless Computing;
- [ ] Εκτέλεση εφαρμογών χωρίς διαδίκτυο
- [ ] Εκτέλεση εφαρμογών χωρίς containers
- [ ] Εκτέλεση μόνο σε φυσικούς servers
- [ ] Εκτέλεση κώδικα σε containers που διαχειρίζεται ο πάροχος cloud

4. Τι χαρακτηρίζει τις μικροϋπηρεσίες;
- [ ] Κοινή βάση δεδομένων για όλες
- [ ] Μικρά, ανεξάρτητα τμήματα λογισμικού με σαφή interfaces
- [ ] Ανάπτυξη από μία μεγάλη ομάδα
- [ ] Υποχρεωτική μονολιθική αρχιτεκτονική

5. Ποια είναι βασική διαφορά containers και virtual machines;
- [ ] Τα containers έχουν δικό τους λειτουργικό σύστημα
- [ ] Οι VMs μοιράζονται τον kernel του host
- [ ] Οι VMs εκκινούν σε λίγα δευτερόλεπτα
- [ ] Τα containers μοιράζονται τον kernel του host και είναι πιο ελαφριά

6. Σε ποια φάση του κύκλου ζωής λογισμικού ανήκει συνήθως η Αντίστροφη Μηχανική;
- [ ] Ανάλυση απαιτήσεων
- [ ] Συντήρηση λογισμικού
- [ ] Σχεδίαση
- [ ] Υλοποίηση

7. Ποιος είναι βασικός στόχος της Αντίστροφης Μηχανικής;
- [ ] Η αντικατάσταση του συστήματος
- [ ] Η διαγραφή παλαιού κώδικα
- [ ] Η κατανόηση του προγράμματος
- [ ] Η αύξηση του μεγέθους του συστήματος

- [ ] Τη φυσική αρχιτεκτονική συστήματος

- [ ] Η επαναλαμβανόμενη αξιολόγηση και βελτίωση των διαδικασιών
- [ ] Η εφάπαξ ανασχεδίαση διαδικασιών
- [ ] Η αντικατάσταση όλων των διαδικασιών
- [ ] Η πλήρης αυτοματοποίηση

14. Σε τι επίπεδο λεπτομέρειας είναι ακριβές ένα Διάγραμμα Ροής Δεδομένων (DFD);

- [ ] Στην ακριβή χρονική στιγμή που εκτελείται κάθε διεργασία.
- [ ] Στο ποιες λειτουργίες γίνονται και όχι στο πώς.
- [ ] Στη δομή των πινάκων της βάσης δεδομένων.

- [ ] Διαχείριση υποδομής πληροφορικής

## IMG_5220.jpg

Πολυτεχνική Σχολή
Τμήμα Μηχανικών Ηλεκτρονικών Υπολογιστών & Πληροφορικής

16. Ποιο από τα παρακάτω περιγράφει καλύτερα τη διαδικασία BI;
- [ ] Ανάπτυξη πολύπλοκων αλγορίθμων
- [ ] Διαχείριση σχέσεων με τους πελάτες
- [ ] Μετατροπή ακατέργαστων δεδομένων σε αξιοποιήσιμες πληροφορίες
- [ ] Σχεδιασμός διεπαφών χρήστη

17. Ποια είναι η βασική διαφορά μεταξύ BI και Data Science;
- [ ] Το BI εστιάζει σε ιστορικά δεδομένα και αναφορές, ενώ το Data Science είναι προβλεπτικό
- [ ] Και τα δύο εστιάζουν σε μελλοντικές προβλέψεις
- [ ] Το Data Science χρησιμοποιείται για απεικόνιση δεδομένων, ενώ το BI όχι
- [ ] Δεν υπάρχει διαφορά μεταξύ BI και Data Science

18. Ποιος είναι ο σκοπός ενός data warehouse στη διαδικασία BI;
- [ ] Για την αποθήκευση μη δομημένων δεδομένων
- [ ] Για τη διαχείριση αλληλεπιδράσεων με τους πελάτες
- [ ] Για τη συλλογή δεδομένων σε πραγματικό χρόνο
- [ ] Για την παροχή κεντρικής αποθήκευσης καθαρών, δομημένων δεδομένων

19. Τι σημαίνει το ακρωνύμιο ETL στη διαδικασία BI;
- [ ] Extract, Transform, Load (Εξαγωγή, Μετασχηματισμός, Φόρτωση)
- [ ] Evaluate, Translate, Link (Αξιολόγηση, Μετάφραση, Σύνδεση)
- [ ] Enter, Track, Locate (Εισαγωγή, Παρακολούθηση, Εντοπισμός)
- [ ] Explore, Test, Learn (Εξερεύνηση, Δοκιμή, Μάθηση)

20. Σε μια τυπική αρχιτεκτονική BI, ποιος είναι ο ρόλος του ETL;
- [ ] Ανάλυση δεδομένων
- [ ] Απεικόνιση δεδομένων
- [ ] Μετασχηματισμός δεδομένων από πηγές σε data warehouse
- [ ] Δημιουργία αναφορών

21. Πώς ενσωματώνεται η τεχνητή νοημοσύνη (AI) στα εργαλεία BI;
- [ ] Για τον περιορισμό της πρόσβασης στα δεδομένα
- [ ] Για αυτοματοποιημένες πληροφορίες
- [ ] Για να καταστούν τα εργαλεία πιο πολύπλοκα
- [ ] Για τη μείωση της αλληλεπίδρασης με το χρήστη

22. Ποια είναι μια βασική πρόκληση στην εφαρμογή του BI;
- [ ] Έλλειψη διαθέσιμων εργαλείων
- [ ] Υπερβολικός αριθμός ειδικευμένων επαγγελματιών
- [ ] Θέματα ποιότητας δεδομένων
- [ ] Απλή τεχνολογία

23. Ποιο από τα παρακάτω είναι παράδειγμα κυβερνο-φυσικού συστήματος;
- [ ] Ένα αυτόνομο όχημα
- [ ] Ένα έξυπνο ψυγείο
- [ ] Ένα πλυντήριο ρούχων με σταθερούς κύκλους
- [ ] Ένα σύστημα διαχείρισης email
