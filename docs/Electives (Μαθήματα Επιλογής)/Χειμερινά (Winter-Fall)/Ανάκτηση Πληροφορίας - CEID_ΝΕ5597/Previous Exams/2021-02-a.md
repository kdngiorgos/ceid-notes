**(ΟΜΑΔΑ 1)**

**_ΘΕΜΑ 1_** ( _Μονάδες 3,5_ )

α. Θεωρώντας ότι ο αριθμός των επιστρεφόμενων κειμένων είναι 30, σχεδιάστε τα γραφήματα ανάκλησης ακρίβειας, για τα ακόλουθα ερωτήματα (δίνονται ο αριθμός των σχετικών κειμένων και η θέση τους στο αποτέλεσμα) :

- Μηχανή1 Αριθμός: 10, Θέση: 2, 3, 7, 9, 10, 13, 17, 20, 27, 29
- Μηχανή2 Αριθμός: 10, Θέση: 1, 2, 4, 8, 11, 12, 15, 16, 28, 30

Με βάση τα δύο προκύπτοντα γραφήματα ανάκλησης ακρίβειας συγκρίνετε μεταξύ τους τις δύο μηχανές.

Στη συνέχεια συγκρίνετε τις δύο μηχανές με χρήση των μετρικών **P@5, MRR** (Mean Reciprocal Rank – Μέσος Όρος Ανάστροφος Βαθμός) και **MAP** (Mean Average Precision – Μέσος Όρος Μέσης Ακρίβειας).

β. . Εξηγήστε πως μία δομή ανεστραμμένων αρχείων θα μπορούσε να χρησιμοποιηθεί για να χειριστεί κείμενα τα οποία δεν είναι χωρισμένα σε λέξεις αλλά ακολουθία χαρακτήρων όπου κάθε δυνατό πρότυπο που είναι υποσυμβολοσειρά της ακολουθίας μπορεί να αποτελέσει αντικείμενο ερώτησης.  Τέτοια κατηγορία κειμένων είναι τα κείμενα των CJK γλωσσών (Chinese, Japanese, Korean).

# **_ΘΕΜΑ 2_ (** Μονάδες 3,5)

α.Σύμφωνα με την _cluster hypothesis_ ( _υπόθεση ομαδοποίησης_ ), κείμενα που ανήκουν στην ίδια συστάδα ομαδοποίησης είναι και σχετικά για παρόμοιες αιτήσεις. Μία ερμηνεία αυτής της υπόθεσης είναι ότι κείμενα που είναι σχετικά ψηλά στην αξιολόγηση σε ένα ερώτημα πρέπει να _παρασύρουν_ και κείμενα της ίδιας ομάδας, ώστε να είναι αντίστοιχα ψηλά.  Εξηγήστε πως το μοντέλο διανυσματικού χώρου θα μπορούσε να τροποποιηθεί ώστε να ενσωματώσει την πληροφορία αυτή. β. Θεωρήστε ότι έχουμε μία συλλογή κειμένων και όρων που περιγράφεται από τον ακόλουθο πίνακα:

||**όρος1**|**όρος2**|**όρος3**|**όρος4**|**όρος5**|
|---|---|---|---|---|---|
|**Κειμ1**|0|1|2|2|0|
|**Κειμ2**|0|1|2|0|1|
|**Κειμ3**|0|1|0|1|0|
|**Κειμ4**|1|0|2|0|0|
|**Κειμ5**|0|2|1|0|0|
|**Κειμ6**|2|2|0|1|0|
|**Κειμ7**|3|1|0|2|1|
|**Κειμ8**|0|2|0|4|0|

Αναπαραστήστε τη συγκεκριμένη συλλογή χρησιμοποιώντας το μοντέλο διανυσματικού χώρου, και αποθηκεύστε αυτή σε ένα ανεστραμμένο αρχείο. Εξηγήστε πως με χρήση του ανεστραμμένου αρχείου, το μοντέλο διανυσματικού χώρου θα απαντήσει το ερώτημα Q={όρος1, όρος2, όρος4}.

# **_ΘΕΜΑ 3_ (** Μονάδες 3)

Στο πρόβλημα του **Document Identifier Assignment** (ανάθεση αναγνωριστικών σε κείμενα) θέλουμε να απεικονίσουμε τίτλους (ή url) κειμένων ΣΕ ακέραιους αριθμούς, ώστε να υλοποιηθούν οι ανεστραμμένες λίστες του ανεστραμμένου αρχείου της συλλογής. Δηλαδή σε κάθε ανεστραμμένη λίστα μίας λέξης θα αναγράφονται ακέραιοι αριθμοί που θα αντιστοιχούν στα κείμενα στα οποία η λέξη εμφανίζεται.

Εξηγήστε την σχέση που έχει η ανάθεση αυτή με την αποδοτική **ΣΥΜΠΙΕΣΗ** του αντίστοιχου ανεστραμμένου αρχείου και προτείνετε τεχνικές αποτελεσματικής απεικόνισης ώστε η συμπίεση που προκύπτει να είναι αποδοτική.
