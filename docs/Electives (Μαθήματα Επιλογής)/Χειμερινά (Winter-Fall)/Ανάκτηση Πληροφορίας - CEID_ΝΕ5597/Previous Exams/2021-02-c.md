# **ΤΜΗΜΑ ΜΗΧΑΝΙΚΩΝ Η/Υ ΚΑΙ ΠΛΗΡΟΦΟΡΙΚΗΣ ΠΑΝΕΠΙΣΤΗΜΙΟ ΠΑΤΡΑΣ ΑΝΑΚΤΗΣΗ ΠΛΗΡΟΦΟΡΙΑΣ ΕΞΕΤΑΣΕΙΣ ΦΕΒΡΟΥΑΡΙΟΣ 2021**

**Διδάσκων:** [όνομα παραλείπεται] **ΔΙΑΡΚΕΙΑ 1:30**

**(ΟΜΑΔΑ 3)**

**_ΘΕΜΑ 1_** ( _Μονάδες 3,5_ )

α. Θεωρώντας ότι ο αριθμός των επιστρεφόμενων κειμένων είναι 30, σχεδιάστε τα γραφήματα ανάκλησης ακρίβειας, για τα ακόλουθα ερωτήματα (δίνονται ο αριθμός των σχετικών κειμένων και η θέση τους στο αποτέλεσμα) :

- Μηχανή1 Αριθμός: 10, Θέση: 1, 3, 6, 9, 11, 13, 19, 20, 27, 30
- Μηχανή2 Αριθμός: 10, Θέση: 1, 4, 6, 10, 11, 12, 15, 16, 28, 30

Με βάση τα δύο προκύπτοντα γραφήματα ανάκλησης ακρίβειας συγκρίνετε μεταξύ τους τις δύο μηχανές.

Στη συνέχεια συγκρίνετε τις δύο μηχανές με χρήση των μετρικών **P@5, MRR** (Mean Reciprocal Rank – Μέσος Όρος Ανάστροφος Βαθμός) και **MAP** (Mean Average Precision – Μέσος Όρος Μέσης Ακρίβειας).

β. Εξηγήστε πως η χρήση λεκτικών "θησαυρών" και γενικότερα οντολογιών (όπως το WordNet) θα μπορούσε να αντιμετωπίσει αποτελεσματικά τα προβλήματα της συνωνυμίας και πολυσημίας.

**_ΘΕΜΑ 2_ (** Μονάδες 3,5)

α.Σύμφωνα με την _cluster hypothesis_ ( _υπόθεση ομαδοποίησης_ ), κείμενα που ανήκουν στην ίδια συστάδα ομαδοποίησης είναι και σχετικά για παρόμοιες αιτήσεις. Μία ερμηνεία αυτής της υπόθεσης είναι ότι κείμενα που είναι σχετικά ψηλά στην αξιολόγηση σε ένα ερώτημα πρέπει να _παρασύρουν_ και κείμενα της ίδιας ομάδας, ώστε να είναι αντίστοιχα ψηλά.  Εξηγήστε πως το μοντέλο διανυσματικού χώρου θα μπορούσε να τροποποιηθεί ώστε να ενσωματώσει την πληροφορία αυτή. β. Θεωρήστε ότι έχουμε μία συλλογή κειμένων και όρων που περιγράφεται από τον ακόλουθο πίνακα:

||**όρος1**|**όρος2**|**όρος3**|**όρος4**|**όρος5**|
|---|---|---|---|---|---|
|**Κειμ1**|0|1|2|2|0|
|**Κειμ2**|0|1|2|0|1|
|**Κειμ3**|0|1|0|1|0|
|**Κειμ4**|1|0|2|0|0|
|**Κειμ5**|0|2|1|0|0|
|**Κειμ6**|2|2|0|1|0|
|**Κειμ7**|3|1|0|2|1|
|**Κειμ8**|0|2|0|4|0|

Αναπαραστήστε τη συγκεκριμένη συλλογή χρησιμοποιώντας το μοντέλο διανυσματικού χώρου, και αποθηκεύσετε αυτή σε ένα ανεστραμμένο αρχείο. Εξηγήστε πως με χρήση του ανεστραμμένου αρχείου θα απαντηθεί το ερώτημα Q={όρος1, όρος2, όρος4}, με βάση το μοντέλο διανυσματικού χώρου.

# **_ΘΕΜΑ 3_ (** Μονάδες 3)

Η διαδικασία απάντησης ενός ερωτήματος με το μοντέλο διανυσματικού χώρου βασίζεται  στον υπολογισμό (με χρήση της πληροφορίας των ανεστραμμένων αρχείων) της μετρικής ομοιότητας του συνημιτόνου μεταξύ κάθε αποθηκευμένου κειμένου και του ερωτήματος, και  την εμφάνιση των K κειμένων με τις μεγαλύτερες τιμές ομοιότητας. Εξηγήστε πως ο χρόνος της διαδικασίας υπολογισμού μπορεί να μειωθεί με τη χρήση προσεγγιστικών τεχνικών που θα «θυσιάζουν» την ακρίβεια στην απάντηση (τα επιστρεφόμενα κείμενα δεν θα είναι σίγουρα τα K μεγαλύτερα, θα είναι όμως περίπου τα Κ μεγαλύτερα), για να μειώσουν το χώρο. Θα μπορούσε η χρήση τεχνικών ομαδοποίησης κειμένων να οδηγήσει σε ακόμα πιο γρήγορη απάντηση;
