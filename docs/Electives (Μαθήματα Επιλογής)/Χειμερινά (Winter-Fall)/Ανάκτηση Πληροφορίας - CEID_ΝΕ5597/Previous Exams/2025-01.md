## 2025-01-11_171338.png

β. Θεωρήστε ότι έχουμε μία συλλογή κειμένων και όρων που περιγράφεται από τον ακόλουθο πίνακα:

| | όρος1 | όρος2 | όρος3 | όρος4 | όρος5 |
|---|---|---|---|---|---|
| Κειμ1 | 0 | 1 | 2 | 2 | 0 |
| Κειμ2 | 0 | 1 | 2 | 0 | 1 |
| Κειμ3 | 0 | 1 | 0 | 1 | 0 |
| Κειμ4 | 1 | 0 | 2 | 0 | 0 |
| Κειμ5 | 0 | 2 | 1 | 0 | 0 |
| Κειμ6 | 2 | 2 | 0 | 1 | 0 |
| Κειμ7 | 3 | 1 | 0 | 2 | 1 |
| Κειμ8 | 0 | 2 | 0 | 4 | 0 |

Εξηγήστε πως με χρήση του ανεστραμμένου αρχείου, το μοντέλο διανυσματικού χώρου θα απαντήσει το ερώτημα Q={όρος1, όρος2, όρος4}.
