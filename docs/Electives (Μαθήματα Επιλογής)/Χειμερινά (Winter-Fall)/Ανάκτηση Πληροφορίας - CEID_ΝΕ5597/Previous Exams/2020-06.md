# **_ΘΕΜΑ 1_** ( _Μονάδες 3.5_ )

Στο πρόβλημα του **Document Identifier Assignment** (ανάθεση αναγνωριστικών σε κείμενα) θέλουμε να απεικονίσουμε τίτλους (ή url) κειμένων ΣΕ ακέραιους αριθμούς, ώστε να υλοποιηθούν οι ανεστραμμένες λίστες του ανεστραμμένου αρχείου της συλλογής. Δηλαδή σε κάθε ανεστραμμένη λίστα μίας λέξης θα αναγράφονται ακέραιοι αριθμοί που θα αντιστοιχούν στα κείμενα στα οποία η λέξη εμφανίζεται. **Εξηγήστε** την σχέση που έχει η ανάθεση αυτή με την αποδοτική **ΣΥΜΠΙΕΣΗ** του αντίστοιχου ανεστραμμένου αρχείου και **προτείνετε** τεχνικές αποτελεσματικής απεικόνισης.
