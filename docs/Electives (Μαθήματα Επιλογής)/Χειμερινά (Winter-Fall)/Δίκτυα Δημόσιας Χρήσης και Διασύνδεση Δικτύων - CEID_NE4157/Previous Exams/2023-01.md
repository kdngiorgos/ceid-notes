    ## Θέμα 1ο

    *Αξιοπιστία: δύο ανεξάρτητες λύσεις συμφωνούν · εμπιστοσύνη λύτη: υψηλή*

    1. Τα επτά επίπεδα του ISO/OSI, από το κατώτερο προς το ανώτερο, είναι:
       1. Φυσικό (Physical)
       2. Ζεύξης Δεδομένων (Data Link)
       3. Δικτύου (Network)
       4. Μεταφοράς (Transport)
       5. Συνεδρίασης (Session)
       6. Παρουσίασης (Presentation)
       7. Εφαρμογής (Application)

    2. Το 3ο επίπεδο, το επίπεδο δικτύου, έχει ως βασικές λειτουργίες:
       - τη λογική διευθυνσιοδότηση των κόμβων (π.χ. διευθύνσεις IP),
       - τη δρομολόγηση (routing), δηλαδή την επιλογή διαδρομής προς τον προορισμό,
       - την προώθηση (forwarding) πακέτων από μια διεπαφή εισόδου σε κατάλληλη διεπαφή εξόδου,
       - τη διασύνδεση ετερογενών δικτύων,
       - τον τεμαχισμό και την επανασυναρμολόγηση πακέτων όταν απαιτείται λόγω διαφορετικού MTU,
       - την αναφορά σφαλμάτων και διαγνωστικές λειτουργίες (π.χ. ICMP),
       - μηχανισμούς ελέγχου συμφόρησης/πολιτικών QoS σε επίπεδο δικτύου.

    3. Δύο πρωτόκολλα του 3ου επιπέδου είναι το IP (IPv4/IPv6) και το ICMP. Εναλλακτικά αναφέρονται και πρωτόκολλα δρομολόγησης όπως OSPF, που λειτουργούν λειτουργικά στο επίπεδο δικτύου.

    ## Θέμα 2ο

    *Αξιοπιστία: δύο ανεξάρτητες λύσεις συμφωνούν · εμπιστοσύνη λύτη: υψηλή*

    1. Η κεφαλίδα TCP (στην κλασική μορφή του RFC 793) περιλαμβάνει τα εξής πεδία:

    | Πεδίο | Μέγεθος |
    |---|---:|
    | Source Port | $16$ bits |
    | Destination Port | $16$ bits |
    | Sequence Number | $32$ bits |
    | Acknowledgment Number | $32$ bits |
    | Data Offset / Header Length | $4$ bits |
    | Reserved | $6$ bits (στα σύγχρονα πρότυπα: $3$ bits + $1$ bit NS) |
    | Flags / Control Bits | $6$ bits (URG, ACK, PSH, RST, SYN, FIN· στα σύγχρονα πρότυπα προστίθενται CWR, ECE και NS) |
    | Window | $16$ bits |
    | Checksum | $16$ bits |
    | Urgent Pointer | $16$ bits |
    | Options | μεταβλητό, έως $40$ bytes ($320$ bits) μαζί με padding |
    | Padding | μεταβλητό, ώστε η κεφαλίδα να είναι πολλαπλάσιο των $32$ bits |

    Η ελάχιστη κεφαλίδα TCP είναι $20$ bytes ($160$ bits) και η μέγιστη $60$ bytes ($480$ bits), λόγω των options/padding.

    2. Η αξιόπιστη και με σωστή σειρά μετάδοση στο TCP εξασφαλίζεται με συνδυασμό μηχανισμών:
       - Κάθε byte της ροής δεδομένων αριθμείται. Το πεδίο Sequence Number δείχνει τον αριθμό του πρώτου byte των δεδομένων του segment.
       - Ο δέκτης χρησιμοποιεί το Acknowledgment Number για να δηλώσει το επόμενο byte που περιμένει. Οι ACK είναι σωρευτικοί (cumulative ACKs).
       - Ο δέκτης αναδιατάσσει τα out-of-order segments με βάση τα sequence numbers, απορρίπτει διπλότυπα και παραδίδει τα δεδομένα στην εφαρμογή με τη σωστή σειρά.
       - Το πεδίο Checksum ανιχνεύει αλλοιώσεις. Segment με λανθασμένο checksum απορρίπτεται και, εφόσον δεν επιβεβαιωθεί, επαναμεταδίδεται.
       - Χρησιμοποιούνται timers/retransmission: αν δεν ληφθεί ACK εντός του RTO, ο αποστολέας επαναμεταδίδει. Επίσης γίνεται fast retransmit μετά από τρία duplicate ACKs.
       - Το πεδίο Window υλοποιεί έλεγχο ροής: ο δέκτης διαφημίζει πόσα bytes μπορεί να δεχθεί, ενώ ο αποστολέας χρησιμοποιεί sliding window για τα μη επιβεβαιωμένα δεδομένα.
       - Τα flags SYN/FIN/RST/ACK χρησιμοποιούνται για εγκατάσταση/τερματισμό σύνδεσης και έλεγχο κατάστασης. Η σύνδεση αρχίζει με three-way handshake (SYN, SYN-ACK, ACK) και τερματίζεται με FIN/ACK.
       - Επιπλέον, μηχανισμοί congestion control (slow start, congestion avoidance, fast recovery) και προαιρετικά SACK βελτιώνουν την απόδοση και την ανάκαμψη από απώλειες.

    ## Θέμα 3ο

    *Αξιοπιστία: δύο ανεξάρτητες λύσεις συμφωνούν · εμπιστοσύνη λύτη: μέτρια*

    1. Το UMTS (Universal Mobile Telecommunications System) είναι σύστημα κινητής τηλεφωνίας 3ης γενιάς (3G), προτυποποιημένο από την 3GPP, ως εξέλιξη των GSM/GPRS. Η βασική ραδιοπρόσβαση είναι το WCDMA/UTRA FDD, με εύρος ζώνης καναλιού περίπου $5$ MHz και chip rate $3.84$ Mcps· υποστηρίζεται και UTRA TDD (TD-CDMA/TD-SCDMA). Παρέχει φωνή με μεταγωγή κυκλώματος και δεδομένα με μεταγωγή πακέτου, κινητικότητα, περιαγωγή και ποιότητα υπηρεσίας (QoS).
       - Ρυθμοί μετάδοσης: στην αρχική UMTS Release 99 προβλέπονται/επιτυγχάνονται έως περίπου $2$ Mbps σε ιδανικές συνθήκες χαμηλής κινητικότητας/εσωτερικού χώρου, περίπου $384$ kbps σε τυπικές εξωτερικές συνθήκες πεζού και $144$ kbps σε συνθήκες υψηλής κινητικότητας. Με τις εξελίξεις HSDPA/HSUPA και HSPA+ οι ρυθμοί αυξάνονται σημαντικά: HSDPA έως περίπου $14.4$ Mbps στην αρχική εκδοχή και αργότερα δεκάδες έως εκατοντάδες Mbps με HSPA+· HSUPA uplink έως περίπου $5.76$ Mbps.
       - Κατηγορίες καναλιών UMTS: διακρίνονται σε λογικά, μεταφοράς και φυσικά κανάλια. Λογικά κανάλια είναι π.χ. BCCH, PCCH, CCCH, DCCH, DTCH, CTCH. Κανάλια μεταφοράς είναι π.χ. BCH, PCH, FACH, RACH, CPCH, DCH, DSCH, HS-DSCH, E-DCH. Φυσικά κανάλια είναι π.χ. P-CCPCH, S-CCPCH, PICH, PRACH, DPCCH, DPDCH, HS-PDSCH, HS-SCCH, E-DPDCH, E-DPCCH.

    2. Η αρχιτεκτονική UMTS αποτελείται από τρία βασικά τμήματα:
       - User Equipment (UE): τερματικό χρήστη, που περιλαμβάνει το Mobile Equipment (ME) και τη μονάδα συνδρομητή USIM. Συνδέεται με το δίκτυο ραδιοπρόσβασης μέσω της διεπαφής Uu.
       - UMTS Terrestrial Radio Access Network (UTRAN): περιλαμβάνει τους σταθμούς βάσης Node B και τους ελεγκτές ραδιοδικτύου RNC. Οι βασικές διεπαφές είναι Uu (UE–Node B), Iub (Node B–RNC), Iur (RNC–RNC) και Iu (RNC–Core Network, με Iu-CS και Iu-PS).
       - Core Network (CN): περιλαμβάνει το τμήμα μεταγωγής κυκλώματος (MSC/VLR, GMSC), το τμήμα μεταγωγής πακέτου (SGSN, GGSN) και κοινούς κόμβους όπως HLR, AuC και EIR. Το SGSN εξυπηρετεί την πρόσβαση πακέτων και το GGSN αποτελεί πύλη προς εξωτερικά δίκτυα πακέτων.
