# ΔΙΚΤΥΑ ΔΗΜΟΣΙΑΣ ΧΡΗΣΗΣ ΚΑΙ ΔΙΑΣΥΝΔΕΣΗ ΔΙΚΤΥΩΝ

**Διάρκεια: 2 ώρες**  
**ΚΑΘΗΓΗΤΡΙΑ: [όνομα παραλείφθηκε]**

### Ζήτημα 1ο (40%)
1. Αναφέρετε τα επτά επίπεδα του μοντέλου ISO/OSI. [15%]
2. Περιγράψτε τις βασικές λειτουργίες του 3ου επιπέδου (επίπεδο δικτύου). [15%]
3. Αναφέρετε δύο πρωτόκολλα που ανήκουν στο 3ο επίπεδο του ISO/OSI. [10%]

### Ζήτημα 2ο (30%)
1. Αναφέρετε τα πεδία που περιλαμβάνει η κεφαλίδα (header) ενός TCP segment, καθώς και το μέγεθος (σε bits) του κάθε πεδίου. [15%]
2. Με ποιο τρόπο εξασφαλίζεται η αξιόπιστη και στη σωστή σειρά μετάδοση των δεδομένων στο TCP; [15%]  
*Σημείωση:* Περιγράψτε αναλυτικά τη διαδικασία, κάνοντας αναφορά και στα πεδία της κεφαλίδας που χρησιμοποιούνται.

### Ζήτημα 3ο (30%)
1. Τι γνωρίζετε για τα δίκτυα κινητής τηλεφωνίας Universal Mobile Telecommunication System (UMTS); [15%]  
*Σημείωση:* Στην απάντησή σας κάνετε αναφορά για τους ρυθμούς μετάδοσης που μπορεί να επιτύχει η τεχνολογία UMTS καθώς και τις κατηγορίες/τύπους καναλιών που χρησιμοποιεί.
2. Αναφέρετε τα τρία τμήματα της αρχιτεκτονική των δικτύων UMTS και τους βασικούς κόμβους κάθε τμήματος. [15%]
