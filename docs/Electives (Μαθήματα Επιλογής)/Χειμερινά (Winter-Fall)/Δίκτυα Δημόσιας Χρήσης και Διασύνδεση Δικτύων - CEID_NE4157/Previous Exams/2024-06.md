    # AI λύσεις — 2024-06

    > Οι λύσεις γράφτηκαν από μοντέλα AI και δεν έχουν ελεγχθεί από άνθρωπο. Η αρίθμηση ακολουθεί το αρχείο θεμάτων.

    ## Θέμα 1º (30%)

    *Αξιοπιστία: μία λύση AI, δεν έχει αντιπαραβληθεί με δεύτερη · εμπιστοσύνη λύτη: υψηλή*

    Περιγράφονται τέσσερις βασικές τοπολογίες:

    1. **Τοπολογία διαύλου (bus)**
    ```
    N1     N2     N3     N4
     |      |      |      |
    ========================  (κοινός δίαυλος)
    ```
    - **Πλεονεκτήματα:** απλή και φθηνή καλωδίωση, εύκολη επέκταση, κατάλληλη για μικρά δίκτυα.
    - **Μειονεκτήματα:** ένα πρόβλημα στον κεντρικό δίαυλο επηρεάζει πολλούς κόμβους, συγκρούσεις και υποβάθμιση απόδοσης υπό φόρτο, δυσκολία εντοπισμού βλάβης.

    2. **Τοπολογία αστέρα (star)**
    ```
            N2
             |
    N1 ---- H/S ---- N3
             |
            N4
    ```
    όπου `H/S` είναι hub ή switch.
    - **Πλεονεκτήματα:** εύκολη διαχείριση, απομόνωση βλάβης ανά σύνδεσμο, εύκολη προσθήκη/αφαίρεση κόμβου, καλή απόδοση με switch.
    - **Μειονεκτήματα:** ο κεντρικός κόμβος αποτελεί σημείο αστοχίας, περισσότερα καλώδια, εξάρτηση από το hub/switch.

    3. **Τοπολογία δακτυλίου (ring)**
    ```
       N1 ----- N2
      /           \
    N4 ---------- N3
    ```
    - **Πλεονεκτήματα:** ντετερμινιστική πρόσβαση σε δακτύλιο με token, ισότιμη πρόσβαση κόμβων, απλές σημείο-προς-σημείο συνδέσεις· με διπλό δακτύλιο αυξάνεται η ανοχή βλαβών.
    - **Μειονεκτήματα:** διακοπή σε απλό δακτύλιο μπορεί να σταματήσει το δίκτυο, η προσθήκη/αφαίρεση κόμβου μπορεί να διακόψει τη λειτουργία, αύξηση καθυστέρησης με πολλούς κόμβους.

    4. **Τοπολογία πλέγματος (mesh)**
    ```
       N1 ----- N2
       | \     / |
       |  \   /  |
       |   \ /   |
       |   / \   |
       |  /   \  |
       N4 ----- N3
    ```
    Σε πλήρες πλέγμα κάθε κόμβος συνδέεται με όλους· σε μερικό πλέγμα υπάρχουν πολλαπλές εναλλακτικές διαδρομές.
    - **Πλεονεκτήματα:** υψηλή αξιοπιστία, ανοχή βλαβών, πολλαπλές διαδρομές, δυνατότητα κατανομής φόρτου.
    - **Μειονεκτήματα:** μεγάλο κόστος καλωδίωσης/θυρών, πολυπλοκότητα δρομολόγησης και διαχείρισης, δύσκολη επέκταση σε μεγάλο πλήρες πλέγμα.

    ## Θέμα 2º (40%)

    *Αξιοπιστία: μία λύση AI, δεν έχει αντιπαραβληθεί με δεύτερη · εμπιστοσύνη λύτη: υψηλή*

    1. Τα δύο πιο διαδεδομένα πρωτόκολλα του επιπέδου μεταφοράς είναι το **TCP** και το **UDP**.  
       - **TCP:** συνδεσμοστρεφές, αξιόπιστο, με σειρά παράδοσης, επιβεβαιώσεις, επαναμεταδόσεις, έλεγχο ροής και συμφόρησης.  
       - **UDP:** ανασύνδετο, χωρίς εγγύηση παράδοσης/σειράς, με πολύ μικρότερο overhead και χαμηλότερη καθυστέρηση.

    2. Για live streaming χωρίς ανάγκη επαναμετάδοσης θα επιλεγόταν το **UDP**.  
       Αιτιολόγηση: το live streaming έχει αυστηρές απαιτήσεις χαμηλής καθυστέρησης· οι επαναμεταδόσεις του TCP μπορούν να προκαλέσουν συσσώρευση και καθυστέρηση. Με UDP οι απώλειες είναι ανεκτές ή αντιμετωπίζονται σε επίπεδο εφαρμογής (π.χ. buffering, FEC, RTP/UDP).

    3. Δομή πακέτου **UDP** (UDP datagram): η κεφαλίδα είναι σταθερή και έχει μέγεθος $8$ bytes, ακολουθούμενη από τα δεδομένα.

    | Πεδίο | Μέγεθος | Λειτουργία |
    |---|---:|---|
    | Source Port | $16$ bits | Θύρα αποστολέα· προσδιορίζει την εφαρμογή/διεργασία αποστολής. |
    | Destination Port | $16$ bits | Θύρα παραλήπτη· προσδιορίζει την εφαρμογή/διεργασία προορισμού. |
    | Length | $16$ bits | Μήκος ολόκληρου του UDP datagram (κεφαλίδα + δεδομένα) σε bytes· ελάχιστο $8$. |
    | Checksum | $16$ bits | Έλεγχος σφαλμάτων πάνω σε pseudo-header, UDP header και δεδομένα· στο IPv4 είναι προαιρετικό, στο IPv6 υποχρεωτικό. Η τιμή $0$ στο IPv4 σημαίνει ότι δεν υπολογίστηκε. |
    | Data | μεταβλητό | Το φορτίο (payload) της εφαρμογής. |

    Το UDP δεν έχει πεδία ακολουθίας, επιβεβαίωσης ή παραθύρου, γι’ αυτό δεν παρέχει αξιόπιστη μεταφορά.

    ## Θέμα 3º (30%)

    *Αξιοπιστία: μία λύση AI, δεν έχει αντιπαραβληθεί με δεύτερη · εμπιστοσύνη λύτη: υψηλή*

    1. Το **IPsec (IP Security)** είναι μια σουίτα πρωτοκόλλων και μηχανισμών ασφαλείας που λειτουργεί στο επίπεδο δικτύου (IP) και προστατεύει πακέτα IP μεταξύ κόμβων ή πυλών. Υποστηρίζεται σε IPv4 και IPv6 και είναι διαφανές στις εφαρμογές.  
       Βασικά στοιχεία:
       - **AH (Authentication Header):** παρέχει ακεραιότητα, πιστοποίηση προέλευσης και προστασία από replay, αλλά όχι εμπιστευτικότητα.
       - **ESP (Encapsulating Security Payload):** παρέχει εμπιστευτικότητα με κρυπτογράφηση και συνήθως και ακεραιότητα/πιστοποίηση/anti-replay.
       - **IKE (Internet Key Exchange):** διαχείριση κλειδιών και διαπραγμάτευση Security Associations (SAs).
       - **Security Associations (SAs):** μονόδρομες συμφωνίες ασφαλείας· η διαχείρισή τους γίνεται μέσω SAD, ενώ οι πολιτικές μέσω SPD.
       - **Λειτουργίες:** transport mode (προστατεύεται το φορτίο, κατάλληλο κυρίως για host-to-host) και tunnel mode (ενθυλακώνεται ολόκληρο το αρχικό IP πακέτο σε νέο IP, κατάλληλο για VPN gateway-to-gateway ή host-to-gateway).
       Χρησιμοποιείται ευρέως σε VPN, ασφαλή απομακρυσμένη πρόσβαση και ασφάλιση επικοινωνιών μεταξύ δικτύων.

    2. Οι υπηρεσίες που μπορούν να θεωρηθούν μέρος του IPsec είναι:
       - **Έλεγχος πρόσβασης (access control)**
       - **Ακεραιότητα χωρίς σύνδεση (connectionless integrity)**
       - **Πιστοποίηση προέλευσης δεδομένων (data origin authentication)**
       - **Απόρριψη επαναπαιγμένων πακέτων (anti-replay / rejection of replayed packets)**
       - **Εμπιστευτικότητα (confidentiality)** μέσω ESP
       - **Περιορισμένη εμπιστευτικότητα ροής κίνησης (limited traffic flow confidentiality)** μέσω ESP, συνήθως σε tunnel mode
       - **Διαχείριση κλειδιών (key management)** ως υποστηρικτική υπηρεσία, μέσω IKE.  
       Το AH παρέχει κυρίως ακεραιότητα/πιστοποίηση/anti-replay, ενώ το ESP μπορεί να παρέχει και εμπιστευτικότητα.
