    ## Θέμα 15

    *Αξιοπιστία: δύο ανεξάρτητες λύσεις συμφωνούν · εμπιστοσύνη λύτη: υψηλή*

    Σφάλματα:
    1. Το `_mm_load_ps()`/`_mm_store_ps()` απαιτούν στοίχιση 16 bytes. Με `data + 2*thread_num`, τα μονά νήματα δείχνουν σε διεύθυνση με στοίχιση 8 bytes, άρα μη έγκυρη aligned πρόσβαση.
    2. Κάθε νήμα φορτώνει/αποθηκεύει 4 floats, αλλά το βήμα είναι 2 floats. Άρα οι περιοχές επικαλύπτονται και υπάρχει data race.
    3. Με `nThreads=16`, το νήμα 15 γράφει/διαβάζει πέρα από τα 32 στοιχεία, εκτός ορίων.

    Διόρθωση: χρησιμοποιούμε 8 νήματα και βήμα 4 floats, ώστε κάθε νήμα να επεξεργάζεται ένα aligned, μη επικαλυπτόμενο διάνυσμα 4 floats:
    ```c
    int nThreads = 8; // 32/4
    float *data;
    if (posix_memalign((void **)&data, 16, 32*sizeof(float)) != 0) {
        /* handle error */
    }
    for (int i = 0; i < 32; ++i) data[i] = drand48();

    omp_set_num_threads(nThreads);
    #pragma omp parallel
    {
        int tid = omp_get_thread_num();
        float * const myData = data + 4*tid;
        __m128 c4 = _mm_set1_ps((float)M_PI);
        __m128 r4 = _mm_load_ps(myData);
        __m128 a4 = _mm_mul_ps(c4, _mm_mul_ps(r4, r4));
        _mm_store_ps(myData, a4);
    }
    ```

    ## Θέμα 16

    *Αξιοπιστία: δύο ανεξάρτητες λύσεις συμφωνούν · εμπιστοσύνη λύτη: υψηλή*

    **a. `kernel<<<10, 256>>>();`** Η σύνταξη είναι `kernel<<<αριθμός_blocks, νήματα_ανά_block>>>(...)`. Η c είναι επίσης συντακτικά αποδεκτή ως `kernel<<<10, 256, 0>>>()` αν δηλωθεί 0 δυναμική shared μνήμη, αλλά η τυπική/ζητούμενη μορφή είναι η a.

    ## Θέμα 17

    *Αξιοπιστία: δύο ανεξάρτητες λύσεις συμφωνούν · εμπιστοσύνη λύτη: υψηλή*

    **b. Καθορίζει μια συνάρτηση που τρέχει στην κάρτα γραφικών και μπορεί να κληθεί από το κύριο σύστημα (host).** Το `__global__` δηλώνει CUDA kernel που εκτελείται στη συσκευή και καλείται από τον host.

    ## Θέμα 18

    *Αξιοπιστία: δύο ανεξάρτητες λύσεις συμφωνούν · εμπιστοσύνη λύτη: υψηλή*

    **c. `cudaMemcpy()` με `cudaMemcpyHostToDevice`.** Αυτή η κλήση αντιγράφει δεδομένα από τη μνήμη του host στη μνήμη της συσκευής.

    ## Θέμα 19

    *Αξιοπιστία: δύο ανεξάρτητες λύσεις συμφωνούν · εμπιστοσύνη λύτη: υψηλή*

    **b. Συγχρονίζει όλα τα νήματα σε ένα μπλοκ.** Το `__syncthreads()` είναι barrier για τα νήματα του ίδιου block, όχι για ολόκληρο το grid ή το warp.

    ## Θέμα 20

    *Αξιοπιστία: δύο ανεξάρτητες λύσεις συμφωνούν · εμπιστοσύνη λύτη: υψηλή*

    **b. 0 2 4 6.** Το kernel εκτελείται με `threadIdx.x = 0,1,2,3`, άρα γράφει `a[tid] = tid*2`, δηλαδή $0,2,4,6$.

    ## Θέμα 21

    *Αξιοπιστία: δύο ανεξάρτητες λύσεις συμφωνούν · εμπιστοσύνη λύτη: υψηλή*

    Σφάλματα:
    1. Το `b` είναι δείκτης σε μνήμη συσκευής (device), αλλά ο βρόχος `b[i] = i` εκτελείται στον host. Η άμεση εγγραφή σε device pointer από host είναι μη έγκυρη.
    2. Σε C++ συχνά απαιτείται cast στη `cudaMalloc`, π.χ. `cudaMalloc((void**)&b, ...)`, και έλεγχος επιστροφής.
    3. Αν το kernel υπολογίζει αποτελέσματα που θα χρησιμοποιήσει ο host, χρειάζεται αντιγραφή πίσω με `cudaMemcpy(..., cudaMemcpyDeviceToHost)`.
    4. Πρέπει να χρησιμοποιείται μοναδικό καθολικό index νήματος, π.χ. `blockIdx.x*blockDim.x + threadIdx.x`, και όχι μόνο `threadIdx.x`, αν θέλουμε επεξεργασία 512 στοιχείων.
    5. Καλό είναι να προστεθεί `cudaDeviceSynchronize()` και έλεγχος σφαλμάτων πριν από το `cudaFree`.

    Ενδεικτική διόρθωση:
    ```c
    __global__ void kernel(int *array, int n)
    {
        int idx = blockIdx.x * blockDim.x + threadIdx.x;
        if (idx < n) {
            // π.χ. array[idx] = array[idx] + 1;
        }
    }

    int main()
    {
        int h_b[512];
        int *d_b;

        for (int i = 0; i < 512; ++i) h_b[i] = i;

        cudaMalloc((void**)&d_b, 512 * sizeof(int));
        cudaMemcpy(d_b, h_b, 512 * sizeof(int), cudaMemcpyHostToDevice);

        kernel<<<16, 32>>>(d_b, 512);
        cudaDeviceSynchronize();

        cudaMemcpy(h_b, d_b, 512 * sizeof(int), cudaMemcpyDeviceToHost);
        cudaFree(d_b);
        return 0;
    }
