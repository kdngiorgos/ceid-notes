Ερώτηση 1 (Πολλαπλής Επιλογής (Μοναδική Απάντηση) — 0.50 βαθμοί)

Δίνεται το γραμμικό πρόγραμμα

minimize $(x_1 + x_2 + x_3)$

υπό τους περιορισμούς:

$$x_1 + 2x_2 + 3x_3 - 6 = 0$$

$$x_1 \ge 0$$

$$x_2 \ge 0$$

$$x_3 \ge 0$$

(5%) Ποιό από τα παρακάτω σημεία $(x_1, x_2, x_3)$ αντιστοιχεί στην βέλτιστη λύση;

- [ ] A: το $(3, 0, 1)$
- [ ] B: το $(0, 0, 2)$
- [ ] Γ: το $(1, 1, 1)$
- [ ] Δ: το $(6, 0, 0)$
- [ ] E: το $(0, 3, 1)$
- [ ] ΣΤ: Κανένα από τα παραπάνω
