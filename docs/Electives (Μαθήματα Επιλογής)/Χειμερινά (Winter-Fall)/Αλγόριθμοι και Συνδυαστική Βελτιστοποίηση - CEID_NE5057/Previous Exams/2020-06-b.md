Ερώτηση 1 (Πολλαπλής Επιλογής (Μοναδική Απάντηση) — 0.60 βαθμοί)

(12%) Θεωρήστε ότι ο αλγόριθμος Dijkstra με χρήση μιας ουράς προτεραιότητας MySuperPQ εφαρμόζεται σε ένα κατευθυνόμενο γράφημα G = (V,E) με μη αρνητικά κόστη στις ακμές του, και έστω n = |V| και |m| = |E|. Οι χρόνοι των βασικών λειτουργιών της MySuperPQ σε ένα σύνολο N δεδομένων έχουν ως εξής: οι λειτουργίες create, insert, find-min εκτελούνται σε επιμερισμένο χρόνο O(1), η λειτουργία delete-min εκτελείται σε χρόνο χειρότερης περίπτωσης O(log² N), και η λειτουργία decrease-key εκτελείται σε επιμερισμένο χρόνο O(log N).

Ποια από τις παρακάτω είναι η ασυμπτωτική πολυπλοκότητα χειρότερης περίπτωσης του αλγορίθμου Dijkstra με χρήση της MySuperPQ ;

- [ ] A: O((m+n)log² n)
- [ ] B: O(mlogn + nlog² n)
- [ ] Γ: O(mlogn + nlogn)
- [ ] Δ: O(m + nlog² n)
- [ ] E: O(mlog² n + nlogn)
- [ ] ΣΤ: καμία από τις προηγούμενες.

Ερώτηση 3 (Ελεύθερου Κειμένου — 1.30 βαθμοί)

(13%) Θεωρήστε τον αλγόριθμο του Dial για την επίλυση του προβλήματος συντομότερων διαδρομών από μια αρχική κορυφή s σε ένα κατευθυνόμενο γράφημα G = (V,E) (|V| = n, |E| = m) με μη αρνητικά κόστη ακμών, που παίρνουν ακέραιες τιμές στο διάστημα [0, Δ]. Έστω S το σύνολο των κορυφών με οριστικοποιημένες (μόνιμες) ετικέτες και S' = V − S το σύνολο των κορυφών με προσωρινές (αλλά πεπερασμένες) ετικέτες. Δείξτε ότι αν d(u) είναι η ετικέτα που δηλώνεται μόνιμη στην αρχή μιας επανάληψης (δηλαδή u είναι η κορυφή με την ελάχιστη ετικέτα), τότε στο τέλος αυτής της επανάληψης θα ισχύει d(v) ≤ d(u) + Δ, για κάθε v ∈ S'.
