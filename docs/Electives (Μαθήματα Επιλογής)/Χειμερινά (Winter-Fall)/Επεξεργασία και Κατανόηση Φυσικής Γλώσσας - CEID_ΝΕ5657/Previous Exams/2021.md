# Επεξεργασία και Κατανόηση Φυσικής Γλώσσας — Χωρίς τυπωμένη ημερομηνία

> Μεταγραφή των φωτογραφιών 1.jpg (σελ. 1/2) και 2.jpg (σελ. 2/2) της ίδιας κόλλας εξέτασης.

## 1.jpg

Θέμα 1ο
Α) Περιγράψτε με λίγα λόγια πώς αντιλαμβάνεστε την επιστήμη της Επεξεργασίας Φυσικής Γλώσσας και γιατί θεωρείτε ότι είναι σημαντική;
5 μονάδες

Β) Περιγράψτε τα επίπεδα ανάλυσης της γλώσσας, το πεδίο της γλωσσολογίας που εμπλέκεται στο καθένα, και τις εργασίες που εκτελούνται σε κάθε επίπεδο.
5 μονάδες

Γ) Με ποιες προσεγγίσεις προσαρμογής ένα σύστημα Εξαγωγής Πληροφορίας μπορεί να αντιμετωπίσει τις δυσκολίες που προκύπτουν; Να τις αξιολογήσετε.
5 μονάδες

Δ) Αυτόματη εξαγωγή περιλήψεων: Να αναφέρετε και να περιγράψετε τις βασικές κατηγορίες περιλήψεων και τα στάδια της αυτόματης παραγωγής περιλήψεων που ακολουθούνται σε όποια προσέγγιση κι αν επιλέξουμε.
5 μονάδες

Θέμα 2ο
Α) Αναφέρετε τα κυρίαρχα μέτρα αποτίμησης της αποδοτικότητας των συστημάτων Επεξεργασίας Φυσικής Γλώσσας και πώς υπολογίζονται σε ένα παράδειγμα ανάκτησης πληροφορίας από ένα σύνολο εγγράφων.
5 μονάδες

Β) Ορίστε τους όρους stem(ρίζα), morpheme(μόρφημα), affix(πρόσφυμα), morphological parsing(μορφολογική ανάλυση). Δώστε από ένα παράδειγμα για κάθε κατηγορία.
5 μονάδες

Γ) Τι είναι μια μηχανή καταστάσεων του τύπου FST (Finite State Transducer), γιατί χρησιμοποιείται στη Γλωσσική Τεχνολογία και ποιά η διαφορά ενός FST από ένα FSA(Finite State Automaton);
5 μονάδες

Θέμα 3ο
Α) Σχεδιάστε ένα FST που αναγνωρίζει την κατάληξη -ly των ομαλών αγγλικών επιρρημάτων και δείξτε πώς το FST σας χειρίζεται σωστά τις παρακάτω περιπτώσεις: bright -brightly, simple-simply, silly- sillily, terrific- terrifically.
10 μονάδες

Β) Να αναλύσετε δενδρικά, με τη στρατηγική αναζήτησης top-down την παρακάτω πρόταση, λαμβάνοντας υπόψη τη γραμματική χωρίς συμφραζόμενα(Context Free Grammar- CFG) που σας δίνεται: 'Ο Κώστας πήγε μέχρι την πλατεία'. Η πρόταση 'Το παιδί έπεσε και χτύπησε στο σχολείο' είναι αποδεκτή; Να αιτιολογήσετε την απάντησή σας.

## 2.jpg

| CFG | |
| :--- | :--- |
| S ->VP | PP ->Prep NP |
| S ->NP VP | Determinant ->ο, η, το |
| VP ->V | Noun ->παιδί, άνθρωπος, πλατεία, αυτοκίνητο, σχολείο |
| VP ->V NP | ProperNoun ->Κώστας, Μαρία, Βασίλης, Ελένη |
| VP ->V PP | Verb ->πηγαίνω, έρχομαι, κάνω, πέφτω, χτυπάω |
| NP ->Det N | Preposition ->μέχρι, από, επί, με, σε |
| NP ->DetPropN | Conjunction ->και, αλλά |

10 μονάδες

Θέμα 4ο
Α) Ορίστε σύντομα τους όρους υπωνυμία, συνωνυμία, μερωνυμία, δίνοντας και παραδείγματα για κάθε σχέση.
5 μονάδες

Β) Υπάρχουν διάφοροι τύποι αμφισημίας (ambiguity) στην Επεξεργασία Φυσικής Γλώσσας. Για κάθε περίπτωση από τις παρακάτω περιγράψτε σύντομα πού εντοπίζεται χρησιμοποιώντας παραδείγματα:
- μορφολογική αμφισημία
- λεξιλογική αμφισημία
5 μονάδες

Γ) Στις προτάσεις που ακολουθούν να αναγνωρίσετε τα φαινόμενα αμφισημίας ή/και ασάφειας, να αναφέρετε σε ποιο επίπεδο ανάλυσης της γλώσσας εντοπίζονται και να δώσετε κάποια κατεύθυνση για το πώς μπορούν να επιλυθούν:
- Η Μαρία αγόρασε μια τηλεόραση με την Ελένη. Ο Κώστας την πήγε σπίτι.
- Σου είπα να είναι πράσινο!
5 μονάδες
