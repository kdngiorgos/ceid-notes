## Τι θα μάθεις

Το επίσημο περίγραμμα ορίζει ως περιεχόμενο, μεταξύ άλλων: εισαγωγή στη μελέτη απόδοσης, μεθοδολογία και επιλογή τεχνικής, επιλογή μετρικών, φορτίο εργασίας, Προγράμματα Αναφοράς (benchmarks) και Ελεγκτές (monitors), σχεδιασμό πειραμάτων, αναλυτικές τεχνικές, απλά μοντέλα Θεωρίας Αναμονής, μοντέλα δικτύων συστημάτων αναμονής και αλγορίθμους επίλυσής τους, προσομοίωση και εφαρμογές [Περίγραμμα](https://www.ceid.upatras.gr/sites/default/files/ceid_ne4547_gr.pdf).

Στις πραγματικές διαφάνειες του μαθήματος η ύλη οργανώνεται σε ενότητες:

- Κεφ. 1 — Εισαγωγή: ορισμός πληροφοριακού συστήματος, μετρικές απόδοσης (reaction time, throughput κ.ά.), επιλογή τεχνικής μελέτης eClass (διαθέσιμο στο πλήρες πακέτο).
- Κεφ. 2 — Φορτίο εργασίας, μείξεις εντολών, SPEC, ελεγκτές (monitors), σχεδιασμός πειραμάτων eClass (διαθέσιμο στο πλήρες πακέτο).
- Κεφ. 3 — Μοντέλα Θεωρίας Αναμονής: αλυσίδες Markov, γεννήσεων–θανάτων, M/M/1, M/M/m, M/M/m/K eClass (διαθέσιμο στο πλήρες πακέτο).
- Κεφ. 4 — Δίκτυα συστημάτων αναμονής: ανοιχτά/κλειστά δίκτυα Jackson, αλγόριθμος του Buzen eClass (διαθέσιμο στο πλήρες πακέτο).
- Κεφ. 5–6 — Εισαγωγή στην προσομοίωση και προσομοίωση ενός συστήματος αναμονής (τυχαίοι αριθμοί, γράφος γεγονότων) eClass (διαθέσιμο στο πλήρες πακέτο).
- Κεφ. 7 — Επιλογή πιθανοτικών κατανομών εισόδου (εμφανίζεται σε παλαιότερες χρονιές· βλ. «Εξετάσεις») eClass (διαθέσιμο στο πλήρες πακέτο).

Στόχοι του μαθήματος, κατά το περίγραμμα, είναι να επιλύεις βασικά μοντέλα αναμονής και δίκτυα, να δημιουργείς προσομοιωτές και να αναλύεις αποτελέσματα πειραμάτων [Περίγραμμα](https://www.ceid.upatras.gr/sites/default/files/ceid_ne4547_gr.pdf).
