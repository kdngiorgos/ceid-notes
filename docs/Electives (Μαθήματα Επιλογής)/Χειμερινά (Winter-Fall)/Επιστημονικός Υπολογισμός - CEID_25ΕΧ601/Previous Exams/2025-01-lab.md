- 2) Να υπολογίσετε όσο ακριβέστερα μπορείτε την τιμή του Ω που αντιστοιχεί στην αποδοτικότερη μέθοδο. Υπενθύμιση: Η mtimes δεν χρησιμοποιεί υπερταχείες μεθόδους.

A = rand(350); B = kron(eye(2),A); p=26; %

B_rec = B; for j = 1 : p – 1, B_rec = mtimes(B, B_rec); end; % προφανής υπολογισμός
