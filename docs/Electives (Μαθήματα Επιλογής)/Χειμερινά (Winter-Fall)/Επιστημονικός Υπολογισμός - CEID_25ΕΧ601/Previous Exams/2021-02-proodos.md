τάξης $n - 1$. Έστω ότι γνωρίζετε τη διάσπαση SVD του $A = U\Sigma V^T$ και άρα ότι $Au_j = \sigma_j v_j$ όπου $\sigma_1 \ge \sigma_2 \ge \dots \sigma_n$. Με χρήση αυτής της πληροφορίας, να επιλέξετε διανύσματα $g, h$ έτσι ώστε το $B = A + gh^T$ να είναι αντιστρέψιμο.

- [ ] $g = u_n, h = v_n$
- [ ] $g = u_1, h = v_n$
- [ ] $g = u_n, h = v_1$

## 149160144_3745687585510398_8557246332622565729_n.jpg

Ερώτηση 1 (Πολλαπλής Επιλογής (Μοναδική Απάντηση) — 20 βαθμοί)

Έστω συμμετρικό θετικά ορισμένο μητρώο $A \in \mathbb{R}^{n \times n}$, με $n \ge 10$. Έστω επίσης ότι έχουμε στη διάθεση μας τη σύνθετη αναδρομική συνάρτηση Cholesky, με το όνομα chol_block(A,r). Το δεύτερο όρισμα εισόδου r, καθορίζει το μέγεθος της διάσπασης και γνωρίζουμε ότι $r < n$. Θεωρούμε επίσης ότι εκτελούνται οι ακόλουθες εντολές Matlab:

```matlab
[G]=chol_block(A,r); k = floor(n/r);
if nnz(G) == (n^2+n)/2
    G1 = G(1:r,r+1:n); G2 = G(r+1:n,r+1:n);
    f = nnz(G1)+nnz(G2);
end
```

Να επιλέξετε τη σωστή απάντηση.

- [ ] Η (απλή) συνάρτηση Cholesky αναμένεται να εκτελεστεί k+1 φορές. Επιπλέον, αν η μεταβλητή f λάβει τιμή, τότε αυτή αναμένεται να είναι $\frac{(n-r)^2+(n-r)}{2}$.
- [ ] Η (απλή) συνάρτηση Cholesky αναμένεται να εκτελεστεί k φορές. Επιπλέον, αν η μεταβλητή f λάβει τιμή, τότε αυτή αναμένεται να είναι $\frac{r^2+r}{2}$.
- [ ] Η (απλή) συνάρτηση Cholesky αναμένεται να εκτελεστεί 1 φορά. Επιπλέον, αν η μεταβλητή f λάβει τιμή, τότε αυτή αναμένεται να είναι $\frac{r^2+r}{2}$.
- [ ] Κανένα από τα υπόλοιπα.
