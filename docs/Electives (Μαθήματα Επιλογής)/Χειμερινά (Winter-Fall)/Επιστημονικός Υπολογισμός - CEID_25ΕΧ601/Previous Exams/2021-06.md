Ερώτηση 1 / 2 (Πολλαπλής Επιλογής (Μοναδική Απάντηση) — 10 βαθμοί)

Δίνεται τανυστής βαθμού 4 και μεγέθους 3 σε κάθε διάσταση, δηλ. $T \in \mathbb{R}^{3\times3\times3\times3}$. Γνωρίζετε επιπλέον ότι ο τανυστής είναι διαγώνιος με όλα τα διαγώνια στοιχεία ίσα με 2. Ποιά θα είναι η πρώτη ίνα;

- [ ] $\begin{pmatrix}2\\2\\2\end{pmatrix}$
- [ ] $\begin{pmatrix}2\\0\\0\end{pmatrix}$
- [ ] $\begin{pmatrix}4\\4\\4\\4\end{pmatrix}$
- [ ] $\begin{pmatrix}2\\0\\0\\0\end{pmatrix}$

## EY_Hadamard_Kroneker_1.jpg

**Ερώτηση 1 / 2 (Ταίριασμα — 10 βαθμοί)**

Δίνονται τετραγωνικά μητρώα $A$, $B$ και $\otimes$ το σύμβολο πολλαπλασιασμού Kronecker. Τότε επιλέξτε:

| Στήλη Α | Κάντε την αντιστοιχία | Στήλη Β |
|---|---|---|
| **1.** Αν $k$ φυσικός αριθμός, τότε ισχύει πάντα ότι $(A \otimes B)^k = A^k \otimes B^k$. | [ ▼ ] | **A.** Σωστό |
| **2.** Αν tr η συνάρτηση ίχνους του μητρώου, τότε $tr(A \otimes B) = tr(A)tr(B)$. | [ ▼ ] | **B.** Λάθος |
| **3.** $A \otimes (B \otimes C) = (B \otimes C) \otimes A$ | [ ▼ ] | |
| **4.** Αν το $A$ είναι $2 \times 2$ τότε το γινόμενο $A \otimes A \otimes A \otimes A \otimes A$ έχει διάσταση $16 \times 16$. | [ ▼ ] | |
| **5.** Αν το $A$ είναι $3 \times 3$ και το $e$ είναι $3 \times 1$ τότε το $(A \otimes e)(e \otimes A)^T$ είναι $9 \times 9$. | [ ▼ ] | |

> Σημείωση: η φωτογραφία περιέχει απαντήσεις φοιτητή (επιλεγμένη τιμή στο αναπτυσσόμενο μενού της πρώτης γραμμής), που δεν μεταγράφονται. Η εικόνα είναι στιγμιότυπο οθόνης από πλατφόρμα ερωτήσεων.

## EY_Cholesky_2.png

Ερώτηση 1 (Πολλαπλής Επιλογής (Μοναδική Απάντηση) — 0 βαθμοί)

Έστω η συνάρτηση σε Matlab cholesky_block η οποία υλοποιεί τη σύνθετη αναδρομική Cholesky, με δεδομένα είσοδου συμμετρικό και θετικά ορισμένο μητρώο $A$, καθώς επίσης και έναν φυσικό $r>1$ που καθορίζει το μέγεθος των επιμέρους σύνθετων υπό μητρώων του $A$. Αν εκτελέσουμε την εντολή G=cholesky_block(A,2) για $A \in \mathbb{R}^{9\times 9}$, πόσες κλήσεις της συνάρτησης cholesky_block απαιτούνται μέχρι να προσδιοριστεί πλήρως το $G$;

- [ ] 1
- [ ] 3
- [ ] 4
- [ ] Κανένα από τα υπόλοιπα.

> Σημείωση: παραλείπονται τα κουμπιά της διεπαφής (Προσωρινή αποθήκευση, Ακύρωση, Υποβολή).
