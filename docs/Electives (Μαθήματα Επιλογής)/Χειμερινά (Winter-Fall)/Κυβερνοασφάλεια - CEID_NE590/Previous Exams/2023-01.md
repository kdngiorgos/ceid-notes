# Κυβερνοασφάλεια — Ιανουάριος 2023

> Μεταγραφή της φωτογραφίας IMG_20230131_161128.jpg (η σελίδα των θεμάτων της εξέτασης).

## IMG_20230131_161128.jpg

Μάθημα: Κυβερνοασφάλεια

Ερωτήματα

1. Να σχεδιαστεί και να αναλυθεί το διάγραμμα το επιθέσεων, για την ασφάλεια των κυβερνοφυσικών συστημάτων.

2. Ποια τα χαρακτηριστικά των καταστρεπτικών (destructive) τεχνικών, ανίχνευσης δούρειων ίππων σε ICs; Να δοθεί σύντομη περιγραφή.

3. Να δοθεί η δομή και η λειτουργία ενός Ring Oscillator PUF. Να περιγράψετε τα πλεονεκτήματα του.

4. Να περιγράψετε τα κριτήρια κατά ISO 27037:2012.

5. Να περιγράψετε τη μεθοδολογία STRIDE.

6. Να περιγράψετε τα ενδεικτικά θέματα των προγραμμάτων επίγνωσης ασφάλειας.

Πληροφορίες:

- Η διάρκεια της εξέτασης είναι 1:30. Δίνεται η δυνατότητα πρόωρης αποχώρησης, εάν το επιθυμείτε, 1:00 αργότερα από την έναρξη της εξέτασης.
- Τα θέματα είναι ισοδύναμα.
- Η κόλλα των θεμάτων θα πρέπει να επιστραφεί, μαζί με τις απαντήσεις σας.
- Δεν επιτρέπεται η χρήση ηλεκτρονικών συσκευών, οι οποίες θα πρέπει να είναι υποχρεωτικά απενεργοποιημένες.
