# Κυβερνοασφάλεια — Φεβρουάριος 2026

> Μεταγραφή της φωτογραφίας IMG_20260205_150217.jpg (η σελίδα των θεμάτων της εξέτασης).

## IMG_20260205_150217.jpg

Κυβερνοασφάλεια

Θέματα Εξέτασης

1. Να δοθεί η δομή και η λειτουργία του MAC-CBC.

2. Να περιγραφούν οι βασικές αρχές, της ψηφιακής δικανικής, κάποιας συγκεκριμένης επίσημης υπηρεσίας.

3. Να περιγράψετε τα χαρακτηριστικά της ταυτοποίησης χρήστη προς πρόγραμμα.

4. Να σχεδιαστεί και να αναλυθεί το διάγραμμα το επιθέσεων, για την ασφάλεια των κυβερνοφυσικών συστημάτων.

5. Να αποδείξετε τις συνθήκες που το επίπεδο ασφαλείας του αλγορίθμου κρυπτογράφησης 3DES είναι ισοδύναμο με αυτό του DES.

6. Να δοθεί η δομή και η λειτουργία μιας Ring Oscilator PUF. Να περιγράψετε συνοπτικά τα πλεονεκτήματα της.
