    | Ανθρώπινοι πόροι | Εκπαιδευτικά ιδρύματα |
    | Οικονομικοί πόροι | Εταιρείες κρουαζιέρας |
    | Πρώτες ύλες | Εντάσεως φυσικών πόρων |

    Σκεπτικό: τα διπλώματα ευρεσιτεχνίας είναι κρίσιμα στη φαρμακοβιομηχανία, το ανθρώπινο δυναμικό στην εκπαίδευση, τα κεφάλαια στις κρουαζιέρες και οι πρώτες ύλες στις φυσικών πόρων βιομηχανίες.

    ## Θέμα 4 — Σωστό ή Λάθος για πόρους/ικανότητες

    *Αξιοπιστία: δύο ανεξάρτητες λύσεις συμφωνούν · εμπιστοσύνη λύτη: μέτρια*

    | Πρόταση | Απάντηση |
    |---|---|
    | Εάν μια επιχείρηση διαθέτει αρκετούς πόρους έχει εξασφαλίσει ανταγωνιστικό πλεονέκτημα | Λάθος |
    | Οι οριακές ικανότητες είναι μοναδικές για την επιχείρηση και δεν τις διαθέτει ο ανταγωνισμός | Λάθος |
    | Οι ανταγωνιστές δεν μπορούν να μιμηθούν εύκολα τις θεμελιώδεις ικανότητες μιας επιχείρησης | Σωστό |
    | Η τεχνολογία ανήκει στις θεμελιώδεις ικανότητες | Σωστό |
    | Η επιχειρησιακή κουλτούρα ανήκει στις θεμελιώδεις ικανότητες | Σωστό |
    | Οι οριακές ικανότητες αποτελούν τη βάση για διατηρήσιμο ανταγωνιστικό πλεονέκτημα | Λάθος |

    Σκεπτικό: οι πόροι από μόνοι τους δεν εξασφαλίζουν πλεονέκτημα· οι θεμελιώδεις/πυρηνικές ικανότητες είναι σπάνιες και δύσκολα μιμήσιμες, ενώ οι οριακές είναι αναγκαίες αλλά όχι μοναδικές. Θεωρώ ότι εδώ η τεχνολογία και η κουλτούρα μπορούν να αποτελέσουν θεμελιώδεις ικανότητες.

    ## Θέμα 5 — Αντιστοίχιση όρων SWOT με περιγραφές

    *Αξιοπιστία: δύο ανεξάρτητες λύσεις συμφωνούν · εμπιστοσύνη λύτη: υψηλή*

    | Περιγραφή | Κατηγορία |
    |---|---|
    | Εσωτερικές ικανότητες που μπορούν να βοηθήσουν την επιχείρηση να πετύχει τους στόχους της | Δυνάμεις |
    | Προκλήσεις που μπορεί να οδηγήσουν σε μείωση πωλήσεων και κερδών | Απειλές |
    | Πιθανά πεδία ενδιαφέροντος που μπορεί να προκαλέσουν κερδοφορία | Ευκαιρίες |
    | Εσωτερικά στοιχεία που μπορούν να είναι επιβλαβή για την επίτευξη των στόχων της επιχείρησης | Αδυναμίες |

    Σκεπτικό: δυνάμεις/αδυναμίες είναι εσωτερικοί παράγοντες, ευκαιρίες/απειλές εξωτερικοί.

    ## Θέμα 6 — Κατάταξη παραγόντων στη μήτρα SWOT

    *Αξιοπιστία: δύο ανεξάρτητες λύσεις συμφωνούν · εμπιστοσύνη λύτη: υψηλή*

    | Παράγοντας | Κατηγορία |
    |---|---|
    | Πρόσβαση σε τραπεζική χρηματοδότηση | Δυνάμεις |
    | Μια νέα ανερχόμενη ή αναπτυσσόμενη αγορά | Ευκαιρίες |
    | Προϊόντα ή υπηρεσίες χωρίς διαφοροποίηση | Αδυναμίες |
    | Η είσοδος στην αγορά ενός νέου ανταγωνιστή | Απειλές |
    | Έντονη αφοσίωση του προσωπικού | Δυνάμεις |
    | Μειωμένη διαθεσιμότητα πρώτων υλών | Απειλές |
    | Ανεπαρκές κεφάλαιο κίνησης | Αδυναμίες |
    | Ύπαρξη «κενού» στην αγορά | Ευκαιρίες |
    | Νέες τεχνολογίες | Ευκαιρίες |
    | Αυξανόμενα επιτόκια δανεισμού | Απειλές |

    Σκεπτικό: η χρηματοδότηση και η αφοσίωση προσωπικού είναι εσωτερικά θετικά στοιχεία· η έλλειψη διαφοροποίησης και κεφαλαίου κίνησης είναι εσωτερικές αδυναμίες· τα υπόλοιπα εξωτερικά.

    ## Θέμα 7 — Πώς αξιοποιούμε την ανάλυση SWOT

    *Αξιοπιστία: δύο ανεξάρτητες λύσεις συμφωνούν · εμπιστοσύνη λύτη: υψηλή*

    | Πρόταση | Απάντηση |
    |---|---|
    | Οι απειλές μετατρέπονται σε αδύναμα σημεία | Λάθος |
    | Οι ευκαιρίες μπορούν να μετατραπούν σε απειλές με την αξιοποίηση κατάλληλων πόρων | Λάθος |
    | Τα Αδύναμα Σημεία μπορούν να μετατραπούν σε Δυνατά Σημεία μέσα από δράσεις στρατηγικής | Σωστό |
    | Μετατροπή Δυνατών Σημείων σε Ικανότητες, συνδυάζοντάς τα με τα αδύναμα σημεία | Λάθος |

    Σκεπτικό: η SWOT χρησιμοποιείται για αξιοποίηση δυνάμεων, διόρθωση αδυναμιών, εκμετάλλευση ευκαιριών και αντιμετώπιση απειλών.

    ## Θέμα 8 — Σωστό ή Λάθος για stakeholders

    *Αξιοπιστία: δύο ανεξάρτητες λύσεις συμφωνούν · εμπιστοσύνη λύτη: υψηλή*

    | Ανήκουν στο εσωτερικό περιβάλλον της επιχείρησης | Λάθος |

    Σκεπτικό: οι stakeholders περιλαμβάνουν και εξωτερικές ομάδες, άμεσες και έμμεσες· η διαχείριση αντικρουόμενων συμφερόντων είναι κεντρική.
