Ερωτήσεις πολλαπλής επιλογής και αντιστοίχισης (Σημειώστε την σωστή απάντηση στο κουτάκι) (5 μονάδες)

1. Αντιστοιχίστε τις παρακάτω σχέσεις εξουσίας με τα χαρακτηριστικά τους:

|  |  |  |
|---|---|---|
| Ασκούνται από άτομα που έχουν ειδικές γνώσεις | [ ] | Α. Επιτελικές |
| Υποχρεωτικός και συμβουλευτικός χαρακτήρας | [ ] | Β. Γραμμικές |
| Ασκούνται από τους μάνατζερ τμημάτων στους υφισταμένους τους | [ ] | Γ. Λειτουργικές |

2. Αντιστοιχίστε τους παρακάτω όρους που αναφέρονται στις στρατηγικές ανταγωνισμού

|  |  |  |
|---|---|---|
| Η επιχείρηση ανταγωνίζεται με χαμηλό κόστος και τιμές σε όλο το εύρος μιας αγοράς | [ ] | Α. Στρατηγική ηγεσίας κόστους |
| Η επιχείρηση ανταγωνίζεται προσφέροντας προϊόντα ή υπηρεσίες διαφορετικά από αυτά των ανταγωνιστών σε όλο το εύρος της αγοράς | [ ] | Β. Εστίαση με χαμηλό κόστος |
| Η επιχείρηση εστιάζει σε ένα συγκεκριμένο τμήμα της αγοράς ώστε να επιτύχει χαμηλότερο κόστος | [ ] | Γ. Στρατηγική διαφοροποίησης |
| Η επιχείρηση εστιάζει σε ένα συγκεκριμένο τμήμα της αγοράς ώστε να επιτύχει διαφοροποίηση | [ ] | Δ. Εστίαση με διαφοροποίηση |

3. Αντιστοιχίστε τις παρακάτω ιδιότητες με τον manager ή τον ηγέτη

|  |  |  |
|---|---|---|
| Περνά όραμα, εμπνέει και πείθει | [ ] | A.Manager |
| Χρησιμοποιεί νόμιμη εξουσία | [ ] | Β. Ηγέτης |
| Καινοτομεί, κάνει αλλαγές | [ ] |  |

4. Ποια από τα παρακάτω χαρακτηριστικά ανήκουν στο ορθολογικό μοντέλο λήψης αποφάσεων;

- [ ] Α) Πλήρης πληροφόρηση
- [ ] Β) Το αποτέλεσμα είναι μια απόφαση ικανοποίησης
- [ ] Γ) Σαφώς προσδιορισμένα προβλήματα
- [ ] Δ) Περιορισμένη ικανότητα πρόβλεψης συνεπειών

5. Αντιστοιχίστε τα παρακάτω στυλ ηγεσίας με την περιγραφή τους

|  |  |  |
|---|---|---|
| Ο ηγέτης αναθέτει εξουσία στους υφισταμένους κι ενθαρρύνει τη συμμετοχή τους | [ ] | Α. Αυταρχικό |
| Ο ηγέτης συγκεντρώνει όλη την εξουσία, και στηρίζεται στη χρήση ανταμοιβών και εξαναγκασμού | [ ] | Β. Φιλελεύθερο |
| Ο ηγέτης συμμετέχει όσο το δυνατό λιγότερο, και παρέχει πλήρη ελευθερία στους υφισταμένους να λαμβάνουν αποφάσεις | [ ] | Γ. Δημοκρατικό |

6. Αντιστοιχίστε τα παρακάτω καθήκοντα με το κατάλληλο διοικητικό στέλεχος

|  |  |  |
|---|---|---|
| Καθοδήγηση υπαλλήλων | [ ] | Α. ανώτερο στέλεχος |
| Παρακολούθηση επιχειρησιακού περιβάλλοντος | [ ] | Β. μεσαίο στέλεχος |
| Προγραμματισμός/κατανομή πόρων | [ ] | Γ. κατώτερο στέλεχος |

7. Ποιον τρόπο τμηματοποίησης θα χρησιμοποιούσατε για να επιτύχετε τα παρακάτω:

|  |  |  |
|---|---|---|
| Αποτελεσματική χρήση διαθέσιμων πόρων | [ ] | Α. Τμηματοποίηση κατά προϊόν |
| Υψηλή εξειδίκευση | [ ] | Β. Τμηματοποίηση κατά λειτουργία |
| Αποτελεσματικές λύσεις σε τεχνικά προβλήματα | [ ] |  |
