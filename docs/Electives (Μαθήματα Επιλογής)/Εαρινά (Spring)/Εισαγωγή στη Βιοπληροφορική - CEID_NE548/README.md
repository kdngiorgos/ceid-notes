# Εισαγωγή στη Βιοπληροφορική

> Εφαρμογή αλγορίθμων συμβολοσειρών σε βιολογικά δεδομένα: ακριβές και προσεγγιστικό ταίριασμα προτύπων (KMP, Boyer–Moore, Aho–Corasick, Shift-Or), suffix trees, στοίχιση ακολουθιών, βάσεις δεδομένων (FASTA, BLAST), φυλογενετικά δέντρα, τεχνικές αλληλούχισης γονιδιώματος και σχεδιασμός φαρμάκων με υπολογιστή. Στην πράξη είναι «αλγόριθμοι σε strings» με βιολογικό περιτύλιγμα, θεωρητικό μάθημα χωρίς κώδικα. Η αξιολόγηση γίνεται με δύο υποχρεωτικά projects και προφορική εξέταση, χωρίς τελική γραπτή.

## Τι θα μάθεις

Το επίσημο περίγραμμα περιγράφει αλγορίθμους διαχείρισης συμβολοσειρών και ακολουθιών βιολογικών δεδομένων [Περίγραμμα](https://www.ceid.upatras.gr/assets/2024/07/ceid_ne548_gr.pdf):

- Ακριβές ταίριασμα προτύπων (Boyer–Moore, Knuth–Morris–Pratt, Karp–Rabin) και ταίριασμα πολλαπλών προτύπων (Aho–Corasick).
- Δέντρα επιθεμάτων (suffix trees) και εφαρμογές τους.
- Προσεγγιστικό ταίριασμα προτύπων και στοίχιση συμβολοσειρών/ακολουθιών (sequence alignment).
- Βάσεις δεδομένων ακολουθιών και εύρεση σε αυτές (FASTA, BLAST, PAM, PROSITE, BLOCKS, BLOSUM).
- Σχεδιασμός φαρμάκων με υπολογιστή (structure-based drug design, σχέση δομής–δραστικότητας, αναπαράσταση μορίων, conformational search, binding sites).
- Κατηγοριοποίηση και ομαδοποίηση βιολογικών δεδομένων (νευρωνικά δίκτυα, γενετικοί αλγόριθμοι, SVMs, k-means/CLARA).
- Φυλογενετικά δέντρα, αλγόριθμοι αλληλούχισης γονιδιώματος και Next Generation Sequencing.

Οι διαφάνειες ακολουθούν την ίδια δομή σε ενότητες: εισαγωγή στη βιολογία, ακριβές ταίριασμα, suffix trees, στοίχιση, κατηγοριοποίηση, σχεδιασμός φαρμάκων, προσεγγιστικά ταιριάσματα, suffix arrays/συμπίεση, data mining eClass (διαθέσιμο στο πλήρες πακέτο).
