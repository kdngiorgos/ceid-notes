## IMG_20250618_122429284_HDR2.jpg

Θέματα Εξέτασης

> [Λείπει από τη φωτογραφία: αρίθμηση «1.» του πρώτου θέματος (κομμένη στο άκρο)]

- Να εξηγήσετε τον κύκλο ανακύκλωσης ενός IC. Ποιοι κίνδυνοι και ποιες απειλές τίθενται σε κάθε στάδιο, (να δοθεί σύντομη περιγραφή τους);

2. Να δοθεί η ταξινόμηση των δούρειων ίππων, με κριτήριο την ενεργοποίηση τους, (μπορείτε να γράψετε το σχηματικό διάγραμμα και μια σύντομη περιγραφή, το πολύ 3-5 γραμμές για κάθε κατηγορία).

3. Να γράψετε, με σύντομη περιγραφή, τις κλάσεις των επιθέσεων και τα χαρακτηριστικά τους.

4. Ποια χαρακτηριστικά πρέπει να υποστηρίζει μια δομή PKI (Public Key Infrastructure);

5. Να εξηγήσετε τα επίπεδα ελέγχου (παραχάραξης), βασισμένα στον κίνδυνο.
