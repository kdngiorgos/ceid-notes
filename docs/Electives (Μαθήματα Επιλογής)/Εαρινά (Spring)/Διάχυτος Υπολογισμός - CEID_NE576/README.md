# Διάχυτος Υπολογισμός

> Επιλογής μάθημα του τομέα ΛΥ γύρω από τον Διάχυτο Υπολογισμό (Ubiquitous Computing): την έννοια και τα πεδία εφαρμογής του (έξυπνες πόλεις, περιρρέουσα νοημοσύνη, υγεία, διάχυτα παίγνια, 4η βιομηχανική επανάσταση), την επίγνωση πλαισίου, τις αρχιτεκτονικές συστημάτων (IoT, cloud/fog/edge) και την αλληλεπίδραση ανθρώπου–συστήματος. Το βάρος πέφτει σε ένα μεγάλο ομαδικό project, ενώ η γραπτή εξέταση είναι μικρότερη (30%). Κατά φοιτητές είναι απαιτητικό, κυρίως λόγω του project και των προαπαιτούμενων γνώσεων.

## Τι θα μάθεις

Το επίσημο περίγραμμα οργανώνει την ύλη σε έξι ενότητες [Περίγραμμα](https://www.ceid.upatras.gr/sites/default/files/ceid_ne576_course_outline_2020_21.pdf):

- Η έννοια του Διάχυτου Υπολογισμού: ιστορικές καταβολές, σχέση με άλλα πεδία της πληροφορικής, της μηχανικής και άλλων επιστημών.
- Πεδία εφαρμογής: ευφυείς πόλεις και περιβάλλοντα, περιρρέουσα νοημοσύνη, υποστήριξη υγείας, διάχυτα παίγνια, ηλεκτρονικό εμπόριο, 4η βιομηχανική επανάσταση.
- Επίγνωση πλαισίου (context awareness) και υπολογιστική νοημοσύνη: τύποι πλαισίου, τεχνικές κτήσης, μηχανική μάθηση/ΤΝ για την επεξεργασία δεδομένων.
- Αρχιτεκτονικές και μοντέλα συστημάτων: συσκευές, τεχνικές επικοινωνίας, κατανομή υπολογισμών και πόρων (IoT, cloud/fog/edge).
- Αλληλεπίδραση με συστήματα: έμμεση/άμεση αλληλεπίδραση, πολυτροπική διάδραση, αξιολόγηση.
- Επαγγελματικά και κοινωνικά ζητήματα: ηθική, ιδιωτικότητα, συμμόρφωση με νομοθεσία, αξιοπιστία/διαφάνεια αλγορίθμων.

Το πρακτικό σκέλος γίνεται μέσω project (σχεδιασμός, υλοποίηση, αξιολόγηση) με τεχνολογίες όπως IoT, κατανεμημένη μηχανική μάθηση (SparkML/Storm/Kafka), Android, Mobile HTML5, Arduino/Raspberry Pi [Περίγραμμα](https://www.ceid.upatras.gr/sites/default/files/ceid_ne576_course_outline_2020_21.pdf).

## Πώς βαθμολογείται

- Περίγραμμα (2020-21): γραπτή εξέταση με ερωτήσεις πολλαπλής επιλογής και σύντομης ανάπτυξης στο 30% και εργασία σε σύνθετη εφαρμογή Διάχυτων Υπολογιστικών Συστημάτων στο 70% [Κατάλογος: Περίγραμμα](https://www.ceid.upatras.gr/sites/default/files/ceid_ne576_course_outline_2020_21.pdf).
- Τα ποσοστά 70%/30% προέρχονται από το περίγραμμα 2020-21 και από μηνύματα του 2021· δεν υπάρχει επιβεβαίωση για το 2025-26 [Κατάλογος: Περίγραμμα](https://www.ceid.upatras.gr/sites/default/files/ceid_ne576_course_outline_2020_21.pdf), Discord 2021-02 (διαθέσιμο στο πλήρες πακέτο), Discord 2021-03 (διαθέσιμο στο πλήρες πακέτο).
- Γλώσσα αξιολόγησης: Ελληνική (Αγγλικά αν χρειαστεί) [Κατάλογος: Περίγραμμα](https://www.ceid.upatras.gr/sites/default/files/ceid_ne576_course_outline_2020_21.pdf).
- 2020-21 (κατά φοιτητές): ομαδικό project 3 ατόμων που πιάνει το 70% του τελικού βαθμού και 30% η γραπτή, που «μάλλον θα είναι πολλαπλής»· το project μπορούσε να παραδοθεί και τον Σεπτέμβριο Discord 2021-02 (διαθέσιμο στο πλήρες πακέτο).
- 2020-21: προαιρετικές εργασίες θα ανέβαιναν στο μέλλον και θα μετρούσαν θετικά σε περίπτωση αποτυχίας στη γραπτή εξέταση Discord 2021-03 (διαθέσιμο στο πλήρες πακέτο).
- 2024-25 (κατά φοιτητή): η γραπτή είναι «εύκολη πολλαπλής με βάση τις διαφάνειες», ενώ τη μεγαλύτερη βαρύτητα την έχει το project Discord 2025-02 (διαθέσιμο στο πλήρες πακέτο).

## Εργασίες & εργαστήρια

Ο κατάλογος δίνει 2 ώρες εργαστηρίου εβδομαδιαίως [Κατάλογος](../../../catalog/curriculum_2025-26.yaml). Στην πράξη το μάθημα οργανώνεται γύρω από ένα μεγάλο ομαδικό project (βλ. «Πώς βαθμολογείται») που περιγράφεται ως υποχρεωτικό (2020-21) Discord 2021-03 (διαθέσιμο στο πλήρες πακέτο).

- 2020-21: ομαδικό project των 3 ατόμων· δυνατότητα παράδοσης και τον Σεπτέμβριο Discord 2021-02 (διαθέσιμο στο πλήρες πακέτο). Αργότερα φοιτητές ρωτούσαν για ομάδες και για το μέγιστο πλήθος ατόμων Discord 2023-04 (διαθέσιμο στο πλήρες πακέτο).
- 2021-22: ένα μεγάλο project με εφαρμογή Android Discord 2022-03 (διαθέσιμο στο πλήρες πακέτο)· φοιτητής χρησιμοποίησε το ThingsBoard για το project Discord 2022-06 (διαθέσιμο στο πλήρες πακέτο).
- 2024-25: κατά φοιτητή, πέρσι υπήρχαν 3 projects με μηχανική μάθηση (κυρίως νευρωνικά δίκτυα) και ένα με AR, χωρίς να είναι υποχρεωτικό το ML· το πιο απλό ήταν εφαρμογή αλγορίθμου σε προσομοιωτή κυκλοφορίας (uxsim) για χρονισμό φαναριών, ενώ σε άλλη χρονιά ζητήθηκε εφαρμογή αναγνώρισης νοηματικής Discord 2025-02 (διαθέσιμο στο πλήρες πακέτο).
- 2025-26: ενιαίο project «smart home»· το πρώτο παραδοτέο (ανάλυση/σχεδιασμός, με ACM template) είχε προτεινόμενη προθεσμία 8 Μαΐου 2026, αλλά η υποβολή των τελικών παραδοτέων (report, κώδικας, βίντεο) γίνεται μία φορά στο τέλος, μόνο στο e-class Discord 2026-05 (διαθέσιμο στο πλήρες πακέτο). Ο διδάσκων συζητά το project με τους φοιτητές πριν το βάλει Discord 2026-02 (διαθέσιμο στο πλήρες πακέτο).
- Το 2026 έμεινε αναπάντητο αν το project έχει προφορική εξέταση Discord 2026-05 (διαθέσιμο στο πλήρες πακέτο).
