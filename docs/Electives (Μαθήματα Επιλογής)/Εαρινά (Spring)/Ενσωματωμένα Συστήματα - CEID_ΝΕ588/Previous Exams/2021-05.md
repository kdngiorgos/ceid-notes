# Ενσωματωμένα Συστήματα — Μάιος 2021

> Μεταγραφή από το στιγμιότυπο unknown.png (μία οθόνη, ολόκληρο το κείμενο της ερώτησης είναι ορατό).

## unknown.png

Ερώτηση 1 (Ελεύθερου Κειμένου — 0 βαθμοί)

Θέμα Α (25%) Θεωρείστε το παράδειγμα ενσωματωμένου πλήρους συστήματος, ενός έξυπνου σπιτιού. Περιγράψτε αναλυτικά τρεις λειτουργίες-υπηρεσίες και να δώσετε τη ροή σχεδιασμού του με βάση, ένα από τα μοντέλα που έχετε διδαχθεί στο μάθημα. (Διευκρίνηση: δεν θα απαντήσετε με τη γενική προσέγγιση, αλλά θα δείξετε πως ακριβώς εφαρμόζεται η συγκεκριμένη προσέγγιση στην επιλογή σας).

Θέμα Β (25%) Για κάθε μία από τις τρεις λειτουργίες-υπηρεσίες που επιλέξατε να υλοποιήσετε μια διαφορετική τεχνική χρόνου.

Θέμα Γ (25%) Να σχεδιάσετε και να εξηγήστε το διάγραμμα pareto points, για τους δύο πιο κρίσιμους σχεδιαστικούς στόχους, αναφορικά με μια λειτουργία-υπηρεσία που επιλέξατε στο Θέμα Α. Πως θα βελτιώνατε το σύστημα μας, ως προς τους στόχους που επιλέξατε; Εξηγείστε σε κατανοητό βαθμό.

Θέμα Δ (25%) Εάν είχατε στη διάθεση σας, ένα τρίωρο σεμινάριο, για να εξειδικεύσετε ένα νέο μηχανικό υπολογιστών, εξηγείστε ποια ενότητα του μαθήματος θα οργανώνατε για διδασκαλία και γιατί. Να τεκμηριώσετε πλήρως την απάντηση σας.
