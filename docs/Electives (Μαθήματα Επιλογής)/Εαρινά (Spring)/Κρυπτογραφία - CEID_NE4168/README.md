# Κρυπτογραφία

> Εισαγωγή στην κρυπτογραφία και την κρυπτανάλυση με έμφαση στο μαθηματικό υπόβαθρο: θεωρία αριθμών, κλασικά και σύγχρονα πρωτόκολλα (RSA, ElGamal, Merkle-Hellman), ψηφιακές υπογραφές και συναρτήσεις κατακερματισμού. Στην πράξη είναι ένα μάθημα «στυλό και χαρτί»: οι φοιτητές θυμούνται κυρίως υπολογισμούς με το χέρι πάνω σε συγκεκριμένα πρωτόκολλα, χωρίς εργασία, με μόνη αξιολόγηση την τελική γραπτή εξέταση.

## Τι θα μάθεις

Το περίγραμμα ορίζει ως στόχους τη θεωρία αριθμών, τις βασικές κατηγορίες κρυπτογραφικών πρωτοκόλλων, τα πρωτόκολλα δημόσιου κλειδιού, τις συναρτήσεις ταυτοποίησης/MAC/hash και τα αλληλεπιδραστικά πρωτόκολλα [Περίγραμμα](https://www.ceid.upatras.gr/sites/default/files/ceid_ne4168_gr.pdf) [Κατάλογος](../../../catalog/curriculum.md). Ως θεματικές αναφέρονται:

- Κρυπτογραφικά πρωτόκολλα και αλληλεπίδραση αποστολέα–παραλήπτη.
- Κλειδιά και διαχείρισή τους· DES και άλλα block ciphers· ασφαλείς ψευδοτυχαίες ακολουθίες.
- Κρυπτογραφία δημόσιου κλειδιού· ψηφιακές υπογραφές και πιστοποίηση αποστολέα.
- Σύνδεση με σχεδιασμό αλγορίθμων/υπολογιστική πολυπλοκότητα· νομικά θέματα.

Στην πράξη, όπως φαίνεται και στα θέματα που έχουν διασωθεί στο `other/`, το βάρος πέφτει στο μαθηματικό κομμάτι: modular αριθμητική, αλγόριθμος Ευκλείδη και αντίστροφα, δυνάμεις mod n (θεωρήματα Fermat/Euler), και τα πρωτόκολλα RSA, ElGamal και Merkle-Hellman other/13_.pdf (δεν δημοσιεύεται εδώ). Φοιτητής το 2023 συμβουλεύει να μάθεις «rsa, merkle-hellman, el gamal» και να κοιτάξεις τα παλιά θέματα των pinned Discord 2023-02 (δεν δημοσιεύεται εδώ).
