# Συστήματα Διαχείρισης Μεγάλων Δεδομένων (πρώην Βάσεις 2)

> Η προχωρημένη συνέχεια των Βάσεων Δεδομένων (αναφέρεται συχνά ως «Βάσεις 2»): χωρικά και πολυμεσικά ευρετήρια (R-trees, kd-trees, quad trees), βελτιστοποίηση επερωτήσεων, δοσοληψίες και συνδρομηκότητα, κατανεμημένες βάσεις, NoSQL (Cassandra, MongoDB, HBase) και το οικοσύστημα Hadoop/Spark. ## Τι θα μάθεις

Το επίσημο περίγραμμα συνοψίζει ένα ευρύ φάσμα προχωρημένης διαχείρισης δεδομένων [Περίγραμμα](https://www.ceid.upatras.gr/sites/default/files/ceid_ne4348_gr_0.pdf):

- **Χωρικές / πολυδιάστατες μέθοδοι προσπέλασης (Spatial Access Methods):** R-trees, kd-trees, quad trees, z-ordering, καμπύλες Hilbert, σύγκριση μεθόδων και πολυπλοκότητα.
- **Δομές ευρετηρίων για μεγάλα δεδομένα και πολυμέσα:** lower bounding lemma, false alarms / false dismissals, colour histograms, ευρετηριοποίηση χρονικών σειρών.
- **Επεξεργασία και βελτιστοποίηση επερωτήσεων (query optimization):** υπολογισμός κόστους, selectivities, joins σε SQL, σχέδια εκτέλεσης.
- **Αντικειμενοστραφή και αντικειμενοσχεσιακά** συστήματα διαχείρισης βάσεων.
- **Δοσοληψίες:** έλεγχος συνδρομηκότητας (serializability, precedence graph, 2PL, locks), deadlocks, ανάκαμψη.
- **Κατανεμημένες βάσεις:** concurrency control, πρωτόκολλα, επίπεδα συνέπειας και CAP theorem.
- **NoSQL και σύγχρονες τεχνολογίες:** HBase, Cassandra, MongoDB, NewSQL, Hadoop, Spark.
- **Βάσεις κειμένου** (inverted files, signature files, Zipf, clustering/VSM), **Big Data analytics**, **συστήματα ροών (DSMS)**, **fractals** και αναδυόμενες τεχνολογίες.

Το project φέρνει την ύλη σε πράξη: οι φοιτητές κατασκευάζουν pipeline με Kafka/Spark και αποθήκευση σε MongoDB/Cassandra Discord 2025-06 (διαθέσιμο στο πλήρες πακέτο).
