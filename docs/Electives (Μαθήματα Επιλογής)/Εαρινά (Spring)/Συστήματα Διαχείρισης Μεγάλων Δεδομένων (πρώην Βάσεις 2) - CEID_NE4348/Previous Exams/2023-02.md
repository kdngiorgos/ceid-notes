- $n_{\text{ΦΟΙΤΗΤΗΣ}} = 4000$ εγγραφές
- $f_{\text{ΦΟΙΤΗΤΗΣ}} = 20$ εγγραφές ανά μπλοκ
- $V(\text{Όνομα}, \text{ΦΟΙΤΗΤΗΣ}) = 128$
- $V(\text{Επώνυμο}, \text{ΦΟΙΤΗΤΗΣ}) = 50$
