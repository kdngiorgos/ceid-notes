- [ ] a. το μέγεθος της κρυφής μνήμης

- [ ] a. την παραλληλοποίηση κώδικα από τον μεταγλωττιστή

- [ ] c. Συστήματα κατανεμημένης κοινής μνήμης

**1.5** Δίνεται ο παρακάτω κώδικας OpenMP.

```c
int test_var = 0;

#pragma omp parallel num_threads(5) reduction(+:test_var)
{
    test_var += omp_get_num_threads();
}

/* σημείο αναφοράς */
```

Ποια θα είναι η τιμή της μεταβλητής test_var μετά την εκτέλεση της παράλληλης περιοχής; Εξηγήστε.

- [ ] a. τίποτα από τα παρακάτω
- [ ] b. 0
- [ ] c. 5
- [ ] d. 10

**1.6** Δίνεται ο παρακάτω κώδικας OpenMP.

```c
int main(int argc, char *argv[]) {
    int b,c ;

    {
        int d ;
        #pragma omp task
        {
            int e ;
            // σημείο αναφοράς εντός του task
        }
    }
    // more code here
    return 0;

```

Στον παραπάνω κώδικα και συγκεκριμένα στο σημείο αναφοράς εντός του task, η μεταβλητή e είναι:

- [ ] a. shared
- [ ] b. private
- [ ] c. threadprivate
- [ ] d. firstprivate

## Θέμα 2° (3 μονάδες)

**2.1** Δίνεται ο παρακάτω κώδικας OpenMP.

```c
// N is large
int *x = (int *) malloc(N*sizeof(int));
int *y = (int *) malloc(N*sizeof(int));

for (int i = 0; i < N; i++) x[i] = i;

#pragma omp parallel for schedule(static, 2)
for (int i = 0; i < N; i++)
    y[i] = x[i];
```

Περιγράψτε τι κάνει ο παραπάνω παράλληλος κώδικας. Αναφέρετε πιθανά ζητήματα απόδοσης.

**2.2** Δίνεται το παρακάτω τμήμα κώδικα MPI.

```c
int rank, size;
MPI_Comm_rank(MPI_COMM_WORLD, &rank);
MPI_Comm_size(MPI_COMM_WORLD, &size);

double var1 = rank+1.0;
double var2 = 0.0;

MPI_Allreduce(&var1,&var2,1, MPI_DOUBLE, MPI_PROD, MPI_COMM_WORLD);
MPI_Reduce(&var2, &var1, 1, MPI_DOUBLE, MPI_SUM, 0, MPI_COMM_WORLD);

if (rank == 0) printf("%f\n", var1);
```

a. Τι τιμή εκτυπώνει ο παραπάνω κώδικας όταν εκτελεστεί με 5 διεργασίες (mpirun -n 5 <executable>);

b. Εξηγήστε αναλυτικά.
