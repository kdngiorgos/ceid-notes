- [ ] c. υποδιπλασιάσουμε την ακρίβεια των πράξεων κινητ[Λείπει από τη φωτογραφία: ή] υποδιαστολής (double σε float)

1.4 Για ποια συστήματα είναι κατάλληλο το μοντέλο προγραμματισμού OpenMP:
- [ ] a. συστήματα κοινής μνήμης
- [ ] b. συστήματα μη ομοιόμορφης προσπέλασης μνήμ[Λείπει από τη φωτογραφία: ης] (NUMA)
- [ ] c. συστήματα κατανεμημένης κοινής μνήμης
- [ ] d. μπορεί να εκτελεστεί σε όλα τα παραπάνω

1.6 Δίνεται ο παρακάτω κώδικας OpenMP.

```c
int main(int argc, char *argv[]) {
 int b,c ;
 #pragma omp parallel shared(c) private(b)
 {
  int d ;
  #pragma omp task
  {
    int e ;
    // σημείο αναφοράς εντός του task
  }
 }
 // more code here
 return 0;
}
```

Στον παραπάνω κώδικα και συγκεκριμένα στο σημείο αναφοράς εντός του task, η μεταβλητή b είναι:
- [ ] a. shared
- [ ] b. private
- [ ] c. threadprivate
- [ ] d. firstprivate
