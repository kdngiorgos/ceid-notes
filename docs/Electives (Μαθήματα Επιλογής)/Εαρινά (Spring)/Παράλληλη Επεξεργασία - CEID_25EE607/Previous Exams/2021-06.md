Ενότητα 2 (POSIX Threads / OpenMP)

Ο παρακάτω κώδικας κάνει χρήση του μοντέλου εργασιών (tasks) του OpenMP.

```c
int a ;

int main(int argc, char *argv[])
{
    int b,c ;
    #pragma omp parallel shared(c) private(b)
    {
        int d ;
        #pragma omp task
        {
            int e ;

            // σημείο αναφοράς εντός του task
        }
    }

    // more code here
    return 0;
}
```

Στον παραπάνω κώδικα και συγκεκριμένα στο σημείο αναφοράς εντός του task, η μεταβλητή b είναι:

- [ ] shared
- [ ] private
- [ ] firstprivate
- [ ] threadprivate

    Ο παρακάτω κώδικας κάνει χρήση του μοντέλου εργασιών (tasks) του OpenMP

    ```c
    int a;

    int main(int argc, char *argv[])
    {
        int b, c;
        #pragma omp parallel shared(c) private(b)
        {
            int d;
            #pragma omp task
            {
                int e;
                //σημείο αναφοράς εντός του task
            }
        }
        //more code here
        return 0;
    }
    ```

    Στον παραπάνω κώδικα και συγκεκριμένα στο σημείο αναφοράς εντός του task η μεταβλητή c είναι:

    a. shared

    b. private

    c. firstprivate

    δ. threadprivate

    Απάντηση

    a. shared

    Παρατήρηση

    Αν σε ένα task δεν δηλώνεται ο τύπος των μεταβλητών τότε ισχύουν οι εξής κανόνες:

    - Μια μεταβλητή που είναι shared στην παράλληλη περιοχή μέσα στο task θεωρείται επίσης ως shared
    - Μια μεταβλητή που είναι private στην παράλληλη περιοχή μέσα στο task θεωρείται ως firstprivate
    - Μια μεταβλητή που δεν δηλώνεται καθόλου στην παράλληλη περιοχή μέσα στο task θεωρείται επίσης ως firstprivate

    Η c είναι shared στην παράλληλη περιοχή και παραμένει shared μέσα στο task, πράγμα που σημαίνει ότι όλα τα νήματα και tasks μοιράζονται την ίδια μεταβλητή c.
