## 2.1.png

Ερώτηση 1 / 6 (Πολλαπλής Επιλογής (Μοναδική Απάντηση) — 0.40 βαθμοί)

Ενότητα 2 (POSIX Threads / OpenMP)

Ποιο clause πρέπει να προσθέσουμε στην οδηγία parallel στον παρακάτω κώδικα ώστε η τιμή της τοπικής μεταβλητής N να έχει τιμή 1000 σε όλα τα νήματα της παράλληλης περιοχής;

```c
int N = 1000;

#pragma omp parallel ΕΠΙΛΕΞΤΕ ΤΟ ΣΩΣΤΟ CLAUSE ΠΟΥ ΠΡΕΠΕΙ ΝΑ ΒΑΛΕΤΕ ΕΔΩ
```

- [ ] firstprivate(N)
- [ ] private(N)
- [ ] lastprivate(N)
- [ ] num_threads(N)

## 2.2.png

Ερώτηση 2 / 6 (Πολλαπλής Επιλογής (Μοναδική Απάντηση) — 0.40 βαθμοί)

Ενότητα 2 (POSIX Threads / OpenMP)

Η αξιοποίηση έργων (tasks) στο OpenMP:

- [ ] Επιτρέπει τον υπολογισμό μεγαλύτερου όγκου έργου σε δοθέν υπολογιστικό σύστημα
- [ ] Δεν προσφέρει επιπλέον λειτουργία σε σχέση με την χρήση μόνο νημάτων
- [ ] Επιτρέπει την ευκολότερη έκφραση μεγαλύτερου εύρους αλγορίθμων με χρήση παραλληλίας
- [ ] Όλα τα παραπάνω

## 2.3.png

Ερώτηση 3 / 6 (Πολλαπλής Επιλογής (Μοναδική Απάντηση) — 0.40 βαθμοί)

Ενότητα 2 (POSIX Threads / OpenMP)

Δίνεται ο παρακάτω κώδικας OpenMP. Ποια θα είναι η τιμή της τοπικής μεταβλητής test_var σε κάθε νήμα της παράλληλης περιοχής;

```c
int test_var = 5;

#pragma omp parallel private(test_var)
{
    /* Τι τιμή έχει η test_var σε κάθε νήμα της παράλληλης περιοχής; */
}
```

- [ ] Απροσδιόριστη
- [ ] 5
- [ ] 0
- [ ] 5 * p, όπου p το πλήθος των νημάτων της παράλληλης περιοχής

## 2.4.png

Ερώτηση 4 / 6 (Πολλαπλής Επιλογής (Μοναδική Απάντηση) — 0.40 βαθμοί)

Ενότητα 2 (POSIX Threads / OpenMP)

Μια υλοποίηση του προτύπου των POSIX Threads επιτρέπεται να υλοποιήσει τα νήματα:

- [ ] Μόνο ως νήματα επιπέδου πυρήνα
- [ ] Μόνο ως νήματα επιπέδου χρήστη
- [ ] Είτε ως νήματα επιπέδου χρήστη είτε ως νήματα επιπέδου πυρήνα
- [ ] Μόνο ως έργα (tasks)

## 2.5.png

Ερώτηση 5 / 6 (Πολλαπλής Επιλογής (Μοναδική Απάντηση) — 0.40 βαθμοί)

Ενότητα 2 (POSIX Threads / OpenMP)

Ο παρακάτω κώδικας τι πρόβλημα παρουσιάζει ως προς την παράλληλη εκτέλεση του σε ένα υπολογιστικό σύστημα που έχει 8 πυρήνες; Θεωρείστε πως η συνάρτηση thread_func() είναι ορισμένη στο πρόγραμμα και σωστή.

```c
pthread_t tid[10];
int i;

for (i = 0; i < 10; i++) {
    pthread_create(&tid[i], NULL, thread_func, NULL);
    pthread_join(tid[i], NULL);
}
```

- [ ] Τα νήματα που δημιουργούνται δεν εκτελούνται ταυτόχρονα, ακόμα και αν κανένας πυρήνας δεν χρησιμοποιείται από άλλο πρόγραμμα
- [ ] Δημιουργούνται περισσότερα νήματα από τους διαθέσιμους πυρήνες
- [ ] Η χρήση της συνάρτησης pthread_join() δεν είναι απαραίτητη στο συγκεκριμένο πρόγραμμα
- [ ] Το πρόγραμμα δεν έχει κάποιο πρόβλημα
