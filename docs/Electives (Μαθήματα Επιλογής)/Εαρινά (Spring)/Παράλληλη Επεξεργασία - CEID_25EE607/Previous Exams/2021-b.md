## Άσκηση 4.png

Ενότητα 4 (Προγραμματισμός με OpenMP)

Ερώτηση 1 / 1 (Ελεύθερου Κειμένου — 2 βαθμοί)

Θεωρήστε μια εφαρμογή που χρησιμοποιεί ένα δυαδικό δέντρο για την οργάνωση των δεδομένων της.

- Η δομή που περιγράφει κάθε κόμβο του δέντρου είναι η παρακάτω:

```c
struct node {
    struct node  *left;  /* Δείχνει στο αριστερό παιδί. NULL αν δεν υπάρχει αριστερό παιδί. */
    struct node  *right; /* Δείχνει στο δεξί παιδί. NULL αν δεν υπάρχει δεξί παιδί.       */
    /*
     * Ακολουθούν τα υπόλοιπα πεδία της δομής στα οποία αποθηκεύονται δεδομένα και
     * τα οποία για λόγους συντομίας δεν αναφέρονται εδώ.
     */
};
```

- Η εφαρμογή υλοποιεί μια συνάρτηση ‘struct node *create_and_init_tree()’, η οποία όταν καλείται δημιουργεί ένα δέντρο και αρχικοποιεί κατάλληλα τα πεδία κάθε κόμβου. Επιστρέφει δε έναν δείκτη στην ρίζα του δέντρου.
- Η συνάρτηση ‘main()’ (στην οποία θα πρέπει να συμπληρώσετε κώδικα στην συνέχεια), περιλαμβάνει μια κλήση στην συνάρτηση ‘create_and_init_tree()’, ενώ έχει ορισμένη και μια μεταβλητή τύπου ‘int’, όπως παρακάτω:

```c
int main() {
    int          numberOfNodes;
    struct node  *root = create_and_init_tree();

    /*
     * Εδώ θα πρέπει στην συνέχεια να συμπληρώσετε κώδικα.
     */
}
```

Υλοποιείστε μια συνάρτηση ‘count()’, η οποία θα δέχεται μόνο μια παράμετρο, και χρησιμοποιώντας Έργα (Tasks) του μοντέλου OpenMP θα διατρέχει με παράλληλο τρόπο το δέντρο και θα μετράει από πόσους κόμβους αποτελείται το δέντρο. Επιπλέον, συμπληρώστε τον κώδικα που απαιτείται στην συνάρτηση ‘main()’ ώστε να εκκινήσετε την όλη διαδικασία παράλληλης καταμέτρησης. Θα πρέπει να λάβετε υπόψη σας τους παρακάτω περιορισμούς και να απαντήσετε στα παρακάτω ερωτήματα:

- Ποιου τύπου δεδομένων θα πρέπει να είναι η μοναδική παράμετρος της ‘count()’;
- Τι τύπου δεδομένων θα πρέπει να είναι το αποτέλεσμα που επιστρέφει η ‘count()’, αν θεωρήσετε πως πρέπει να επιστρέφει κάποιο αποτέλεσμα; Ορίστε κατάλληλα την συνάρτηση χρησιμοποιώντας της απαντήσεις σας σε αυτό και το προηγούμενο ερώτημα.
- Το τελικό αποτέλεσμα (το συνολικό πλήθος κόμβων) θα πρέπει θα πρέπει στο τέλος του προγράμματος να είναι αποθηκευμένο στην τοπική μεταβλητή ‘numberOfNodes’ της συνάρτησης ‘main()’.
- Δεν επιτρέπεται να ορίσετε άλλες τοπικές μεταβλητές στην συνάρτηση ‘main()’ και δεν επιτρέπεται να ορίσετε καθολικές μεταβλητές.

    ## Θέμα Άσκηση 4.png — Ενότητα 4, Ερώτηση 1/1

    *Αξιοπιστία: δύο ανεξάρτητες λύσεις συμφωνούν · εμπιστοσύνη λύτη: υψηλή*

    Η μοναδική παράμετρος της `count()` πρέπει να είναι δείκτης σε κόμβο δέντρου, δηλαδή `struct node *p` (στη `main()` καλείται με το `root`). Το αποτέλεσμα της `count()` πρέπει να είναι `int`, ώστε να είναι συμβατό με τη μεταβλητή `numberOfNodes` της `main()`.

    Ενδεικτική υλοποίηση:

    ```c
    int count(struct node *p)
    {
        if (p == NULL)
            return 0;

        int left_count = 0, right_count = 0;

        #pragma omp taskgroup
        {
            #pragma omp task shared(left_count) firstprivate(p)
            {
                left_count = count(p->left);
            }

            #pragma omp task shared(right_count) firstprivate(p)
            {
                right_count = count(p->right);
            }
        }

        return 1 + left_count + right_count;
    }

    int main(void)
    {
        int numberOfNodes;
        struct node *root = create_and_init_tree();

        #pragma omp parallel
        {
            #pragma omp single
            numberOfNodes = count(root);
        }

        return 0;
    }
    ```

    Αιτιολόγηση: Η `count()` δημιουργεί δύο tasks, ένα για το αριστερό και ένα για το δεξί υποδέντρο. Το `taskgroup` εξασφαλίζει ότι όλα τα αναδρομικά tasks ολοκληρώνονται πριν γίνει η πρόσθεση και η επιστροφή του αποτελέσματος. Η κλήση γίνεται μέσα σε ενεργή παράλληλη περιοχή (`#pragma omp parallel`) και ξεκινά από ένα μόνο νήμα (`#pragma omp single`). Έτσι το τελικό πλήθος αποθηκεύεται στη μοναδική τοπική μεταβλητή `numberOfNodes` της `main()`, χωρίς επιπλέον τοπικές μεταβλητές στη `main()` και χωρίς καθολικές μεταβλητές.
