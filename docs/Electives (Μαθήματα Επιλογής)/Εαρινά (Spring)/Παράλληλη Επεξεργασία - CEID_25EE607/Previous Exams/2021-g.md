# Παράλληλη Επεξεργασία — Εξέταση Φεβρουαρίου (Ενότητα 3, 5 ερωτήσεις)

> Μεταγραφή από τις φωτογραφίες ερωτήσεων 1–5 της Ενότητας 3. Οι φωτογραφίες unknown (30) και unknown (31) είναι ίδιες με τις ερωτήσεις 2 και 3 (unknown (25) και unknown (26)) και δεν μεταγράφονται ξανά. Οι unknown (29), (32) και (33) προστέθηκαν ως σελίδες άλλης εκδοχής του δοκιμίου.

## unknown (24).png

Ερώτηση 1 / 5 (Πολλαπλής Επιλογής (Μοναδική Απάντηση) — 0.40 βαθμοί)

Ενότητα 3 (MPI)

Το παράλληλο προγραμματιστικό μοντέλο MPI έχει σχεδιαστεί κυρίως για συστήματα:

- [ ] Κοινής μνήμης
- [ ] Κατανεμημένης μνήμης
- [ ] Κατανεμημένης κοινής μνήμης
- [ ] Κοινής κατανεμημένης μνήμης

## unknown (25).png

Ερώτηση 2 / 5 (Πολλαπλής Επιλογής (Μοναδική Απάντηση) — 0.40 βαθμοί)

Ενότητα 3 (MPI)

Η συλλογική (collective) επικοινωνία στο MPI, σε σχέση με την υλοποίηση των αντίστοιχων λειτουργιών χρησιμοποιώντας μόνο συναρτήσεις επικοινωνίας «σημείο-προς-σημείο» (point-to-point):

- [ ] Κάνει το πρόγραμμα MPI πιο ευανάγνωστο και συνήθως πιο αποτελεσματικό στη μεταφορά δεδομένων
- [ ] Συνήθως υποχρεώνει το πρόγραμμα MPI να μεταφέρει περισσότερα δεδομένα μεταξύ διεργασιών
- [ ] Συνήθως κάνει το πρόγραμμα MPI πιο γρήγορο στο τμήμα εκείνο που πραγματοποιεί τους υπολογισμούς
- [ ] Όλα τα υπόλοιπα

## unknown (26).png

Ερώτηση 3 / 5 (Πολλαπλής Επιλογής (Μοναδική Απάντηση) — 0.40 βαθμοί)

Ενότητα 3 (MPI)

Στη «συλλογική» (collective) επικοινωνία στο MPI:

- [ ] Ανταλλάσσει δεδομένα η διεργασία με βαθμό 0 με μια ακόμα διεργασία του προγράμματος MPI
- [ ] Ανταλλάσσουν μεταξύ τους δεδομένα δύο ακριβώς διεργασίες MPI
- [ ] Ανταλλάσσουν μεταξύ τους δεδομένα όλες οι διεργασίες του προγράμματος MPI
- [ ] Ανταλλάσσουν μεταξύ τους δεδομένα όλες οι διεργασίες του προγράμματος MPI που ανήκουν σε έναν επικοινωνητή (communicator)

## unknown (27).png

Ερώτηση 4 / 5 (Πολλαπλής Επιλογής (Μοναδική Απάντηση) — 0.40 βαθμοί)

Ενότητα 3 (MPI)

Η συνάρτηση MPI_Send():

- [ ] Αποστέλλει δεδομένα από μια διεργασία MPI σε όλες τις διεργασίες του προγράμματος MPI
- [ ] Αποστέλλει δεδομένα από μια διεργασία MPI σε όλες τις διεργασίες ενός επικοινωνητή (communicator) του προγράμματος MPI
- [ ] Αποστέλλει δεδομένα από μια διεργασία MPI σε μια άλλη διεργασία MPI
- [ ] Αποστέλλει δεδομένα από μια διεργασία MPI στην ίδια διεργασία, αλλά προς άλλη εικονική μνήμη της διεργασίας

## unknown (28).png

Ερώτηση 5 / 5 (Πολλαπλής Επιλογής (Μοναδική Απάντηση) — 0.40 βαθμοί)

Ενότητα 3 (MPI)

Θεωρείστε ένα διδιάστατο πίνακα Α που έχει οριστεί σε ένα πρόγραμμα MPI ως A[N][N], όπου N μια σταθερά. Στο πρόγραμμα χρησιμοποιούμε μόνο το άνω τριγωνικό μέρος του πίνακα. Ποια συνάρτηση θα χρησιμοποιούσατε για να διαμοιράσετε μεταξύ των διεργασιών MPI τα στοιχεία του πίνακα που πραγματικά χρησιμοποιούνται στο πρόγραμμα με τον πλέον αποδοτικό τρόπο;

- [ ] MPI_Send()
- [ ] MPI_Scatter()
- [ ] MPI_Scatterv()
- [ ] MPI_Bcast()

## unknown (29).png

Ερώτηση 1 / 5 (Πολλαπλής Επιλογής (Μοναδική Απάντηση) — 0.40 βαθμοί)

Ενότητα 3 (MPI)

Η συνάρτηση MPI_Bcast():

- [ ] Αποστέλλει δεδομένα από μια διεργασία MPI σε όλες τις διεργασίες του προγράμματος MPI
- [ ] Αποστέλλει δεδομένα από μια διεργασία MPI σε όλες τις διεργασίες ενός επικοινωνητή (communicator) του προγράμματος MPI
- [ ] Αποστέλλει δεδομένα από μια διεργασία MPI σε μια άλλη διεργασία MPI
- [ ] Αποστέλλει δεδομένα από μια διεργασία MPI στην ίδια διεργασία, αλλά προς άλλη εικονική μνήμη της διεργασίας

## unknown (32).png

Ερώτηση 4 / 5 (Πολλαπλής Επιλογής (Μοναδική Απάντηση) — 0.40 βαθμοί)

Ενότητα 3 (MPI)

Ο επικοινωνητής (communicator) είναι:

- [ ] Ένα σύνολο διεργασιών του προγράμματος MPI, οι οποίες μπορούν να επικοινωνήσουν μεταξύ τους μέσω συναρτήσεων συλλογικής επικοινωνίας
- [ ] Μια ειδική διεργασία του MPI που αναλαμβάνει να διεκπεραιώσει όλες τις λειτουργίες ανταλλαγής δεδομένων μεταξύ διεργασιών του προγράμματος MPI
- [ ] Ένα νήμα σε κάθε διεργασία MPI που παραλαμβάνει τα δεδομένα που αποστέλλονται από άλλες διεργασίες προς αυτήν
- [ ] Ανάλογα με το πλαίσιο στο οποίο αναφερόμαστε, μπορεί να είναι οποιοδήποτε από τα υπόλοιπα

## unknown (33).png

Ερώτηση 5 / 5 (Πολλαπλής Επιλογής (Μοναδική Απάντηση) — 0.40 βαθμοί)

Ενότητα 3 (MPI)

Το παράλληλο προγραμματιστικό μοντέλο MPI ακολουθεί το μοντέλο εκτέλεσης:

- [ ] Single Instruction Multiple Data (SIMD)
- [ ] Multiple Instructions Multiple Data (MIMD)
- [ ] Single Program Multiple Data (SPMD)
- [ ] Multiple Programs Multiple Data (MPMD)
