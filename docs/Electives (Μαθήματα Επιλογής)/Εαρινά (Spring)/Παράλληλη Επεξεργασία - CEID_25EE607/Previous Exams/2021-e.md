# Παράλληλη Επεξεργασία — Εξέταση Φεβρουαρίου, σειρά Α (Ενότητα 2, 7 ερωτήσεις)

> Μεταγραφή από τις φωτογραφίες ερωτήσεων 1–7 της Ενότητας 2 (σειρά Α).

## unknown (10).png

Ερώτηση 1 / 7 (Πολλαπλής Επιλογής (Μοναδική Απάντηση) — 0.40 βαθμοί)

Ενότητα 2 (POSIX Threads / OpenMP)

Η οδηγία #pragma omp parallel του OpenMP:

- [ ] Δημιουργεί ένα πλήθος νημάτων και διαμοιράζει το φόρτο εργασίας μεταξύ των νημάτων αυτών
- [ ] Δημιουργεί ένα πλήθος νημάτων, τα οποία όλα εκτελούν τον κώδικα της παράλληλης περιοχής
- [ ] Δημιουργεί ένα πλήθος νημάτων εκ των οποίων ένα μόνο ξεκινάει την εκτέλεση του κώδικα της παράλληλης περιοχής
- [ ] Δημιουργεί το αρχικό νήμα της παράλληλης περιοχής

## unknown (11).png

Ερώτηση 2 / 7 (Πολλαπλής Επιλογής (Μοναδική Απάντηση) — 0.40 βαθμοί)

Ενότητα 2 (POSIX Threads / OpenMP)

Ένα παράλληλο πρόγραμμα OpenMP χρησιμοποιεί μια διπλά διασυνδεδεμένη λίστα. Για να υλοποιήσετε μια λειτουργία εισαγωγής νέου στοιχείου στη λίστα θα χρησιμοποιήσετε:

- [ ] Την οδηγία #pragma omp atomic
- [ ] Την οδηγία #pragma omp critical
- [ ] Την οδηγία #pragma omp flush
- [ ] Την οδηγία #pragma omp reduction

## unknown (12).png

Ερώτηση 3 / 7 (Πολλαπλής Επιλογής (Μοναδική Απάντηση) — 0.40 βαθμοί)

Ενότητα 2 (POSIX Threads / OpenMP)

Για την οδηγία #pragma omp for schedule(dynamic, chunk) ισχύει πως:

- [ ] Κάθε νήμα της παράλληλης περιοχής αναλαμβάνει να εκτελέσει chunk συνεχόμενες επαναλήψεις του βρόχου for που ακολουθεί, χωρίς να είναι εκ των προτέρων γνωστό ποιο νήμα θα αναλάβει ποιες ακριβώς επαναλήψεις
- [ ] Κάθε νήμα της παράλληλης περιοχής αναλαμβάνει να εκτελέσει chunk τυχαίες επαναλήψεις του βρόχου for που ακολουθεί, χωρίς να είναι εκ των προτέρων γνωστό ποιο νήμα θα αναλάβει ποιες ακριβώς επαναλήψεις. Η υλοποίηση του OpenMP διασφαλίζει πως δεν θα εκτελεστεί 2 φορές καμία επανάληψη
- [ ] Κάθε φορά που ένα νήμα της παράλληλης περιοχής δεν έχει δουλειά να εκτελέσει αναλαμβάνει να εκτελέσει τις επόμενες chunk συνεχόμενες επαναλήψεις του βρόχου for που ακολουθεί, έως ότου ολοκληρωθούν όλες οι επαναλήψεις
- [ ] Κάθε φορά που ένα νήμα της παράλληλης περιοχής δεν έχει δουλειά να εκτελέσει αναλαμβάνει να εκτελέσει chunk τυχαίες επαναλήψεις του βρόχου for που ακολουθεί, έως ότου ολοκληρωθούν όλες οι επαναλήψεις. Η υλοποίηση του OpenMP διασφαλίζει πως δεν θα εκτελεστεί 2 φορές καμία επανάληψη

## unknown (13).png

Ερώτηση 4 / 7 (Πολλαπλής Επιλογής (Μοναδική Απάντηση) — 0.40 βαθμοί)

Ενότητα 2 (POSIX Threads / OpenMP)

Μια υλοποίηση του προτύπου των POSIX Threads επιτρέπεται να υλοποιήσει τα νήματα:

- [ ] Μόνο ως νήματα επιπέδου πυρήνα
- [ ] Μόνο ως νήματα επιπέδου χρήστη
- [ ] Είτε ως νήματα επιπέδου χρήστη είτε ως νήματα επιπέδου πυρήνα
- [ ] Μόνο ως έργα (tasks)

## unknown (14).png

Ερώτηση 5 / 7 (Πολλαπλής Επιλογής (Μοναδική Απάντηση) — 0.40 βαθμοί)

Ενότητα 2 (POSIX Threads / OpenMP)

Η οδηγία #pragma omp taskwait

- [ ] Είναι η αντίστοιχη οδηγία για τα έργα (tasks) της #pragma omp barrier για τα νήματα
- [ ] Υποχρεώνει το έργο (task) που την συναντάει να περιμένει για το καθορισμένο χρονικό διάστημα (σε δευτερόλεπτα)
- [ ] Υποχρεώνει ένα έργο που δημιούργησε νέα έργα να περιμένει την ολοκλήρωση των έργων αυτών
- [ ] Δημιουργεί ένα έργο (task) που αναμένει για εντολές συγχρονισμού από άλλα έργα
