**Θέμα 2º (3 μονάδες)**

Η παρακάτω συνάρτηση υπολογίζει και εκτυπώνει το μέγιστο στοιχείο ενός διανύσματος αλλά και τη θέση αυτού. Παραλληλοποιήστε τη συνάρτηση με χρήση του μοντέλου OpenMP. Περιγράψτε και αιτιολογήστε τη λύση σας.

```c
void find_max_and_pos(int *A, int N) {
   int max_val = A[0];
   int max_pos = 0;

   for (int i=1; i<N; i++) {
      if (A[i] > max_val) {
         max_val = A[i];
         max_pos = i;
      }
   }
   print("max value = %d at position %d\n", max_val, max_pos);
}
```

Σχετικές οδηγίες του OpenMP:

```c
#pragma omp parallel
#pragma omp for
#pragma omp critical
```

**Θέμα 3ο (3 μονάδες)**

Ο παρακάτω κώδικας υπολογίζει το γινόμενο $y=A*x$, όπου A μητρώο διάστασης NxN και x, y διανύσματα διάστασης $N$, και εκτελείται σε ένα παράλληλο σύστημα κοινής μνήμης με 8 επεξεργαστικούς πυρήνες.

α. Εξηγήστε την παραλληλοποίηση του κώδικα και πόσα νήματα είναι ενεργά κατά την εκτέλεσή του.

β. Αναφέρετε πιθανά προβλήματα στον κώδικα.

γ. Τροποποιήστε τον κώδικα ώστε να τα λύσετε και αιτιολογήστε συνοπτικά τη λύση σας.

```c
void matvec(double A[N][N], double x[N], double y[N], int N)
{
  int i, j;
  omp_set_nested(1);
  omp_set_num_threads(8);

  #pragma omp parallel for
  for (i=0; i[δυσανάγνωστο]N; i++)
  {
    y[i] = 0.0;
    #pragma omp parallel for
    for (j=0; j[δυσανάγνωστο]N; j++)
    {
      y[i] += A[i][j] * x[j];
    }
  }
}
```

> Σημείωση: ο τελεστής σύγκρισης στις δύο εντολές for δεν διακρίνεται καθαρά στη φωτογραφία.

**Θέμα 4ο (2 μονάδες)**

Ο παρακάτω σειριακός κώδικας αρχικοποιεί το διάνυσμα A διάστασης N και μετά υπολογίζει την ελάχιστη τιμή του. Θεωρείστε ότι η διάσταση N μπορεί να είναι αυθαίρετα μεγάλη.

Παραλληλοποιήστε τον κώδικα με χρήση του μοντέλου MPI.

```c
/* Κώδικας */
#include <stdio.h>   // printf
#include <math.h>    // sqrt
#include <stdlib.h>  // malloc

#define N (1024*1024)
extern float initialize(int i); // υλοποιημένη κάπου αλλού

int main (int argc, char **argv)
{
  float *A;
  A = (float *)malloc(N*sizeof(double));

  for (int i = 0; i [δυσανάγνωστο] N; i++) A[i] = initialize(i);

  float m = 1e10;
  for (int i = 0; i [δυσανάγνωστο] N; i++)
    if (A[i] [δυσανάγνωστο] m) m = A[i];

  printf("min value=%f\n", m);
  free(A);
  return 0;
}
```

```c
#include <mpi.h>
#include <stdio.h>

int main(int argc, char** argv)
{
    MPI_Init(&argc, &argv);

    int rank, size;
    MPI_Comm_rank(MPI_COMM_WORLD, &rank);
    MPI_Comm_size(MPI_COMM_WORLD, &size);

    double data=(double)rank;
    double total=0.;

    MPI_Bcast(&data, 1, MPI_DOUBLE, 2, MPI_COMM_WORLD);
    MPI_Allreduce(&data, &total, 1, MPI_DOUBLE, MPI_PROD, MPI_COMM_WORLD);

    if (rank == 1) printf("%lf\n", total);

    MPI_Finalize();
    return 0;
}
```

**Θέμα 4º (1,5 μονάδες)**

Δίνεται ο παρακάτω κώδικας MPI:

```c
#include <mpi.h>
#include <stdio.h>

int main(int argc, char** argv)
{
   MPI_Init(&argc, &argv);

   int rank, size;
   MPI_Comm_rank(MPI_COMM_WORLD, &rank);
   MPI_Comm_size(MPI_COMM_WORLD, &size);

   double total = 0.0;
   double local = rank+1.0;

   MPI_Reduce(&local, &total, 1, MPI_DOUBLE, MPI_PROD, 0, MPI_COMM_WORLD);

   if (rank == 0) printf("%lf\n", total);

   MPI_Finalize();
   return 0;
}
```

> Σημείωση μεταγραφής: η λέξη MPI_PROD είναι με έντονη γραφή στο πρωτότυπο.
