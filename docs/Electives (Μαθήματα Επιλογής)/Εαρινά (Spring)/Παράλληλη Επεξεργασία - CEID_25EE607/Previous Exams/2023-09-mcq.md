Ενότητα 3 (MPI)
Η συνάρτηση MPI_Send():

- [ ] Αποστέλλει δεδομένα από μια διεργασία MPI σε όλες τις διεργασίες του προγράμματος MPI
- [ ] Αποστέλλει δεδομένα από μια διεργασία MPI σε όλες τις διεργασίες ενός επικοινωνητή (communicator) του προγράμματος MPI
- [ ] Αποστέλλει δεδομένα από μια διεργασία MPI σε μια άλλη διεργασία MPI
- [ ] Αποστέλλει δεδομένα από μια διεργασία MPI στην ίδια διεργασία, αλλά προς άλλη εικονική μνήμη της διεργασίας

8)Για την οδηγία #pragma omp for schedule(dynamic, chunk) ισχύει πως:

Ερώτηση 3 / 7 (Πολλαπλής Επιλογής (Μοναδική Απάντηση) — 0.40 βαθμοί)

Ενότητα 2 (POSIX Threads / OpenMP)
Για την οδηγία #pragma omp for schedule(dynamic, chunk) ισχύει πως:

- [ ] Κάθε νήμα της παράλληλης περιοχής αναλαμβάνει να εκτελέσει chunk συνεχόμενες επαναλήψεις του βρόχου for που ακολουθεί, χωρίς να είναι εκ των προτέρων γνωστό ποιο νήμα θα αναλάβει ποιες ακριβώς επαναλήψεις
- [ ] Κάθε νήμα της παράλληλης περιοχής αναλαμβάνει να εκτελέσει chunk τυχαίες επαναλήψεις του βρόχου for που ακολουθεί, χωρίς να είναι εκ των προτέρων γνωστό ποιο νήμα θα αναλάβει ποιες ακριβώς επαναλήψεις. Η υλοποίηση του OpenMP διασφαλίζει πως δεν θα εκτελεστεί 2 φορές καμία επανάληψη
- [ ] Κάθε φορά που ένα νήμα της παράλληλης περιοχής δεν έχει δουλειά να εκτελέσει αναλαμβάνει να εκτελέσει τις επόμενες chunk συνεχόμενες επαναλήψεις του βρόχου for που ακολουθεί, έως ότου ολοκληρωθούν όλες οι επαναλήψεις
- [ ] Κάθε φορά που ένα νήμα της παράλληλης περιοχής δεν έχει δουλειά να εκτελέσει αναλαμβάνει να εκτελέσει chunk τυχαίες επαναλήψεις του βρόχου for που ακολουθεί, έως ότου ολοκληρωθούν όλες οι επαναλήψεις. Η υλοποίηση του OpenMP διασφαλίζει πως δεν θα εκτελεστεί 2 φορές καμία επανάληψη
