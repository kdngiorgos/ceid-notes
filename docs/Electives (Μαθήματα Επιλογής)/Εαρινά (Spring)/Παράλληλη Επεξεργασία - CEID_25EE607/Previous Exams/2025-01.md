    # Λύσεις — Παράλληλη Επεξεργασία — Ιανουάριος 2025

    ## IMG_6261.jpg

    ```c
    int A[12]
    omp_set_num_threads(4);
    #pragma omp parallel for schedule(static,3)
    for (int i=0; i<12; i++) {
        A[i] = omp_get_thread_num();
    }
    ```

    > [Σχήμα: αγκύλη που ομαδοποιεί δύο ερωτήματα] a) [δυσανάγνωστο] ο [δυσανάγνωστο]; b) Ποιες είναι οι [δυσανάγνωστο] του A;

    **Λύση**

    Χρησιμοποιούμε 4 threads. Το loop for μοιράζεται με schedule(static,3) = κάθε thread παίρνει 3 συνεχόμενες επαναλήψεις. Το omp_get_thread_num() επιστρέφει τον αριθμό του τρέχοντος thread. Ο πίνακας A [δυσανάγνωστο] που δείχνουν ποιο thread έγραψε σε κάθε θέση.

    | thread | Επεξεργάζεται τις θέσεις A[i] |
    |---|---|
    | 0 | i=0, 1, 2 |
    | 1 | i=3, 4, 5 |
    | 2 | i=6, 7, 8 |
    | 3 | i=9, 10, 11 |

    A[0]=0, A[1]=0, A[2]=0, A[3]=1, A[4]=1, A[5]=1, A[6]=2, A[7]=2, A[8]=2, A[9]=3, A[10]=3, A[11]=3

    A = {0,0,0,1,1,1,2,2,2,3,3,3}

    ```c
    int rank, size;
    MPI_Comm_rank(MPI_COMM_WORLD, &rank);
    MPI_Comm_size(MPI_COMM_WORLD, &size);
    int var1 = rank + 1 - size;
    int var2 = 0, var3 = 0;
    MPI_Allreduce(&var1, &var2, 1, MPI_INT, MPI_SUM, MPI_COMM_WORLD);
    MPI_Reduce(&var2, &var3, 1, MPI_INT, MPI_PROD, 0, MPI_COMM_WORLD);
    printf("%d : %d\n", rank, var3);
    ```

    > [Σχήμα: αγκύλη με σημείωση «[δυσανάγνωστο] 3 διεργασίες», «mpirun -n 3 <executable>» και «[δυσανάγνωστο]»]

    var1 = rank + 1 − 3

    | rank | var1 |
    |---|---|
    | 0 | 0 + 1 − 3 = −2 |
    | 1 | 1 + 1 − 3 = −1 |
    | 2 | 2 + 1 − 3 = 0 |

    **Βήμα 2:** var2 = −2 + (−1) + 0 = −3. Άρα και τα 3 processes έχουν var2 = −3.

    **Βήμα 3:** var3 = (−3)(−3)(−3) = −27. Μόνο το process με rank=0 παίρνει το αποτέλεσμα στο var3, στα άλλα δύο (rank=1,2) θα έχουν var3=0 (δεν συνεισφέρουν σε αυτά).

    **Βήμα 4:**
    - rank=0 → −27
    - rank=1 → 0
    - rank=2 → 0

    Η σειρά [δυσανάγνωστο] διαφέρει αναλόγως της εκτέλεσης.
