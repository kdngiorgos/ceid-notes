# Αλγοριθμικές Τεχνικές Επιστήμης Δεδομένων

> Εαρινό μάθημα επιλογής για αλγορίθμους μεγάλου όγκου δεδομένων: τεχνικές επεξεργασίας (π.χ. MapReduce), εξόρυξη συχνών συνόλων και κανόνων συσχέτισης, τοπικός κατακερματισμός (LSH/MinHash), συσταδοποίηση, μείωση διάστασης, ανάλυση συνδέσμων (PageRank), εντοπισμός κοινοτήτων, συστήματα συστάσεων και αλγόριθμοι ρευμάτων. ## Τι θα μάθεις

Το επίσημο περίγραμμα [Περίγραμμα](https://www.ceid.upatras.gr/assets/2026/06/CEID_24ΕΕ594_Αλγ_Τεχνικές_Επιστ_Δεδομένων_GR.pdf) έχει ως στόχο την εφαρμογή θεμελιωδών και προηγμένων αλγοριθμικών τεχνικών για την ανάλυση μεγάλου όγκου δεδομένων. Η ύλη περιλαμβάνει:

- Εισαγωγή σε προγραμματιστικές τεχνικές επεξεργασίας μεγάλου όγκου δεδομένων (π.χ. MapReduce).
- Πολυπλοκότητα αλγορίθμων για μεγάλα δεδομένα.
- Εξόρυξη κανόνων συσχέτισης μέσω συχνών ομάδων αντικειμένων (Apriori, PCY).
- Κατακερματισμός ευαίσθητος ως προς την τοπικότητα (LSH, MinHash).
- Συσταδοποίηση δεδομένων (clustering).
- Μείωση διάστασης.
- Ανάλυση συνδέσμων και συσχετίσεων σε τεράστια γραφήματα (π.χ. PageRank).
- Ανάλυση κοινωνικών δικτύων και εντοπισμός κοινοτήτων (π.χ. Girvan-Newman).
- Συστήματα παροχής συστάσεων.
- Αλγόριθμοι ρευματοροών μεγάλου όγκου δεδομένων (π.χ. Flajolet-Martin).

Σύμφωνα με τις ανακλήσεις εξετάσεων, στην πράξη εξετάζονται συγκεκριμένες τεχνικές από τις παραπάνω ενότητες (βλ. «Εξετάσεις»)· το SVM εμφανίζεται στα θέματα του Ιουνίου 2026, αλλά δεν περιλαμβάνεται στη λίστα ύλης του περιγράμματος [Περίγραμμα](https://www.ceid.upatras.gr/assets/2026/06/CEID_24ΕΕ594_Αλγ_Τεχνικές_Επιστ_Δεδομένων_GR.pdf).
