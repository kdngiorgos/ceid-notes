## Πώς βαθμολογείται

- Δεν βρέθηκαν πληροφορίες.
- Τον Απρίλιο 2026 φοιτητής έγραψε ότι είδε email για «2 παρουσιάσεις» και ρώτησε αν θα παρουσιάσουν όλοι· άλλος απάντησε μόνο «ναι». Η απάντηση «ναι» δεν έχει σαφή αναφορά, οπότε δεν επιβεβαιώνει ότι υπάρχουν παρουσιάσεις· δεν φαίνεται αν βαθμολογούνται ή πόσο μετρούν Discord 2026-04 (δεν δημοσιεύεται εδώ).
