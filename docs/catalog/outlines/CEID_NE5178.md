# Τηλεματική και Νέες Υπηρεσίες

> Επίσημο περίγραμμα μαθήματος του ΤΜΗΥΠ (Πανεπιστήμιο Πατρών), όπως δημοσιεύεται στη σελίδα του μαθήματος και στο συνημμένο αρχείο «Περίγραμμα Μαθήματος». Το κείμενο παρατίθεται αυτούσιο, χωρίς τα πρότυπα οδηγιών του εντύπου.

## Στόχοι

Με την ολοκλήρωση της διδασκαλίας του μαθήματος οι φοιτητές θα είναι ικανοί να:
Να γνωρίζουν την κωδικοποίηση των πολυμεσικών δεδομένων για μετάδοση και αποθήκευση.
Να χρησιμοποιούν τα πρωτόκολλα πραγματικά χρόνου Να σχεδιάζουν υπηρεσίες Τηλεργασίας, Τηλεσυνεργασίας, Τηλεκπαίδευσης Να γνωρίζουν τη χρήση των κοινωνικών δικτύων, τη χρησιμότητα της ηλεκτρονικής διακυβέρνησης και του ηλεκτρονικού εμπορίου Να χρησιμοποιούν εικονική πραγματικότητα.
Να κάνουν χρήση virtualization
Να γνωρίσουν το IoT
Με την ολοκλήρωση της διδασκαλίας του μαθήματος οι φοιτητές θα έχουν αναπτύξει τις ακόλουθες δεξιότητες:

Να μπορούν να επιλέγουν τη κατάλληλη νέα υπηρεσία ανάλογα την εφαρμογή Να υλοποιούν virtualization Να έχουν την ικανότητα να επιλέγουν σχεδιάζουν νέες υπηρεσίες Να υλοποιούν IOoT

## Περιεχόμενο (ύλη)

Μετάδοση - κωδικοποίηση πολυμεσικών δεδομένων Πρωτόκολλα πραγματικού χρόνου Τηλε-εργασία – Τηλεσυνεργασία – Τηλεϊατρική Ηλεκτρονική μάθηση (σύγχρονη – ασύγχρονη)
Ηλεκτρονικό εμπόριο - Ηλεκτρονική τραπεζική
Ηλεκτρονική διακυβέρνηση
Κοινωνικά δίκτυα
Κινητές εφαρμογές
Video κατ’ απαίτηση
Εικονική πραγματικότητα – Δικτυακά εικονικά περιβάλλοντα Network Virtualization Cloud computing – Ιnternet of Τhings
