# Κατανεμημένα Συστήματα

> Επίσημο περίγραμμα μαθήματος του ΤΜΗΥΠ (Πανεπιστήμιο Πατρών), όπως δημοσιεύεται στη σελίδα του μαθήματος και στο συνημμένο αρχείο «Περίγραμμα Μαθήματος». Το κείμενο παρατίθεται αυτούσιο, χωρίς τα πρότυπα οδηγιών του εντύπου.

## Στόχοι

- Μετά την επιτυχή ολοκλήρωση του μαθήματος, οι φοιτητές θα έχουν αποκτήσει τις ακόλουθες γνώσεις:
- Θα μπορούν να προσδιορίσουν τι είναι ένα κατανεμημένο σύστήμα και ποια είναι τα βασικά θεωρητικά μοντέλα που περιγράφουν τα κατανεμημένα συστήματατα, καθώς και να διακρίνουν τα χαρακτηριστικά τους, τις δυνατότητές τους και τους περιορισμούς τους.
- Θα έχουν κατανοήσει τα βασικά αλγοριθμικά προβλήματα που ανακύπτουν στα κατανεμημένα συστήματα και τις βασικές αλγοριθμικές τεχνικές επίλυσής τους.
- Θα γνωρίζουν ποιες είναι οι ποιοτικές και ποσοτικές μετρικές με τις οποίες αξιολογείται η απόδοση και η ορθότητα των κατανεμημένων αλγορίθμων.

Μετά την επιτυχή ολοκλήρωση του μαθήματος, οι φοιτητές θα έχουν αποκτήσει τις ακόλουθες ικανότητες:

- Θα μπορούν να διακρίνουν μεταξύ των διαφορετικών μοντέλων κατανεμημένων συστημάτων και να αποφασίζουν ποιο είναι το κατάλληλο μοντέλο για διάφορες περιπτώσεις.
- Θα μπορούν να τροποποιούν και να συνδυάζουν τους βασικούς κατανεμημένους αλγορίθμους που διδάσκονται στο μάθημα ώστε να επιλύουν περισσότερο σύνθετα αλγοριθμικά προβλήματα.
- Θα μπορούν να αποδεικνύουν την ορθότητα ενός κατανεμημένου αλγορίθμου και να αναλύουν την πολυπλοκότητά του.

Μετά την επιτυχή ολοκλήρωση του μαθήματος, οι φοιτητές θα έχουν αποκτήσει τις ακόλουθες δεξιότητες:

- Θα μπορούν να αναπτύσσουν νέους σύγχρονους και ασύγχρονους κατανεμημένους αλγορίθμους, να αποδεικνύουν την ορθότητά τους και να αναλύουν τα ποιοτικά και ποσοτικά χαρακτηριστικά τους (πόσο κοντά στη βέλτιστη λύση είναι η λύση που δίνουν, ποια είναι η πολυπλοκότητά τους).
- Θα μπορούν να συνδυάζουν και να τροποποιούν τα βασικά θεωρητικά μοντέλα κατανεμημένων συστημάτων ώστε να είναι σε θέση να περιγράφουν και να μελετούν σε ένα περισσότερο ρεαλιστικό πλαίσιο ειδικές περιπτώσεις κατανεμημένων συστημάτων.

## Περιεχόμενο (ύλη)

1. Αρχιτεκτονικές Κατανεμημένων Συστημάτων: Μορφές κατανεμημένων αρχιτεκτονικών.
Κατανεμημένα συστήματα διαμεσολάβησης.
Δομημένες, αδόμητες και ιεραρχικές αρχιτεκτονικές.
2. Διεργασίες: Νήματα. Εικονικοποίηση. Μοντέλα πελάτη-εξυπηρετητή και διαμεσολάβησης.
Μετανάστευση κώδικα/δεδομένων.
3. Επικοινωνία: Σύγχρονη και ασύγχρονη επικοινωνία. Μοντέλα επικοινωνίας βάσει απομακρυσμένης κλήση διεργασιών ή μέσω ανταλλαγής μηνυμάτων. Πρωτόκολλα Διάχυσης Πληροφορίας.
4. Συντονισμός: Συγχρονισμός ρολογιών: Λογικά ρολόγια. Τεχνικές αμοιβαίου αποκλεισμού.
Αλγόριθμοι επιλογής αρχηγού και συναίνεσης. Συντονισμός μέσω κουτσομπολιών. Συστήματα κατανεμημένης χωροθέτησης.
5. Ονοματοδοσία: Ονόματα, προσδιοριστικά και διευθύνσεις αντικειμένων. Οριζόντια ονοματοδοσία, δομημένη ονοματοδοσία, και ονοματοδοσία βάσει ιδιοτήτων.
6. Συνέπεια και Αντίγραφα: Μοντέλα συνέπειας δεδομένων και λειτουργιών. Διαχείριση αντιγράφων. Πρωτόκολλα για εξασφάλιση συνέπειας.
7. Ανοχή σε Σφάλματα: Μοντέλα αποτυχιών. Ανοχή διεργασιών σε σφάλματα. Αξιόπιστη επικοινωνία πελάτη-εξυπηρετητή. Αξιόπιστη ομαδική επικοινωνία. Κατανεμημένη δέσμευση (ολοκλήρωσης) λειτουργιών. Ανάκτηση δεδομένων και λειτουργιών μετά από αποτυχίες.
8. Ασφάλεια: Αλγόριθμοι για κατανεμημένα πρωτόκολλα ασφαλούς επικοινωνίας. Απειλές, πολιτικές και μηχανισμοί ασφάλειας κατανεμημένων συστημάτων. Αυθεντικοποίηση.
Εμπιστοσύνη στα κατανεμημένα συστήματα. Εξουσιοδότηση πρόσβασης. Παρακολούθηση συμβάντων.

## Αξιολόγηση

Γλώσσα αξιολόγησης:

- Ελληνική

Μέθοδοι αξιολόγησης:

1. Γραπτή εξέταση που περιλαμβάνει Ερωτήσεις
Σύντομης Απάντησης και Επίλυση Προβλημάτων
(διαβαθμισμένης δυσκολίας). Συνεισφέρει 80% του τελικού βαθμού.

2. Γραπτές Εργασίες που περιλαμβάνουν επίλυση προβλημάτων (θεωρητικές ασκήσεις) και υλοποίηση κατανεμημένων αλγορίθμων (προγραμματιστικές ασκήσεις). Συνεισφέρουν 20% του τελικού βαθμού.
