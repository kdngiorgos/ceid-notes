# Βάση γνώσης CEID — ξεκίνα εδώ

> Η κεντρική σελίδα της φοιτητικής βάσης γνώσης του CEID (Πανεπιστήμιο Πατρών): εξηγεί τι περιέχει, δείχνει τους πέντε θεματικούς οδηγούς του τμήματος και συνδέει κάθε μάθημα και κανάλι με τον οδηγό του. Δεν είναι επίσημο έγγραφο του τμήματος· συγκεντρώνει τον Κατάλογο Μαθημάτων 2025-2026, υλικό μαθημάτων και φοιτητικές συζητήσεις.

## Τι θα βρεις εδώ

Η βάση γνώσης οργανώνει σε **έναν φάκελο ανά μάθημα ή κανάλι** ό,τι έχει μαζευτεί από το Discord, το eClass και τα αρχεία του τμήματος. Η τρέχουσα έκδοση έχει **180 φάκελους** Κατάλογος (διαθέσιμο στο πλήρες πακέτο):

- **32 υποχρεωτικά** μαθήματα κορμού (εξάμηνα 1–7),
- **79 μαθήματα επιλογής**, **13 γενικής παιδείας** και **32 του παλαιού προγράμματος**,
- **23 κανάλια** της κοινότητας (γενική συζήτηση, διπλωματικές, πρακτική, Erasmus, μεταπτυχιακά, θέσεις εργασίας κ.ά.),
- **1** φάκελος μεταπτυχιακού.

Κάθε φάκελος έχει οδηγό (`README.md`) με περίληψη, βαθμολόγηση, εξετάσεις και τρόπο μελέτης. Δίπλα του μπορεί να υπάρχουν:

- `discord/` — το ιστορικό του καναλιού/μαθήματος σε αρχεία-περιόδους (`2024-25_winter.md` κ.λπ.),
- `Previous Exams/` — μεταγραφές παλιών θεμάτων, με σημείωση αν είναι πλήρεις ή από μνήμη, και χωριστά αρχεία λύσεων,
- `eclass/` — υλικό μαθήματος (διαφάνειες, ασκήσεις) και τα κείμενά τους,
- `other/` — διάφορα αρχεία του καναλιού.

Αυτή η σελίδα είναι ο χάρτης· τα υπόλοιπα είναι τα πέντε θεματικά guides.

Κάθε φάκελος της βάσης γνώσης έχει τον δικό του οδηγό (`README.md`). Οι σύνδεσμοι παρακάτω οδηγούν στον οδηγό κάθε μαθήματος ή καναλιού· μέσα σε αυτόν υπάρχουν σύνδεσμοι για τα παλιά θέματα (`Previous Exams/`), το ιστορικό του Discord (`discord/`) και το υλικό (`eclass/`, `other/`).
