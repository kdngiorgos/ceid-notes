# Θέμα Ιουνίου 2020 (3 μονάδες)

> [Σχήμα: Διάγραμμα μηχανής Turing με καταστάσεις q_0, q_1, q_2, q_3, q_ΟΧΙ, q_ΝΑΙ. Μεταβάσεις: q_0 → q_1: α → Δ; q_0 → q_2: ⊔ → Α; q_1 → q_2: α → Δ; q_1 → q_3: ⊔ → α, Α; q_2 → q_3: α → Δ; q_2 → q_ΝΑΙ: ⊔ → α, Δ; q_3 → q_0: α → Δ; q_3 → q_ΟΧΙ: ⊔ → Α.]

**(α1)** Εκτελέστε την TM με είσοδο αααα. Επιλέξτε ένα από τα παρακάτω σχετικά με τη λειτουργία της TM:
- [ ] A. Η TM αποδέχεται
- [ ] B. Η TM απορρίπτει
- [ ] Γ. Η TM εγκλωβίζεται

**(α2)** Είναι η TM διαγνώστης;
- [ ] A. Ναι, η TM είναι διαγνώστης
- [ ] B. Όχι, δεν είναι διαγνώστης γιατί με είσοδο τη συμβολοσειρά α εγκλωβίζεται
- [ ] Γ. Όχι, δεν είναι διαγνώστης γιατί με είσοδο τη συμβολοσειρά αααα εγκλωβίζεται

**(α3)** Ποια είναι η γλώσσα της TM;
- [ ] A. ε + αα(αααα)*
- [ ] B. αα(αααα)*
- [ ] Γ. (αααα)*(ε + αα + ααα)
- [ ] Δ. αα(ααα)*
- [ ] Ε. (ααα)*(αα + α)

    3) Ποια είναι η γλώσσα της TM;

    a) ε + aa(aaaa)*

    β) aa(aaaa)*

    γ) (aaaa)*(ε + aa + aaa) — το aaaa απορρίπτεται, άρα λάθος· [δυσανάγνωστο] μπαίνει 2 φορές αυτό

    δ) aa(aaa)* → aaaaaaaaa → 8 a → φτάνει σε κατάσταση απόρριψης

    ε) (aaa)*(aa+a) — aaaa που απορρίπτεται, άρα λάθος

    β) aa(aaaa)* → aa → αποδοχή [κυκλωμένο]

    α) ε + aa(aaaa)* [κυκλωμένο] άρα σωστό, γιατί το β δεν περιέχει το ε, ενώ για ε [δυσανάγνωστο]

    ε → αποδέχεται
