# Προηγμένοι Μικροεπεξεργαστές & Εργαστήριο — Ιούνιος 2022

## Screenshot_1.jpg

**Ερώτηση 1** (Ελεύθερου Κειμένου — 5 βαθμοί)

Να αναπτύξετε και να περιγράψετε λεπτομερώς ένα σύστημα προηγμένου επεξεργαστή: α) Περιγραφή εφαρμογής και λειτουργίας: τεχνικές προδιαγραφές. β) Μοντελοποίηση. γ) Μετασχηματισμός ροής δεδομένων. δ) Μηχανή πεπερασμένων καταστάσεων. ε) Αρχιτεκτονική.

(Γενικές απαντήσεις, γενικές περιγραφές και απαντήσεις εκτός θέματος, δεν αξιολογούνται. Να είστε όσο πιο ακριβείς, συγκριτικά με την ύλη του μαθήματος μπορείτε. Τα θέματα είναι ισοδύναμα.)

[πλαίσιο απάντησης: κενό]

## IMG_20220622_212646.jpg

**Ερωτήματα**

1. Για το SoC του παρακάτω σχήματος, να σχεδιάσετε (50%) και να εξηγήσετε (50%), το χάρτη της μνήμης:

> [Σχήμα: Διάγραμμα SoC. Στον "Υψηλής-ταχύτητας Δίαυλο" (32) συνδέονται CPU, SRAM (16 MB), NVRAM Boot (128 KB) και η "Γέφυρα", η οποία συνδέει τον υψηλής ταχύτητας δίαυλο με τον "Περιφερειακό Δίαυλο" (32). Στον περιφερειακό δίαυλο συνδέονται UART (32 B), VGA (16 KB) και Flash (16 MB).]

- Να λάβετε υπόψη, ότι η γέφυρα του διαύλου μπορεί να μετατρέπει μεταφορές διαύλων μέσα σε ένα ενιαίο, συνεχή χώρο διεύθυνσης.
- Να καθορίσετε ποιο εύρος διευθύνσεων μπορεί να αποθηκευτεί σε κρυφή μνήμη.

2. Μια συνάρτηση f, έχει πέντε εισόδους και πέντε εξόδους, όλες ακέραιοι. Η εκτέλεση της σε λογισμικό, απαιτεί 100 κύκλους. Να αξιολογήσετε το σχεδιασμό ενός συνεπεξεργαστή, για τη συνάρτηση αυτή, μέσω αντίστοιχου γραφήματος: να εξηγήσετε τις περιοχές του γραφήματος.

3. Να σχεδιάσετε και να εξηγήσετε το διάγραμμα που απεικονίζει μια μεταφορά εγγραφής σε ένα γενικό περιφερειακό δίαυλο, για τους πέντε πρώτους κύκλους.

> [Σχήμα: Δύο μπλοκ, "Master" (αριστερά) και "Slave" (δεξιά), με τα σήματα: Master → Slave: m_addr (από addr προς addr), m_rnw (rnw προς rnw), m_sel (sel προς sel), m_data (data προς data)· Slave → Master: s_ack (ack προς ack).]

## IMG_20220622_212712.jpg

4. Για το παρακάτω πρόγραμμα, να γράψετε πίνακα της χρονικής εκτέλεσης των εντολών (50%) και να εξηγήσετε τους πιθανούς δομικούς κινδύνους, εάν υπάρχουν (50%):

```
Mov R5, #7
Ldmia R5, {R8, R9}
Add R1, R2, R3
Add R1, R1, R4
```

Οδηγίες:

- Η κόλλα των θεμάτων θα πρέπει να επιστραφεί, μαζί με την κόλλα των απαντήσεων.
- Τα θέματα είναι ισοδύναμα.
- Δεν επιτρέπεται η χρήση καμίας ηλεκτρονικής συσκευής, οι οποίες θα πρέπει να είναι υποχρεωτικά απενεργοποιημένες.
