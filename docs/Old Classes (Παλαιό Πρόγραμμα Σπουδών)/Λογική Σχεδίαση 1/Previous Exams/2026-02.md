**<u>Θέμα 1</u>**

- α) Χρησιμοποιώντας μόνο τα αξιώματα και βασικά θεωρήματα της άλγεβρας Boole να απλοποιήσετε την λογική συνάρτηση F(A, B, C), έτσι ώστε αυτή να μπορεί να υλοποιηθεί μόνο με 2 λογικές πύλες 2 εισόδων:

F(A, B, C) = AB'C + A'BC + A'B'C.

Σε κάθε βήμα της απλοποίησης, να αναφέρετε το αξίωμα ή το θεώρημα που χρησιμοποιήσατε και μετά την απλοποίηση να σχεδιάσετε το λογικό κύκλωμα που υλοποιεί την απλοποιημένη συνάρτηση. _Λύσεις που βασίζονται σε πίνακες αληθείας και χάρτες Karnaugh δε θα βαθμολογηθούν._

- β) Χρησιμοποιώντας μόνο τα αξιώματα και βασικά θεωρήματα της άλγεβρας Boole να απλοποιήσετε την λογική συνάρτηση G(A, B, C), έτσι ώστε αυτή να μην χρειάζεται λογικές πύλες για την υλοποίησή της:

G(A, B, C) = (A + AB)(A + A'B)(A + C).

Σε κάθε βήμα της απλοποίησης, να αναφέρετε το αξίωμα ή το θεώρημα που χρησιμοποιήσατε. _Λύσεις που βασίζονται σε πίνακες αληθείας και χάρτες Karnaugh δε θα βαθμολογηθούν._
