Η έξοδος μιας πύλης μπορεί να συνδεθεί στην έξοδο μίας ή περισσότερων άλλων πυλών :

- [ ] Πάντοτε
- [ ] Ποτέ
- [ ] Αν όλες οι πύλες πάντοτε έχουν την ίδια τιμή στην έξοδο.
- [ ] Αν τουλάχιστον μία από τις πύλες υποστηρίζει κατάσταση υψηλής εμπέδησης.
- [ ] Αν τουλάχιστον η πλειοψηφία των συνδεδεμένων εξόδων υποστηρίζουν κατάσταση υψηλής εμπέδησης.
- [ ] Αν όλες οι πύλες υποστηρίζουν κατάσταση υψηλής εμπέδησης
- [ ] Αν όλες οι πύλες υποστηρίζουν κατάσταση υψηλής εμπέδησης και έχει διασφαλιστεί ότι ή όλες θα βρίσκονται σε υψηλή εμπέδηση ή όλες πλην μίας ανά χρονική στιγμή θα βρίσκονται σε κατάσταση υψηλής εμπέδησης.
