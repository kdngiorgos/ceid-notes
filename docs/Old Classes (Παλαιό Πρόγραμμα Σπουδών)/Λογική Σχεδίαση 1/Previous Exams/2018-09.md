Λογική Σχεδίαση Ι - Σεπτέμβριος 2018
Διάρκεια Εξέτασης : 150'

> Σημείωση: τα πεδία ονοματεπωνύμου και ΑΜ δεν μεταγράφονται.

Θέμα 1 [2,0 (= 4 x 0,5) μονάδες]

Έστω ότι θέλουμε να επεξεργαστούμε μια εικόνα που αποτελείται από 1010 x 510 εικονοστοιχεία. Η συνάρτηση επεξεργασίας της εικόνας δέχεται ως είσοδο τις συντεταγμένες (x, y) ενός εικονοστοιχείου και παράγει στην έξοδο μια τιμή στο διάστημα [-21, +11] σε κώδικα συμπληρώματος ως προς 2. Συμπληρώστε :

(α) Ο αριθμός των δυαδικών σημάτων εισόδου της συνάρτησης είναι ____

(β) Ο αριθμός των δυαδικών σημάτων εξόδου της συνάρτησης είναι ____

(γ) Ο πίνακας αληθείας αυτού του κυκλώματος θα έχει ____ γραμμές και ____ στήλες.

(δ) Στον πίνακα αληθείας θα υπάρχουν ____ γραμμές στις οποίες οι έξοδοι θα είναι αδιάφορες.

Θέμα 2 [2,0 (= 1,0 + 1,0) μονάδες]

Έστω οι

- $F(a,b,c,d) = \Sigma(0, 2, 3, 5, 8, 10, 11, 13, 15) + DC(1, 7, 9, 12)$, και
- $G(a, b, c, d) = \Sigma(2, 3, 7, 11) + DC(0, 1, 8, 10, 12, 13)$

όπου DC οι αδιάφοροι όροι της συνάρτησης. Να απλοποιήσετε τις συναρτήσεις χρησιμοποιώντας χάρτες Karnaugh και να τις υλοποιήσετε με τον ελάχιστο αριθμό πυλών NAND.
