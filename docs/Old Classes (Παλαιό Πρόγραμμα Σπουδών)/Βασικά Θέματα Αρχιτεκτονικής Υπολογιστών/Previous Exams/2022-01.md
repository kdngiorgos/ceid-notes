Ερώτηση 1 (Συμπλήρωση Κενών (Χαλαρή Ταυτοποίηση) — 1.50 βαθμοί)

Υπολογιστικό σύστημα ειδικού σκοπού με καταχωρητές των 8 δυαδικών ψηφίων και αρτηρία δεδομένων των 8 δυαδικών ψηφίων χρησιμοποιεί την τεχνική του χρονοπρογραμματισμένου ελέγχου (polling) για να ελέγξει εάν θέλει εξυπηρέτηση κάποια από τις περιφερειακές συσκευές/εισόδου και την τεχνική της προγραμματισμένης διαδικασίας εισόδου (programmed input/output) για τη μεταφορά του περιεχομένου των καταχωρητών δεδομένων του ελεγκτή της περιφερειακής συσκευής εισόδου στην κύρια μνήμη. Ο ελεγκτής της περιφερειακής συσκευής έχει 3 καταχωρητές. Κάθε περιφερειακή συσκευή μεταφέρει σειριακά δεδομένα στους καταχωρητές του ελεγκτή της, με ρυθμό μεταφοράς ο οποίος δεν είναι σταθερός και η μέγιστη τιμή του είναι 1 δυαδικό ψηφίο ανά 0,125 sec. Θεωρήστε ότι όταν γεμίσουν οι καταχωρητές του ελεγκτή, θα πρέπει να αδειάσουν τελείως για να μπορέσει η περιφερειακή συσκευή να γράψει σ' αυτούς δεδομένα. Η μεταφορά της πληροφορίας από τους καταχωρητές του ελεγκτή της περιφερειακής συσκευής προς το υπολογιστικό σύστημα γίνεται μέσω αρτηρίας των 8 δυαδικών ψηφίων. Κάθε έλεγχος της κατάστασης του ελεγκτή της περιφερειακής συσκευής από την κεντρική μονάδα επεξεργασίας απαιτεί 0,004 sec, η εκτέλεση μιας εντολής ανάγνωσης ενός καταχωρητή δεδομένων του ελεγκτή της περιφερειακής συσκευής εισόδου/εξόδου απαιτεί 0,003 sec, η εκτέλεση μιας εντολής εγγραφής στην κύρια μνήμη απαιτεί 0,00004 sec. Τα ανωτέρω δεδομένα ισχύουν για όλες τις ερωτήσεις, ενώ τα στοιχεία που αναφέρονται σε κάθε ερώτηση ισχύουν μόνο σε αυτή την ερώτηση.

    | πρόγραμμα | σχόλια |
    |---|---|
    | LOAD E | $\Sigma \leftarrow E$ |
    | SUB G | $\Sigma \leftarrow \Sigma-G = E-G$ |
    | STORE F | $F \leftarrow \Sigma = E-G$ |
    | LOAD D | $\Sigma \leftarrow D$ |
    | DIV F | $\Sigma \leftarrow \Sigma / F = D/(E-G)$ |
    | STORE F | $F \leftarrow \Sigma = D/(E-G)$ |
    | LOAD B | $\Sigma \leftarrow B$ |
    | SUB C | $\Sigma \leftarrow \Sigma-C = B-C$ |
    | MULT A | $\Sigma \leftarrow \Sigma\times A = (B-C)\times A$ |
    | SUB F | $\Sigma \leftarrow \Sigma-F = (B-C)\times A - D/(E-G)$ |
    | STORE F | $F = (B-C)\times A - D/(E-G)$ |

    | πρόγραμμα | σχόλια |
    |---|---|
    | LOAD R1, B | $R1\leftarrow B$ |
    | LOAD R2, C | $R2\leftarrow C$ |
    | SUB R1, R2 | $R1\leftarrow R1-R2=B-C$ |
    | LOAD R2, A | $R2\leftarrow A$ |

    | LOAD R4, G | $R4\leftarrow G$ |

    | STORE F, R1 | $F = (B-C)\times A- D/(E-G)$ |

    > Σημείωση μεταγραφής: στη φωτογραφία η ετικέτα «β.» εμφανίζεται πάνω από καθέναν από τους δύο πίνακες· η αρχική γραμμή $F= (B-C)\times A-D/(E-G)$ δεν έχει ετικέτα.
