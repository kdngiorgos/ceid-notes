
## 20200827_103638.jpg

Ερώτηση 1 / 1 (Ελεύθερου Κειμένου — 8 βαθμοί)

Υποθέστε ότι στη διεύθυνση 2X (hex) (όπου X το τελευταίο ψηφίο του ΑΜ σας όπως έχει δηλωθεί στο eclass π.χ. 21) της κύριας μνήμης βρίσκεται ο αριθμός A και στη θέση 2X+1 (hex) ο αριθμός B ενώ στη θέση 2X+2 (hex) βρίσκεται ένας αριθμός από 0-15 - 8-bit). Να υλοποιηθεί ένα μικροπρόγραμμα που να υπολογίζει την διαφορά A-B-1 και το αποτέλεσμα να αποθηκευτεί σε καταχωρητή του οποίου η διεύθυνση στο register file είναι το περιεχόμενο της διεύθυνσης 2X+2 (hex) της κύριας μνήμης. Θα πρέπει να συμπεριλάβετε και τον αντίστοιχο ψευδοκώδικα των εντολών.

Ισχύουν τα κάτωθι:

- Δεν σας απασχολεί το bootstrap και θεωρείται δεδομένο
- Δεν μπορείτε να χρησιμοποιήσετε τα β DIP Switches της πλακέτας (PCE~)
- Δεν σας απασχολεί η προηγούμενη/επόμενη εντολή

Η λύση σας θα πρέπει να γραφτεί στο αρχείο excel των 40δων και να υποβληθεί ως εργασία στην πλατφόρμα EXAMS (ενότητα Εργασίες).

(https://exams.eclass.upatras.gr/modules/work/?course=CEID147)

Προσοχή μην αφήσετε την υποβολή για την τελευταία στιγμή γιατί η πλατφόρμα μπορεί να την απορρίψει.
