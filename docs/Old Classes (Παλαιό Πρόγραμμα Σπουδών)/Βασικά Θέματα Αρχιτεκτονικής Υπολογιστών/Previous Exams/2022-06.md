# Βασικά Θέματα Αρχιτεκτονικής Υπολογιστών — Ιούνιος 2022

> Μεταγραφή από τα αρχεία της συνεδρίας (χωρίς λύσεις). Όπου το κείμενο δεν διαβάζεται, σημειώνεται [δυσανάγνωστο].

## Screenshot_308.png

| εντολές | σχόλια |
|---|---|
| LOADSB R1, A | Φόρτωσε προσημασμένη ψηφιολέξη |
| LOADSHW R1, A | Φόρτωσε προσημασμένη μισή λέξη |
| LOADW R1, A | Φόρτωσε λέξη |
| LOADUB R1, A | Φόρτωσε απρόσημη ψηφιολέξη |
| LOADUHW R1, A | Φόρτωσε απρόσημη μισή λέξη |
| STOREB A, R1 | αποθήκευσε ψηφιολέξη |
| STOREHW A, R1 | αποθήκευσε μισή λέξη |
| STOREW A, R1 | αποθήκευσε λέξη |

Στον διπλανό πίνακα δίνονται τα περιεχόμενα τμήματος της κυρίας μνήμης.
Θεωρήστε ότι χρησιμοποιείται απεικόνιση αντιστρόφως ανάλογου του μεγέθους (big endian).
Οι προσημασμένοι αριθμοί είναι σε αναπαράσταση συμπληρώματος ως προς 2.
Υπενθυμίζεται
ψηφιολέξη: 8 δυαδικά ψηφία
μισή λέξη: 16 δυαδικά ψηφία
λέξη: 32 δυαδικά ψηφία

Να συμπληρώσετε στην μνήμη και στον κάτωθι πίνακα (στους καταχωρητές) το αποτέλεσμα της εκτέλεσης των εντολών.
