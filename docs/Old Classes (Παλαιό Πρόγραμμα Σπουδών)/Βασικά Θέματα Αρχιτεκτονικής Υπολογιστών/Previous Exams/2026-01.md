**Θέμα 1**

Να γράψετε τη συντομότερη ακολουθία πραγματικών εντολών σε συμβολική γλώσσα RISC-V οι οποίες θα υλοποιούν την παρακάτω ψευδοεντολή:

`ori t0, t0, 0xABCDE678`

Θεωρήστε ότι όλοι οι καταχωρητές αρχικά έχουν τιμή 0.

> [Πεδίο απάντησης]

**Θέμα 2**

Θεωρήστε τον δυαδικό κώδικα σε συμβολική γλώσσα RISC-V. Ποια είναι η τιμή του καταχωρητή s1 αν ο υπολογιστής ακολουθεί διάταξη μνήμης «μικρού άκρου» (little endian).

```
li t1, 0x1234FEDC
sw t1, 200(x0)
lb s1, 202(x0)
```

- [ ] (α) 0xFFFFFFFE
- [ ] (β) 0x34
- [ ] (γ) 0xFE
- [ ] (δ) 0xFFFFFF34
- [ ] (ε) άλλο

**Θέμα 3**

Υποθέστε ότι τροποποιούμε την αρχιτεκτονική RISC-V (RV32I) έτσι ώστε το πλήθος των αρχιτεκτονικών καταχωρητών να είναι 64, και το άμεσο πεδίο (immediate) να έχει πλέον μέγεθος 16 bits. Να προσδιορίσετε το μέγεθος (σε bits) όλων των πεδίων για καθεμία από τις μορφές εντολών του RISC-V και να υπολογίσετε το συνολικό πλήθος bits κάθε μορφής εντολής μετά από αυτές τις τροποποιήσεις. Θεωρήστε ότι δεν υπάρχει κάποιος περιορισμός ή απαίτηση για το συνολικό πλήθος των bit των εντολών.

> [Πεδίο απάντησης]

**Θέμα 4**

Μετατρέψτε την παρακάτω εντολή από κώδικα μηχανής (σε δεκαεξαδική μορφή) σε κώδικα συμβολικής γλώσσας RISC-V.

**Θέμα 5**

Ένας επεξεργαστής RISC-V έχει σχεδιαστεί με δίαυλο δεδομένων ενός κύκλου ρολογιού (single cycle datapath) όπως φαίνεται στο διάγραμμα παρακάτω. Για τις εντολές add, sub, and, or, lw, sw, και beq, σας ζητείται να απαντήσετε τα παρακάτω ερωτήματα.

> [Σχήμα: βλ. το διάγραμμα single-cycle datapath στο τέλος της δεύτερης σελίδας]

(α) Για ποιες από τις παραπάνω εντολές το σήμα ALUSrc θα πάρει την τιμή 0 όταν εκτελεστούν;

> [Πεδίο απάντησης]

(β) Υποθέτουμε ότι η είσοδος «Εντολή[6]» (από αριστερά γραμμή της ομάδας σημάτων «Εντολή[6-0]») της μονάδας «Έλεγχος» έχει πάντα την τιμή 1 (stuck-at-1) εξαιτίας ενός κατασκευαστικού λάθους. Ποιες από τις παραπάνω εντολές θα εκτελεστούν σωστά;

> [Πεδίο απάντησης]

**Θέμα 9**

Για τις παρακάτω εντολές σε συμβολική γλώσσα RISC-V, [δυσανάγνωστο] είναι η αντίστοιχη δήλωση στη γλώσσα C. Υποθέστε ότι οι μεταβλητές i και j έχουν προσκολληθεί στους καταχωρητές x28 και x29, αντίστοιχα, και η διεύθυνση βάσης των διανυσμάτων A και B βρίσκεται στους καταχωρητές x10 και x11, αντίστοιχα.

```
add x30, x28, x29
slli x30, x30, 2
add x3, x30, x11
lw x30, 0(x3)
sw x30, 32(x10)
```

- [ ] (α) $B[16]=A[i+j]$
- [ ] (β) $B[32]=A[i*]$ [δυσανάγνωστο]
- [ ] (γ) $A[8]=B[i+j]$
- [ ] (δ) $A[i]=B[32]$ [δυσανάγνωστο]
- [ ] (ε) άλλο
