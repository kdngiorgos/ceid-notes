    # Λύσεις — Βασικά Θέματα Αρχιτεκτονικής Υπολογιστών — Αύγουστος 2021

    ## 2021-08-29_21.19.46.png

    Ερώτηση 1 / 1 (Συμπλήρωση Κενών (Χαλαρή Ταυτοποίηση) — 2 βαθμοί)

    Έχετε στη διάθεση σας ολοκληρωμένα κυκλώματα μνήμης ΟΚ0 με χωρητικότητα 256 Kbits και οργάνωση οκτώ δυαδικών ψηφίων ανά θέση μνήμης καθώς και ολοκληρωμένα κυκλώματα ΟΚ2 με χωρητικότητα 32Kbytes και οργάνωση δύο δυαδικών ψηφίων ανά θέση.

    Πόσα ολοκληρωμένα κυκλώματα τύπου ΟΚ0 και πόσα τύπου ΟΚ2 χρειάζεστε για να σχεδιάσετε ένα σύστημα μνήμης με χωρητικότητα 160Kbytes και 10 bits ανά θέση; Να δώσετε το αποτέλεσμα ως δύο διψήφιους αριθμούς που χωρίζονται με το σύμβολο + πχ. 01+12 το οποίο σημαίνει 4 τύπου ΟΚ0 και 12 τύπου ΟΚ2.

    Λύση

    **ΟΚ1**

    | | |
    |---|---|
    | 1 θ.μ. | 8 bits |
    | x; | 256kbits |

    $x = 2^8 \times 2^{10} / 2^3 = 2^{15}$ θ.μ.

    **ΟΚ2**

    | | |
    |---|---|
    | 1 θ.μ. | 2 bits |
    | x | 32KB |

    $x = 2^5 \times 2^{10} \times 2^3 / 2^1 = 2^{18} / 2^1 = 2^{17}$ θ.μ.

    **Κύρια μνήμη**

    | | |
    |---|---|
    | 1 θ.μ. | 10 bits |
    | x | 160KB |

    $x = 160 \times 2^{10} \times 2^3 / 10 = 2^{17}$ θ.μ.

    Πρέπει να χρησιμοποιήσουμε **μόνο** το ΟΚ2.

    Οριζόντια επανάληψη: **5** (2 bits + 2 bits + 2 bits + 2 bits + 2 bits)

    Κατακόρυφη επανάληψη: $\dfrac{\text{θ.μ. που θέλουμε να έχουμε}}{\text{θ.μ. που διαθέτουμε από τα ΟΚΜ}} = \dfrac{2^{17}\ \text{θ.μ.}}{2^{17}\ \text{θ.μ.}} = 1$ επανάληψη

    > [Σχήμα: πέντε πορτοκαλί ορθογώνια με την ένδειξη ΟΚ2, τοποθετημένα σε σειρά]

    Επομένως χρειαζόμαστε 5 ΟΚ2.

    > Σημείωση: στη λύση η πρώτη μνήμη (256kbits) φέρει την ένδειξη «ΟΚ1», ενώ στην εκφώνηση είναι «ΟΚ0»· η ένδειξη αντιγράφεται όπως είναι γραμμένη στη φωτογραφία.
