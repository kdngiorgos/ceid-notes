## 1.jpg

ΕΞΕΤΑΣΕΙΣ ΑΡΧΙΤΕΚΤΟΝΙΚΗΣ ΥΠΟΛΟΓΙΣΤΩΝ Ι

6 ΙΟΥΝΙΟΥ 2017

ΘΕΜΑ 1. (μον. 1) Να αναφέρετε και να αιτιολογήσετε το πολύ σε πέντε γραμμές που βασίζεται η επιτυχία της κρυφής μνήμης του επεξεργαστή.

ΘΕΜΑ 2. (μον. 3) Να γράψετε πρόγραμμα για τον υπολογισμό της έκφρασης: $F = A \times (B-C) - D/(E-G)$ για κάθε μια των κάτωθι αρχιτεκτονικών.

α. Επεξεργαστής που βασίζεται στη χρήση στοίβας (stuck architecture). (1 μον.)

> [sic: «stuck» αντί «stack», όπως είναι τυπωμένο]

β. Επεξεργαστής που βασίζεται στη χρήση συσσωρευτή (accumulator based architecture). Εάν το πρόγραμμά σας κάνει σωστά τον υπολογισμό λαμβάνει 0.5 μον., ενώ αν χρησιμοποιεί και το ελάχιστο πλήθος εντολών λαμβάνει 1 μον.

γ. Επεξεργαστής που βασίζεται στη χρήση καταχωρητών γενικού σκοπού (general-purpose register architecture) με 4 καταχωρητές γενικού σκοπού και εντολές των 2 τελούμενων.

Και στα τρία προγράμματα δίπλα σε κάθε εντολή πρέπει να δώσετε με συμβολικό τρόπο τι κάνει η συγκεκριμένη εντολή.

    ## 1.jpg

    ΕΞΕΤΑΣΕΙΣ ΑΡΧΙΤΕΚΤΟΝΙΚΗΣ ΥΠΟΛΟΓΙΣΤΩΝ Ι

    6 ΙΟΥΝΙΟΥ 2017

    ΘΕΜΑ 1. (μον. 1) Να αναφέρετε και να αιτιολογήσετε το πολύ σε πέντε γραμμές που βασίζεται η επιτυχία της κρυφής μνήμης του επεξεργαστή.

    Απάντηση

    Η επιτυχία της κρυφής μνήμης του επεξεργαστή βασίζεται στην τοπικότητα των αναφορών. Σύμφωνα με την τοπικότητα των αναφορών η πληροφορία (εντολές και δεδομένα) που χρησιμοποιήθηκε πρόσφατα και η πληροφορία που βρίσκεται κοντά στην πληροφορία που χρησιμοποιείται τώρα, έχει μεγάλη πιθανότητα να χρησιμοποιηθεί στο άμεσο μέλλον.

    ΘΕΜΑ 2. (μον. 3) Να γράψετε πρόγραμμα για τον υπολογισμό της έκφρασης: F = A×(B-C)-D/(E-G) για κάθε μια των κάτωθι αρχιτεκτονικών.

    α. Επεξεργαστής που βασίζεται στη χρήση στοίβας (stuck architecture). (1 μον.)

    β. Επεξεργαστής που βασίζεται στη χρήση συσσωρευτή (accumulator based architecture). Εάν το πρόγραμμά σας κάνει σωστά τον υπολογισμό λαμβάνει 0.5 μον., ενώ αν χρησιμοποιεί και το ελάχιστο πλήθος εντολών λαμβάνει 1 μον.

    γ. Επεξεργαστής που βασίζεται στη χρήση καταχωρητών γενικού σκοπού (general-purpose register architecture) με 4 καταχωρητές γενικού σκοπού και εντολές των 2 τελούμενων.

    Και στα τρία προγράμματα δίπλα σε κάθε εντολή πρέπει να δώσετε με συμβολικό τρόπο τι κάνει η συγκεκριμένη εντολή.

    Απάντηση

    α. F = A×(B-C)-D/(E-G) = A×CB--D/GE- = ACB-x-GE-D/ = GE-D/ACB-x-

    | πρόγραμμα | Κορυφή στοίβας |
    | --- | --- |
    | PUSH G | G |
    | PUSH E | E, G |
    | SUB | E-G |
    | PUSH D | D, (E-G) |
    | DIV | D/(E-G) |
    | PUSH A | A, D/(E-G) |
    | PUSH C | C, A, D/(E-G) |
    | PUSH B | B, C, A, D/(E-G) |
    | SUB | B-C, A, D/(E-G) |
    | MULT | (B-C)×A, D/(E-G) |
    | SUB | (B-C)×A-D/(E-G) |
    | POP F | - |
