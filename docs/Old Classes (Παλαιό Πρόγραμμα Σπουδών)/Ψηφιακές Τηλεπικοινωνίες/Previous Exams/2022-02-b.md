ΘΕΜΑ 3 (26 μονάδες)

1. Θεωρήστε μια διακριτή πηγή χωρίς μνήμη (discrete memoryless source, DMS) η οποία έχει ένα αλφάβητο τεσσάρων συμβόλων Φ = {"s1", "s2", "s3", "s4"} με πιθανότητες εμφάνισης 0.15, 0.15, 0.56 και 0.14, αντίστοιχα. Ζητούνται:

a. Να υπολογίσετε την εντροπία της πηγής.

b. Να υπολογίσετε το ελάχιστο μήκος κώδικα για την κωδικοποίηση αυτής της πηγής.

c. Να βρείτε έναν κώδικα Huffman για την πηγή αυτή και να υπολογίσετε την αποδοτικότητά του.

2. Θεωρήστε τώρα μια διακριτή πηγή με αλφάβητο Φ = {"A", "B"}. Θεωρήστε επίσης ότι η πηγή αυτή παράγει μια ακολουθία συμβόλων $x_n$, $n = 0, 1, 2, \dots$ όπου οι πιθανότητες των συμβόλων δίνονται από τον τύπο:

$$
P(x_n = s_k) =
\begin{cases}
0.3, & \text{Αν } s_k = \text{"A"} \text{ και } n = 0, 2, 4, 6, 8, \dots \\
0.7, & \text{Αν } s_k = \text{"B"} \text{ και } n = 0, 2, 4, 6, 8, \dots \\
0.5, & \text{Αν } s_k = \text{"A"} \text{ και } n = 1, 3, 5, 7, 9, \dots \\
0.5, & \text{Αν } s_k = \text{"B"} \text{ και } n = 1, 3, 5, 7, 9, \dots \text{ και } x_{n-1} = [\text{δυσανάγνωστο}] \\
0.8, & \text{Αν } s_k = \text{"A"} \text{ και } n = 1, 3, 5, 7, 9, \dots \text{ και } x_{n-1} = \text{"A"} \\
0.2, & \text{Αν } s_k = \text{"B"} \text{ και } n = 1, 3, 5, 7, 9, \dots \text{ και } x_{n-1} = \text{"B"}
\end{cases}
$$

Με άλλα λόγια, η πηγή αυτή τις άρτιες χρονικές στιγμές έχει πιθανότητες εμφάνισης των συμβόλων «A» και «B» ίσες με 0.3 και 0.7 αντίστοιχα, ενώ στις περιττές χρονικές στιγμές έχει πιθανότητες εμφάνισης που εξαρτώνται από το σύμβολο που εμφανίζει η πηγή την αμέσως προηγούμενη χρονική στιγμή.

a. [δυσανάγνωστο]

b. Να υπολογίσετε την εντροπία, το ελάχιστο μήκος κώδικα, καθώς και έναν κώδικα Huffman για τη νέα πηγή [δυσανάγνωστο] χωρίς μνήμη.

> [Λείπει από τη φωτογραφία: το τέλος της εκφώνησης του ερωτήματος 2b και τυχόν επόμενα ερωτήματα]

> Σημείωση: η εικόνα είναι μικρής ανάλυσης και το κείμενο των ερωτημάτων 2a και 2b είναι μερικώς δυσανάγνωστο. Ελέγξτε το πρωτότυπο.
