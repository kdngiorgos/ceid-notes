**ΘΕΜΑ 3** (26 μονάδες)

1. Θεωρήστε μια διακριτή πηγή χωρίς μνήμη (discrete memoryless source, DMS) η οποία έχει ένα αλφάβητο τεσσάρων συμβόλων $\Phi = \{\text{"s1"}, \text{"s2"}, \text{"s3"}, \text{"s4"}\}$, με πιθανότητες εμφάνισης 0.15, 0.15, 0.56 και 0.14, αντίστοιχα. Ζητούνται:
   - a. Να υπολογίσετε την εντροπία της πηγής.
   - b. Να υπολογίσετε το ελάχιστο μήκος ενός κώδικα για την κωδικοποίηση αυτής της πηγής.
   - c. Να βρείτε έναν κώδικα Huffman για την πηγή αυτή και να υπολογίσετε την αποδοτικότητά του.

2. Θεωρήστε τώρα μια διακριτή πηγή με αλφάβητο $\Phi' = \{\text{"A"}, \text{"B"}\}$. Θεωρήστε επίσης πως η πηγή αυτή παράγει μια ακολουθία συμβόλων $x_n$, $n = 0, 1, 2, \dots$ όπου οι πιθανότητες εμφάνισης των συμβόλων δίνονται από τον τύπο:

$$
P(x_n = s_k) = \begin{cases}
0.3, & \text{αν } s_k = \text{"A"} \text{ και } n = 0, 2, 4, 6, 8, \dots \\
0.7, & \text{αν } s_k = \text{"B"} \text{ και } n = 0, 2, 4, 6, 8, \dots \\
0.5, & \text{αν } s_k = \text{"A"} \text{ και } n = 1, 3, 5, 7, 9, \dots \text{ και } x_{n-1} = \text{"A"} \\
0.5, & \text{αν } s_k = \text{"B"} \text{ και } n = 1, 3, 5, 7, 9, \dots \text{ και } x_{n-1} = \text{"A"} \\
0.8, & \text{αν } s_k = \text{"A"} \text{ και } n = 1, 3, 5, 7, 9, \dots \text{ και } x_{n-1} = \text{"[δυσανάγνωστο]"} \\
0.2, & \text{αν } s_k = \text{"B"} \text{ και } n = 1, 3, 5, 7, 9, \dots \text{ και } x_{n-1} = \text{"B"}
\end{cases}
$$

> [δυσανάγνωστο: η συνθήκη x_{n-1} στη γραμμή με πιθανότητα 0.8· στη φωτογραφία φαίνεται χαμηλής ανάλυσης, επαληθεύστε στο πρωτότυπο]

Με άλλα λόγια, η πηγή αυτή τις άρτιες χρονικές στιγμές έχει πιθανότητες εμφάνισης των συμβόλων «Α» και «Β» ίσες με 0.3 και 0.7 αντίστοιχα, ενώ στις περιττές χρονικές στιγμές έχει πιθανότητες που εξαρτώνται από το σύμβολο που είχε η πηγή την αμέσως προηγούμενη χρονική στιγμή.

   - a. Να μετασχηματίσετε την διακριτή αυτή πηγή με μνήμη, σε μια ισοδύναμη διακριτή πηγή χωρίς μνήμη.
   - b. Να υπολογίσετε την εντροπία, το ελάχιστο μήκος κώδικα, καθώς και έναν κώδικα Huffman για τη νέα πηγή.
