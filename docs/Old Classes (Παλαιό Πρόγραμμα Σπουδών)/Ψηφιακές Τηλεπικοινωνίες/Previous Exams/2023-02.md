**2° ΜΕΡΟΣ: ΑΣΚΗΣΗ (40μ)**

Το αλφάβητο μιας πηγής χωρίς μνήμη είναι $S = \{0, 1, 3, 5, 7\}$ με αντίστοιχες πιθανότητες εμφάνισης τις: $\{16/50, 16/100, 1/10, 4/50, 17/50\}$.

Ζητούνται:

α) Να βρεθεί η εντροπία $H(S)$ της πηγής. (Ισχύει ότι: $\log_a x = \log_b x / \log_b a$)

β) Έστω ότι η έξοδος της παραπάνω πηγής εισέρχεται σε έναν κβαντιστή τριών επιπέδων του οποίου η έξοδος αποτελείται από τα σύμβολα $S' = \{A, B, \Gamma\}$, ενώ η λειτουργία του περιγράφεται από τη συνάρτηση

$$f(x) = A \text{ για } x=0,\; B \text{ για } 0 < x \le c,\; \Gamma \text{ για } x>c$$

Να επιλέξετε την τιμή της παραμέτρου $c$, όπου $c \in [0, 7)$, ώστε να μεγιστοποιείται η εντροπία της νέας (κβαντισμένης) πηγής.

γ) Να βρεθεί η εντροπία $H(S')$ της νέας πηγής $S'$.

δ) Έστω ότι παράγονται δυαδικά σύμβολα με ρυθμό $1000H(S')$ kbit/sec. Εάν για τη μετάδοση αυτής της ακολουθίας συμβόλων χρησιμοποιηθεί σύστημα διαμόρφωσης 16-PAM, τότε ποιο είναι το ελάχιστο εύρος ζώνης που απαιτείται να έχει το κανάλι μετάδοσης ώστε να μην υπάρχει διασυμβολική παρεμβολή; Τι παλμός πρέπει να χρησιμοποιηθεί σε αυτήν την περίπτωση; Σχολιάστε τα πιθανά μειονεκτήματα της χρήσης του συγκεκριμένου παλμού.

ε) Έστω ότι το εύρος ζώνης του καναλιού είναι αυτό που υπολογίσατε στο ερώτημα δ. Τότε, εάν χρησιμοποιηθεί σύστημα διαμόρφωσης 32-PAM και παλμός ανυψωμένου συνημιτόνου, ποια είναι η τιμή του παράγοντα αναδίπλωσης του παλμού αυτού;

Διάρκεια εξετάσεων: 2 ώρες και 15'
