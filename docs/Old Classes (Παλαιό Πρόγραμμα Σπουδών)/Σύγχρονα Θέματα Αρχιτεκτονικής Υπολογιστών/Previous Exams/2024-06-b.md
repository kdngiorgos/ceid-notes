# Σύγχρονα Θέματα Αρχιτεκτονικής Υπολογιστών — Ιούνιος 2024 — παραλλαγή Β

## IMG_20240608_033413.jpg

**ΘΕΜΑ 3. (2.2 μον.)** Θεωρήστε επεξεργαστή μερικώς επικαλυπτόμενων λειτουργιών (pipeline) με πέντε βαθμίδες ΙΠΕ, ΑΕ, ΕΠ, ΠΜ και ΑΑ ο οποίος διαθέτει κοινή κρυφή μνήμη εντολών και δεδομένων με μια πόρτα ανάγνωσης/εγγραφής. Δίνεται το διπλανό τμήμα προγράμματος.

```
ADD  r1, r6, r2     / r2
LOAD r7, (r2)       / r7
ADD  r3, r5, r8     / r8
STORE r7, (r3)      / r7
SUB  r7, r3, r4     / r4
SUB  r8, r4, r5     / r5
LOAD r6, (r3)       / r6
ADD  r5, r6, r9     / r9
```

> [δυσανάγνωστο: σύμβολο στο δεξιό άκρο της λίστας, μετά τα r4, r6 και r9]

α. Να φτιάξετε το χρονικό διάγραμμα χρήσης των βαθμίδων, να σημειώσετε τις εξαρτήσεις που δημιουργούν πρόβλημα και να αναφέρετε το είδος κάθε εξάρτησης (απλά να αναφέρετε το είδος, δεν χρειάζεται αιτιολόγηση) για τις ακόλουθες δύο περιπτώσεις:

i. Δεν έχει υλοποιηθεί η τεχνική της παροχέτευσης (bypassing).

ii. Έχει υλοποιηθεί η τεχνική της παροχέτευσης (bypassing).

**Για κάθε λάθος δήλωση εξάρτησης που δημιουργεί πρόβλημα αφαιρείται μια σωστή δήλωση.**

β. Χωρίς να αλλάξετε τη σειρά των εντολών να αναφέρετε την τεχνική ή τις τεχνικές που πρέπει να χρησιμοποιηθούν ώστε να μην υπάρχει πρόβλημα στην ορθή εκτέλεση του τμήματος προγράμματος. Να ξαναφτιάξετε το χρονικό διάγραμμα χρήσης των βαθμίδων εφαρμόζοντας την τεχνική ή τις τεχνικές που προτείνατε για την περίπτωση που έχει υλοποιηθεί τεχνική της παροχέτευσης.

> Σημείωση: η φωτογραφία περιέχει χειρόγραφες απαντήσεις φοιτητή.

## IMG_20240608_033640.jpg

ΘΕΜΑ 6. (2.0 μον)

Θεωρήστε επεξεργαστή ειδικού σκοπού στον οποίο τόσο οι λογικές διευθύνσεις όσο και οι φυσικές διευθύνσεις είναι των 16 δυαδικών ψηφίων. Η σελίδα είναι των 4 KBytes και ο πίνακας σελίδων υλοποιείται σε 2 επίπεδα όπως φαίνεται στο επόμενο σχήμα. Η αποθήκευση του πίνακα σελίδων πρώτου επιπέδου αρχίζει από τη φυσική διεύθυνση $0000_{(16)}$ ενώ η αποθήκευση των πινάκων σελίδων 0, 1, 2 και 3 του δεύτερου επιπέδου αρχίζουν από τις φυσικές διευθύνσεις $FF00_{(16)}$, $FE00_{(16)}$, $FD00_{(16)}$ και $FC00_{(16)}$. Να απαντήσετε εάν οι σελίδες στις οποίες βρίσκονται οι λογικές διευθύνσεις $1F23_{(16)}$, $7E11_{(16)}$ και $CA20_{(16)}$ βρίσκονται στην κύρια μνήμη του υπολογιστή και αν ναι σε ποια φυσική διεύθυνση αντιστοιχεί κάθε μία. Να αιτιολογήσετε την απάντησή σας.

> [Σχήμα: Σχήμα δύο επιπέδων πίνακα σελίδων. Αριστερά κουτί "ΒΚΠΣ" (κενό) και κουτί "0000". Στη μέση "Πίνακας σελίδων 1ου επιπέδου" με στήλη "Π-φδΠΣ 2ου επιπέδου" και εγγραφές: 1-FF00, 1-FE00, 0-FD00, 1-FC00. Δεξιά "Πίνακες σελίδων 2ου επιπέδου" με στήλη "Π-φδΣ" και τέσσερις πίνακες με βέλη από τις παραπάνω εγγραφές: Πίνακας 0: 1-0, 1-4, 1-5, 0-A. Πίνακας 1: 1-B, 1-D, 1-6, 0-3. Πίνακας 2: 0-3, 0-2, 0-E, 0-1. Πίνακας 3: 1-7, 1-9, 1-8, 0-C.]

> Σημείωση: Μέρος της φωτογραφίας (αριστερά) καλύπτεται από ένα χέρι. Το κουτί "ΒΚΠΣ" είναι κενό στη φωτογραφία.
