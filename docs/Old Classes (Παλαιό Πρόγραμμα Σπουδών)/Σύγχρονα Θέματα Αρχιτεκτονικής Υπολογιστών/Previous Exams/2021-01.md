Θεωρήστε υπολογιστή με ιδεατή μνήμη, virtual memory, που υλοποιείται με την τεχνική της σελιδοποίησης. Το μέγεθος της σελίδας είναι $2^{12}$ bytes. Σε κάθε byte αντιστοιχεί μια διεύθυνση. Υποθέστε ότι η ιδεατή μνήμη υλοποιείται με την τεχνική του αντιστρόφου πίνακα σελίδων, inverted page table, με 5 αντιστοιχίσεις ανά θέση του πίνακα. Το πλήθος των δυαδικών ψηφίων ελέγχου στον πίνακα σελίδων είναι 7. Η λογική διεύθυνση είναι των 47 bits ενώ η φυσική διεύθυνση των 36 bits. Να υπολογίσετε τη χωρητικότητα του αντιστρόφου πίνακα σελίδων σε bits. Να δώσετε την τιμή χρησιμοποιώντας 6 ψηφία και Κ, Μ ή G ανάλογα π.χ. 003472K ή 000321M ή 348848G. Εάν η χωρητικότητα μπορεί να δοθεί ως ακέραιος αριθμός σε Gbits, πρέπει να δοθεί υποχρεωτικά σε Gbits, εάν δεν μπορεί να δοθεί ως ακέραιος αριθμός σε Gbits και μπορεί να δοθεί ως ακέραιος αριθμός σε Mbits [συμπληρώθηκε από 6.png] να δοθεί σε Mbits, διαφορετικά να δοθεί σε Kbits π.χ. το 5120K πρέπει να δοθεί ως 5M.

## sl.png

Θεωρήστε ότι το τμήμα προγράμματος που ακολουθεί ανήκει σε πρόγραμμα που εκτελείται σε υπερβαθμωτό (superscalar) επεξεργαστή με ρυθμό αποστολής εντολών προς εκτέλεση 4.

...

```
1. NOR r1, r7, r8       / r1 <-- NOR(r7, r8)
2. LOAD r0, (r9)        / r0 <-- M(r9)
3. ADD r3, r1, r10      / r3 <-- r1+r10
4. SUB r4, r1, r2       / r4 <-- r1-r2
5. ADD r6, r4, r5       / r6 <-- r4+r5
6. ADD r3, r8, r2       / r3<-- r8+r2
7. MUL r7, r5, r2       / r7<-- r5*r2
8. STORE r1, (r6)       / r1 --> M(r6)
```

...

Να απαντήσετε εάν η ακόλουθη πρόταση είναι σωστή ή λάθος.

Σε επεξεργαστή που ισχύει το μοντέλο της ισχυρής σειριακής συνέπειας στην εκτέλεση των εντολών, η υπ' αριθμόν 4 εντολή μπορεί να ολοκληρωθεί πριν την υπ' αριθμόν 3 εντολή.
