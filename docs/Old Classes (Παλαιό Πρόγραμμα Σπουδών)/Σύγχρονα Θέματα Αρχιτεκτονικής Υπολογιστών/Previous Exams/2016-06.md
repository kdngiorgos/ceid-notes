# Σύγχρονα Θέματα Αρχιτεκτονικής Υπολογιστών — Ιούνιος 2016

> Μεταγραφή από την φωτογραφία image.png (πρώτη σελίδα της εξέτασης της 14ης Ιουνίου 2016).

## image.png

**ΕΞΕΤΑΣΕΙΣ ΑΡΧΙΤΕΚΤΟΝΙΚΗΣ ΥΠΟΛΟΓΙΣΤΩΝ ΙΙ**

**14 Ιουνίου 2016**

**Θέμα 1.** (μον. 1) Θεωρήστε μία μονάδα επεξεργασίας δεδομένων σταθερής υποδιαστολής. Να σημειώσετε θέτοντας ένα ν αν έχει νόημα να υπάρχουν και οι δύο εντολές LOAD r1, (r2) [r1←M(r2)], LOAD r1, d(r2) [r1←M((r2)+d)], μέσα στις αγκύλες είναι η επεξήγηση των εντολών, σε κάθε μία από τις κάτωθι περιπτώσεις **και να αιτιολογήσετε το πολύ σε πέντε γραμμές την απάντησή σας.**

α. Έχει νόημα στην περίπτωση που κάθε εντολή εκτελείται σε ένα κύκλο ρολογιού. ΝΑΙ / ΟΧΙ

β. Έχει νόημα στην περίπτωση που κάθε εντολή εκτελείται σε τόσους κύκλους ρολογιού όσους απαιτείται. ΝΑΙ / ΟΧΙ

**Αιτιολόγηση.**

**Θέμα 2.** (μον. 2) Η επόμενη μονάδα επεξεργασίας δεδομένων σταθερής υποδιαστολής έχει σχεδιαστεί για την εκτέλεση των εντολών: LOAD r1, (r2) [r1← M(r2)], STORE r1, (r2) [r1→ M(r2)], ADD r1, r2, r3 [r1+r2 → r3], SUB r1, r2, r3 [r1-r2 →r3], AND r1, r2, r3 [r1∧r2 → r3], και BRE r1, r2, d [εάν r1-r2=0 τότε ΜΠ=ΜΠ+d, όπου d αριθμός των 17 δυαδικών ψηφίων σε αναπαράσταση συμπληρώματος ως προς 2], στις αγκύλες είναι η επεξήγηση της εντολής. Να κάνετε, πάνω στο σχήμα (δεν χρειάζεται αιτιολόγηση), τις απαιτούμενες τροποποιήσεις ώστε η μονάδα να μπορεί να εκτελεί και την εντολή STORE r1, d(r2) [r1→ M((r2)+d)], ο αριθμός d έχει τα ίδια χαρακτηριστικά με τον αριθμό d της εντολής BRE] και **να θέσετε τις τιμές των σημάτων που απαιτούνται για την εκτέλεση αυτής της εντολής.**

> [Λείπει από τη φωτογραφία: το διάγραμμα της μονάδας επεξεργασίας, που βρίσκεται κάτω από το κείμενο του θέματος 2 στη σελίδα 1 και δεν περιλαμβάνεται στο στιγμιότυπο.]
