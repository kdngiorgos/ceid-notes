# Τεχνολογία και Προγραμματισμός Υπολογιστών

> Παλιό μάθημα του προγράμματος σπουδών που ένωνε τρία αντικείμενα: προγραμματισμό σε C (προγράμματα γραμμένα σε χαρτί), αριθμητικά συστήματα και αναπαραστάσεις (μετατροπές, συμπληρώματα, πράξεις) και θεωρητική οργάνωση υπολογιστικών συστημάτων (μνήμη, περιφερειακές συσκευές, στοιχεία δικτύων/λειτουργικών). Το υλικό εδώ είναι ανεπίσημο (συζητήσεις φοιτητών στο Discord και παλιά θέματα).

## Τι θα μάθεις

- **Προγραμματισμός σε C**: συναρτήσεις, μονοδιάστατοι και δισδιάστατοι πίνακες, strings, structs/unions, αμυντικός προγραμματισμός· τα θέματα ζητούσαν ολοκληρωμένα προγράμματα γραμμένα σε χαρτί Discord 2022-01 (δεν δημοσιεύεται εδώ), Discord 2024-11 (δεν δημοσιεύεται εδώ).
- **Αριθμητικά συστήματα**: μετατροπές δυαδικό/οκταδικό/δεκαεξαδικό, πράξεις, συμπληρώματα ως προς 1 και 2, αναπαράσταση αρνητικών αριθμών, IEEE 754 Discord 2023-08 (δεν δημοσιεύεται εδώ), Discord 2024-09 (δεν δημοσιεύεται εδώ).
- **Θεωρητικό μέρος (Βέργου)**: οργάνωση μνήμης, περιφερειακές συσκευές, «τουλάχιστον 5 μακροσκοπικά χαρακτηριστικά» κύριας μνήμης/οθόνης, μετατροπές μονάδων μνήμης (bytes↔kbytes), στοιχεία assembly/διευθυνσιοδότησης Discord 2024-06 (δεν δημοσιεύεται εδώ), Discord 2021-09 (δεν δημοσιεύεται εδώ).
- **Μέρος Ηλία**: διευθύνσεις IP/υποδίκτυα και εντολές διαδρομών (ls, cd) Discord 2021-09 (δεν δημοσιεύεται εδώ).
- Η επίσημη ύλη δεν δημοσιεύτηκε ποτέ καθαρά· φοιτητές τη συμπέραιναν από eclass/PDF. Σε κάποια ύλη εμφανιζόταν και Python, αν και η διδασκαλία ήταν σε C Discord 2023-01 (δεν δημοσιεύεται εδώ).
