ΕΡΓΑΣΤΗΡΙΟ ΤΕΧΝΟΛΟΓΙΑ ΚΑΙ ΠΡΟΓΡΑΜΜΑΤΙΣΜΟΣ ΥΠΟΛΟΓΙΣΤΩΝ (1)

ΠΡΕΠΕΙ ΝΑ ΑΠΑΝΤΗΣΕΤΕ ΣΕ ΔΥΟ ΑΠΟ ΤΑ ΤΡΙΑ ΘΕΜΑΤΑ

ΟΔΗΓΙΕΣ

ΟΙ ΑΠΑΝΤΗΣΕΙΣ ΣΑΣ ΘΑ ΕΙΝΑΙ ΣΤΟΝ ΥΠΟΛΟΓΙΣΤΗ ΚΑΙ ΣΤΗΝ ΚΟΛΛΑ

1. Να ορίσετε μία δομή (struct) που θα αποθηκεύει τα στοιχεία ενός βιβλίου με πεδία: ονοματεπώνυμο συγγραφέα, τίτλος και τιμή. Γράψτε πρόγραμμα το οποίο: (i) θα δηλώνει ένα πίνακα με το όνομα library που θα αποθηκεύει ένα σύνολο N βιβλίων (το N θα δηλώνεται ως σταθερά με την οδηγία #define), (ii) θα διαβάζει τα στοιχεία των N βιβλίων από τον χρήστη, (iii) θα διαβάζει τον τίτλο για ένα βιβλίο που θα δίνει ο χρήστης και θα εκτυπώνει το πλήθος των βιβλίων με τον τίτλο αυτό.

2. Υλοποιήστε συνάρτηση που παίρνει σαν όρισμα ένα τετραγωνικό πίνακα ακεραίων (δηλαδή πίνακα δύο διαστάσεων με ίδιο αριθμό γραμμών και στηλών) και θα υπολογίζει **και θα εκτυπώνει για κάθε γραμμή το μικρότερο στοιχείο και για κάθε στήλη το μεγαλύτερο στοιχείο.** Φτιάξτε κυρίως πρόγραμμα που γεμίζει τον πίνακα με στοιχεία και καλεί την συνάρτηση. Το κυρίως πρόγραμμα θα πρέπει να ελέγχει με προγραμματισμό αμυντικό ότι τα στοιχεία που δίνονται είναι θετικά.

3. Να γραφεί πρόγραμμα σε C το οποίο:

α) να ζητά από τον χρήστη την εισαγωγή των στοιχείων ενός μονοδιάστατου πίνακα Α, 30 θέσεων, που περιέχει θετικούς ακέραιους αριθμούς. Το κυρίως πρόγραμμα θα πρέπει να ελέγχει με προγραμματισμό αμυντικό ότι τα στοιχεία που δίνονται είναι θετικά.

β) να μεταφέρει τα στοιχεία του πίνακα Α στον δισδιάστατο πίνακα Β, διαστάσεων 6 x 5, με τέτοιο τρόπο ώστε πρώτα να συμπληρωθεί η πρώτη γραμμή του πίνακα Β, μετά η δεύτερη γραμμή του κ.ο.κ. Στη συνέχεια να εκτυπώνει τα στοιχεία του πίνακα Β.

**Η ενέργεια (β) να υλοποιηθεί με συνάρτηση που καλείται από το κυρίως πρόγραμμα.**
