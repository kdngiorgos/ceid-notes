# **ΕΠΩΝΥΜΟ / ΟΝΟΜΑ …………………………………… ΑΜ………………………….**

Χρησιμοποιούμε  ΥΠΟΧΡΕΩΤΙΚΑ το 7ψηφιο ΑΜ για να φτιάξουμε τα Α, B, C, D, E, F και G. πχ αν το ΑΜ είναι το 1234567 τότε D=34,12 δηλ 3ο, 4ο, 1ο και 2ο ψηφίο του ΑΜ,  Ε=((1234567)/1000)*2,   ομοίως F=0,765  (7ο, 6ο, 5ο ψηφίο) A=17 (1o και 7ο ψηφίο)  Β=-43(4o και 3ο ψηφίο)  C=-3,45 (3ο,4ο, 5ο ψηφίο), **G=4** (4ο ψηφίο)
