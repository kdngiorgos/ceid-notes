**Ερώτηση: 1**

Για κάθε φυσικό αριθμό $k$ υπάρχει $r_k$ στο διάστημα $(0,1)$ ώστε
$$\ln(k+1) = \ln k + \frac{1}{k + r_k}.$$

- [ ] Λάθος (Βαθμολογία: -1.00)

Δίνεται το ολοκλήρωμα
$$I = \int_a^b \tan x \, \mathrm{d}x,$$
με $a < b$.

- [ ] Αν $a = -\pi/2$ και $b = \pi/2$, τότε $I = 0$ αφού η $\tan$ είναι περιττή συνάρτηση σ′ αυτό το διάστημα. (Βαθμολογία: -1.00)
- [ ] Αν το ολοκλήρωμα υπάρχει, τότε αναγκαστικά $b - a < \pi$. (Βαθμολογία: 2.00)
- [ ] Αν $a = \pi/2 - \pi/3$ και $b = \pi/2 + \pi/3$, τότε το ολοκλήρωμα υπάρχει. (Βαθμολογία: -1.00)
- [ ] Αν το ολοκλήρωμα υπάρχει, τότε $I = (b - a)\tan \xi$ για κάποιο $\xi \in (a,b)$. (Βαθμολογία: 2.00)

**Ερώτηση: 7**

Δίνεται ο μιγαδικός αριθμός $z = (1+\sqrt{3}i)^m$, όπου $m$ είναι φυσικός αριθμός.

Απάντηση

- [ ] Ισχύει $\operatorname{Re} z \neq 0$ για κάθε φυσικό αριθμό $m$. (Βαθμολογία: 2.00)
- [ ] Ισχύει $\operatorname{Im} z \neq 0$ για κάθε φυσικό αριθμό $m$. (Βαθμολογία: -0.50)
- [ ] $|z| = 2^m$. (Βαθμολογία: 2.00)
- [ ] Για κάθε φυσικό αριθμό $m$ ισχύει $z \neq \bar{z}$. (Βαθμολογία: -0.50)
- [ ] Αν $m = 6k - 1$ για κάποιο φυσικό αριθμό $k$, τότε το πρωτεύον όρισμα του $z$ είναι $\operatorname{Arg} z = \dfrac{5\pi}{3}$. (Βαθμολογία: 2.00)

> [Δεύτερο τμήμα του στιγμιοτύπου: η επικεφαλίδα/αριθμός της ερώτησης δεν φαίνεται, ορατά μόνο το «Αν» και το ολοκλήρωμα.]

$I = \displaystyle\int_1^2 \frac{x}{\sqrt{x^2-1}}\,\mathrm{d}x,$

Απάντηση

- [ ] Το ολοκλήρωμα δεν ορίζεται γιατί στο $x = 1$ η υπό ολοκλήρωση συνάρτηση δεν ορίζεται. (Βαθμολογία: -1.00)
- [ ] $I = \sqrt{3}.$ (Βαθμολογία: 2.00)
- [ ] $I = \dfrac{1}{\sqrt{3}}.$ (Βαθμολογία: -1.00)
