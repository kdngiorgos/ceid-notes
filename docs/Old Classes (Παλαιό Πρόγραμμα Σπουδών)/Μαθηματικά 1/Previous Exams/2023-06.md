## Θέμα 1

- ■ $\displaystyle\lim_{N\to\infty}\int_{-N}^{N}\frac{1}{1+kx^2}\,dx = \ldots\ldots$, όπου $k = 2, 3$.
- ■ $\displaystyle\lim_{x\to 0}\frac{\sin(\tan x)}{x} = \ldots\ldots$
- ■ $\displaystyle\lim_{n\to\infty}\left(1+\frac{k}{n+m}\right)^{n} = \ldots\ldots$, όπου $k, m$ σταθεροί φυσικοί αριθμοί.
- ■ Αν $z$ είναι μιγαδικός αριθμός και $|z-i| = |z-1|$, τότε $z = x + ix$ με $x \in \mathbb{R}$.
- ■ Εάν $a \in \mathbb{R}$, η σειρά $\displaystyle\sum_{n=0}^{\infty}(4a^2)^{-n/2}$ συγκλίνει αν και μόνο αν $|a| > 1/2$.
- ■ $\displaystyle\int_1^\infty \frac{1+\sqrt[3]{x}}{x^p}\,dx < \infty$ αν και μόνο αν $p > 4/3$.

## Θέμα 3

Γράψτε Σ για σωστό ή Λ για λάθος στο λευκό κυκλάκι.

- (   ) Αν $0 < a < b$, τότε $\displaystyle\int_0^L \ln(a+x)\,dx \le \int_0^L \ln(b+x)\,dx$, για κάθε $L > 0$.
- (   ) Αν η σειρά $\displaystyle\sum_{n=0}^{\infty}|a_n|$ συγκλίνει, τότε και η σειρά $\displaystyle\sum_{n=0}^{\infty}\frac{a_n}{1+\sqrt{|a_n|}}$ συγκλίνει.
- (   ) Αν η $f$ είναι συνεχής, $f \ge 0$ και $f(x) \to 0$, καθώς $x \to \infty$, τότε $\displaystyle\int_1^\infty \frac{f(x)}{x^{2/3}}\,dx < \infty$.
- (   ) Η σειρά $\displaystyle\sum_{n=1}^{\infty}\frac{\cos(n\pi)}{n^p}$ συγκλίνει αν και μόνο αν $p > 1$.
- (   ) $\displaystyle\left|\int_{-\pi/2}^{\pi/2}\cos(a+x)\,dx\right| \le \pi$, για κάθε $a \in \mathbb{R}$.
- (   ) Αν ο $z$ είναι μιγαδικός αριθμός, τότε $|e^z| \le e^{|z|}$.

## Θέμα 4

Δίνεται η εξίσωση
$$\frac{dy}{dx} = y(\alpha - y),$$
όπου $\alpha$ είναι το τελευταίο μη μηδενικό ψηφίο του αριθμού μητρώου σας.

- (α') Σε ένα γράφημα δώστε τη συμπεριφορά των λύσεων, καθώς $x \to +\infty$, ανάλογα με την αρχική συνθήκη $y(0) = y_0$.
- (β') Να βρεθούν **όλες** οι λύσεις της εξίσωσης.
