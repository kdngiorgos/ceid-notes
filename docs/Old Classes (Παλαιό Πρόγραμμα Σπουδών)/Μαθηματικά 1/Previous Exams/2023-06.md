## Θέμα 3

Γράψτε Σ για σωστό ή Λ για λάθος στο λευκό κυκλάκι.

- (   ) Αν $0 < a < b$, τότε $\displaystyle\int_0^L \ln(a+x)\,dx \le \int_0^L \ln(b+x)\,dx$, για κάθε $L > 0$.
- (   ) Αν η σειρά $\displaystyle\sum_{n=0}^{\infty}|a_n|$ συγκλίνει, τότε και η σειρά $\displaystyle\sum_{n=0}^{\infty}\frac{a_n}{1+\sqrt{|a_n|}}$ συγκλίνει.
- (   ) Αν η $f$ είναι συνεχής, $f \ge 0$ και $f(x) \to 0$, καθώς $x \to \infty$, τότε $\displaystyle\int_1^\infty \frac{f(x)}{x^{2/3}}\,dx < \infty$.
- (   ) Η σειρά $\displaystyle\sum_{n=1}^{\infty}\frac{\cos(n\pi)}{n^p}$ συγκλίνει αν και μόνο αν $p > 1$.
- (   ) $\displaystyle\left|\int_{-\pi/2}^{\pi/2}\cos(a+x)\,dx\right| \le \pi$, για κάθε $a \in \mathbb{R}$.
- (   ) Αν ο $z$ είναι μιγαδικός αριθμός, τότε $|e^z| \le e^{|z|}$.

## Θέμα 4

$$\frac{dy}{dx} = y(\alpha - y),$$

- (β') Να βρεθούν **όλες** οι λύσεις της εξίσωσης.
