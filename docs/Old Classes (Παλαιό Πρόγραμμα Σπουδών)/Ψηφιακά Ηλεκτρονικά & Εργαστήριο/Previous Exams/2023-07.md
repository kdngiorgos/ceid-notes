**Question 28**

Στην παρακάτω μνήμη δώστε το περιεχόμενο, της γραμμής W5.

> [Σχήμα: μνήμη με αποκωδικοποιητή γραμμών (Row decoder) στα αριστερά, τρεις γραμμές διεύθυνσης λέξης (Word address) που καταλήγουν σε αυτόν, οκτώ οριζόντιες γραμμές λέξεων με ετικέτες W [δυσανάγνωστο], τέσσερις κάθετες γραμμές με ετικέτες B3, B2, B1, B0 [δυσανάγνωστο] στο κάτω μέρος και τροφοδοσία V_DD στο πάνω μέρος.]

- [ ] B3,B2,B1,B0 = 0 1 0 1
- [ ] B3,B2,B1,B0 = 1 1 1 1
- [ ] B3,B2,B1,B0 = 1 0 0 0
- [ ] B3,B2,B1,B0 = 0 0 1 0
- [ ] B3,B2,B1,B0 = 1 1 0 1
- [ ] B3,B2,B1,B0 = 1 0 1 0
