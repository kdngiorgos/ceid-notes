Ερώτηση 1 (Πολλαπλής Επιλογής (Πολλαπλές Απαντήσεις) — 1 βαθμός)

Έστω $\vec{f} : R^3 \rightarrow R^3$ με $\vec{f} = (P, Q, R)$ μια φορά συνεχώς παραγωγίσιμη. Αν το $\vec{f}$ είναι σωληνοειδές ($div\vec{f} = 0$), και $\vec{F}(x,y,z) = (\int_{z_0}^z Q(x,y,t)\,dt, \int_{x_0}^x R(t,y,z_0)\,dt - \int_{z_0}^z P(x,y,t)\,dt, 0)$ τότε ισχύει:

- [ ] $\vec{f} = div\vec{F}$
- [ ] $\vec{F} = rot\vec{f}$
- [ ] $\vec{F} = div\vec{f}$
- [ ] $\vec{f} = rot\vec{F}$

## 6,7.png

Ερώτηση 6 (Πολλαπλής Επιλογής (Πολλαπλές Απαντήσεις) — 1 βαθμός)

Είναι γνωστό ότι ο ορισμός της συνέχειας μιας συνάρτησης $f : \mathbb{R}^2 \to \mathbb{R}$ σε ένα σημείο $(x_0, y_0)$ του πεδίου ορισμού της δίνεται από τον κάτωθι ορισμό:

$$\lim_{(x,y)\to(x_0,y_0)} f(x, y) = l \Leftrightarrow (\forall \varepsilon > 0) (\exists \delta_1(\varepsilon) > 0) (\exists \delta_2(\varepsilon) > 0) \text{ τέτοιο ώστε : } (|x - x_0| < \delta_1) \text{ και } (|y - y_0| < \delta_2) \longrightarrow (|f(x, y) - l| < \varepsilon).$$

Έστω η συνάρτηση

$$f(x, y) = \begin{cases} \frac{y^3}{x^2+y^2}, & \alpha\nu\ (x, y) \neq (0, 0) \\ 0 & \alpha\nu\ (x, y) = (0, 0). \end{cases}$$

Χρησιμοποιώντας τον άνω ορισμό, για να είναι η συνάρτηση $f$ συνεχής στο σημείο $\mathrm{O}(0, 0)$ θα πρέπει:

- [ ] $\delta_1 \le \varepsilon$
- [ ] $\delta_1 - \delta_2 \le \varepsilon$
- [ ] $\delta_1 \le \frac{\varepsilon}{2} \text{ και } \delta_2 \le \frac{\varepsilon}{2}$
- [ ] $\delta_2 \le \varepsilon$
