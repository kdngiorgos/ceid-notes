Ερώτηση 2 (Πολλαπλής Επιλογής (Πολλαπλές Απαντήσεις) – 1 βαθμός)

Για το διανυσματικό πεδίο $\vec{F} = (\sin y^2 + z^3, 2xy \cos y^2 - 2, 3xz^2 + 4)$ ισχύει ότι:
- [ ] Το $\vec{F}$ είναι διανυσματικό πεδίο και έχει δυναμική ενέργεια $f(x,y,z) = x \sin y^2 + xz^3 - 2y + 4z$
- [ ] Το $\vec{F}$ δεν είναι διανυσματικό πεδίο και έχει δυναμική ενέργεια $f(x,y,z) = x \sin y^2 + xz^3 - 2y + 4z$
- [ ] Το $\vec{F}$ είναι διανυσματικό πεδίο και έχει δυναμική ενέργεια $f(x,y,z) = y \sin x^2 + xz^3 - 2z + 4y$
- [ ] Το $\vec{F}$ δεν είναι διανυσματικό πεδίο και έχει δυναμική ενέργεια $f(x,y,z) = y \sin x^2 + xz^3 - 2z + 4y$

Ερώτηση 3 (Πολλαπλής Επιλογής (Πολλαπλές Απαντήσεις) – 1 βαθμός)

Είναι γνωστό ότι ο ορισμός της συνέχειας μιας συνάρτησης $f : \mathbb{R}^2 \to \mathbb{R}$ σε ένα σημείο $(x_0, y_0)$ του πεδίου ορισμού της δίνεται από τον κάτωθι ορισμό:
$$\lim_{(x,y) \to (x_0, y_0)} f(x,y) = l \Leftrightarrow (\forall \varepsilon > 0) (\exists \delta_1(\varepsilon) > 0) (\exists \delta_2(\varepsilon) > 0) \text{ τέτοιο ώστε} :$$
$$(|x - x_0| < \delta_1) \text{ και } (|y - y_0| < \delta_2) \longrightarrow (|f(x,y) - l| < \varepsilon).$$

Έστω η συνάρτηση
$$f(x,y) = \begin{cases} \frac{1}{x} \sin(xy), & \text{αν } x \neq 0 \\ 0, & \text{αν } x = 0 \end{cases}$$

Χρησιμοποιώντας τον άνω ορισμό, για να είναι η συνάρτηση $f$ συνεχής στο σημείο $O(0,0)$ θα πρέπει:
- [ ] $\delta_1 \le \varepsilon$
- [ ] $\delta_2 \le \varepsilon$
- [ ] $\delta_1 \le \frac{\varepsilon}{2} \text{ και } \delta_2 \le \frac{\varepsilon}{2}$
- [ ] $\delta_1 - \delta_2 \le \varepsilon$

Τα ακρότατα της συνάρτησης $f(x,y,z) = x^2 + y^2 + z^2$, $(x,y,z) \in \mathbb{R}^3$ υπό τη συνθήκη $\phi(x,y,z) = x + y + z + 1 = 0$ είναι:

Ερώτηση 5 (Πολλαπλής Επιλογής (Πολλαπλές Απαντήσεις) – 1 βαθμός)

Έστω συνάρτηση $f(x,y,z) = x^2 y z^3$ και σημείο $M(1, -2, 3)$. Η κατεύθυνση του διανύσματος ώστε η $\frac{\partial f}{\partial \vec{u}}(M)$ να γίνεται μέγιστη είναι:

Ερώτηση 9 (Πολλαπλής Επιλογής (Πολλαπλές Απαντήσεις) – 1 βαθμός)

Εάν $W(s,t) = F(u(s,t), v(s,t))$, τότε:

Ερώτηση 10 (Πολλαπλής Επιλογής (Πολλαπλές Απαντήσεις) – 1 βαθμός)

Η γενική λύση της ΔΕ $xy \sin(xy) - \cos(xy) + x^2 \sin(xy) y' = 0$ είναι:
- [ ] $x \cos(xy) = c$ όπου $c$ αυθαίρετη σταθερά ή σχέση αυθαίρετων σταθερών.
- [ ] $x \sin(xy) = c$ όπου $c$ αυθαίρετη σταθερά ή σχέση αυθαίρετων σταθερών.
- [ ] $\cos(xy) = c$ όπου $c$ αυθαίρετη σταθερά ή σχέση αυθαίρετων σταθερών.
- [ ] $x \cos(y) = c$ όπου $c$ αυθαίρετη σταθερά ή σχέση αυθαίρετων σταθερών.
