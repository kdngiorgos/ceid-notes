    Θ1 Το ολοκλήρωμα που υπολογίζει το μέσο ύψος της "οροφής" του σχήματος που ορίζεται από το σχέδιο $z = y^2 \sin x$ στο παραλληλόγραμμο που δίνεται από τα όρια $0 \le x \le \pi$ και $0 \le y \le 1$ είναι:

    Μέσο ύψος $= \dfrac{1}{\text{Περιοχή}}\iint_R z\,dA$, όπου $R$: η περιοχή στο επίπεδο $xy$ με τα δοσμένα όρια, $z = y^2 \sin x$: η συνάρτηση "οροφής", $dA = dx\,dy$: η διαφορική επιφάνεια περιοχή.

    Άρα: Μέσο ύψος $= \dfrac{1}{\pi}\int_0^{\pi}\int_0^1 y^2 \sin x\,dy\,dx$

    ① Υπολογίζοντας αρχικά το εσωτερικό ολοκλήρωμα:
    $$\int_0^1 y^2\,dy = \left[\frac{y^3}{3}\right]_0^1 = \frac{1^3}{3} - \frac{0^3}{3} = \frac{1}{3}$$

    ② Αντικαθιστώντας αυτό το αποτέλεσμα στο έξω ολοκλήρωμα:
    $$\text{Μέσο ύψος} = \frac{1}{\pi}\int_0^{\pi} \sin x \cdot \frac{1}{3}\,dx = \frac{1}{3\pi}\int_0^{\pi}\sin x\,dx \overset{(*)}{=} \frac{2}{3\pi}$$

    $(*)$ $\displaystyle\int_0^{\pi}\sin x\,dx = \left[-\cos x\right]_0^{\pi} = -\cos\pi - (-\cos 0) = -(-1) - (-1) = 2$

    03 Για να αποδείξουμε ότι $y\frac{\partial z}{\partial x} + x\frac{\partial z}{\partial y} = x$, όπου $z = y - f(x^2 - y^2)$ [το σύμβολο της συνάρτησης μοιάζει με «I» στη φωτογραφία, πιθανώς «z»], ξεκινάμε υπολογίζοντας τις μερικές παραγώγους του z ως προς x και y.

    **(1) Ως προς x:** $\frac{\partial z}{\partial x} = \frac{\partial}{\partial x}\big(y - f(x^2-y^2)\big)$

    - Η y είναι ανεξάρτητη του x, άρα η παράγωγος της 0
    - Χρησιμοποιούμε τον κανόνα της αλυσίδας για τον παραγωγο τους $f(x^2-y^2)$

    $$\frac{\partial z}{\partial x} = 0 - f'(x^2-y^2)\cdot \underbrace{\frac{\partial}{\partial x}(x^2-y^2)}_{2x} = -2x\, f'(x^2-y^2)$$

    **(2) Ως προς y:** $\frac{\partial z}{\partial y} = \frac{\partial}{\partial y}\big(y - f(x^2-y^2)\big)$

    - Εδώ η παράγωγος του y είναι 1
    - Και πάλι χρησιμοποιούμε τον κανόνα της αλυσίδας

    $$\frac{\partial z}{\partial y} = 1 - f'(x^2-y^2)\cdot \underbrace{\frac{\partial}{\partial y}(x^2-y^2)}_{-2y} = 1 - f'(x^2-y^2)(-2y)$$

    **(3) Αντικαθιστώ στην έκφραση και αποδεικνύω:**

    $$y\frac{\partial z}{\partial x} + x\frac{\partial z}{\partial y} = y\big(-2x f'(x^2-y^2)\big) + x\big(1 + 2y f'(x^2-y^2)\big)$$

    $$= -2xy f'(x^2-y^2) + x + 2xy f'(x^2-y^2)$$

    $$= x$$

    Θεωρώ συνάρτ. $E(x,y) = xy + \frac{216}{y} + \frac{216}{x}, \quad D = \{(x,y) \dots \}$

    - $\frac{\partial E}{\partial x} = \frac{\partial \left(xy + \frac{216}{y} + \frac{216}{x}\right)}{\partial x} = y + \left(-\frac{216}{x^2}\right)$

    - $\frac{\partial E}{\partial y} = x + \left(-\frac{216}{y^2}\right)$

    Συνθήκες 1ης τάξης:

    $E_x = E_y = 0 \quad \text{συνεπώς :}$
