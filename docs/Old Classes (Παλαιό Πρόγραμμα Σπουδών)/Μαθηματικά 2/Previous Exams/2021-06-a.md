## 3_5kai6.png

Ερώτηση 5 (Πολλαπλής Επιλογής (Πολλαπλές Απαντήσεις) — 1 βαθμός)

Είναι γνωστό ότι ο ορισμός της συνέχειας μιας συνάρτησης $f : \mathbb{R}^2 \rightarrow \mathbb{R}$ σε ένα σημείο $(x_0, y_0)$ του πεδίου ορισμού της δίνεται από τον κάτωθι ορισμό:
$$ \lim_{(x,y)\to(x_0,y_0)} f(x, y) = l \Leftrightarrow (\forall \varepsilon > 0) \; (\exists \delta_1(\varepsilon) > 0) \; (\exists \delta_2(\varepsilon) > 0) \text{ τέτοιο ώστε} : $$
$$ (|x - x_0| < \delta_1) \text{ και } (|y - y_0| < \delta_2) \longrightarrow (|f(x, y) - l| < \varepsilon). $$

Έστω η συνάρτηση
$$ f(x, y) = \begin{cases} \frac{3xy^2}{x^2+y^2}, & \text{αν } (x, y) \neq (0, 0) \\ 0 & \text{αν } (x, y) = (0, 0). \end{cases} $$

Χρησιμοποιώντας τον άνω ορισμό, για να είναι η συνάρτηση $f$ συνεχής στο σημείο $\text{O}(0, 0)$ θα πρέπει:

- [ ] $\delta_1 \le \frac{\varepsilon}{3}$
- [ ] $\delta_2 \le \frac{\varepsilon}{3}$
- [ ] $\delta_1 \le \frac{\varepsilon}{6} \text{ και } \delta_2 \le \frac{\varepsilon}{6}$
- [ ] $\delta_1 + \delta_2 \le \varepsilon$

Ερώτηση 10 (Πολλαπλής Επιλογής (Πολλαπλές Απαντήσεις) — 1 βαθμός)

Η γενική λύση της ΔΕ $y' + \frac{1}{x} y = -y^2 + \frac{1}{x^2}$ με μία μερική της λύση την $y_1 = \frac{1}{x}$ είναι:

- [ ] $y = \frac{1}{x} + \frac{1}{cx^2 - \frac{1}{2}x}$ όπου $c$ αυθαίρετη σταθερά ή σχέση αυθαίρετων σταθερών.
- [ ] $y = \frac{1}{x} + \frac{1}{cx^3 - \frac{1}{2}x}$ όπου $c$ αυθαίρετη σταθερά ή σχέση αυθαίρετων σταθερών.
- [ ] $y = \frac{1}{x^2} + \frac{1}{cx^3 - \frac{1}{2}x}$ όπου $c$ αυθαίρετη σταθερά ή σχέση αυθαίρετων σταθερών.
- [ ] $y = \frac{1}{x} + \frac{1}{cx^3 - \frac{1}{3}x}$ όπου $c$ αυθαίρετη σταθερά ή σχέση αυθαίρετων σταθερών.
