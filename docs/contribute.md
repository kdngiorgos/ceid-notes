# Συνεισφορά

Το CEID Notes φτιάχνεται από φοιτητές για φοιτητές και **χρειάζεται τη βοήθειά σου**. Κάθε θέμα που λείπει ή λύση που ελέγχεται βοηθά τους επόμενους.

<div class="grid cards" markdown>

-   **📥 Ανέβασε θέματα**

    Έχεις φωτογραφίες ή PDF από εξετάσεις; Ή θυμάσαι τι έπεσε; Στείλ' τα, τα μεταγράφουμε εμείς.

    [→ Ανέβασμα θεμάτων](https://github.com/kdngiorgos/ceid-notes/issues/new?template=upload-exam.yml){ .md-button .md-button--primary }

-   **✖ Βρήκα λάθος**

    Λάθος σε θέμα, λύση ή οδηγό μαθήματος;

    [→ Αναφορά λάθους](https://github.com/kdngiorgos/ceid-notes/issues/new?template=fix-mistake.yml){ .md-button }

-   **✔ Επιβεβαίωσε λύση**

    Έλεγξες μια λύση; Πες μας αν είναι σωστή. Οι λύσεις με ένδειξη AI χρειάζονται έλεγχο.

    [→ Επιβεβαίωση λύσης](https://github.com/kdngiorgos/ceid-notes/issues/new?template=verify-solution.yml){ .md-button }

-   **ℹ Πληροφορίες μαθήματος**

    Βαθμολόγηση, εργασίες, συμβουλές μελέτης ή αλλαγές στο μάθημα.

    [→ Πρόσθεσε πληροφορίες](https://github.com/kdngiorgos/ceid-notes/issues/new?template=course-info.yml){ .md-button }

</div>

Χρειάζεσαι δωρεάν λογαριασμό GitHub. Όλα ελέγχονται από τον διαχειριστή πριν δημοσιευτούν. Αν θες credit, γράψε ψευδώνυμο στο πεδίο «Όνομα» και θα μπεις στη σελίδα ευχαριστιών.

## Κανόνες

- Όχι ονόματα φοιτητών, ΑΜ, τηλέφωνα ή e-mail.
- Όχι διαφάνειες, σημειώσεις ή λύσεις των διδασκόντων (αυτά μένουν στο eClass).
- Όχι βαθμολογίες ή λίστες βαθμών.
- Σεβασμός προς διδάσκοντες και συμφοιτητές.

Για προχωρημένους (Pull Request, μορφή αρχείων): [CONTRIBUTING.md](https://github.com/kdngiorgos/ceid-notes/blob/main/CONTRIBUTING.md).
