# CEID Notes

Ανοιχτός οδηγός για τα μαθήματα του ΤΜΗΥΠ (CEID, Πανεπιστήμιο Πατρών): οδηγοί μαθημάτων, θέματα εξετάσεων με λύσεις και τι λένε οι φοιτητές, όλα σε ένα μέρος.

**Site:** https://kdngiorgos.github.io/ceid-notes/

## Τι θα βρεις
- Οδηγός ανά μάθημα: βαθμολόγηση, εργασίες, παγίδες, τρόπος μελέτης.
- Θέματα προηγούμενων εξετάσεων, με λύσεις και ένδειξη αξιοπιστίας: 🟢 official · 🔵 verified · 🟡 community · ⚪ AI, μη επαληθευμένο.
- Αναζήτηση στα ελληνικά (αγνοεί τόνους).
- Σελίδα «Χρήση με AI»: κατέβασε το υλικό ενός μαθήματος για NotebookLM, ChatGPT, Claude ή Gemini.
- **Οδηγοί μελέτης (PDF)** ανά μάθημα: θέματα εξετάσεων ανά ενότητα, μέθοδοι επίλυσης, λυμένα παραδείγματα και ένδειξη αξιοπιστίας κάθε λύσης. [Κατέβασέ τους](https://kdngiorgos.github.io/ceid-notes/study-guides.html).
- Τα πρωτότυπα θεμάτων (φωτογραφίες, PDF) δεν δημοσιεύονται εδώ· θα ανακοινωθεί ξεχωριστό πακέτο.

## Συνεισφορά
